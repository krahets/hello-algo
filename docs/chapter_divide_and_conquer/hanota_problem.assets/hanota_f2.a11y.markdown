# 两个圆盘借助缓冲柱 B 完成移动

先把小盘暂存到柱 B，再把大盘移到柱 C，最后把小盘叠到大盘上，共三次移动。

## 问题与输入

图中从左到右为三根柱子 A、B、C，目标是把柱 A 上的两个圆盘全部移到柱 C。每次只能移动柱顶的一个圆盘，且大盘不能压在小盘之上；下文柱上圆盘均按从下到上的顺序表述。

绿色圆盘为大盘，蓝色圆盘为小盘；初始时柱 A 从下到上依次叠放大盘和小盘，柱 B 与柱 C 为空。
