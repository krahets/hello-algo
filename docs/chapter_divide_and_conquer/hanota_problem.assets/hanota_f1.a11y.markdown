# 一个圆盘的汉诺塔（f(1)）

将柱 A 上的唯一圆盘直接移到目标柱 C，一次单盘移动即完成。

## 问题与输入

图中从左到右共有三根柱子 A、B、C，目标是把柱 A 上的圆盘移动到柱 C。移动规则为每次只能移动柱顶的一个圆盘，且大盘不能压在小盘之上；下文柱上圆盘均按从下到上的顺序表述。

规模 f(1) 表示只需迁移一个圆盘，代表汉诺塔递归分解的基本情况。

## 结构与关系

本组用绿色圆角矩形表示唯一圆盘，两帧分别展示移动前的初始状态与直接移入柱 C 后的完成状态。

## 第 1 步：唯一圆盘位于柱 A

柱 A 上只有一个绿色圆盘，上方没有其他圆盘阻挡，也不存在大小顺序冲突，因此可以直接从柱 A 移往目标柱 C，无需借助缓冲柱 B。
