# 三盘汉诺塔的分治

先将顶部两盘迁到 B，再把最大盘移到 C，最后把两盘从 B 迁到 C；三个阶段共含七次单盘移动。

## 问题与输入

图中从左到右为三根柱子 A、B、C，目标是把柱 A 上的三个圆盘移到柱 C。每次只能移动柱顶的一个圆盘，且大盘不能压在小盘之上；下文柱上圆盘均按从下到上的顺序表述。

三只圆盘从大到小依次为绿色大盘、蓝色中盘、橙色小盘，初始全部叠在柱 A。青色实线轮廓将上方的中盘与小盘圈作一个规模为 f(2) 的递归子问题。

将两盘看作整体只是分治递归的抽象表示，并不代表物理上同时端起两个圆盘；两个 f(2) 子问题各自需要展开为三次合法的单盘移动，加上中间最大盘的一次移动，共执行七次单盘移动。

## 结构与关系

四帧依次展示初始划分状态以及三个子阶段的完成终点，未逐帧展开 f(2) 子问题内部的三次单盘移动细节。

## 第 1 步：将顶部两盘作为子问题

要移动最下面的绿色大盘，必须先把柱 A 顶部的蓝色中盘和橙色小盘移开。把这两只圆盘整体迁往柱 B 时，柱 B 是该 f(2) 子问题的目标柱，柱 C 充当缓冲柱。

## 第 3 步：将最大盘从 A 移至 C

两只较小圆盘暂存在柱 B 后，柱 A 上的绿色大盘露出且目标柱 C 为空，直接将绿色大盘从柱 A 移到柱 C。

第二个 f(2) 子问题以柱 B 为源柱、柱 A 为缓冲柱、柱 C 为目标柱，内部展开为小盘 B→A、中盘 B→C、小盘 A→C 三次单盘移动，最终将两盘叠放到柱 C 的大盘之上。

## 结果

经过七次单盘移动后，柱 C 从下到上依次为大盘、中盘、小盘，柱 A 和柱 B 为空；四帧展示起点与三个阶段终点。
