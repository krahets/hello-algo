# 用归并排序理解“分”与“治”

将八元素排序问题逐层分解至单元素最小子问题，再自底向上合并有序结果，得到 0 至 7 的升序数组。

## 问题与输入

输入数组为 \[7, 3, 2, 6, 0, 1, 5, 4\]。分治策略包含两个核心步骤：“分（划分阶段）”递归地将原问题拆解为规模更小、互不重叠的子问题，直至到达最小子问题；“治（合并阶段）”从已知解的最小子问题出发，自底向上将子问题的解合并为原问题的解。

## 结构与关系

不断把当前数组对半划分，直到每个子问题只含一个元素。左右两部分互不重叠，可各自求解；单元素无需比较就是有序结果。

返回时将相邻的两个有序结果合并。每次比较两边首个尚未取出的元素，取较小者；一边取完后接上另一边的剩余元素。逐层合并后解决完整八元素问题。
