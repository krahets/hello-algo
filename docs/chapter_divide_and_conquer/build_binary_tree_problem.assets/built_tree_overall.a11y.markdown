# 逐个子问题查看前序与中序的划分

根 3 拆出左叶 9 与以 2 为根的右子树，节点 2 再拆出左右叶 1、7；各节点旁标出对应的遍历有效区间。

## 问题与输入

输入为前序遍历 preorder = \[3, 9, 2, 1, 7\] 与中序遍历 inorder = \[9, 3, 1, 2, 7\]，节点值互不重复。

重建出的二叉树以 3 为根，左子节点为 9，右子节点为 2；节点 2 的左右子节点分别为 1 和 7；节点 9、1、7 均为叶节点。

## 结构与关系

画面在树的五个节点旁各画出一组完整长度的 preorder 和 inorder 数组，仅将属于当前递归子问题的区间着色，其余无关位置置为浅灰色。在每个子问题中，青色代表当前子树的根节点，蓝色代表其左子树区间，紫色代表其右子树区间（完整划分见附表）。

在顶层根节点 3 处，前序划分为 3 \| \[9\] \| \[2, 1, 7\]，中序划分为 \[9\] \| 3 \| \[1, 2, 7\]；在左子节点 9 处，前序与中序的有效区间均仅剩青色单元素 \[9\]，其左右子树均为空。

在右子树根节点 2 处，前序有效段划分为 2 \| \[1\] \| \[7\]，中序有效段划分为 \[1\] \| 2 \| \[7\]；在其下方的叶节点 1 和 7 处，前序与中序的有效区间又分别缩减为单元素 \[1\] 和 \[7\]，不再有非空子节点。

## 结果

五个节点的递归调用遵循完全相同的分治规则：在各自的有效区间内由前序首元素定根、由中序切分左右子树，直至单节点叶子的左右空区间返回空引用。
