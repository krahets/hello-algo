# 由前序与中序序列重建五节点二叉树

由前序 \[3,9,2,1,7\] 与中序 \[9,3,1,2,7\]，唯一重建以 3 为根的五节点二叉树。

## 问题与输入

已知一棵二叉树的前序遍历序列 preorder = \[3, 9, 2, 1, 7\] 和中序遍历序列 inorder = \[9, 3, 1, 2, 7\]，且树中所有节点的值互不重复。

前序遍历遵循“根 → 左子树 → 右子树”的访问顺序，中序遍历遵循“左子树 → 根 → 右子树”的访问顺序。利用两条序列的互补位置关系，可以从中唯一还原整棵二叉树。

## 结构与关系

画面左侧展示待重建的目标二叉树：根节点为 3，其左子节点为 9、右子节点为 2；节点 2 的左子节点为 1、右子节点为 7；节点 9、1、7 均为叶节点。

画面右侧上下排列前序遍历 \[3, 9, 2, 1, 7\] 与中序遍历 \[9, 3, 1, 2, 7\]，并通过向左的箭头“重建二叉树”指向左侧树结构：前序首元素 3 确定整棵树的根；在中序中，3 左侧仅有 9，说明左子树只含节点 9；3 右侧为 \[1, 2, 7\]，对应前序后三项 \[2, 1, 7\]，说明右子树以 2 为根、以 1 和 7 为左右子节点。

注意这是一棵普通二叉树而非二叉搜索树，节点位置由遍历次序决定，并不要求左子节点的值小于父节点（例如左子节点 9 大于根节点 3）。

右侧的前序遍历序列负责定位各子树的根节点，中序遍历序列负责划分左右子树的成员范围，二者结合即可重建左侧的五节点二叉树。

## 结果

在节点值互不重复的前提下，前序遍历与中序遍历共同唯一确定了这棵包含 3、9、2、1、7 五个节点的二叉树。
