# 用 i、l、m、r 表示构树递归的索引区间

左子树根的前序索引为 i+1，右子树根的前序索引为 i+1+(m−l)，其中 m−l 为左子树节点数。

## 问题与输入

输入为前序遍历 preorder = \[3, 9, 2, 1, 7\] 与中序遍历 inorder = \[9, 3, 1, 2, 7\]，节点值互不重复。

数组索引从 0 开始：i 表示当前子树根节点在 preorder 中的索引；\[l, r\] 表示当前子树在 inorder 中的闭区间；m 表示当前子树根节点在 inorder 中的索引。注意 m 是通过根的值在 inorder（或哈希表）中查表得到的索引，并非区间 \[l, r\] 的几何中点。

## 结构与关系

画面以整棵树的顶层调用为例标出各指针位置：当前根节点 3 在前序中的索引为 i = 0，整棵树在中序中的闭区间为 \[l, r\] = \[0, 4\]，根节点 3 在中序中的索引为 m = 1，因此左子树的节点数量为 m − l = 1。

由此可直接推导出左右子树的递归参数（通用公式见附表）：左子树根节点紧跟在当前根之后，其前序索引为 i + 1 = 1（对应元素 9），中序闭区间为 \[l, m − 1\] = \[0, 0\]；右子树根节点需跳过当前根和全部 m − l 个左子树节点，其前序索引为 i + 1 + (m − l) = 2（对应元素 2），中序闭区间为 \[m + 1, r\] = \[2, 4\]（对应 \[1, 2, 7\]）。

递归过程中只需传递前序根索引与中序闭区间端点，当遇到 l &gt; r 的空区间时直接返回空子树。画面左侧同步展示对应的五节点树：根节点 3 的左子节点为 9、右子节点为 2，2 的左右子节点分别为 1 和 7。

在前序遍历中定位右子树根节点时，必须从当前根索引 i 出发跳过当前根（+1）以及左子树的全部节点（m − l），因此右子树根的前序索引为 i + 1 + (m − l)。

## 结果

借助指针变量 i、l、m、r 的代数关系，每次递归调用仅需传递整数索引即可精确界定左右子树，无需切片复制子数组。
