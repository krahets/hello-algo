# ASCII 字符与编码对照

按十进制编码或字符查阅对应的二进制表示，区分控制字符与可打印字符。

## 问题与输入

ASCII 使用 7 位二进制数表示 128 个字符，十进制编码范围为 0 至 127。图中按单字节 8 位展示二进制，每 4 位以空格分组，最高位恒为 0。下方数据表已将原图四列面板合并为按十进制 0 至 127 递增的完整对照表，可按行列检索。

## 结构与关系

按编码区间划分：0 至 31 与 127 为控制字符；32 为空格（SP）；48 至 57 为数字字符 0 至 9；65 至 90 为大写字母 A 至 Z；97 至 122 为小写字母 a 至 z；其余可打印标点与符号分布在 33 至 47、58 至 64、91 至 96 以及 123 至 126。

表中“含义（图中注明）”列保留原图注文，阅读时需注意其与现代通用术语的差异：编码 14 的 SO（Shift Out）与 15 的 SI（Shift In）分别表示移出切换与移入切换；编码 27 的 ESC（Escape）表示转义，原图注文“换码(溢出)”中的“溢出”并非算术溢出；编码 10（LF）、12（FF）、13（CR）分别控制换行、换页与回车，原图带有的“键”字仅作功能提示，不代表必须对应实体按键。

## 结果

字符字面与编码数值不同：数字字符 0 的编码是 48（0011 0000），而编码 0 对应空字符 NUL（0000 0000）；大写 A 编码为 65，小写 a 编码为 97；空字符 NUL（0）、空格 SP（32）与删除字符 DEL（127）也各自对应不同编码。
