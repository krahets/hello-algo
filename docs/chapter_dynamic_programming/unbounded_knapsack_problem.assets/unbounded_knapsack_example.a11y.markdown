# 完全背包示例：物品可以重复选择

背包容量为 50 时，允许重复选取同类物品，最优方案为选择 1 个苹果与 2 个香蕉，总重量 50、最大价值 290。

## 问题与输入

完全背包问题给定 5 种候选物品，背包容量 cap = 50。与 0-1 背包不同，每种物品的选取次数不受限制，只要放入背包的物品总重量不超过 50 即可（注意本图采用的是容量 50、5 种物品的独立示例数据，与前两组容量 4 的 0-1 背包不是同一组输入）。

从左侧 5 种物品中选取第 1 种苹果 1 个（重量 10、价值 50）和第 2 种香蕉 2 个（单个重量 20、价值 120，两个共重 40、价值 240）一并放入容量为 50 的背包，其余三种物品（葡萄、菠萝、西瓜）均选 0 个。通过重复选择高性价比的香蕉，刚好占满 50 的背包容量，获得最大价值 290。

## 结果

在允许同类物品重复选取的规则下，容量 50 的最优方案为放入 1 个苹果和 2 个香蕉，总重量为 10 + 2 × 20 = 50，最大总价值达到 50 + 2 × 120 = 290，高于只选 1 个重量 50 的西瓜（价值 240）或苹果加菠萝（价值 260）等不重复方案。
