# 零钱兑换的最少硬币数

面值为 1、2、5 的硬币均可重复选取，求恰好凑出金额 11 所需的最少硬币枚数。

## 问题与输入

零钱兑换问题给定 3 种硬币面值 coins = \[1, 2, 5\]，每种面值的硬币数量无限；本示例的目标金额为 amt = 11（注意与后续零钱兑换 II 示例的目标金额 5、以及动态规划填表图的目标金额 4 区分）。任务是求恰好凑出目标金额 11 所需的最少硬币数量。

## 结构与关系

画面左侧表格列出 3 种硬币的编号 i 与面值 coins\[i-1\]：1 号硬币面值 1、2 号硬币面值 2、3 号硬币面值 5。其中第 1 行（面值 1）以浅橙色、第 3 行（面值 5）以浅绿色高亮，并通过两条向右的实线箭头指向右侧钱袋，钱袋上方标注“目标金额 amt = 11”；两条箭头上方分别标有“1 元硬币 × 1”和“5 元硬币 × 2”，第 2 行面值 2 的硬币未被选用。

画面底部给出结论：“最优硬币组合：1 + 5 + 5”以及“最少硬币数量：3”。由于最大面值为 5，任意两枚硬币的最大面值之和仅为 5 + 5 = 10 &lt; 11，因此不可能用少于 3 枚硬币凑出 11。

## 金额 11 的最优硬币组合

从面值 1、2、5 的三种硬币中，选取 1 枚面值 1 的硬币和 2 枚面值 5 的硬币汇入右侧代表目标金额的钱袋，面值总和为 1 + 5 + 5 = 11，恰好达到目标金额 amt = 11，所用硬币总数最少，共 3 枚。

## 结果

凑出目标金额 11 的最少硬币数量为 3 枚，对应的最优硬币组合为 1 + 5 + 5。
