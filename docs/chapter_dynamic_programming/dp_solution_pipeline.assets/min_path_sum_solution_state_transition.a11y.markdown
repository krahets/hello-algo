# 最小路径和的状态转移

到达内部格子的最后一步只能来自上方或左方，取两处累计最小路径和的较小值再加当前格代价。

## 问题与输入

在非负数字网格中，从左上角 \[0, 0\] 出发，每次只能向右或向下移动一格，沿途所有格子的数值（含起点和终点）累加为路径和。记 dp\[i, j\] 为从起点到达第 i 行、第 j 列格子的最小路径和，行列索引均从 0 开始；本例的 4×4 输入网格见表。

## 结构与关系

左图为 4×4 原始代价网格 grid，右图为同尺寸的符号 dp 表，各格仅标出状态名 dp\[0, 0\] 至 dp\[3, 3\]。左图将当前格 \[2, 2\]（值为 2）涂成绿色，将其上方相邻格 \[1, 2\]（值为 4）涂成紫色、左方相邻格 \[2, 1\]（值为 3）涂成蓝色；右表用相同颜色高亮对应的 dp\[2, 2\]、dp\[1, 2\] 与 dp\[2, 1\]。

右表中一条向下箭头从 dp\[1, 2\] 指向 dp\[2, 2\]，一条向右箭头从 dp\[2, 1\] 指向 dp\[2, 2\]。图下方写出状态转移方程 dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\]；注意方程中的 min 比较的是到达两个前驱格的累计最小路径和，而不是左图原始网格里的单格代价 4 和 3。

以图中绿色高亮的内部格 i=2、j=2 为例，只能从上方 \[1, 2\] 向下走一格、或从左方 \[2, 1\] 向右走一格到达该格，因此状态转移写为 dp\[2, 2\] = min(dp\[1, 2\], dp\[2, 1\]) + grid\[2, 2\]，其中 grid\[2, 2\]=2。右侧 dp 表在此仅展示符号依赖关系，尚未填入具体累计数值。

## 结果

任意非首行首列的内部状态 dp\[i, j\]，都由上方状态 dp\[i-1, j\] 与左方状态 dp\[i, j-1\] 中的较小值加上当前格代价 grid\[i, j\] 求得。
