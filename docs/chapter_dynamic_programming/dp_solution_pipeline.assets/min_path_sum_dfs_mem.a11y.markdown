# 最小路径和的记忆化递归

右子树再次遇到 dp\[1, 0\] 时直接读取缓存返回有效路径和，不再展开子节点，并与越界返回正无穷区分。

## 问题与输入

在非负数字网格中从 \[0, 0\] 出发只能向右或向下移动，dp\[i, j\] 表示到达第 i 行、第 j 列的最小路径和（索引从 0 开始）。本图同样以 dp\[2, 1\] 为搜索根，展示引入记忆化缓存 mem 后对重叠子问题的剪枝效果，不展示具体网格权重。

有效内部状态取两个前驱返回值的较小值，再加当前格代价：dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\]。起点返回 grid\[0, 0\]，负索引越界时返回正无穷。

## 结构与关系

从根状态 dp\[2, 1\] 反向查找“上一行”与“上一列”前驱时，同样有两条调用路线到达同一个子问题 dp\[1, 0\]：先查上一行到 dp\[1, 1\] 再查上一列（路线“上→左”），或先查上一列到 dp\[2, 0\] 再查上一行（路线“左→上”）。

递归先遍历左子树：首次访问 dp\[1, 0\]（路线“上→左”）时向下展开求出其最小路径和并写入缓存；随后右子树从 dp\[2, 0\] 再次请求 dp\[1, 0\]（路线“左→上”）时触发“剪枝：已有记录”，直接返回缓存结果，不再展开下方的 dp\[0, 0\] 与 dp\[1, -1\]。需区分右子树中两处停止展开的语义：dp\[1, 0\] 命中缓存返回的是有效最小路径和，而右邻 dp\[2, -1\] 触发“剪枝：索引越界”返回的是正无穷，二者不能混同。

到达起点 dp\[0, 0\] 时返回基例值 grid\[0, 0\]；出现负索引（dp\[-1, 1\]、dp\[1, -1\]、dp\[2, -1\]）时返回正无穷，使不可行的前驱不会被最小值选中。整棵树涉及 4×4 网格中的六种有效状态 \[0, 0\]、\[0, 1\]、\[1, 0\]、\[1, 1\]、\[2, 0\]、\[2, 1\]；由于仅剪去了第二次 dp\[1, 0\] 的子树，左子树的 dp\[0, 1\] 与 dp\[1, 0\] 下方仍保留 2 个起点叶节点 dp\[0, 0\]。

## 命中缓存直接复用 dp\[1, 0\] 并区分越界剪枝

左子树首次解出 dp\[1, 0\] 后存入缓存；右子树在 dp\[2, 0\] 下再次请求 dp\[1, 0\] 时直接读取缓存的有效路径和参与最小值比较，省去重复子树展开，而同层的 dp\[2, -1\] 则因列索引越界返回正无穷。

## 结果

记忆化搜索在首次算出 dp\[1, 0\] 后将其缓存，右子树第二次访问时直接复用已求出的有效最小路径和，省去了两个子节点的重复展开，使全树节点由 13 个减少为 11 个。
