# 最小路径和的重复递归

从目标 dp\[2, 1\] 向前回溯上方与左方前驱时，两条调用路线汇合到 dp\[1, 0\] 并将其子树重复展开两次。

## 问题与输入

在非负数字网格中从 \[0, 0\] 出发只能向右或向下移动，dp\[i, j\] 表示到达第 i 行、第 j 列的最小路径和（索引从 0 开始）。本图以 dp\[2, 1\] 为根节点展示自顶向下的暴力搜索递归树，不给出具体网格权重；注意递归是反向查找“上一行”与“上一列”前驱，方向与实际行走时的向下、向右相反。

有效内部状态取两个前驱返回值的较小值，再加当前格代价：dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\]。起点返回 grid\[0, 0\]，负索引越界时返回正无穷。

## 结构与关系

从根状态 dp\[2, 1\] 反向查找“上一行”和“上一列”前驱时，有两条不同调用路线都会到达 dp\[1, 0\]：一条先查上一行到 dp\[1, 1\]、再查上一列到 dp\[1, 0\]（路线“上→左”）；另一条先查上一列到 dp\[2, 0\]、再查上一行到 dp\[1, 0\]（路线“左→上”）。正如右下方说明所指出的，“重叠子问题来源：dp\[i+1, j\] 和 dp\[i, j+1\] 都依赖 dp\[i, j\]”。

暴力搜索不记录已解状态，因此第二次遇到 dp\[1, 0\]（路线“左→上”）时会像第一次（路线“上→左”）一样，再次向下展开其上一行子节点 dp\[0, 0\] 与上一列越界节点 dp\[1, -1\]。加上左子树“上→上→左”路线下的 dp\[0, 0\]，整棵 13 节点递归树中起点 dp\[0, 0\] 共出现 3 次。

递归到达起点 dp\[0, 0\] 时返回基例值 grid\[0, 0\]；当行或列索引小于 0（图中 dp\[-1, 1\]、两处 dp\[1, -1\] 及 dp\[2, -1\]）时触发“剪枝：索引越界”，按代码返回正无穷，使非法前驱在最小值比较中被自动排除。下方 4×4 符号 dp 表标出了本次搜索涉及的六种有效状态：\[0, 0\]、\[0, 1\]、\[1, 0\]、\[1, 1\]、\[2, 0\]、\[2, 1\]。

## 两条回溯路线重复展开子问题 dp\[1, 0\]

从根 dp\[2, 1\] 经 dp\[1, 1\] 或 dp\[2, 0\] 回溯都会请求 dp\[1, 0\]；暴力搜索将两处 dp\[1, 0\] 各自展开为起点 dp\[0, 0\] 与越界节点 dp\[1, -1\]，造成同一子问题被重复求解。

## 结果

由于任意状态 dp\[i, j\] 同时是下方状态 dp\[i+1, j\] 和右方状态 dp\[i, j+1\] 的前驱，暴力递归会产生大量重叠子问题；仅从 dp\[2, 1\] 回溯就把 dp\[1, 0\] 重复展开了两次。
