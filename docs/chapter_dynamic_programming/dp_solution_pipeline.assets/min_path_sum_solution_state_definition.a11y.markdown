# 把网格位置定义为二维 dp 状态

用行列坐标 \[i, j\] 定义状态，建立同尺寸 4×4 二维 dp 表对应从起点到各格的最小路径和子问题。

## 问题与输入

输入为 4×4 非负代价网格 grid（行列索引 0 至 3 的完整数值见表），从左上角起点 \[0, 0\] 出发每次只能向右或向下走一格，起点与终点均计入路径和。本图对比原网格 grid 与动态规划表 dp 的状态定义。

## 结构与关系

首先区分两个 4×4 矩阵的含义：grid\[i, j\] 仅记录经过单个格子的代价，而 dp\[i, j\] 记录从左上角起点 \[0, 0\] 走到格子 \[i, j\]（含首尾两格）的累计最小路径和。例如 grid\[1, 1\] = 2 只代表该格自身的单格代价，不能直接当作累计路径和 dp\[1, 1\]（后者还包含从起点到达该格的路径代价）。

图中在 grid 旁标出行索引 i、i+1 与列索引 j、j+1，并以当前格 \[1, 1\]（代价 2）演示每轮移动决策：向右走一格列索引加 1，到达 \[1, 2\]（即 \[i, j+1\]），该格代价为 4；向下走一格行索引加 1，到达 \[2, 1\]（即 \[i+1, j\]），该格代价为 3。每次移动只改变行或列中的一个坐标，因此用二维行列索引 \[i, j\] 定义状态。

右侧 dp 表是与 grid 尺寸相同的 4×4 矩阵，行列索引均为 0 至 3，单元格依次记作 dp\[0, 0\] 至 dp\[3, 3\]，分别对应到达各格的最小路径和子问题。本图只建立状态定义与坐标映射，尚未计算和填写具体路径和数值。

## 单格代价 grid 与累计状态 dp\[i, j\] 的对应关系

按底部四项建模定义：每轮决策向右或向下走一格，将行列索引 \[i, j\] 定义为状态（从 \[1, 1\] 向右到 \[1, 2\]、向下到 \[2, 1\]），并用同尺寸 4×4 的 dp 表记录从左上角到各格 \[i, j\] 的最小路径和。

## 结果

每轮向右或向下移动分别对应坐标 \[i, j\] 到 \[i, j+1\] 或 \[i+1, j\] 的状态转移，16 个二维状态与 4×4 的 dp 表单元格一一对应；右侧 dp 表仅展示符号状态名 dp\[0, 0\] 至 dp\[3, 3\]，不含已算出的路径和数值。
