# 最小路径和的边界与填表顺序

先设定起点并沿首行向右、首列向下累加初始化边界，再按从上到下、从左到右的正序遍历内部格。

## 问题与输入

在非负数字网格中从 \[0, 0\] 出发只能向右或向下移动，起点与终点均计入路径和，dp\[i, j\] 表示到达第 i 行、第 j 列的最小路径和（行列索引 0 至 3）。本图用左右两个 4×4 符号 dp 表分别说明“边界条件：初始化首行首列”与“状态转移顺序：正序遍历矩阵”，不展示具体网格数值。

## 结构与关系

第一步初始化左上角起点 \[0, 0\]：路径和包含起点自身的代价，故直接设 dp\[0, 0\] = grid\[0, 0\]。

第二步按左图初始化首行与首列边界：处在首行的状态 \[0, j\]（j = 1、2、3）只能从左邻一路向右到达，故按 dp\[0, j\] = dp\[0, j-1\] + grid\[0, j\] 从左向右依次累加；处在首列的状态 \[i, 0\]（i = 1、2、3）只能从上邻一路向下到达，故按 dp\[i, 0\] = dp\[i-1, 0\] + grid\[i, 0\] 从上向下依次累加。

第三步按右图逐行正序填写内部九格：外层按行索引 i = 1、2、3 从上到下，内层按列索引 j = 1、2、3 从左到右依次推进。计算当前格 dp\[i, j\] 时，上方前驱 dp\[i-1, j\] 已在前一行算好，左方前驱 dp\[i, j-1\] 已在本行左侧算好，直接按 dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\] 取较小前驱加当前格代价。

## 先初始化首行首列边界，再按行优先正序填表

左图先由起点 dp\[0, 0\] 沿首行向右、沿首列向下单向累加得出边界；右图在边界就绪后按先行后列的正序遍历内部九格，确保每格所需的上方与左方前驱在计算前均已求出。

## 结果

先完成起点 \[0, 0\] 以及首行、首列的单向累加，再从第 1 行到第 3 行、每行从第 1 列到第 3 列正序填表，就能保证求解每个内部状态时其上方和左方前驱均已就绪，最终在右下角得到 dp\[3, 3\]。
