# 禁止连续两次上 1 阶后的第三阶走法

加上不能连续两轮跳 1 阶的限制后，0→1→2→3 被舍弃，到达第 3 阶只剩 2 种方案。

## 问题与输入

从地面 0 出发，每步仍可上 1 阶或 2 阶，目标是爬上第 3 阶楼梯，但新增约束条件：不能连续两轮都跳 1 阶。

## 结构与关系

楼梯轮廓画至第 6 阶，目标第 3 阶踏面为绿色。原 0→1→2→3 路线改为灰色点线，并在上方标注“由于不能连续两轮跳 1 阶，因此方案 0→1→2→3 被舍弃”；蓝色实线 0→2→3 与橙色实线 0→1→3 保持彩色高亮，底部汇总剩余的 2 种方案。

<a id="source-374"></a>

方案 0→1→2→3 需要连续三次各跳 1 阶，在前两步就已经违反了“不能连续两轮跳 1 阶”的限制，因此被置灰舍弃。蓝色方案 0→2→3 先跳 2 阶再跳 1 阶，橙色方案 0→1→3 先跳 1 阶再跳 2 阶，两者都没有出现相邻两次 1 阶跳跃，因此均合法保留。

## 结果

在禁止连续两步跳 1 阶的约束下，爬上第 3 阶的合法方案减少为 2 种。
