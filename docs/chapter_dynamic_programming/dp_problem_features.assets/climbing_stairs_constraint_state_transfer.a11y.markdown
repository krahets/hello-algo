# 用上一步步长扩展动态规划状态

将最后一步跳了 1 阶还是 2 阶纳入二维状态 dp\[i, j\]，即可在转移时排除连续两次跳 1 阶。

## 问题与输入

每步可上 1 阶或 2 阶，但不能连续两轮跳 1 阶。由于当前能否跳 1 阶取决于上一轮的步长，需要将状态扩展为二维 dp\[i, j\]，表示爬到第 i 阶且上一轮跳了 j 阶（j 取 1 或 2）的方案数。

## 结构与关系

图中在最高一阶标出两个目标状态：青色 dp\[i, 1\] 与蓝色 dp\[i, 2\]；在前一阶标出青色 dp\[i-1, 2\] 与灰色 dp\[i-1, 1\]；在前两阶标出蓝色 dp\[i-2, 1\] 与蓝色 dp\[i-2, 2\]。从 dp\[i-1, 2\] 有一条青色实线跨 1 阶指向 dp\[i, 1\]，而从灰色 dp\[i-1, 1\] 引出的灰色点线旁注明“不能连续两轮跳 1 阶，因此该项被舍去”；从 dp\[i-2, 1\] 和 dp\[i-2, 2\] 各有一条蓝色实线跨 2 阶汇入 dp\[i, 2\]。

分析到达第 i 阶的两类状态：第一类是最后一步跳 1 阶到达 dp\[i, 1\]，此时上一步位于第 i-1 阶，且再上一步决不能也是 1 阶，因此只能从 dp\[i-1, 2\] 转移而来，即 dp\[i, 1\]=dp\[i-1, 2\]，而 dp\[i-1, 1\] 因会导致连续两轮跳 1 阶被舍去；第二类是最后一步跳 2 阶到达 dp\[i, 2\]，此时上一步位于第 i-2 阶，无论前一步是跳 1 阶还是跳 2 阶都不违背约束，因此 dp\[i, 2\]=dp\[i-2, 1\]+dp\[i-2, 2\]。结合表中给出的正文代码第 1、第 2 阶初始状态即可顺序递推。

## 结果

扩展状态后问题重新满足无后效性，状态转移方程为 dp\[i, 1\]=dp\[i-1, 2\] 与 dp\[i, 2\]=dp\[i-2, 1\]+dp\[i-2, 2\]，爬到第 n 阶的总方案数为 dp\[n, 1\]+dp\[n, 2\]。
