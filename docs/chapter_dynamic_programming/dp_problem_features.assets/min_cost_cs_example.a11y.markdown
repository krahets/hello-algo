# 三阶楼梯的最小代价

当各阶代价为 0、1、10、1 时，跨过代价高昂的第 2 阶，走 0→1→3 可得最小总代价 2。

## 问题与输入

每步可以上 1 阶或 2 阶，每踏上第 n 阶楼梯都需要支付该阶对应的代价 cost\[n\]。地面起点代价为 cost\[0\]=0，本题目标是踏上第 3 阶并支付第 3 阶的代价（不同于越过第 3 阶免付末阶费用的变体）。

## 结构与关系

楼梯下方依次对齐列出楼梯阶数 n=0、1、2、3 与代价 cost\[n\]=0、1、10、1；其中第 2 阶的踏面与数字 10 用红色突出显示，目标第 3 阶的踏面用绿色突出显示。楼梯上方用青色实线、蓝色点线和橙色虚线画出三条走法，底部列出三种方案并指出最优方案。

三条到达第 3 阶的方案费用如下：青色实线 0→1→2→3 依次踏上第 1、第 2、第 3 阶，支付 1+10+1=12；蓝色点线 0→2→3 踏上第 2、第 3 阶，支付 10+1=11；橙色虚线 0→1→3 踏上第 1、第 3 阶，直接跨过了代价为 10 的红色第 2 阶，只需支付 1+1=2。比较可知 0→1→3 的总代价最小。

## 结果

到达第 3 阶的最小总代价为 2，对应先上 1 阶、再上 2 阶的路径 0→1→3。
