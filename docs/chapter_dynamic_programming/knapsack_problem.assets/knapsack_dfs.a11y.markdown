# 0-1 背包的重复递归

在容量 30 的专用三物品示例中，两条不同选择路线都会进入状态 dp\[1, 10\] 并重复展开其子树。

## 问题与输入

0-1 背包中每件物品最多选一次。注意本图采用与前图及代码主程序不同的独立 3 物品示例：背包容量 cap = 30，3 件物品的重量依次为 10、20、20，价值依次为 60、110、120（见表）。状态 dp\[i, c\] 表示在前 i 件物品中做选择、剩余可用容量为 c 时的最大价值；图中表头写为 wgt\[i\]、val\[i\]（编号 i 从 1 开始），而正文代码访问数组时使用下标 i-1。

当当前物品装得下时，比较不选它的 dp\[i-1, c\] 与选它的 dp\[i-1, c-wgt\[i-1\]\] + val\[i-1\]，取较大值；装不下时只取不选分支。无物品（i = 0）或容量为 0（c = 0）时返回 0。图中的负容量节点仅示意被排除的选择，代码在递归前判断超重，不实际调用负容量状态。

## 结构与关系

递归从根 dp\[3, 30\] 出发，按物品 3（菠萝，重 20、价值 120）、物品 2（西瓜，重 20、价值 110）、物品 1（苹果，重 10、价值 60）的顺序决策。由于物品 2 和物品 3 的重量同为 20，无论走“不选物品 3、再选物品 2”（dp\[3, 30\] → dp\[2, 30\] → dp\[1, 10\]）还是“选物品 3、再不选物品 2”（dp\[3, 30\] → dp\[2, 10\] → dp\[1, 10\]），都会扣减重量 20、剩下容量 10，且待选范围只剩物品 1，因此两条不同路径汇合到同一个子问题 dp\[1, 10\]。

暴力搜索不会记录已算出的子问题，遇到两处 dp\[1, 10\] 时会分别向下展开，各自比较不选物品 1 的 dp\[0, 10\] 与选物品 1 的 dp\[0, 0\] + 60，使相同的两个叶节点被重复搜索两次。

在右子树 dp\[2, 10\] 处，当前剩余容量为 10，而物品 2 的重量为 20，超过剩余容量。图中画出的 dp\[1, -10\] 标注“剪枝：物品重量 &gt; 背包容量”，仅用于示意被排除的超重分支；正文代码在递归前先判断物品重量是否大于剩余容量，超重时只调用不选分支 dp\[1, 10\]，不会实际发起负容量调用。

## 两条选择路线重复展开子问题 dp\[1, 10\]

物品 2 与物品 3 重量均为 20，只选其一都会从容量 30 减至剩余容量 10 并进入 dp\[1, 10\]；暴力递归将两处 dp\[1, 10\] 各自展开为 dp\[0, 10\] 和 dp\[0, 0\]，而 dp\[2, 10\] 下选物品 2 的超重分支 dp\[1, -10\] 则被排除。

## 结果

重叠子问题 dp\[1, 10\] 在两条分支中被重复展开了两次，使图中出现 6 个 i = 0 的基例叶节点；若按图中三件物品的数据推算，选入物品 1 和物品 3（重量 10 + 20 = 30）可得最大总价值 60 + 120 = 180（该数值由输入表推导，未直接标在树节点上）。
