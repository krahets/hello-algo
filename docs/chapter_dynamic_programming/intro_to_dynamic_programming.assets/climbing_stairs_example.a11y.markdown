# 爬到第三阶的三种方案

每次可上 1 阶或 2 阶，从地面 0 爬到第 3 阶共有三种不同的走法。

## 问题与输入

设地面起点编号为 0，每一步可以选择向上爬 1 阶或 2 阶，目标是恰好爬上第 3 阶楼梯。

## 结构与关系

图中楼梯轮廓从 0 画到第 6 阶，其中目标第 3 阶的踏面以绿色高亮。楼梯上方用青色实线、蓝色点线和橙色虚线画出三条从 0 到 3 的跳跃弧线，图下方文字依次列出这三种方案经过的台阶编号。

<a id="source-367"></a>

青色实线方案按台阶编号 0→1→2→3 前进，即连续三次各上 1 阶；蓝色点线方案按 0→2→3 前进，即先上 2 阶到第 2 阶、再上 1 阶到第 3 阶；橙色虚线方案按 0→1→3 前进，即先上 1 阶到第 1 阶、再上 2 阶到第 3 阶。三条路线都从地面 0 出发并恰好停在绿色高亮的第 3 阶。

## 结果

爬上第 3 阶共有 3 种方案；每步跨 1 阶与跨 2 阶的先后顺序不同（如先 2 后 1 与先 1 后 2），经过的台阶序列不同，计为不同方案。
