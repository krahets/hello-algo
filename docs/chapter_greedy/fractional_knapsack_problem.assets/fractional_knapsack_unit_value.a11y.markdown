# 物品在单位重量下的价值

单位价值等于物品价值除以重量；选取其中重量为 w 的一部分时，背包增加的价值为 w 乘以该物品的单位价值。

## 问题与输入

由于分数背包允许对物品任意切分，衡量一件物品性价比的核心指标不再是整件总价值，而是它在单位重量下的价值（简称单位价值）。5 件物品的重量仍为 10、20、30、40、50，价值仍为 50、120、150、210、240。

## 结构与关系

画面左侧为四列表格，在前三列（编号 i、重量 wgt\[i-1\]、价值 val\[i-1\]）右侧新增了第 4 列“单位价值 val\[i-1\] / wgt\[i-1\]”；画面右侧给出按所取重量 w 计算背包内增加价值的代数关系式。

左侧表格逐行用价值除以重量算出 5 件物品的单位价值：1 号苹果 50 / 10 = 5，2 号香蕉 120 / 20 = 6，3 号葡萄 150 / 30 = 5，4 号菠萝 210 / 40 = 5.25，5 号西瓜 240 / 50 = 4.8。右侧公式表明：若从第 i 件物品中切取重量 w 放入背包，则“背包内的增加价值 = 当前物品选取重量 w × 当前物品单位价值 (val\[i-1\] / wgt\[i-1\])”。

## 结果

通过单位价值可以直接比较各物品每占用 1 单位背包容量所带来的收益：2 号香蕉最高（6），4 号菠萝次之（5.25），1 号苹果与 3 号葡萄并列第三（5），5 号西瓜最低（4.8）。
