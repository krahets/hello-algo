# 分数背包问题的贪心策略

将五件物品按单位价值从高到低重排为香蕉（6）、菠萝（5.25）、苹果（5）、葡萄（5）、西瓜（4.8），确立优先选取高单位价值物品的贪心次序。

## 问题与输入

最大化限定容量下的背包总价值，本质上是让每一单位背包容量尽可能装入单位价值最高的物品。因此，分数背包的贪心策略需要先对所有候选物品按单位价值降序排序。

## 结构与关系

经过按单位价值降序排序，表格自上而下的物品顺序由原编号 1、2、3、4、5 变为 2 号香蕉（重 20、价值 120、单位价值 6）、4 号菠萝（重 40、价值 210、单位价值 5.25）、1 号苹果（重 10、价值 50、单位价值 5）、3 号葡萄（重 30、价值 150、单位价值 5）、5 号西瓜（重 50、价值 240、单位价值 4.8）。遍历时每轮优先拿取当前单位价值最高的物品，若剩余容量不足以装下整件，则切取一部分将背包填满。

## 结果

按排定的优先级 \[2 号香蕉, 4 号菠萝, 1 号苹果, 3 号葡萄, 5 号西瓜\] 依次贪心装包：在容量 50 的实例中，先全取排名第一的香蕉（重 20），再取排名第二的菠萝的一部分（重 30）填满剩余容量，即可直接求得全局最大价值 277.5。
