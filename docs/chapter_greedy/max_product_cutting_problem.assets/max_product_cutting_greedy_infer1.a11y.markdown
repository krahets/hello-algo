# 切分可使乘积不减

当整数因子 n ≥ 4 时，将其切分为 2 和 n - 2 后的乘积满足 2(n - 2) ≥ n（n = 4 时相等，n &gt; 4 时严格变大），说明所有大于等于 4 的因子都可继续切分。

## 问题与输入

给定整数 n ≥ 2，将其切分为至少两个正整数之和，并在总和固定为 n 的条件下最大化各段的乘积。

为确定最大切分乘积的贪心策略，首先考察：一个较大的正整数因子是否应该继续切分？为此比较原整数 n 与从中切出一个因子 2 后的乘积 2(n - 2)。

## 结构与关系

把长度为 n 的整数条切分为长度 2 和长度 n - 2 两段后，比较切分前后的数值：由不等式 2(n - 2) ≥ n 解得 n ≥ 4。注意在边界 n = 4 时，2 × (4 - 2) = 4，切分前后乘积相等；当 n &gt; 4 时，2(n - 2) &gt; n，切分后乘积严格变大。因此任何大于等于 4 的因子都可以继续向下切分而不损失乘积，直至所有因子均属于 {1, 2, 3}。

## 结果

只要切分方案中存在大于等于 4 的因子，就总能将其拆成 2 和 n - 2 而使乘积不减（n = 4 时乘积保持 4 不变，n &gt; 4 时乘积严格增大），因此必然存在仅由 1、2、3 三种因子组成的最优切分方案。
