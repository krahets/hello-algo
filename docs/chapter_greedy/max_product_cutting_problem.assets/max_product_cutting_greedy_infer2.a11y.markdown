# 将三个 2 换成两个 3

在总长度不变的前提下，将三个因子 2（和为 6，乘积为 8）替换为两个因子 3（和为 6，乘积为 9），可使整体乘积严格增大。

## 问题与输入

给定整数 n ≥ 2，将其切分为至少两个正整数之和，并在总和固定为 n 的条件下最大化各段的乘积。

在已知最优切分只需考虑因子 1、2、3 后，本图进一步比较总和同为 6 的两种组合：三个 2 与两个 3（需注意当 n = 2 或 3 时，为满足至少切成两段的要求，仍必须切出因子 1，不能因其无法增大乘积而略去这一边界情况）。

## 结构与关系

画面顶层为总长 n 的灰色整条；中层左侧连续排列三个蓝色的“2”（总长 6），右侧接灰色剩余段；底层仅画出左侧同样长度 6 的区间，将它替换为两个紫色的“3”。中间一支向下的灰色实心箭头标示从“三个 2”到“两个 3”的转化，图下方标注“当存在三个 2 时，应该贪心地转化为两个 3”。

考察总长 n 中长度为 6 的局部前缀：若切分为三个 2，局部乘积为 2 × 2 × 2 = 8；若将其合并重切为两个 3，局部长度仍为 3 + 3 = 6，但局部乘积提升为 3 × 3 = 9。由于右侧未改动的灰色余段乘积为正数，将三个 2 转化为两个 3 会使整体切分乘积从 8 倍余段乘积增大到 9 倍余段乘积。

## 结果

由于 3 × 3 = 9 &gt; 2 × 2 × 2 = 8，在总和同为 6 且其余正整数因子不变时，将三个 2 换成两个 3 必定提升总乘积。因此，最优切分方案中最多保留两个 2。
