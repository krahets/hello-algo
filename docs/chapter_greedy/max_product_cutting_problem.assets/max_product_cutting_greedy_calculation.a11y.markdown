# 最大切分乘积的计算方法

通过整除与取模将 n 写成 3×a+b 并按余数分类调整切分；边界 n=2、3 须单独满足至少切分为两段的要求。

## 问题与输入

给定整数 n ≥ 2，要求将其切分为至少两个正整数之和，并在总和固定为 n 的条件下最大化各段乘积。

既然贪心最优策略是尽可能多地切出因子 3，代码实现便无需循环逐段切分，而是直接利用向下整除 a = n // 3 与取模 b = n % 3，一步算出可切出的 3 的个数 a 与余数 b。

## 结构与关系

图中把总长为 n 的整条分解为 a 个长度为 3 的段与一段“余数 b”，下方给出代数恒等式 n = 3 × a + b（其中 a = n // 3，b = n % 3，余数 b 只可能是 0、1、2）。注意图中将“余数 b”画在左侧仅作符号分解示意，并未指定具体 n 或 b 的数值，也不代表按从左到右顺序执行切分。

结合正文与代码的分类规则，首先单独处理必须“至少切分为两段”的边界情况：n = 2 只能切为 1 + 1（乘积 1），n = 3 的最优切分为 1 + 2（乘积 2），即 n ≤ 3 时直接返回 1 × (n - 1)。当 n ≥ 4 时按余数 b 分为三类：若 b = 0，全部使用 a 个因子 3，乘积为 3^a；若 b = 2，保留余数 2 不再拆分，乘积为 3^a × 2；若 b = 1，由于 1 × 3 = 3 &lt; 2 × 2 = 4，需退回一个 3 与余数 1 重组为 2 + 2。

在余数 b = 1 的重组中，将“一个 3 与余数 1”改为“2 + 2”后，该部分长度总和仍为 4（全段总和保持 n 不变），局部乘积从 3 提升到 4，而因子 3 的个数从 a 减少 1 个变为 a−1，故最大乘积公式为 3^(a−1) × 2 × 2。表中汇总了边界与三种余数的完整计算规则。

## 用商 a 与余数 b 直接分类计算最大切分乘积

图面建立 n = 3 × a + b 的通用商余分解；结合正文规则，边界 n = 2、3 单独满足至少两段限制，n ≥ 4 且余数 b = 1 时将最后一个 3 与 1 重组为 2 + 2。

## 结果

先判断边界 n = 2（返回 1）与 n = 3（返回 2）；当 n ≥ 4 时由 a = n // 3、b = n % 3 按余数查表：b = 0 返回 3^a，b = 1 将一个 3 与 1 重组为 2 + 2 返回 3^(a−1) × 2 × 2，b = 2 返回 3^a × 2。
