# 最大切分乘积的问题定义

将正整数 n 切分为至少两个正整数因子之和（n₁ + n₂ + … + nₘ = n），在总和固定为 n 的条件下求所有因子乘积的最大值。

## 问题与输入

最大切分乘积问题要求：给定一个正整数 n（n ≥ 2），将其拆分为 m 个（m ≥ 2）正整数的和 n = n₁ + n₂ + … + nₘ，最大化这 m 个切分因子的乘积 n₁ × n₂ × … × nₘ。

上方完整灰条代表待切分的正整数 n，下方等长条被切分为 m 个正整数因子 n₁、n₂、n₃、…、nₘ₋₂、nₘ₋₁、nₘ（中间省略号代表任意切分段数）。因为各段首尾相连后的总长度与上方 n 完全对齐，即加和恒为 n，在此约束下求解乘积 n₁ × n₂ × … × nₘ 的最大值。

## 结果

问题需要在满足 n₁ + n₂ + … + nₘ = n（m ≥ 2）的前提下，同时决定切分段数 m 与每一段的正整数大小 nᵢ，使各段连乘积达到最大（本图为通用符号定义，未指定具体的 n 数值）。
