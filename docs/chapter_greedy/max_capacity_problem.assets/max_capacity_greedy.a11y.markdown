# 最大容量：双指针贪心

双指针从数组两端 \[0, 7\] 出发，每轮计算当前容器容量并更新历史最大值 res，随后向内移动短板指针，直至两指针在索引 1 相遇并返回最大容量 28。

## 问题与输入

给定高度数组 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]（索引 0 至 7），容器容量为 cap\[i, j\] = min(ht\[i\], ht\[j\]) × (j - i)。

双指针贪心算法初始化左指针 i = 0、右指针 j = 7、最大容量记录 res = 0。当 i &lt; j 时循环执行：先计算当前容量 cap 并用 res = max(res, cap) 更新全局最大值，然后比较左右两板高度，将较短一侧的指针向内移动一格，直到 i 与 j 相遇时跳出循环。
