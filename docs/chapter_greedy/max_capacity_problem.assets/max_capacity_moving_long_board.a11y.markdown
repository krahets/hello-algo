# 容器向内移动长板

保持短板不动而将长板向内移动，只会缩短容器宽度且无法提高水位上限，容量不能增大；本例容量从 21 降至 18。

## 问题与输入

高度数组为 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]。初始状态 i = 0（短板高 3）、j = 7（长板高 4），容量为 21。本图在保持左端短板不动的前提下，将右端长板向内移动一格，考察这一局部操作为何不能改善当前容量。

## 结构与关系

画面中左指针仍停在 i = 0（高度 3），右指针由索引 7 向左移动一格至 j = 6（高度 ht\[6\] = 3，原索引 7 的隔板变回普通未选中灰柱）。浅蓝色盛水区域随之缩窄为横跨索引 0 至 6、高度为 3 的矩形，图下方标注“向内移动长板，容量一定减小”及更新后的容量算式。

将右侧长板指针 j 从索引 7 左移到索引 6 后，新右板高度为 ht\[6\] = 3，与左端短板 ht\[0\] = 3 相等。此时有效水位高度 min(3, 3) = 3 并未突破原短板上界，但容器底宽已从 7 - 0 = 7 缩短为 6 - 0 = 6，导致当前容量变为 cap = min(3, 3) × (6 - 0) = 18，比移动前的 21 减少了 3。

## 结果

向内移动长板 j 后，容器宽度必然严格减小（从 7 减为 6），而盛水高度仍受原地未动的左端短板 ht\[0\] = 3 限制（至多不变或变得更矮），因此容量由 21 下降到 18。因此，保留当前短板并只内移另一端，不能得到比当前状态更大的容量；贪心搜索可舍弃保留此短板的这些状态，转而内移短板。此处 18 是局部比较值，不是全数组最终最优值。
