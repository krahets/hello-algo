# 容器双指针的初始状态

双指针初始分列数组两端 i = 0（短板高 3）和 j = 7（长板高 4），围成的初始容器宽度为 7、水位高为 3，当前容量为 21。

## 问题与输入

为探究双指针贪心策略的移动方向，对同一高度数组 ht = \[3, 8, 5, 2, 7, 7, 3, 4\] 考察两指针分别位于左右两端的初始状态 \[i, j\] = \[0, 7\]，用作后续比较“向内移动长板”与“向内移动短板”的基准。

## 结构与关系

画面索引 0 的隔板上方标有左指针 i，对应隔板高度 ht\[0\] = 3；索引 7 的隔板上方标有右指针 j，对应隔板高度 ht\[7\] = 4。两端的隔板高亮，横跨索引 0 至 7、高度齐平左端短板 3 的浅蓝色矩形表示当前盛水区域，图下方标注“i 为短板，j 为长板”及当前容量算式。

左指针 i = 0 指向高度 3 的隔板，右指针 j = 7 指向高度 4 的隔板；由于 ht\[0\] = 3 &lt; ht\[7\] = 4，左板 i 为决定水位上限的短板，右板 j 为长板。此时容器宽度为 7 - 0 = 7，有效水高为 min(3, 4) = 3，算得当前容量 cap = min(3, 4) × (7 - 0) = 21。

## 结果

初始状态 \[0, 7\] 的容器容量为 min(3, 4) × (7 - 0) = 21；这是双指针搜索的起点状态，而非全数组的最大容量。
