# 用插入排序整理扑克牌

每次从未排序区取出一张牌，插入已排序区的恰当位置，直到所有牌按点数从小到大排列。

## 问题与输入

正文以打牌时理牌的日常操作为例说明插入排序思想：要将手中顺序打乱的一组扑克牌按从小到大的顺序排好，可以将手牌划分为左侧“已排序”和右侧“未排序”两部分，每次从未排序部分取出一张牌，插入到左侧已排序部分的合适位置。

## 结构与关系

画面按顺时针 U 形路径展示 6 个理牌状态，上排自左向右、右侧向下转折、下排自右向左由 5 支箭头依次串联。每张牌都是白底红桃花色，点数与红桃图案用颜色区分：4 为绿色、2 为橙色、A 的点数为橙红色且红桃为红色、5 为青色、3 为蓝色。初始牌组位于浅红色“未排序”区，最终牌组位于浅绿色“已排序”区；中间 4 个状态均将左侧“已排序”牌扇与右侧“未排序”牌扇分开摆放，并标有对应文字。本例按 A 小于 2 的顺序排列。

顺着图中的顺时针 U 形箭头方向，左上角第 1 组为标注“未排序”的五张初始手牌 \[4, 2, A, 5, 3\]。中上第 2 组先将最左侧的 \[4\] 划为“已排序”，其余四张 \[2, A, 5, 3\] 划为“未排序”；随后每次从未排序牌扇的最右端取出一张牌，按点数插入左侧已排序牌扇的合适位置：右上第 3 组将 3 插入 4 前面，形成已排序 \[3, 4\] 与未排序 \[2, A, 5\]；右下第 4 组将 5 插入 4 后面，形成已排序 \[3, 4, 5\] 与未排序 \[2, A\]；中下第 5 组将 A 插入最前面，形成已排序 \[A, 3, 4, 5\] 与未排序 \[2\]；左下第 6 组将最后一张 2 插入 A 与 3 之间，得到全部已排序的 \[A, 2, 3, 4, 5\]。

## 结果

经过逐张抽取并按大小插入适当位置后，原本杂乱的未排序手牌 \[4, 2, A, 5, 3\] 全部并入已排序区间，最终形成按点数升序排列的 \[A, 2, 3, 4, 5\]。

## 用插入排序整理扑克牌：动画

先将 4 划入已排序区，再依次取出 3、5、A、2 插入已排序区的对应位置，直到五张牌全部排好。

手中共有五张红桃扑克牌，点数分别为 A、2、3、4、5，排序时将 A 视为最小点数 1。初始时五张牌全部位于粉色“未排序”区域内，扇形牌面按左上角可见角标从左到右依次为 \[4, 2, A, 5, 3\]。

理牌目标是按点数从小到大排成升序：左侧浅绿色背景面板表示“已排序”区，右侧浅粉色背景面板表示“未排序”区。扇形握牌使相邻牌面部分重叠，但每张牌的左上角点数角标始终清晰可见，没有任何牌被删除。

动画完整保留源图的六个离散阶段：第一阶段五张牌全部未排序；第二阶段先将最左侧的 4 单独划入已排序区；第三至第六阶段每次从未排序区取出一张牌（按 3、5、A、2 的先后顺序），直接插入已排序区的恰当位置。

随着各阶段推进，左侧已排序区的牌面依次扩展为 \[4\] → \[3, 4\] → \[3, 4, 5\] → \[A, 3, 4, 5\] → \[A, 2, 3, 4, 5\]，右侧未排序区则相应缩减直至为空。

每个阶段直接呈现该张牌插入完成后的扇形结果，未拆解插入时的逐张比较或临时移动动作。

从未排序区取出扑克牌 A（按点数 1 计算），因为它小于 3、4、5，将它插入已排序区最左端，形成 \[A, 3, 4, 5\]；右侧未排序区仅剩最后一张牌 \[2\]。

取出未排序区最后一张牌 2，因其点数大于 A（1）且小于 3，将它插入 A 与 3 之间。此时粉色未排序面板消失，画面仅保留绿色“已排序”面板，五张牌按 \[A, 2, 3, 4, 5\] 整齐排列。

### 结果

六个阶段结束后，五张扑克牌全部进入绿色“已排序”区，按点数从小到大排为 \[A, 2, 3, 4, 5\]，未排序区为空。
