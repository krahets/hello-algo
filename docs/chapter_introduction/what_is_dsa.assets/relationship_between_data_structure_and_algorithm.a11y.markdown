# 数据结构与算法的关系

算法通过操作指令将输入转换为输出，数据结构为输入、算法处理和输出全程提供存储与操作支撑。

<a id="source-17"></a>

图中上方处理流按“输入（input）→ 算法（algorithm，一系列操作指令）→ 输出（output）”从左到右推进。下方“数据结构（data structure，提供结构化存储的数据及对应操作方法）”并非只在算法开始前存储输入，而是同时指向并支撑输入、算法、输出三个环节：组织输入数据、在算法执行期间提供读写操作，并承载最终输出结果。

## 结果

数据结构与算法紧密配合：数据结构组织数据并提供读写操作方法，算法调用这些操作将输入转换为输出。
