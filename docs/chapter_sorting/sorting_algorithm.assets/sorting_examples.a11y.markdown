## 问题与输入

排序算法不仅适用于不同数据类型，还需要明确的先后判断规则。画面分三行展示三组数据：每行左侧为无序输入，经中间标注排序规则的向右箭头后，右侧给出排序完成的结果（不涉及具体排序算法的内部交换步骤）。

## 结构与关系

第一行“按照数字大小排序整数”：将八个无序整数 \[7, 3, 2, 6, 0, 1, 5, 4\] 按从小到大的数值顺序排列为 \[0, 1, 2, 3, 4, 5, 6, 7\]。

第二行“按照字典序排序字符串”：将五个英文姓名字符串 \[Kobe, Durant, Curry, Lebron, Harden\] 按首字母字典序排列为 \[Curry, Durant, Harden, Kobe, Lebron\]（完全保留原图拼写与大小写）。
