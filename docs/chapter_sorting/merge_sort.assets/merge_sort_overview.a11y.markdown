# 归并排序的划分与合并

先按位置中点将数组递归拆分为单元素子数组，再逐层将相邻有序子数组合并为完整有序数组。

## 问题与输入

输入数组为 \[7, 3, 2, 6, 0, 1, 5, 4\]。划分阶段只按位置中点将数组不断对半切分，不按数值大小分组；当子数组长度为 1 时停止划分，因为单元素子数组天然有序。

上半部分经过三层对半划分，拆解为 8 个单元素子数组（触发递归终止条件）；下半部分自底向上逐层两两归并。每次合并的两个输入子数组都已各自升序排列：算法比较两侧尚未取出的首元素，先将较小者放入结果区间，待一侧取尽后直接追加另一侧的剩余元素，从而保证每次合并的结果依然有序。图中下半部分的交叉箭头用于追踪各元素进入下一层合并结果的目标位置，不表示两两原地交换。

## 结果

经过三层中点划分与三层有序合并，最终得到升序数组 \[0, 1, 2, 3, 4, 5, 6, 7\]。图按递归树层级并列展示数据依赖关系；实际后序递归执行时，会先完整处理完左分支、再处理右分支，最后合并左右结果。
