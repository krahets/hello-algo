# 快速排序递归概览

每轮哨兵划分先将基准数固定到最终位置，再对左右子数组递归划分，直至子区间长度不超过 1。

## 问题与输入

输入数组为 \[2, 4, 1, 0, 3, 5\]，索引为 0 至 5。每次划分取当前子数组最左端元素作为基准数，重排后使基准左侧元素均不大于基准、右侧元素均不小于基准，基准数随即落入最终有序位置。

## 结构与关系

第一层对全区间 \[0, 5\] 取最左元素 2 为基准进行划分，得到 \[1, 0, 2, 4, 3, 5\]：基准 2 固定在索引 2，留下左子区间 \[0, 1\]（子数组 \[1, 0\]）与右子区间 \[3, 5\]（子数组 \[4, 3, 5\]）。

下一层对两个子区间分别划分：左子区间 \[0, 1\] 以 1 为基准划分为 \[0, 1\]，基准 1 固定在索引 1；右子区间 \[3, 5\] 以 4 为基准划分为 \[3, 4, 5\]，基准 4 固定在索引 4。此时仅剩 \[0, 0\]、\[3, 3\]、\[5, 5\] 三个单元素子区间（以及空区间），均满足递归终止条件，无需继续划分。

全过程共包含三次非平凡划分：首层以 2 划分全数组 \[0, 5\]，第二层对左子区间 \[0, 1\] 以 1 划分、对右子区间 \[3, 5\] 以 4 划分。图中蓝色格标出各层已归位的基准数，向下箭头指示拆分出的子区间，到达单元素区间 \[0, 0\]、\[3, 3\]、\[5, 5\] 时直接终止。

## 结果

最终有序数组为 \[0, 1, 2, 3, 4, 5\]。快速排序在自顶向下的每次划分中直接确定基准数的最终索引，递归基终止时整个数组已经有序，无需像归并排序那样在回溯阶段执行合并操作。
