# 以 2 为基准的一次哨兵划分

双指针将 \[2,4,1,0,3,5\] 划分为 \[1,0\]、基准 2 与 \[4,3,5\]，两侧仍待递归排序。

## 问题与输入

初始数组为 nums = \[2, 4, 1, 0, 3, 5\]，索引从 0 到 5，当前处理区间为 left = 0、right = 5，选取最左端元素 nums\[left\] = 2 作为基准数。

左指针 i 从左向右寻找首个大于基准数的元素，右指针 j 从右向左寻找首个小于基准数的元素。本实现每轮循环先移动 j、再移动 i，且移动条件均要求 i &lt; j；当两端都找到放错分区的元素后便交换它们，直到两指针相遇，最后将基准数交换到相遇位置。

## 第 2 步：指针 j 从右向左找到小于基准数的 0

每轮先移动右指针 j：索引 5 的元素 5 和索引 4 的元素 3 均不小于基准数 2，因此 j 依次向左跳过它们；移至索引 3 时遇到元素 0，因 0 &lt; 2 满足小于基准数的条件而停止。左指针 i 仍停在索引 0。

## 第 3 步：指针 i 从左向右找到大于基准数的 4

接着从索引 0 开始向右移动左指针 i：索引 0 的基准数 2 不大于自身，i 越过索引 0；移至索引 1 时遇到元素 4，因 4 &gt; 2 满足大于基准数的条件而停止。此时 i 指向偏大的元素 4，j 指向偏小的元素 0。

## 第 5 步：指针 j 继续向左找到小于基准数的 1

进入下一轮循环，继续先移动右指针 j：当前索引 3 的元素 4 满足 4 ≥ 2，j 向左移至索引 2；索引 2 的元素为 1，因 1 &lt; 2 满足小于基准数的条件而停止。左指针 i 仍停在索引 1，指向元素 0。

## 第 6 步：指针 i 右移并与指针 j 相遇

接着移动左指针 i：当前索引 1 的元素 0 满足 0 ≤ 2，i 向右移至索引 2。此时 i = j = 2，内层扫描因两指针相遇（i &lt; j 不再成立）而停止；注意相遇处的元素 1 并不大于基准数 2，此处停下是因为双指针相遇，而非找到了第二个偏大元素。

## 第 7 步：相遇位置的自交换不改变数组

## 结果

单次哨兵划分结果为 \[1, 0, 2, 4, 3, 5\]，并返回基准数最终所在的索引 2。此时左侧子数组 \[1, 0\] 的所有元素均满足 ≤ 2，右侧子数组 \[4, 3, 5\] 的所有元素均满足 ≥ 2；但左右两个子数组内部仍处于无序状态，完成整个数组的快速排序还需分别对它们递归执行哨兵划分。
