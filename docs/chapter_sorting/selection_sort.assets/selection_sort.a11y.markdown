# 选择排序

每轮在未排序区间中选出最小元素 nums\[k\] 并与区间首元素 nums\[i\] 交换，经五轮将 \[4, 1, 3, 1, 5, 2\] 排为 \[1, 1, 2, 3, 4, 5\]。

## 问题与输入

待排序数组为 nums = \[4, 1, 3, 1, 5, 2\]，共 6 个元素，索引从 0 到 5，目标是按非递减顺序完成排序。

每轮由指针 i 指向当前“未排序区间”的首个元素，由指针 k 记录从该未排序区间中选出的最小元素索引。左侧灰色方格表示已排好序的前缀，上方花括号标出当前“未排序区间”；选定 k 后，将最小元素 nums\[k\] 与区间首元素 nums\[i\] 交换，使已排序前缀向右扩展一位。
