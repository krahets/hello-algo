# 选择排序中的跨位置交换

观察首轮跨位置交换如何打乱两个相等元素 4 的相对次序，并区分单轮中间状态与完整排序的最终稳定性。

## 问题与输入

初始数组为 \[4A, 4B, 3, 1, 5, 2\]，索引从 0 到 5。其中 4A 表示初始位于索引 0 的蓝色 4，4B 表示初始位于索引 1 的紫色 4；字母 A、B 仅为说明中区分两个相等元素身份的辅助标记，原图方块内均印数字 4。

选择排序每一轮在未排序区间中找出最小元素，与该区间的首个元素直接交换。排序算法的稳定性，则是按全部轮次结束后的最终输出中相等元素是否保持初始先后次序来判定的。

首轮在未排序区间 \[0, 5\] 内定位最小元素 1（索引 3），与索引 0 的 4A 交换。交换后 1 在索引 0 归位，未排序区间缩为 \[1, 5\]；而原本在索引 0 的 4A 直接跨过索引 1 的 4B 落到索引 3，使两个 4 在首轮后出现中间逆序。图中仅展示这第一轮，未画出后续轮次。

## 结果

第一轮交换后数组变为 \[1, 4B, 3, 4A, 5, 2\]，4B 排在 4A 之前，直观展示了跨位置交换可能跨越其它相等元素。但这只是第一轮中间状态，不能单独证明该具体输入在最终输出中也逆序：按正文严格小于的比较规则继续，第二轮将索引 1 的 4B 与索引 5 的 2 交换，最终排序结果中 4A 仍排在 4B 之前。选择排序在一般意义上是不稳定排序，并不等于对任意输入都会产生最终逆序。

### 第 1 步：定位最小值与两个相等元素 4

初始状态下索引 0 至 5 全部处于未排序区间，蓝色 4A（索引 0）排在紫色 4B（索引 1）之前。扫描区间找到最小元素 1 位于索引 3，准备将它与区间首元素 4A 交换。

交换索引 0 的 4A 与索引 3 的 1 后，最小元素 1 在索引 0 归位，而 4A 跨过索引 1 的 4B 落到索引 3，导致两个 4 在首轮后暂时逆序。这只是第一轮结果，剩余未排序区间 \[1, 5\] 在后续轮次中还会继续交换。
