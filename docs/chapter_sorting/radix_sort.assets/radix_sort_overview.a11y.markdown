# 从个位到最高位进行稳定的基数排序

十个八位整数从第 1 位（个位）到第 8 位（千万位）逐位执行稳定排序，最终按完整数值升序排列。

## 问题与输入

输入数组 nums 包含十个八位十进制整数（如学号数据，完整数值见附表）。位数索引 k 从 1 开始：第 1 位是最右端的最低位（个位），第 2 位是十位，依此类推，第 8 位是最左端的最高位（千万位）。

## 结构与关系

完整表的四个数据列分别是输入、个位排序后、十位排序后和最终结果；每列各自从上到下表示数组索引 0 至 9。同一行表示相同的当前位置，不表示同一个整数跨轮的移动轨迹。第 3 至 7 位的五轮排序确实执行，只省略了中间画面。

每一轮都对当前位执行稳定的计数排序：当两个数的当前位数字相同时，严格保持它们在上一轮结束时的相对先后次序。例如第 1 位（个位）同为 0 的 35663510 与 88906420 在第一轮后保持原先后顺序；第 2 位（十位）同为 7 的 81883077 与 30524779 在第二轮后也保持上一轮排好的相对顺序（即个位为 7 的 81883077 排在个位为 9 的 30524779 前面）。

由于高位数字对数值大小的决定权高于低位，后一轮排序应当覆盖前一轮的次序，而在高位相同处则依靠排序算法的稳定性继承低位已排好的次序。注意每轮重排时都是将八位完整整数整体移动，而非只单独交换某一位上的数字。
