# 原地堆排序：把最大值逐个放入数组右端

建立大顶堆后，反复交换堆顶与有效堆尾并缩小堆范围，将六个元素排成 \[1, 1, 2, 3, 4, 5\]。

## 问题与输入

本组第一帧已完成初始建堆，数组为 \[5, 4, 3, 1, 1, 2\]。大顶堆要求任意父节点的值不小于其子节点的值，因此建堆或堆化修复完成后，堆顶根节点是当前有效堆中的最大元素。

左侧上方的二叉树与其下方数组按层序一一对应，索引从 0 开始；索引 i 的左右子节点分别位于 2i+1 与 2i+2，且只有落在当前有效区间内的索引才属于堆。图中绿色节点表示堆的有效区间，灰色节点表示右侧已排序区间。

## 结构与关系

每轮提取操作先将堆顶元素与当前有效堆的堆底（最右端）元素交换，使当前最大值归入右侧灰色的已排序后缀；随后仅在缩短后的绿色有效前缀内从顶至底执行堆化（sift down）。

当节点变为灰色归入已排序区间后，左侧二叉树中连向它的树边会隐去，代表它不再参与后续堆化比较；但该元素始终原地保存在下方数组中，有效堆缩短并非从数组中删除元素。
