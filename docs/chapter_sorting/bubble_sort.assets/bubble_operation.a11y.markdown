# 一轮冒泡操作

对 \[4, 1, 3, 1, 5, 2\] 从左向右依次比较五对相邻“泡泡”，执行四次交换、一次保持不变，将最大元素 5 浮到最右端索引 5。

## 问题与输入

输入数组为 nums = \[4, 1, 3, 1, 5, 2\]，索引从 0 到 5。单轮冒泡从最左端开始向右遍历，每次比较相邻两个元素：若“左边元素 &gt; 右边元素”则交换二者，若“左边元素 ≤ 右边元素”则维持不变。

画面将数组元素形象地画成一排圆球“泡泡”，元素数值越大则泡泡体积越大；数组左端对应“水底”，右端对应“水面”。每步用浅绿色方框圈出当前比较的相邻位置对，浅框内位于泡泡上、下方的交换弧线表示该对刚刚完成了交换。

## 结构与关系

七幅分步画面完整演示第一轮冒泡：第 1 步将六个数组方格映射为六个大小成正比的泡泡；第 2 至第 6 步依次检查索引 (0, 1)、(1, 2)、(2, 3)、(3, 4)、(4, 5) 五对相邻位置（其中第 2、3、4、6 步展示已完成相邻交换后的结果，第 5 步因 4 ≤ 5 维持原位不交换）；第 7 步展示最大泡泡 5 到达右端“水面”就位，剩余左侧前 n − 1 = 5 个元素留待后续轮次继续冒泡。
