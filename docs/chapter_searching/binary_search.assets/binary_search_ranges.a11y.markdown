# 二分查找的区间约定

右边界指针 j 是否包含在搜索区间内，直接决定 j 的初始值、循环终止条件以及向左收缩时的赋值方式。

## 问题与输入

示意升序数组包含 n = 10 个元素，索引为 0 至 9；指针 i、j 分别标识当前搜索区间的左、右边界，m 表示当前折半中点索引。图中柱高仅示意元素单调递增，未标注具体元素数值。

## 结构与关系

左半幅展示“双闭区间 \[i, j\]”（左右边界都包含自身）：初始化指针为 i = 0, j = n - 1（即 j = 9，指向最后一根柱子）；当 i = j 时区间内仍含一个待查元素，直到 i &gt; j 时搜索区间才为空。

右半幅展示“左闭右开区间 \[i, j)”（左边界包含自身、右边界不包含自身）：初始化指针为 i = 0, j = n（即 j = 10，指向数组最右端外侧的排除位置）；当 i = j 时区间已经为空，因此循环终止条件为 i ≥ j。

在缩小区间操作上：若中点值小于目标，两种写法都已排除 m 及其左侧，左边界均更新为 i = m + 1；若中点值大于目标，双闭区间需将右边界设为包含在内的 j = m − 1，而左闭右开区间由于本身不包含右端点 j，需将右边界设为 j = m。完整对照见附表。

## 双闭区间与左闭右开区间

左右两图的蓝色虚线框都恰好框住索引 0 至 9 的十个元素，但左图双闭区间的右指针 j 指向索引 9（包含该位置），右图左闭右开区间的右指针 j 指向越界的索引 10（排除该位置），下方四行文字逐项列出由此决定的算法规则差异。

## 结果

双闭区间 \[i, j\] 与左闭右开区间 \[i, j) 都能正确实现二分查找，但初始化指针、循环终止条件与缩小区间操作必须严格配套使用；双闭区间左右收缩对称（i = m + 1 与 j = m − 1），通常更不易出错。
