# 二分查找

在升序数组中查找目标值 6，每轮比较中点元素后排除不可能包含目标的一半区间。

## 问题与输入

输入为含 10 个互异元素的升序数组 \[1, 3, 6, 8, 12, 15, 23, 26, 31, 35\]，索引为 0 至 9，查找目标值 target = 6；各索引与元素值的对应关系见输入表。

指针 i、j 分别表示当前搜索闭区间 \[i, j\] 的左、右边界（两端点均包含在搜索范围内）；m 表示区间中点索引，按 (i + j) / 2 向下取整计算。每轮先计算中点 m，再比较 nums\[m\] 与目标值。
