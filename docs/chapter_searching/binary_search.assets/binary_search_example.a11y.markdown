# 二分查找示例数据：在十个升序元素中定位 target = 6

有序数组 nums 从 1 严格递增到 35，目标值 target = 6 位于索引 2。

## 问题与输入

给定严格递增的有序数组 nums = \[1, 3, 6, 8, 12, 15, 23, 26, 31, 35\]，索引从 0 到 9，查找目标元素 target = 6。
