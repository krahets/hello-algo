# 线性查找求解两数之和：两层循环枚举不同索引组合

对数组 nums = \[2, 7, 11, 15\] 与 target = 13，枚举不同位置的配对，由 2 + 11 = 13 找到索引组合 \[0, 2\]。

## 问题与输入

给定整数数组 nums = \[2, 7, 11, 15\]（索引从 0 到 3）与目标和 target = 13。

题目要求找出和为 target 的两个不同数组位置并返回它们的索引（同一个位置的元素不能重复使用两次）。暴力解法通过外层索引 i 与内层索引 j（j &gt; i）开启两层循环，逐对检查两数之和。

## 结构与关系

矩阵中第 0 行（元素 2）与第 2 列（元素 11）交叉处的单元格 13 用紫蓝色文字标出。按照代码从左到右的枚举顺序，外层固定 i = 0（元素 2）后，内层先算 2 + 7 = 9，紧接着算到 2 + 11 = 13 即命中目标并直接返回 \[0, 2\]；图中将其余候选和一并画出仅用于展示完整的组合空间，并不代表命中后仍需继续算完后续组合。
