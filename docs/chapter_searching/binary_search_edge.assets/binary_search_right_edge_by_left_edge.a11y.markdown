# 用插入点查找右边界

在有序整数数组中，用 target + 1 的插入点减 1 得到右边界候选索引；返回前须确认索引有效且对应元素等于 target。

## 问题与输入

有序整数数组为 nums = \[1, 3, 6, 6, 6, 6, 6, 10, 12, 15\]，目标元素 target = 6；其中索引 2 至 6 为五个连续的 6。画面同时标出查找左边界与查找右边界结束时的两组双指针状态。

## 结构与关系

左侧直接执行“查找最左一个 target”：二分插入点搜索结束时，指针 i 停在索引 2（首个 6，青色方格），指针 j 停在索引 1（值为 3），因此 6 的左边界即为 i = 2。

右侧展示“查找最右一个 target”与“查找最左一个 target + 1”之间的双向“等价”转化：对 target + 1 = 7 执行二分查找插入点，搜索结束时指针 i 指向首个大于等于 7 的元素（即索引 7 的值 10），而指针 j = i − 1 恰好指向索引 6 的最后一个 6（青色方格）。注意数组中并不存在元素 7，图中的“查找最左一个 target + 1”是指调用二分插入点函数求 7 的左边界插入位置 i = 7，而非直接命中元素 7。

这一等价转化利用了数组元素皆为整数的性质：严格大于整数 6 的最小整数必不小于 7。在实际代码中得到 j = i − 1 后，还需检查 j 是否未越界且 nums\[j\] == target，若不满足则说明数组中不存在 target，应返回 −1。

左侧指针对 (j = 1, i = 2) 夹在元素 3 与首个 6 之间，给出左边界 i = 2；右侧指针对 (j = 6, i = 7) 夹在最右一个 6 与元素 10 之间，说明查找 target + 1 = 7 的插入点 i = 7 后取 j = i − 1 = 6 即可得到 6 的右边界。

## 结果

本例中 target = 6 的左边界为索引 2，右边界通过 target + 1 = 7 的插入点索引 7 减 1 得到 j = 6。
