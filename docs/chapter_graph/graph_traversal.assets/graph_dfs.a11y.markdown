# 图的深度优先遍历

从起点出发沿未访问邻居递归深入，无路可走时回溯到上一层顶点，继续探索剩余分支。

## 问题与输入

无向连通图包含顶点 0 至 6，共 6 条无向边：0—1、0—3、1—2、2—5、4—5、5—6。遍历从起点 0 出发；本例在顶点 0 处按先 1 后 3 的次序检查邻居，在顶点 5 处按先 4 后 6 的次序检查邻居。

列表 res 按首次访问顺序记录顶点；集合 visited 记录已访问顶点，防止沿无向边重复进入。每到达一个新顶点，先将其记入 res 与 visited，再依次对未访问邻居发起递归调用；若当前顶点的所有邻居均已访问，则结束当前调用并返回上一层顶点。visited 的花括号写法仅表示集合成员，不代表顺序。

## 深度优先遍历概览

总览图汇总了全部 14 个递归事件：从 0 依次深入 1、2、5、4（事件 1 至 5），4 无新邻居而返回 5（事件 6）；再由 5 深入 6 并返回 5（事件 7、8），随后沿 5→2→1→0 连续返回起点 0（事件 9 至 11）；最后从 0 深入 3（事件 12），再经 3 返回 0 及起始调用返回（事件 13、14）。每次回溯只退回上层调用，不重复记入 res。

## 结果

最终首次访问序列为 res = \[0, 1, 2, 5, 4, 6, 3\]，每个顶点仅在首次到达时记录一次，回溯返回不会再次写入 res。即使 7 个顶点已全部访问，仍需依次结束剩余递归调用才算完成遍历；若改变同一图中邻居的检查次序，所得 DFS 序列也会随之改变。
