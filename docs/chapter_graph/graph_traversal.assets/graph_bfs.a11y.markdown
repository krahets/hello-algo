# 图的广度优先遍历

从左上角起点 0 出发，借助先进先出队列与去重集合，按距离由近及远逐层遍历各顶点。

## 问题与输入

待遍历的无向图有 9 个顶点，编号为 0 至 8，按三行三列网格排列：三行依次为 0、1、2；3、4、5；6、7、8。图中只在水平或竖直相邻的顶点之间连接无向边，共 12 条边，没有对角边；各顶点的邻居列在邻接表中。

res 是按出队顺序记录的遍历序列；que 是先进先出的待处理队列，下文均按从队首到队尾的顺序写出；visited 是记录已发现顶点的哈希集合。注意顶点在入队时就立即记入 visited，因此即使某顶点仍在队列中等待出队，后续遇到它时也不会再次入队。

## 结构与关系

每轮循环从队列 que 队首取出一个顶点并追加到 res，随后检查它的所有邻接顶点：将尚未出现在 visited 中的新邻居依次加入 que 队尾，并同步记入 visited。先进先出队列保证了同一距离层的顶点先于更远层的顶点被处理。图中队列槽位左侧的空白格表示此前元素出队后留下的位置，并非空元素；visited 的横向排列也不代表集合内部有序。

## 广度优先遍历概览

从左上角起点 0 出发，按到起点的最少边数由近及远逐层访问：距离 1 的 {1, 3}、距离 2 的 {2, 4, 6}、距离 3 的 {5, 7}，最后是距离 4 的 {8}。图中蓝色虚线箭头仅表示访问先后次序，并非原图中的边（例如对角方向的 1 与 3、6 与 5 在原图中并不直接相连）。

## 结果

队列清空后循环结束，返回遍历序列 \[0, 1, 3, 2, 4, 6, 5, 7, 8\]。按到起点 0 的最少边数划分，距离层 0 至 4 依次为 {0}、{1, 3}、{2, 4, 6}、{5, 7}、{8}；同一距离层内部的先后取决于邻接顶点的遍历次序，因此广度优先遍历序列并不唯一。
