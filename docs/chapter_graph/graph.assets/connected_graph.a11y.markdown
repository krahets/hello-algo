# 连通图与非连通图：所有顶点皆可达与存在孤立顶点

左图五个顶点通过七条边彼此全部可达；右图去掉与顶点 4 相连的两条边后，顶点 4 孤立，形成非连通图。

## 问题与输入

左右两幅图均为包含顶点 1、2、3、4、5 的无向图。无向图的“连通”是指从任意顶点出发，都能沿一条或多条边组成的路径到达其余任意顶点，不要求每对顶点之间都有直接相连的边。

## 结构与关系

左侧为“连通图（所有顶点皆可达）”：共有七条无向边 1—2、1—3、1—5、2—3、2—4、2—5、4—5。即使像顶点 3 与顶点 4 之间没有直接边，也能通过路径 3—2—4 或 3—1—5—4 互相到达，因此五个顶点构成单一连通整体。

右侧为“非连通图（存在顶点不可达）”：保留了左侧四个顶点之间的五条无向边 1—2、1—3、1—5、2—3、2—5，但删去了连接顶点 4 的两条边 2—4 和 4—5。此时顶点 1、2、3、5 内部依然彼此可达，但没有任何路径能够通往右侧孤立的顶点 4。

图左右对比“连通图（所有顶点皆可达）”与“非连通图（存在顶点不可达）”：两图的唯一结构差异在于顶点 4——左图中顶点 4 通过边 2—4 和 4—5 接入网络，五点全连通；右图去掉这两条边后，顶点 4 成为没有任何边的孤立顶点，其余四个顶点无法到达 4。

## 结果

只要无向图中存在至少一对顶点无法通过路径互相到达（如右图中孤立的 {4} 与连通子集 {1, 2, 3, 5}），该图就属于非连通图。
