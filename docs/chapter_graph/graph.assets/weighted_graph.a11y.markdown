# 无权图与有权图：为边附加权重数值属性

左右两图具有完全相同的五个顶点与七条无向边；右图在每条边旁标注 0.2 至 1.0 的小数作为边的权重。

## 问题与输入

左右两幅图均为无向图，顶点同为 1 至 5，七条无向边同为 1—2、1—3、1—5、2—3、2—4、2—5、4—5。左图仅表达顶点间是否存在连接，右图进一步为每条边赋予一个数值权重。

## 结构与关系

左侧为“无权图（所有边等价）”：七条边上没有任何数值标注，所谓“所有边等价”是指已存在的这七条边在图模型中地位相同、不区分强弱或长短，并非指所有顶点两两之间都有边。

右侧为“有权图（边具有权重属性）”：在完全相同的七条无向边旁分别标出小数权重——上方的边 1—5 为 0.25，左侧竖边 1—3 为 0.2，中间斜边 1—2 为 0.5，下方横边 2—3 为 0.3，中间竖边 2—5 为 0.7，右上斜边 4—5 为 0.88，右下斜边 2—4 为 1.0。全部边与权重的对应关系列于数据表。

边权在不同应用场景中可代表距离、耗费、亲密度等量化属性；图本身只给出纯数值，未绑定具体物理单位。

## 结果

向边引入权重属性后，无权图即扩展为有权图：底层顶点与边的拓扑连接不变，但每条边多了一维可用于最短路径、最小生成树等图计算的量化信息。
