# 链表、树与图的连接关系

用同样的五个节点比较线性后继、树形层级与允许交叉和环路的网络关系。

## 问题与输入

三幅子图均使用编号 1 至 5 的五个节点：链表与树的箭头表示有向引用，无向图的线段表示双向邻接。三者是并列的结构对比，而非将同一结构逐步变形的算法过程。

## 结构与关系

按连接约束从严到宽对比：单向链表要求每个非尾节点仅有一个后继，呈单一线性链；树允许一个父节点分出多个子节点，形成自根向下的层级分支，但每个非根节点只有一个父节点且不能跨分支或成环；图则解除根与层级限制，任意两个顶点之间均可按关系建立连接，并允许出现环路。

本例无向图中包含 1—2—3—1、2—4—5—2 等环路，共连接 7 条边，但并非每对顶点之间都有边（例如 3 与 4、3 与 5 未相连，不是完全图）。图下方标注的“逻辑自由度最高”是指连接约束最少，而非比较某次算法运行的复杂度。

单向链表将连接限制为单线后继；树放宽为一对多的单向层级分支；图进一步允许跨分支连接与环路。相同的 5 个节点在不同连接约束下呈现出线性、层级与网络三类结构。

## 结果

把节点视作顶点、引用视作边，链表与树都能从图的角度理解。一般图容许更广泛的连接方式；本图展示的是结构关系的拓展。
