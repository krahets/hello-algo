# 二叉树的最佳结构与链状退化结构

同样由节点 1 至 7 组成：左侧完美二叉树有 3 层、高度为 2；右侧单侧退化为链表，有 7 层、高度为 6。

## 问题与输入

左右两棵二叉树都由值为 1 至 7 的 7 个节点构成，用来对比相同节点总数下的最佳结构与最差退化结构。

## 结构与关系

左图下方标注“理想结构：完美二叉树”。根节点为 1；1 的左、右子节点为 2、3；2 的左、右子节点为 4、5；3 的左、右子节点为 6、7；底层 4、5、6、7 都是叶节点。整棵树共 3 层，从根 1 到任意叶节点只经过 2 条边，高度为 2。

右图下方标注“退化结构：链表”。7 个节点全部偏向左侧，沿左子节点指针依次串成 1 → 2 → 3 → 4 → 5 → 6 → 7，所有节点的右子节点均为空。整棵树拉长为 7 层，从根 1 到唯一叶节点 7 需要经过 6 条边，高度达到 6。

左图将节点 1 至 7 均匀分叉为 3 层完美二叉树（高度 2），右图将节点 1 至 7 沿左指针串成 7 层单链（高度 6），直观对比分治理想形态与线性退化形态。

## 结果

当每层填满成完美二叉树时，树高最小，可发挥分治优势；当节点全部偏向一侧退化为链表时，树高达到最大，按路径操作退化为线性时间。
