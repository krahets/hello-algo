# 二叉树的根、叶、深度与高度

以一棵四层二叉树为例，展示根节点、叶节点，以及节点 2 的深度 1、高度 2 和整棵树的高度 3。

## 结构与关系

图中是一棵四层二叉树，绿色圆圈内为节点值，灰色箭头从父节点指向左、右子节点。顶层的 1 是根节点；1 的左、右子节点是 2、3；2 的左、右子节点是 4、5；3 的左、右子节点是 6、7；4 的左、右子节点是 8、9；6 只有左子节点 12；7 的左、右子节点是 14、15。

每条有向连线代表一条边。顶部的“根节点”标注指向最上方没有父节点的 1；底部的“叶节点”通过六条引线指向 8、9、5、12、14、15。这六个节点都没有子节点，其中 5 位于第 3 层，其余五个位于第 4 层，说明叶节点不必处在同一层。

两侧标尺按经过的边数度量深度与高度：左侧上方标尺从根 1 量到节点 2，经过 1 条边，标明“节点 2 深度 = 1”；左侧下方标尺从节点 2 量到其最远叶节点 8、9，经过 2 条边，标明“节点 2 高度 = 2”。右侧长标尺从根 1 量到底层最远叶节点，经过 3 条边，标明“二叉树高度 = 3”。

## 结果

本图以经过的边数定义深度和高度：节点 2 的深度为 1、高度为 2，四层二叉树的高度为 3 而非 4。
