# 二叉树的插入与摘除

通过改连左子节点引用，在完整保留节点 2 子树的前提下插入或摘除中间节点 P。

<a id="source-91"></a>

预先用 n2 保存节点 2 的引用。插入时执行 n1.left = P 与 P.left = n2，把原边 1 → 2 改连为 1 → P(0) → 2，节点 2 的左右连接仍为 4、5，整棵子树得以接回。摘除时执行 n1.left = n2，绕过 P 直接恢复 1 → 2。

## 结果

摘除后恢复原树连接，仅能断言从根节点不再能到达 P，不能据此断言 P 的对象内存已被释放，也不表示删去了整棵左子树。

## 二叉树的插入与摘除：动画

通过改连左子节点引用，在完整保留节点 2 子树的前提下插入或摘除中间节点 P。

n1 指向值为 1 的根节点，n2 保留值为 2 的原左子节点引用；待插入节点 P 的值为 0。

### 第 1 步：准备插入 P

在改写 n1.left 之前，先由引用 n2 指向节点 2，以便后续把以 2 为根的原左子树接回新节点 P 下方。

<details><summary>本步完整状态</summary><p>根节点 1（n1）的左子节点为 2（n2）、右子节点为 3；节点 2 的左右子节点为 4、5；3、4、5 为叶节点。值为 0 的节点 P 独立于树外，左右子节点均为空。</p></details>

### 第 2 步：将 P 插入左连接

依次执行 n1.left = P 与 P.left = n2：因 n2 保留了节点 2 的引用，P.left = n2 能将整棵原左子树接回 P 下方，节点 2 的左右连接仍为 4、5，不会丢失子树。

<details><summary>本步完整状态</summary><p>根节点 1（n1）的左子节点改为 P（值为 0）、右子节点仍为 3；P 的左子节点为 2（n2）、右子节点为空；节点 2 的左右子节点仍为 4、5；3、4、5 为叶节点。</p></details>

### 第 3 步：绕过 P 接回原子树

执行赋值 n1.left = n2，令根节点 1 绕过 P 直接连回节点 2，恢复原左子树连接；这只是把 P 从根可达路径中摘除，不表示删去整棵子树或已释放 P 的内存。

<details><summary>本步完整状态</summary><p>根节点 1（n1）的左子节点恢复为 2（n2）、右子节点为 3；节点 2 的左右子节点为 4、5；3、4、5 为叶节点。节点 P 已无法从根节点到达；仅凭此状态不能断言 P 的内存已释放。</p></details>

### 结果

摘除后恢复原树连接，仅能断言从根节点不再能到达 P，不能据此断言 P 的对象内存已被释放，也不表示删去了整棵左子树。
