# 完满二叉树：所有节点的度都为 0 或 2

四层共 7 个节点，每个节点要么是度为 0 的叶节点，要么是度为 2 的双子节点。

## 结构与关系

左侧无数值标签的二叉树分布在四层，共 7 个节点：第一层根节点有左、右两个子节点；第二层右侧节点是叶节点，左侧节点又有左、右两个子节点；第三层左侧节点是叶节点，右侧节点继续分出第四层的左、右两个叶节点。

节点的“度”即它拥有的子节点数量。右侧标出“完满二叉树（full binary tree）”，底部灰色说明框写着“所有节点的度都为 0 或 2”：图中三个非叶节点的度全为 2，4 个叶节点的度全为 0，不存在度为 1 的单子节点；同时叶节点分布在不用填满的第二、第三、第四层。

图中三个分叉节点都成对拥有左、右子节点（度为 2），其余 4 个节点均为无子节点的叶节点（度为 0），没有任何节点只带单个子节点。

## 结果

完满二叉树只要求每个节点有 0 个或 2 个子节点，不要求每一层填满或所有叶节点处于同一层。
