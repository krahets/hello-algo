# 完美二叉树：每一层都完全填满

四层二叉树的节点数从上到下依次为 1、2、4、8，所有层全部填满，共 15 个节点。

## 结构与关系

左侧是一棵四层无数值标签的二叉树：第一层有 1 个根节点；第二层有 2 个节点；第三层有 4 个节点；第四层有 8 个叶节点。树下方的灰色说明框写着“所有层的节点都被填满”。

图中每个非叶节点都同时拥有左、右两个子节点，全部 8 个叶节点都整齐排列在最底部的第四层。右侧标题标出“完美二叉树”、英文“perfect binary tree”，并注明“（也被称为满二叉树）”。

<a id="source-92"></a>

从第一层到第四层每层节点数依次翻倍为 1、2、4、8，没有任何空缺位置，展示“所有层的节点都被填满”的完美二叉树（满二叉树）形态。

## 结果

这棵四层完美二叉树按边数计算的高度为 3，共有 15 个节点；一般地，高度为 h 的完美二叉树共有 2^(h+1) − 1 个节点。
