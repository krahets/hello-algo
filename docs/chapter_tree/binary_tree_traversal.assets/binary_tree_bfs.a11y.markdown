# 二叉树的层序遍历

按从顶层到底层、同一层内从左到右的次序逐层访问二叉树节点。

## 问题与输入

示例二叉树共三层 7 个节点：根节点为 1；1 的左、右子节点分别为 2、3；2 的左、右子节点分别为 4、5；3 的左、右子节点分别为 6、7。其中 4、5、6、7 为叶节点。

遍历按层推进：先访问第 1 层的根 1，再从左到右访问第 2 层的 2、3；第 2 层完成后转入第 3 层最左侧的节点 4，再依次访问同层的 5、6、7，因此访问 3 之后是 4。图中灰色实线箭头表示父子关系，串联各节点底部蓝点的虚线箭头仅表示访问先后次序——例如 4 的父节点是 2，从 3 指向 4 的斜向虚线只表示从第 2 层末尾进入第 3 层首节点，不表示 3 是 4 的父节点。

## 结果

层序遍历序列为 \[1, 2, 3, 4, 5, 6, 7\]，每个节点恰好访问一次。
