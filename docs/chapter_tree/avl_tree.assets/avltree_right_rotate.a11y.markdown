# AVL 树右旋

对首个失衡节点执行右旋，先重连局部子树的父子指针，再将新子树根接回上层父节点。

## 问题与输入

初始树根为 4，左右子节点为 3、5；3 只有左子节点 1，1 只有左子节点 0；0、5 为叶节点。

平衡因子定义为左子树高度减右子树高度；高度按边数计，叶节点高度为 0，空子树高度为 −1。自底向上检查时，首个失衡节点是 3，记为 node；其左子节点 1 记为 child。

## 结构与关系

本例中 child（1）的右子树为空，右旋时 node（3）的左指针因而改为空。若一般情形下 child 带有非空右子树 grand\_child，实现中会将它改接到 node 的左侧；本组不包含这一非空中间子树。

## 第 1 步：找到首个失衡节点 3

各节点下方标注平衡因子：叶节点 0、5 为 0，节点 1 为 1，节点 3 与根 4 均为 2。沿左分支自底向上检查，首先超出平衡范围的是节点 3，因此优先修复以 3 为根的子树。

<a id="source-131"></a>

## 第 2 步：标记旋转的两个节点

将失衡子树根 3 记为 node，其左子节点 1 记为 child。本例 child 的右子树为空，因此旋转后 node 的左子树也为空。

<details><summary>本步完整状态</summary><p>右旋第 2 步（标记旋转节点）：根 4 的左右子节点仍为 3、5；node 指向 3，child 指向 1，3.left 为 1，1.left 为 0，1.right 为空，树连接尚未改变。</p></details>

<a id="source-132"></a>

## 第 3 步：形成以 1 为根的局部子树

以 child（1）为原点将 node（3）向右旋转：令 child.right 指向 node（3），并把 node.left 改为原 child.right（本例为空），使 1 的左右子节点分别为 0、3。此时局部子树虽已形成，但图中父节点 4 还未接到新根 1，整次旋转尚未完成。

<details><summary>本步完整状态</summary><p>右旋第 3 步（局部子树已形成、未接回父节点）：局部子树根已是 child（1），1 的左子节点为 0、右子节点为 node（3），0 和 3 为叶节点；但图中父节点 4 仅连着右子节点 5，还未接到新根 1。原 3 位置处的虚线轮廓仅示意旋转前的旧位置。</p></details>

<a id="source-133"></a>

## 第 4 步：将新子树根接回父节点

最后用新子树根 child（1）替换原 node（3）在父节点 4 下的位置，最后使 4.left 指向 1，完成整次右旋。该子树高度下降 1，根 4 的左右子树高度差也恢复到 1 以内。

<details><summary>本步完整状态</summary><p>右旋第 4 步（接回父节点、旋转完成）：根为 4；4 左为 1、右为 5，1 左为 0、右为 3，0、3、5 均为叶节点。全树满足二叉搜索树顺序与 AVL 平衡条件，中序序列为 [0, 1, 3, 4, 5]。</p></details>

## 结果

旋转完成后，根为 4；4 左为 1、右为 5，1 左为 0、右为 3，0、3、5 均为叶节点。局部子树与整棵树均恢复平衡，中序序列仍为 \[0, 1, 3, 4, 5\]。
