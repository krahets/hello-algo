# 插入导致搜索树失衡

向同一侧连续插入节点会逐层拉长分支高度，使原本平衡的二叉树超出平衡条件。

<a id="source-129"></a>

初始根 4 的左右子节点为 3、5。插入 2 时，2 小于 4 和 3，接到 3 的左侧；虽然最底层不再填满，4 与 3 的平衡因子都只是 1，仍保持平衡。再插入 1 时，沿 4 → 3 → 2 接到 2 的左侧，此时 3 与 4 的平衡因子都变为 2 而失衡。

## 结果

不再完美并不等于已经失衡：插入 2 后节点 4 与 3 的平衡因子都是 1，仍满足平衡条件；再插入 1 后两者的平衡因子才都变为 2，AVL 树会通过旋转维护避免此类退化。

## 插入导致搜索树失衡：动画

向同一侧连续插入节点会逐层拉长分支高度，使原本平衡的二叉树超出平衡条件。

从根为 4、左右子节点为 3 和 5 的二叉搜索树开始，依次插入 2、1；本演示不执行平衡旋转。节点高度按边数计，叶节点高度为 0，空子树高度为 −1。

### 第 1 步：初始完美二叉树

3 个节点填满两层，根 4 的左右子树高度相同（均为 0），各节点平衡因子均为 0。

<details><summary>本步完整状态</summary><p>初始状态：根 4 的左右子节点是叶节点 3、5，共 3 个节点填满两层，既是完美二叉树，也满足平衡条件。</p></details>

### 第 2 步：插入 2 后仍然平衡

2 小于 4 和 3，接为 3 的左子节点；虽然不再是完美二叉树，但各节点的左右子树高度差至多为 1。

<details><summary>本步完整状态</summary><p>第一次插入后：根 4 的左右子节点为 3、5；3 仅有左子节点 2，2 和 5 为叶节点。全树共 4 个节点，尚未失衡，4 与 3 的平衡因子都是 1，仍然平衡。</p></details>

### 第 3 步：插入 1 后出现失衡

1 小于 4、3、2，接在 2 的左侧。此时节点 3 的左子树高度为 1、右子树为空（高度 −1），根 4 的左子树高度为 2、右子树高度为 0，插入 1 后 3 与 4 的平衡因子才都变为 2。

<details><summary>本步完整状态</summary><p>第二次插入后：1 是 2 的左子节点（左侧形成 4 → 3 → 2 → 1 的连续左连接），4 的右子节点仍为叶节点 5。全树共 5 个节点，节点 3 与根 4 的平衡因子均为 2，树已失衡。</p></details>

### 结果

不再完美并不等于已经失衡：插入 2 后节点 4 与 3 的平衡因子都是 1，仍满足平衡条件；再插入 1 后两者的平衡因子才都变为 2，AVL 树会通过旋转维护避免此类退化。
