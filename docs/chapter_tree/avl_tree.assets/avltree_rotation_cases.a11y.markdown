# AVL 树的四种失衡形状与旋转选择

左左偏斜用右旋，左右弯折用先左旋后右旋，右左弯折用先右旋后左旋，右右偏斜用左旋。

## 问题与输入

四幅子图中，橙色节点 3 均为待修复的失衡节点，蓝色节点是它较高一侧的子节点，绿色节点标示子树继续延伸的方向；灰色圆角背景框圈出需要旋转调整的局部失衡子树。

## 结构与关系

从左到右排列四个旋转前案例：前两幅图的外层根节点均为 4、右子节点为 5，左侧挂着以 3 为根的失衡子树；后两幅图的外层根节点均为 2、左子节点为 1，右侧挂着以 3 为根的失衡子树。四种局部连接形态及下方标注的旋转方法汇总于数据表。

结合正文选择规则，设平衡因子 f 为左子树高度减去右子树高度：当失衡节点 f &gt; 1（左偏树）时检查左子节点，若左子节点 f ≥ 0 则直接右旋，若 f &lt; 0 则先左旋后右旋；当失衡节点 f &lt; −1（右偏树）时检查右子节点，若右子节点 f ≤ 0 则直接左旋，若 f &gt; 0 则先右旋后左旋。其中子节点平衡因子等于 0 的情形属于通用判定条件的一部分（例如删除节点后可能出现），并非指图中四个具体子节点的平衡因子都等于 0。

图中并列画出四种旋转前的失衡形态，并在各自下方标出对应的修复操作：同向倾斜的“左左”（3 → 1 → 0）和“右右”（3 → 5 → 6）分别只需一次右旋或左旋；反向弯折的“左右”（3 → 1 → 2）和“右左”（3 → 5 → 4）则分别需要“先左旋后右旋”和“先右旋后左旋”。

## 结果

先根据失衡节点的平衡因子符号判断偏向哪一侧，再看较高一侧子节点是否同向倾斜，即可在单旋与双旋之间唯一确定修复操作，且旋转后中序次序不变。
