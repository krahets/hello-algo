# AVL 树先左旋后右旋

针对先向左再向右弯折的路径 3 → 1 → 2，先对 child（1）执行左旋，再对 node（3）执行右旋，使 2 成为局部新根。

## 问题与输入

外层根节点为 4，右子节点为 5，左子节点为失衡节点 3；节点 3 只有左子节点 1，节点 1 只有右子节点 2。图中将失衡节点 3 记为 node，其左子节点 1 记为 child。

## 结构与关系

第一步对 child（节点 1）执行左旋：节点 2 上升为这棵小子树的根，节点 1 降为 2 的左子节点，节点 3 的左子节点随之变为 2。如中间子图所示，原本弯折的路径被拉直为连续向左倾斜的路径 3 → 2 → 1。

第二步对原失衡节点 node（节点 3）执行右旋：节点 2 继续上升为局部子树的根，节点 3 降为 2 的右子节点，节点 1 保持为 2 的左子节点。外层父节点 4 的左子节点更新为 2，右子节点 5 保持不变。

对于这种“左-右”弯折形态，若直接对节点 3 做单次右旋，仍会留下新的失衡；只有先通过左旋把局部形态转化为“左-左”同向倾斜，再执行右旋，才能让节点 1、2、3 均匀分布在两侧。

图分三阶段展示“先左旋后右旋”：两次旋转针对的对象不同，第一步先对左子节点 child（节点 1）执行左旋，把 3 → 1 → 2 拉直为 3 → 2 → 1；第二步再对失衡节点 node（节点 3）执行右旋，使节点 2 升为局部新根、左右分别接 1 和 3。

## 结果

双旋完成后，外层根 4 的左、右子节点分别为 2 和 5，节点 2 的左、右子节点分别为 1 和 3；局部子树恢复平衡，整棵树的中序遍历序列保持为 \[1, 2, 3, 4, 5\]。

当失衡节点 node 的左子树更高，但左子节点 child 自身的优势分支却在右侧时，单次右旋无法消除失衡，需要采用“先对 child 左旋、再对 node 右旋”的双旋操作来恢复平衡。

整个过程中根节点 4 与右子节点 5 保持不动，双旋重连左子树内部的父子指针，并将根节点 4 的左子指针接到新子树根 2，不改变五个节点的中序排列。
