# 二叉搜索树的中序遍历

## 问题与输入

本书二叉搜索树不存重复值；每个节点的左子树所有值小于该节点值，右子树所有值大于该节点值。

每个节点都先递归遍历比它小的左子树，再记录自身，最后遍历比它大的右子树。根 8 的左子树先输出 2、4、6，随后记录根 8，右子树再输出 10、12、14，由此得到严格递增序列；图中蓝点标记记录各节点的时机。

## 结果
