# 计算机存储系统的金字塔层级

从顶到底依次为 CPU 内的 L1、L2、L3 缓存，以及内存（RAM）和硬盘（HDD/SSD），体现速度与容量、成本的权衡。

## 问题与输入

中央金字塔从上到下由窄变宽，共分五层：前三层为 L1 Cache、L2 Cache、L3 Cache，左侧归类为“缓存”，上方由绿色边框归入“CPU”内部；第四层为 RAM，左侧标为“内存”；最底层为 HDD/SSD，左侧标为“硬盘”。

## 结构与关系

金字塔右侧有两条方向相反的纵向箭头：向上箭头旁标“速度、价格”，表示越靠近顶端的存储层级，访问速度越快、单位容量价格越高；向下箭头旁标“容量、持久性”，表示越靠近底端的存储层级，容量越大，且到底层硬盘（HDD/SSD）具备断电后长期保存数据的持久性（缓存与内存属于易失性存储，断电后数据会丢失）。

金字塔从顶到底由窄变宽分为五层：位于 CPU 绿色框内的 L1 Cache、L2 Cache、L3 Cache（左侧统称“缓存”），其下的 RAM（“内存”），以及最底层的 HDD/SSD（“硬盘”）。右侧向上箭头标“速度、价格”，说明越往上访问越快、单位容量成本越高；向下箭头标“容量、持久性”，说明越往下容量越大，且底层硬盘能够在断电后持久保存数据，而上方的缓存和内存断电后数据会丢失。

## 结果

多层级存储结构在高速低容量的缓存、中等速度与容量的内存、大容量可持久化的硬盘之间取得速度、容量与成本的平衡。
