# 三种常见链表类型

以同一组节点 1、3、2、5、4 对比单向链表、环形链表和双向链表的连接方式。

## 问题与输入

画面从上到下分三行对比三种常见链表结构，每一行都包含按相同顺序排列的五个节点 1、3、2、5、4，区别仅在于节点间及首尾两端的引用连接方式。

## 结构与关系

上方为“单向链表（singly linked list）”：节点依次为 1 → 3 → 2 → 5 → 4 → None。每对相邻节点之间只有一条向右的后继箭头，尾节点 4 指向空值 None，只能从头到尾单向遍历。

中间为“环形链表（circular linked list）”：节点同样依次为 1 → 3 → 2 → 5 → 4，但尾节点 4 的箭头不再指向 None，而是经下方折线回到首个节点 1，形成首尾相接的闭环。在环形链表中，任意节点都可视作头节点。

下方为“双向链表（doubly linked list）”：表示为 None ← 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4 → None。每对相邻节点之间都有向右（next，指向后继）和向左（prev，指向前驱）两条方向相反的箭头，头节点 1 的前驱指向左侧 None，尾节点 4 的后继指向右侧 None，支持向前和向后双向遍历。

图从上到下用节点 1、3、2、5、4 对比三种链表：上方单向链表为 1 → 3 → 2 → 5 → 4 → None，仅含向后的单向箭头，尾节点指向 None；中间环形链表为 1 → 3 → 2 → 5 → 4，并由尾节点 4 的折线箭头连回节点 1，实现首尾相接；下方双向链表为 None ← 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4 → None，相邻节点间同时具有向前和向后的双向箭头，头节点 1 的前驱与尾节点 4 的后继均指向 None。

## 结果

单向链表单向连接至 None，环形链表首尾相接成环，双向链表同时维护前驱与后继引用以支持双向遍历。
