# 链表删除节点

修改前驱节点的后继引用，绕过待删除节点。

<a id="source-52"></a>

已知前驱节点 n0（值为 1）、待删节点 P（值为 0）及后继节点 n1（值为 3），原连接为 n0 → P → n1 → 后续节点。执行 n0.next = n1 后，从入口 n0 出发会直接到达 n1，从而绕过 P。此时 P.next 虽仍指向 n1，但从链表入口已无法访问 P；图中保留 P 的虚线框仅作对比示意，不表示它仍在链表中，也未展示内存释放。

## 链表删除节点：动画

修改前驱节点的后继引用，绕过待删除节点。

局部链表为 n0(1) → P(0) → n1(3) → …；已知前驱节点 n0，目标是删除节点 P。

删除操作通过改变前驱引用使目标节点从入口不可达。节点 P 自身的 next 引用仍可指向 n1，不能据此认为 P 仍在链表中；图中未展示内存释放。

### 第 1 步：删除前：n0 → P → n1

初始状态下 n0.next 指向 P，P.next 指向 n1，从 n0 出发需经过 P 才能到达 n1。接下来准备将 n0.next 改指 n1。

<details><summary>本步完整状态</summary><p>当前局部链表为 n0(1) → P(0) → n1(3) → 后续节点；n0.next 指向 P，P.next 指向 n1，n0、P、n1 均从入口 n0 可达。</p></details>

### 第 2 步：改接引用：n0.next = n1

将前驱 n0 的后继引用直接指向 n1，主链随即跳过 P。此时 P.next 虽仍指向 n1，但从入口 n0 已无法访问 P，逻辑删除完成。
