# 链表的节点与连接

节点用引用连接成序列，存储位置无须连续。

## 结构与关系

逻辑视图与内存网格展示的是同一条链表，并非两份独立数据。网格中每个节点占相邻两格，分别存放节点值与后继引用（指针），其余浅色格为可用空间；格子大小仅为示意。

<a id="source-50"></a>

链表从头节点 1 沿 next 引用依次连接到 3、2、5、4，尾节点 4 指向 None。每个节点包含值和指向下一节点的引用，例如节点 3 的值为 3，其 next 指向节点 2。内存示意中，节点 4 位于上方，而排在它前面的节点 2 和 5 位于下方，说明遍历顺序由 next 引用决定，与物理存储位置无关。

## 结果

链表节点可分散存放，依靠 next 引用保持逻辑顺序；每个节点需要额外的引用存储空间。
