# 在数组中插入元素

在索引 1 处插入元素 3：先从末端开始将原有元素依次向右复制一位，再写入新元素。

## 问题与输入

数组 nums 共有 5 个槽位，索引为 0 至 4。初始存储为 \[1, 2, 5, 4, 0\]，其中只有前 4 个元素 \[1, 2, 5, 4\] 有效，末尾索引 4 的 0 是无意义的占位值。目标是在索引 1 处插入 3，并保持原有有效元素的相对顺序。

为腾出索引 1，算法从有效序列末端开始倒序复制：先把索引 3 的 4 复制到索引 4（nums\[4\] = nums\[3\]），再把索引 2 的 5 复制到索引 3（nums\[3\] = nums\[2\]），最后把索引 1 的 2 复制到索引 2（nums\[2\] = nums\[1\]）；随后在索引 1 写入 3（nums\[1\] = 3）。从末端向插入点倒序复制，能保证每个即将被覆盖、仍需保留的有效元素都已提前复制到右侧相邻格，避免从左向右移动时覆盖尚未保存的元素。赋值操作不会清空源槽位，因此过程中会暂时出现重复数值。在数组中间插入平均需移动 O(n) 个元素；若原本 5 个槽位全部有效，这种定长覆盖会丢失末尾有效元素，需先扩容或拒绝插入。

## 结果

插入完成后数组为 \[1, 3, 2, 5, 4\]，有效元素数量由 4 增至 5。被覆盖的是末尾无意义的占位值 0，四个原有有效元素均未丢失。

## 在数组中插入元素：动画

在索引 1 处插入元素 3：先从末端开始将原有元素依次向右复制一位，再写入新元素。

数组 nums 共有 5 个槽位，索引为 0 至 4。初始存储为 \[1, 2, 5, 4, 0\]，其中只有前 4 个元素 \[1, 2, 5, 4\] 有效，末尾索引 4 的 0 是无意义的占位值。目标是在索引 1 处插入 3，并保持原有有效元素的相对顺序。

先从最右端的有效元素开始向右复制，再逐步推进到插入位置，避免覆盖尚未备份的数据。赋值复制不会清空源槽位，因此中间状态会暂时出现重复数值。

### 第 1 步：准备插入

索引 1 当前存放有效元素 2，若直接写入 3 会将其覆盖丢失，因此需先把索引 1 至 3 的有效元素依次向右复制一位。

### 第 2 步：复制末尾的 4

执行 nums\[4\] = nums\[3\]，把索引 3 的 4 复制到末尾索引 4，覆盖原本无意义的 0。此时索引 3 的 4 已备份到索引 4，下一步可以安全覆盖索引 3。

<details><summary>本步完整状态</summary><p>在容量为 5 的数组索引 1 处插入 3；当前五个槽位存储为 [1, 2, 5, 4, 4]。已将末尾的 4 复制到索引 4，尚未写入 3，有效长度尚记为 4。</p></details>

### 第 3 步：复制 5

执行 nums\[3\] = nums\[2\]，把索引 2 的 5 复制到索引 3。原索引 3 的 4 已在上一步保存到索引 4，因此不会丢失。

<details><summary>本步完整状态</summary><p>在容量为 5 的数组索引 1 处插入 3；当前五个槽位存储为 [1, 2, 5, 5, 4]。只复制了 4 和 5，尚未复制 2，也尚未写入 3，有效长度尚记为 4。</p></details>

### 第 4 步：复制 2

执行 nums\[2\] = nums\[1\]，把索引 1 的 2 复制到索引 2。至此，原有的 2、5、4 已分别保存到索引 2、3、4，索引 1 可以安全写入新元素。

<details><summary>本步完整状态</summary><p>在容量为 5 的数组索引 1 处插入 3；当前五个槽位存储为 [1, 2, 2, 5, 4]。原有的 2、5、4 已全部后移一位，尚未写入 3，有效长度尚记为 4。</p></details>

### 第 5 步：写入 3

执行 nums\[1\] = 3，将新元素 3 写入索引 1。插入完成，有效元素数量由 4 增至 5，五个槽位全部有效。

<details><summary>本步完整状态</summary><p>在容量为 5 的数组索引 1 处插入 3；当前五个槽位存储为 [1, 3, 2, 5, 4]。新元素 3 已写入索引 1，插入完成，有效长度为 5。</p></details>

### 结果

插入完成后数组为 \[1, 3, 2, 5, 4\]，有效元素数量由 4 增至 5。被覆盖的是末尾无意义的占位值 0，四个原有有效元素均未丢失。
