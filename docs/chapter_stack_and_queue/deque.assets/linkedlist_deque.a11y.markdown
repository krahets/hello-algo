# 双向链表实现双向队列

维护头尾节点及双向引用，在两端增删时保持中间节点不动。

## 问题与输入

每个节点同时保存前驱引用 prev 和后继引用 next，链表头、尾节点分别作为队首和队尾。初始链表为 3 ⇄ 2 ⇄ 5（头为 3、尾为 5），序列按队首到队尾书写。

## 结构与关系

五帧连续演示：初始状态、队尾加入 4、队首加入 1、队尾取出 4、队首取出 1。每次操作仅修改头尾引用及端点处的相邻 prev/next 引用；图中逻辑队列与底层双向链表是同一份数据的两种视图。

在已维护头尾节点引用的前提下，两端入队与出队均为 O(1)：队尾出队可直接通过尾节点的 prev 找到新队尾，无须从头遍历。

## 第 1 步：初始双向队列

初始链表为 3 ⇄ 2 ⇄ 5，相邻节点通过 prev 和 next 双向连接，头、尾引用分别指向节点 3 和节点 5。

## 第 2 步：队尾加入4

在原尾节点 5 后接入新节点 4，令 5.next 指向 4、4.prev 指向 5，并将尾引用更新为 4；头引用仍为 3。

<details><summary>本步完整状态</summary><p>执行队尾入队后，当前有效队列为 [3, 2, 5, 4]，底层双向链表为 3 ⇄ 2 ⇄ 5 ⇄ 4，头节点为 3、尾节点更新为 4；无返回值。</p></details>

<a id="source-73"></a>

## 第 3 步：队首加入1

在原头节点 3 前接入新节点 1，令 1.next 指向 3、3.prev 指向 1，并将头引用更新为 1；尾引用仍为 4。

<details><summary>本步完整状态</summary><p>执行队首入队后，当前有效队列为 [1, 3, 2, 5, 4]，底层双向链表为 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4，头节点更新为 1、尾节点为 4；无返回值。</p></details>

<a id="source-74"></a>

## 第 4 步：队尾取出4

通过原尾节点 4 的 prev 引用直接定位前驱节点 5，将尾引用回退为 5，断开 5 与 4 之间的双向连接并返回 4。

<details><summary>本步完整状态</summary><p>执行队尾出队后，当前有效队列为 [1, 3, 2, 5]，底层双向链表为 1 ⇄ 3 ⇄ 2 ⇄ 5，头节点为 1、尾节点恢复为 5；本次从队尾返回 4。</p></details>

<a id="source-75"></a>

## 第 5 步：队首取出1

通过原头节点 1 的 next 引用定位后继节点 3，将头引用推进为 3，断开 1 与 3 之间的双向连接并返回 1。

<details><summary>本步完整状态</summary><p>执行队首出队后，当前有效队列恢复为 [3, 2, 5]，底层双向链表为 3 ⇄ 2 ⇄ 5，头节点恢复为 3、尾节点为 5；本次从队首返回 1。</p></details>

## 结果

经四次连续操作后，先从队尾返回 4，再从队首返回 1，链表恢复为 3 ⇄ 2 ⇄ 5（头为 3、尾为 5）。
