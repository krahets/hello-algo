## 双向队列的队尾操作：动画

在队尾添加再取出同一元素，其余元素次序不变。

本例为独立的队尾操作示例，初始队列按队首到队尾为 \[3, 2, 5\]，仅在队尾入队和出队。

虚线方块仅示意元素操作前的旧位置，不计入当前队列；移出容器外的实心方块表示本次出队的返回值。

### 第 2 步：push\_last(4)

### 第 3 步：pop\_last()

从队尾移除并返回 4，队尾恢复为 5。

### 结果

先后执行 push\_last(4) 与 pop\_last()，返回 4，队列恢复为 \[3, 2, 5\]。
