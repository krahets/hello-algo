# 基于链表实现队列的入队与出队

将链表头节点作为队首、尾节点作为队尾：在链表尾部追加 4 完成入队，删除链表头节点 1 完成出队。

## 问题与输入

每帧左侧展示对外表现的队列（上为队首、下为队尾），右侧展示底层竖直绘制的单向链表（上为头节点、下为尾节点，箭头向下指向 next），中间标注“底层实现是链表，对外表现为队列”。

## 结构与关系

链表从头节点到尾节点的顺序与队列从队首到队尾的顺序完全一致，规定仅在链表尾部添加节点（入队）、仅在链表头部删除节点（出队）。下面三帧依次展示初始状态（\[1, 3, 2, 5\]）、执行 push(4) 入队和执行 pop() 出队。

## 结果

基于链表实现队列时，尾节点入队与头节点出队均只需修改局部引用，时间复杂度均为 O(1)；本例最终队列为 \[3, 2, 5, 4\]。
