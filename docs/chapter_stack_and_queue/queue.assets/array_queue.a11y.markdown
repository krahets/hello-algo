# 基于数组实现队列的入队与出队

在未跨越数组末端的前提下，用 front 标记队首、size 记录队列长度，通过 rear = front + size 定位入队写入位置，并在出队时仅移动 front、减小 size。

## 问题与输入

每帧左侧展示对外表现的队列（上为队首、下为队尾），右侧展示底层竖直绘制的数组（有效元素自上而下按队首到队尾排列，两端画有灰色虚线空位和竖排省略号），中间标注“底层实现是数组，对外表现为队列”。

## 结构与关系

变量 front 指向队首元素，size 记录队列长度；在不越过数组末端时，由公式 rear = front + size 计算队尾元素之后的下一个位置（即有效区间为 \[front, rear - 1\]）。下面三帧依次展示初始状态（\[1, 3, 2, 5\]）、执行 push(4) 入队和执行 pop() 出队。

左侧标注“出队 pop()”，右上角说明框列出两步：“1. 将 front 自增 1；2. 将 size 自减 1”。橙色指针 front 向下移动一格，从原队首 1 的位置移到元素 3，同时队列长度更新为 size = 4。原来存放 1 的单元格不再属于有效区间，在图中变为灰色虚线空位；其余有效元素 \[3, 2, 5, 4\] 保持原数组位置不动，无须整体前移。由于出队操作不计算尾指针，此帧未绘制 rear 标记。这里的空位表示该槽已退出队列有效区间，不表示代码把槽内原值清零。

## 结果

入队只需在 rear 处写入元素并将 size 加 1，出队只需将 front 加 1 并将 size 减 1，避免了每次出队搬移剩余元素，时间复杂度均为 O(1)。
