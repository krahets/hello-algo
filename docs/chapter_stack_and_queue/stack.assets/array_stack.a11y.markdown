# 基于数组实现栈的入栈与出栈

将数组尾部作为栈顶、首部作为栈底：在数组尾部追加 4 完成入栈，删除数组尾元素 4 完成出栈。

## 问题与输入

每帧左侧展示对外表现的栈（上为栈顶、下为栈底），右侧展示底层竖直绘制的数组（下方为“首元素”，上方有效末端为“尾元素”，更上方灰色虚线格和竖排省略号表示“数组剩余空位”），中间标注“底层实现是数组，对外表现为栈”。

## 结构与关系

数组从首元素到尾元素的顺序与栈从栈底到栈顶的顺序一致。下面三帧依次展示初始状态（\[1, 3, 2, 5\]）、执行 push(4) 在数组尾部添加元素，以及执行 pop() 删除数组尾元素。

左侧标注“出栈 pop()”，右侧标注“删除数组尾元素”。移除上一步追加在数组尾部的元素 4，原来 4 所在的单元格恢复为灰色虚线空位，“尾元素”标记下移回 5。有效数组与栈从底到顶均恢复为 \[1, 3, 2, 5\]，栈顶回到 5。

## 结果

基于数组实现栈时，入栈和出栈分别对应在数组尾部追加和删除元素，未触发扩容时时间复杂度均为 O(1)，已有元素无须搬移。
