# 基于链表实现栈的入栈与出栈

将链表头节点作为栈顶、尾节点作为栈底：头插节点 4 完成入栈，删除头节点 4 完成出栈。

## 问题与输入

每帧左侧展示对外表现的栈（上为栈顶、下为栈底），右侧展示底层竖直绘制的单向链表（上为头节点、下为尾节点，箭头向下指向 next），中间以向左箭头标注“底层实现是链表，对外表现为栈”。

## 结构与关系

栈顶对应链表头节点，栈底对应链表尾节点。下面三帧依次展示初始状态（\[1, 3, 2, 5\]）、执行 push(4) 头插法入栈，以及执行 pop() 删除头节点出栈。

## 第 1 步：初始栈：头节点 5 为栈顶

初始时，左侧栈从栈底到栈顶依次为 \[1, 3, 2, 5\]，栈顶开口处标有入栈（向下）和出栈（向上）箭头。右侧单向链表从上到下依次为 5 → 2 → 3 → 1，上方头节点 5 对应栈顶，下方尾节点 1 对应栈底。

## 第 2 步：在链表头部入栈 4

左侧标注“入栈 push(4)”，右侧标注“将节点 4 添加至链表头部”。青色新节点 4 采用头插法插入在原头节点 5 上方并指向 5，成为新的头节点。此时链表从头到尾变为 4 → 5 → 2 → 3 → 1，左侧栈从栈底到栈顶变为 \[1, 3, 2, 5, 4\]，栈顶更新为 4。

<details><summary>本步完整状态</summary><p>当前为执行 push(4) 后的链表栈（Step 2）：左侧栈从栈底到栈顶为 [1, 3, 2, 5, 4]，共 5 个元素；右侧链表从头节点到尾节点为 4 → 5 → 2 → 3 → 1。新节点 4 为头节点和栈顶，尾节点和栈底仍为 1。</p></details>

## 第 3 步：在链表头部出栈 4

左侧标注“出栈 pop()”，右侧标注“删除头节点”。移除上一步位于链表头部的节点 4，使其后继节点 5 重新成为头节点。右侧链表恢复为 5 → 2 → 3 → 1，左侧栈从栈底到栈顶也恢复为 \[1, 3, 2, 5\]，栈顶回到 5。

<details><summary>本步完整状态</summary><p>当前为执行 pop() 后的链表栈（Step 3）：原头节点 4 已删除，左侧栈从栈底到栈顶恢复为 [1, 3, 2, 5]，共 4 个元素；右侧链表从头节点到尾节点为 5 → 2 → 3 → 1。头节点与栈顶恢复为 5，尾节点与栈底为 1。</p></details>

## 结果

基于链表实现栈时，入栈和出栈都只在链表头部增删节点，时间复杂度均为 O(1)。
