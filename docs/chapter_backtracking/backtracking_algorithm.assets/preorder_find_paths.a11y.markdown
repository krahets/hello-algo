# 尝试与回退：保存到达 7 的路径

进入节点时追加进 path，退出时弹出；两次命中 7 复制保存路径副本，搜索结束时 path 清空。

## 问题与输入

二叉树共 7 个节点：根节点为 1，左、右子节点分别为左侧 7 和节点 3；左侧 7 的左、右子节点为 4、5；节点 3 的左、右子节点为 6 和右侧 7；4、5、6 与右侧 7 为叶节点。

本例对应不带节点 3 剪枝约束的全量搜索：按“根 → 左 → 右”的前序顺序遍历整棵树，找出从根节点 1 到所有值为 7 节点的路径。

状态列表 path 实时维护从根到当前节点的活跃路径，结果列表 res 保存每次命中 7 时的路径副本。图中以节点值简写 path 与 res，配套代码实际保存节点对象及列表拷贝 list(path)，左、右两个值为 7 的节点是不同对象。

## 结构与关系

每次向前“尝试”进入节点时将其追加到 path 末尾；若当前节点值为 7，则复制当前 path 的副本加入 res；离开节点“回退”前将其从 path 末尾弹出，恢复进入该节点前的路径。

本组没有禁止经过节点 3 的约束：命中左侧 7 后仍继续访问其子节点 4、5，后续也会经过节点 3 找到右侧 7。由于命中时向 res 保存的是 path 的独立副本，后续回退弹出只修改当前 path，不会改变 res 中已保存的两条路径。
