# 根据路径不含 3 的约束条件剪枝

搜索根节点到 7 且不含 3 的路径时，在节点 3 处提前返回并剪去其子树，跳过节点 6 和右侧 7。

## 问题与输入

二叉树共七个节点：根节点为 1，其左、右子节点分别为 7 和 3；左侧节点 7 的左、右子节点为 4 和 5；节点 3 的左、右子节点为 6 和另一个 7；节点 4、5、6 与右侧 7 均为叶节点。

例题要求找出从根节点到所有值为 7 节点的路径，且路径中不能包含值为 3 的节点。一旦当前路径经过节点 3，其下方所有延伸路径都必然违反约束。

## 结构与关系

左子树不包含 3，前序访问左侧节点 7 时记录合法路径 \[1, 7\]，并继续检查其子节点 4 和 5。

当搜索到达根的右子节点 3 时触发约束条件，算法立即提前返回，不再递归进入其子节点 6 和右侧 7。图中将节点 3 标为红色，并用剪刀图标与半透明虚化子树表示跳过该搜索分支，树节点本身并未从数据结构中删除。

## 在节点 3 处提前返回以剪除无效搜索分支

遇到节点 3 时即可判定其整棵子树不可能产生合法解，因为后续任何延伸路径都会包含 3。在此处直接返回可省去对节点 6 和右侧 7 的无意义访问。

## 结果

唯一满足约束的路径为 \[1, 7\]。右侧叶节点 7 虽然节点值等于目标 7，但从根到达它的路径 \[1, 3, 7\] 经过了被禁止的节点 3，因此在剪枝阶段被排除。
