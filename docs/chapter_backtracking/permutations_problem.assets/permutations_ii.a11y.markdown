# 相等元素使全排列重复

把两个值为 1 的元素当作不同候选展开，会产生六条路径但只有三种不同的数值排列。

## 问题与输入

输入数组为 \[1, 1, 2\]，图中用 1̂ 标记第二个 1 的元素身份，其实际数值仍为 1。在每个索引最多使用一次的前提下，仅依靠 selected 限制同一索引重用，还不足以排除因相等数值交换位置而造成的重复排列。

## 结构与关系

顶部列出初始状态 state 的三个空槽与候选数组 choices=\[1, 1̂, 2\]。三轮选择展开为六个叶节点，其中蓝色方块表示第一个 1、青色方块表示第二个 1（即 1̂）、紫色方块表示 2。底部第 3、第 4、第 6 个叶节点加有橙色边框，并汇总指向下方“应当去除的重复排列”说明。

第一轮分别尝试选 1、1̂、2，得到 \[1\]、\[1̂\]、\[2\] 三个分支；第二轮在每个分支下分别选取剩余两个索引之一，第三轮填入最后一个未用索引，共形成表中所列的六个叶节点。其中橙框标出的 \[1̂, 1, 2\]、\[1̂, 2, 1\] 和 \[2, 1̂, 1\]，分别只是将 \[1, 1̂, 2\]、\[1, 2, 1̂\] 和 \[2, 1, 1̂\] 中两个值为 1 的元素互换了位置，并未产生新的数值排列。

## 结果

忽略区分元素身份的标记后，六个叶节点只对应 \[1, 1, 2\]、\[1, 2, 1\]、\[2, 1, 1\] 三种不重复的数值排列。
