# 遍历选择 Top-k

对 nums = \[1, 7, 6, 3, 2\] 与 k = 3，每轮从未选元素中找出最大值，三轮依次提取 7、6、3。

## 问题与输入

给定无序数组 nums = \[1, 7, 6, 3, 2\] 和参数 k = 3，任务是通过“遍历搜索最大元素”找出其中最大的三个元素。

## 结构与关系

第一轮遍历全部五个元素 \[1, 7, 6, 3, 2\]，找到第 1 大元素 7；曲线箭头将 7 抽离到右侧蓝框结果区 \[7\]，左侧待选区剩下 \[1, 6, 3, 2\]。

第二轮在剩余的 \[1, 6, 3, 2\] 中继续遍历，找到第 2 大元素 6 并移入右侧结果区，此时待选区变为 \[1, 3, 2\]，右侧结果区显示 \[6, 7\]。

第三轮在剩余的 \[1, 3, 2\] 中找到第 3 大元素 3 并移入结果区，待选区只剩 \[1, 2\]，右侧结果区汇聚为三个蓝框元素 \[3, 6, 7\]。图中向下的灰色粗箭头表示轮次推进，曲线细箭头标示每轮被提取的最大值。

## 结果

经过 k = 3 轮遍历，依次选出第 1、2、3 大元素 7、6、3（图中结果区展示为 \[3, 6, 7\]）。对长度为 n 的数组执行 k 轮线性扫描，总时间复杂度为 O(nk)。
