# 方法二（排序）：先升序排序，再返回最右 k 个元素

将 nums = \[1, 7, 6, 3, 2\] 升序排序为 \[1, 2, 3, 6, 7\]，直接截取最右侧的 k = 3 个元素 \[3, 6, 7\]。

## 问题与输入

给定无序数组 nums = \[1, 7, 6, 3, 2\] 和参数 k = 3，任务是找出其中最大的三个元素。

## 结构与关系

第一行展示原始无序数组 nums = \[1, 7, 6, 3, 2\]。经第一个向下箭头“对数组进行排序”后，第二行得到升序排列的 \[1, 2, 3, 6, 7\]，其中最右侧的三个元素 3、6、7 用蓝色边框与下方花括号标出。

经第二个向下箭头“返回最右 k 个元素”后，第三行单独列出提取出的结果 \[3, 6, 7\]，较小的 1 和 2 被舍弃。

图自上而下分三行展示排序法求 Top-k：先将原数组 \[1, 7, 6, 3, 2\] 整体升序排序为 \[1, 2, 3, 6, 7\]，由于升序数组右侧元素更大，直接截取最右边的 k = 3 个元素即可得到 \[3, 6, 7\]。

## 结果

升序排序后最大的 k 个元素必然集中在数组末尾，直接切片返回 \[3, 6, 7\] 即可。使用 O(n log n) 的排序算法时，该方法的时间复杂度为 O(n log n)，但也对无需返回的其余元素做了排序。
