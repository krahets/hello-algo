# 建堆的分层工作量

高度为 h 的完美二叉树中，从根层到叶节点层，单层节点数按 2^0, 2^1, …, 2^h 翻倍，而节点高度（最多下沉层数）按 h, h−1, …, 0 递减。

## 问题与输入

图中以高度为 h 的完美二叉树分析自下而上建堆的时间复杂度。节点高度为该节点到最深叶节点的边数：叶节点高度为 0，根节点高度为 h。一个节点最多向下交换的层数等于其高度；这不包含代码循环最后一次判断并停止的检查。

## 结构与关系

若把全部 n 个节点都按根节点的最大下沉层数 h 估算，会显著高估工作量：完美二叉树越靠近底部，单层节点数越多，但每个节点还能向下交换的层数越短；最底部的叶层占约一半节点，却完全无须下沉。

设深度 d 从根层 0 计到叶层 h。第 d 层有 2^d 个节点，每个节点高度为 h−d（即最多下沉 h−d 层），因此该层下沉次数上界为 2^d×(h−d)；到叶层 d=h 时，2^h 个叶节点高度为 0，下沉次数为 0。图中纵向省略号代表中间各层，并非固定只有四层。

按层加权求和得总上界 T(h) = 2^0×h + 2^1×(h−1) + … + 2^(h−1)×1 + 2^h×0；由正文错位相减化简可得 T(h) = 2^(h+1) − h − 2。该式是建堆累计下沉次数的理论上界，实际建堆时若提前满足堆序还会更早停止。

根节点最多下沉 h 层但只有 2^0=1 个；倒数第二层有 2^(h−1) 个节点、每个最多下沉 1 层；最底叶层有 2^h 个节点、下沉 0 层。按深度分别将“节点数”与“最多下沉层数”相乘再求和，即可紧致推导出 O(n) 的线性建堆上界。

## 结果

高度为 h 的完美二叉树有 n = 2^(h+1) − 1 个节点，累计下沉次数上界 T(h) = 2^(h+1) − h − 2 属于 O(2^h) = O(n)。加上各节点的检查等线性开销，自下而上建堆的时间复杂度为 O(n)。
