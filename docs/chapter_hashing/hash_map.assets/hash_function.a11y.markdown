# 哈希函数将输入 key 映射为桶数组索引

以哈希函数 key % 100 将学号转换为容量 100 的数组桶索引，演示 13276、12836、16750 三条查询路径如何分别定位到 76、36、50 号桶并取出姓名。

## 问题与输入

画面从左到右分为四个部分：“输入 key”列、“哈希函数 key % 100”计算框、“索引”与“数组（每个桶内保存一个键值对）”列，以及最右侧的“输出 value”列。

底层数组容量为 100，哈希函数定义为 index = key % 100，即直接截取五位学号的后两位数字作为数组桶索引。

## 结构与关系

数组列共画出 5 个非空哈希桶（见表 1），其余位置用省略号“…”略去。左侧“输入 key”列从上到下给出三个待查询学号：橙色 13276、蓝色 12836、绿色 16750（见表 2）。

由于左侧输入学号未按后两位从小到大排列，而中间数组按桶索引 36、37、50、76、83 升序排列，三条彩色查询曲线在穿过“哈希函数 key % 100”时发生了视觉交叉：顶部橙色 13276 映射到下方索引 76 并输出底部橙色“小法”；中部蓝色 12836 映射到上方索引 36 并输出顶部蓝色“小哈”；底部绿色 16750 映射到中部索引 50 并输出中部绿色“小算”。

## 通过 key % 100 定位桶索引的三条查询路径

三条同色有向曲线完整展示了哈希查找的两步过程：橙色路径输入 13276，计算 13276 % 100 = 76，定位到 76 号桶 (13276, “小法”) 并输出“小法”；蓝色路径输入 12836，计算 12836 % 100 = 36，定位到 36 号桶 (12836, “小哈”) 并输出“小哈”；绿色路径输入 16750，计算 16750 % 100 = 50，定位到 50 号桶 (16750, “小算”) 并输出“小算”。数组中一并画出的 37 号桶 (15937, “小啰”) 和 83 号桶 (10583, “小鸭”) 未参与本次三条查询。

## 结果

哈希函数在输入 key 与底层数组桶索引之间架起确定性桥梁：先由 key % 100 算出桶索引，再直接访问该桶取出对应的 value。
