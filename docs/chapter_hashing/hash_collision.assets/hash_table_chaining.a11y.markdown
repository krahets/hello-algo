# 链式地址哈希表：用桶内单向链表收纳冲突元素

每个哈希桶对应一条保存键值对节点的单向链表；当多个 key 对 100 取余落入同一桶时，依次串联在该桶链表中。

## 问题与输入

画面左侧说明框给出核心定义：“链式地址：每个桶存储一个链表，其中包含所有冲突元素”，下方注明“哈希函数 key % 100；后两位相同的 key 会发生哈希冲突”。

右侧主体由三列标题构成：“索引”列、浅蓝色“数组”列，以及向右延伸的浅绿色“链表（节点为键值对）”区域。蓝色数组列存放每条非空链表的头节点，后续冲突节点通过向右的单向箭头依次串联。

## 结构与关系

图中一共展示了 00、37、50、76、83 五个非空桶，共包含 13 个键值对节点，各桶从链头到链尾的完整节点顺序见下表。

## 五个哈希桶各自的冲突链表

由于哈希函数为 key % 100，凡是后两位相同的键都会进入同一条横向链表：例如 200、500、300 后两位均为 00，依次串在 00 号桶；937、637、437、237 后两位均为 37，依次串在 37 号桶。若要查询 key = 437，程序先算得 437 % 100 = 37 进入 37 号桶，再沿链表依次检查头节点 937、第二节点 637，在第 3 个节点匹配到 437 并取出值 K。

## 结果

链式地址通过“桶数组 + 链表”的组合结构，允许任意多个后两位相同的冲突 key 共存于同一桶对应的链表内，不会相互覆盖。
