# 每次保留一半的对数增长

长度为 n 的数组每层删减一半，最终缩减至长度 1；图中包含长度为 1 的末层在内共 log₂n + 1 层，每层 1 个计算操作，对应对数阶时间复杂度 O(log n)。

## 问题与输入

画面分为左、中、右三列，顶部标题依次为“剩余数组长度”、“输入数组长度为 n 每层删减一半”和“每层包含 1 个计算操作”。数组行中，深绿色格子并加绿色外框表示当前保留的区间，浅灰色格子表示已被排除的区间。

## 结构与关系

三列顶部均以竖向省略号开头，表示从一般规模 n 持续减半的前序过程；其下具体画出最后 4 层（对应从长度 8 缩减到 1 的过程），各层之间用向下的灰色箭头衔接。这 4 层的左侧“剩余数组长度”依次标注 8、4、2、1；中间 8 格数组依次保留全部 8 格、最右侧 4 格、最右侧 2 格和最右侧 1 格；右侧每层各画出 1 个浅绿色计算操作方块，由向下箭头串联。

最右侧大括号跨越从顶部省略号到末尾长度 1 的全部层级，标注“共 log₂n + 1 层”。底部说明框写出：计算操作总数为 log₂n + 1，箭头指向“时间复杂度 对数阶 O(log n)”。

设 n 为 2 的整数次幂，需要区分“减半动作的次数”与“图中画出的数组层数”：从长度 n 连续除以 2 直到变为 1，共执行 log₂n 次减半（对应代码 while n &gt; 1 循环体执行的次数）；而图示把起始状态和末尾长度为 1 的状态都作为独立的一层画出，因此总层数为 log₂n + 1。以图中具体画出的后四行 8、4、2、1 为例，共经历了 3 次减半，但包含首尾共有 4 层。

## 结果

当数据规模每轮缩减为原来的一半时，执行层数仅随输入规模 n 按对数级别缓慢增长；忽略常数项 +1 与对数底数后，时间复杂度记为对数阶 O(log n)。
