# 全排列的逐层选择与阶乘增长

生成 n 个不重复元素的全排列时，各层分支数从 n 依次递减到 1，第 n 层共产生 n! 个完整排列叶节点，按图中每个递归节点仅做常数工作的计数模型，对应阶乘阶时间复杂度 O(n!)。

## 问题与输入

图对应全排列的递归展开过程：最上方居中的单个灰色小方块代表尚未做出任何选择的起始根节点；往下每一层代表为排列的下一个位置挑选一个尚未使用的元素。

画面左列标题为“各层的分裂数量”，右列标题为“各层的节点数量”；右侧大括号标注“共 n 层”，范围覆盖根节点下方的 n 个选择层（不含最顶部的起始根节点）。

## 结构与关系

从顶部起始节点向下，第 1 个虚线框层分裂出 n 个灰色节点（中间用省略号表示其余分支），左列分裂数量标注 n，右列节点数量标注 n。第 2 个虚线框层中，上一层的每个节点各分裂出 n - 1 个子节点，左列标注 n - 1，右列标注 n(n - 1)。第 3 个虚线框层中，每个节点再各分裂出 n - 2 个子节点，左列标注 n - 2，右列标注 n(n - 1)(n - 2)。

第 4 个虚线框层用省略号表示中间继续递减的各层；最底层（第 n 层）的左列分裂数量标注 1，框内画出绿色的叶节点方块，右列节点数量标注 n!。底部说明框写出：全排列的方案数（即最底层的节点数量）为 n × (n - 1) × (n - 2) × … × 2 × 1 = n!，右侧箭头指向“时间复杂度 阶乘阶 O(n!)”。

在第 1 层有 n 种选择，第 2 层对每种已选前缀各有 n - 1 种剩余选择，依此类推，到第 n 层只剩最后 1 个可选元素并停止分裂。将各层分裂数量连乘得到的 n × (n - 1) × (n - 2) × … × 2 × 1 = n!，准确对应最底层的绿色叶节点数量（即全部排列方案数，也等于代码 factorial\_recur 累加返回的基例计数），而非把树中所有中间层节点也加在一起的总节点数。

## 结果

随着元素个数 n 增大，全排列方案数按 n! 呈阶乘级急剧增长；当 n ≥ 4 时恒有 n! &gt; 2ⁿ，阶乘阶 O(n!) 比指数阶 O(2ⁿ) 的增长还要快得多。
