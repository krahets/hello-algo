# 渐近上界：越过阈值后的大小关系

当输入规模 n 超过阈值 n₀ 后，正常数倍函数 c·f(n) 始终不低于操作数量 T(n)，据此将 f(n) 定义为 T(n) 的渐近上界 O(f(n))。

## 问题与输入

坐标图横轴表示输入数据大小 n，标有刻度 0 至 14 及向右箭头；纵轴表示函数值，配有向上箭头，未标出可见数值刻度。

蓝色曲线表示算法的操作数量函数 T(n)，橙色曲线表示候选函数 f(n) 乘以正常数系数 c 后的函数 c·f(n)。图中曲线用于阐释渐近上界的数学关系，未绑定特定的代数公式。

## 结构与关系

绿色竖直虚线标出阈值 n₀，位置紧靠横轴刻度 7 右侧（位于 7 与 8 之间的两线交点处）。在虚线 n₀ 左侧的小规模区间内，蓝色 T(n) 曲线有小幅起伏，并在刻度 1 至 7 之间高于橙色 c·f(n) 曲线；越过虚线 n₀ 之后，橙色 c·f(n) 曲线始终位于蓝色 T(n) 曲线上方，且两条曲线随 n 增大一同向上攀升。

图下方说明框总结定义：当 n &gt; n₀ 时，始终有 c·f(n) ≥ T(n)，此时可认为 f(n) 是 T(n) 的一个渐近上界，记为 T(n) = O(f(n))。

渐近上界关注的是输入规模 n 趋向无穷大时的增长级别。即使在 n 较小时（n ≤ n₀）操作数量 T(n) 一度超过 c·f(n)，只要越过阈值 n₀ 后 c·f(n) 始终能够覆盖 T(n)，f(n) 就给出了 T(n) 的有效渐近上界。

## 结果

判定 T(n) = O(f(n)) 只要求存在正实数 c 和阈值 n₀，使所有大于 n₀ 的输入规模都满足 T(n) ≤ c·f(n)；并不要求两条曲线在所有输入规模下处处相等，也不受阈值 n₀ 之前局部大小关系的影响。
