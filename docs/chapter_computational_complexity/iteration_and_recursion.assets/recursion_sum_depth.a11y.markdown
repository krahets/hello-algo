# 递归求和的递归深度

在普通递归求和图的基础上将右侧返回过程淡化，用左侧大括号框出从 recur(n) 到 recur(1) 的整列向下调用链，标明其“递归深度 n”。

## 问题与输入

正文以正整数 n 为输入、计算 1 + 2 + … + n 的 recur(n) 为例，说明递归的调用栈：每次递归调用但尚未返回的函数都会占用栈帧空间，因此需要度量同时存在的最大调用层数，即“递归深度”。

## 结构与关系

画面沿用了普通递归求和的左右双列布局，右侧 return 表达式、大括号与返回箭头均被淡化；左右列标题及底部“触发递归终止条件”文字和向右箭头仍清晰可见。视觉焦点集中在左侧“向下‘递’”调用列，从 recur(n)、recur(n-1)、… 到 recur(4)、recur(3)、recur(2)、recur(1)；其左侧设有贯穿首尾的纵向大括号，大括号左侧的灰色标签标注“递归深度 n”。

画面通过淡化右侧“向上‘归’”部分，突显左侧“向下‘递’”阶段在触底前累积的调用链：从顶层 recur(n) 依次向下调用 recur(n-1)、…、recur(4)、recur(3)、recur(2) 直至底层 recur(1)，左侧纵向大括号将这串连续嵌套的调用整体括起并标注“递归深度 n”，直观展示到达 recur(1) 时，包括顶层在内共有 n 层调用尚未返回。在 recur(1) 处触发终止条件后返回 1，再沿被淡化的右列逐层加上当前层参数，最终返回 1 到 n 的总和。

## 结果

从 recur(n) 到 recur(1)，包括顶层在内共 n 层嵌套调用；最深时调用栈上同时存在 n 个尚未返回的栈帧。因此该函数的递归深度为 n，空间复杂度为 O(n)。
