# 空间复杂度通常统计哪些空间

算法运行涉及的内存分为输入空间、暂存空间和输出空间三类；空间复杂度通常统计暂存空间与输出空间，且实际分析中一般忽略指令空间。

## 问题与输入

画面自左向右依次排列三个圆角矩形框：“输入空间”、“暂存空间”和“输出空间”，框间用向右的灰色粗箭头连接，表示算法接收输入、借助暂存区完成计算并产生输出的过程。

## 结构与关系

左侧绿色框为“输入空间”，正下方标注“输入数据”；中间蓝色框为“暂存空间”，正下方分三行依次列出“暂存数据”、“栈帧空间”和“指令空间”；右侧青色框为“输出空间”，正下方标注“输出数据”。

图上方有一道水平大括号，仅跨过中间的“暂存空间”和右侧的“输出空间”，未包含左侧的“输入空间”，大括号上方标注“通常情况下空间复杂度的统计范围”。

暂存空间中的三个子项各有职责：暂存数据用于保存运行过程中的常量、变量和对象；栈帧空间用于保存函数调用的上下文数据（每次调用入栈、返回后释放）；指令空间用于保存编译后的程序指令。图中的向右箭头表示算法的数据处理流程，并不表示这三类内存会依次自动释放。

## 结果

在推算一段程序的空间复杂度时，输入数据本身占用的输入空间不计入额外开销，编译后的指令空间在实际统计中也通常忽略不计；重点统计的是暂存数据、栈帧空间和输出数据三部分。
