# 递归各层保留数组形成平方空间

递归函数 quadratic\_recur 在参数从 n 到 1 的 n 个调用层分别创建并保留长度为 n、n - 1、…、2、1 的数组，峰值数组总长度为 n(n + 1)/2，空间复杂度为平方阶 O(n²)。

## 问题与输入

画面自左向右分为三列，顶部标题依次为“数组 nums 长度”、“向下‘递’”和“向上‘归’”。函数在参数为正数的每一层递归中都会初始化一个长度等于当前参数值的局部数组 nums，再发起下一层递归调用。

## 结构与关系

中间“向下‘递’”列自上而下由向下箭头连接 quadratic\_recur(n)、quadratic\_recur(n-1)、省略号、quadratic\_recur(2) 和 quadratic\_recur(1)；左列“数组 nums 长度”以蓝色字体对应标注 n、n-1、省略号、2、1，并通过带圆点的水平线段与各层调用框相连。最左侧大括号覆盖从 n 到 1 的这 n 层，标注“递归深度 n”。

在最底层的 quadratic\_recur(1) 右侧，水平向右箭头标注“触发递归终止条件”，指向右列底部的“return 0”，随后由向上箭头串联各层“return 0”向上返回。底部说明框写出：“在每个递归函数中都初始化了一个数组，总长度为 1 + 2 + … + (n-1) + n = n(n+1)/2”，右侧箭头指向“空间复杂度 平方阶 O(n²)”。

在上层函数等待下层递归返回期间，上层创建的数组 nums 始终保留在内存中无法释放。到达递归最深处时，内存中同时存在长度为 n、n - 1、…、2、1 的 n 个数组，按等差数列求和得到总长度 n(n + 1)/2 = (n² + n)/2（图中将末端的终止与返回简化画在参数 1 这一行，准确覆盖了分配数组的全部 n 层；Python 代码还会调用参数 0，在该层直接返回且不分配数组）。因此，峰值空间由平方阶 O(n²) 的数组总长度主导，远大于调用栈本身的 O(n) 栈帧开销。

## 结果

当递归函数在每一层栈帧内还额外分配了与当前参数成正比的数据结构时，峰值内存需要将该调用链上所有未返回层的局部数据结构一并累加；此处 n 层数组的总长度为 n(n + 1)/2，主导项决定了最差空间复杂度为平方阶 O(n²)。
