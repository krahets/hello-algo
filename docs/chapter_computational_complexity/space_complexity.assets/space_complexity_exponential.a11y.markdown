# 存储 n 层满二叉树所需的空间

构建并保存一棵 n 层满二叉树时，各层节点数从 2⁰ 翻倍至 2ⁿ⁻¹，内存中同时保留全部 2ⁿ - 1 个节点，对应指数阶空间复杂度 O(2ⁿ)。

## 问题与输入

图对应递归构建满二叉树（build\_tree）完成后在内存中保存的树结构：每个带双层边框的绿色圆圈代表 1 个树节点对象（占用固定大小的内存空间），有向箭头从父节点指向左、右子节点。右侧列标题为“各层的节点总数”，大括号标明整棵树“共 n 层”。

## 结构与关系

从上到下，第 1 层画出 1 个绿色根节点，右侧标注 2⁰（即 1）；根节点向左下、右下各伸出 1 条箭头，指向第 2 层的 2 个节点，右侧标注 2¹（即 2）；第 2 层每个节点再各伸出 2 条箭头，指向第 3 层的 4 个节点，右侧标注 2²（即 4）。

第 3 层的 4 个节点下方共伸出 8 条向下箭头指向省略号，表示树继续按满二叉树规律向下展开直至第 n 层；右列在省略号下方标注第 n 层的节点总数 2ⁿ⁻¹（即 2 的 n - 1 次方）。底部说明框写出：“所有节点数量 2⁰ + 2¹ + 2² + … + 2ⁿ⁻¹ = 2ⁿ - 1”，右侧箭头指向“空间复杂度 指数阶 O(2ⁿ)”。

注意区分“递归调用栈深度”与“持久化的树节点总数”：构建这棵 n 层满二叉树时，单条从根到叶路径上的递归调用栈深度虽然只有 O(n)，但每次调用创建的树节点都会通过左右指针挂载到树上并长期保留。因此峰值内存必须统计整棵树同时存在的所有节点：将第 1 层至第 n 层的节点数相加得到 1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ - 1，每个节点占用常数空间，总空间复杂度即为指数阶 O(2ⁿ)。

## 结果

当算法需要在内存中完整保存一棵层数为 n 的满二叉树时，所有新创建的节点对象都不会随递归返回而销毁；节点总数 2ⁿ - 1 决定了其占用的存储空间呈指数级增长，空间复杂度为指数阶 O(2ⁿ)。
