# 常见空间复杂度的增长趋势

对比常数阶 O(1)、对数阶 O(log n)、线性阶 O(n)、平方阶 O(n²) 和指数阶 O(2ⁿ) 五条曲线，展示内存需求随输入规模 n 增大的增长快慢排序。

## 问题与输入

坐标图横轴表示输入数据大小 n，可见刻度为 1 至 14；纵轴表示内存空间大小，未标出可见的具体容量数值。图中曲线用于对比不同空间复杂度的渐近增长趋势，而非某段具体代码的实测字节数。

## 结构与关系

图中绘有五条不同颜色的示意曲线：绿色常数阶 O(1) 是紧贴横轴上方的水平直线，内存占用不随 n 变化；青色对数阶 O(log n) 随 n 增大而缓步上升，斜率逐渐变缓；蓝色线性阶 O(n) 是以恒定斜率向上延伸的直线；橙色平方阶 O(n²) 呈向上弯曲的抛物线走势，斜率越来越陡；红色指数阶 O(2ⁿ) 在刻度 1 至 8 之间贴近底部，进入后段则急剧陡峭攀升。

在横轴末端 n = 14 右侧，五条曲线的终点由下到上依次对齐标注“常数阶 O(1)”、“对数阶 O(log n)”、“线性阶 O(n)”、“平方阶 O(n²)”和“指数阶 O(2ⁿ)”；最右侧配有向上的灰色粗箭头，内写“从低至高、从优至差”。

右侧向上箭头“从低至高、从优至差”反映的是当 n 足够大时的渐近增长阶排序（注意图中只包含这五种常见空间复杂度，未绘制时间复杂度图中的线性对数阶或阶乘阶）。在小规模区间内，示意曲线之间存在交叉（例如青色对数曲线在刻度 2 至 6 之间略高于蓝色线性直线，红色指数曲线在前段低于其他曲线），这些交点仅作趋势示意，不能当作具体内存大小或复杂度优劣切换的精确阈值。

## 结果

常见空间复杂度的渐近增长速度由慢到快依次为：常数阶 O(1) &lt; 对数阶 O(log n) &lt; 线性阶 O(n) &lt; 平方阶 O(n²) &lt; 指数阶 O(2ⁿ)。当输入数据规模足够大时，空间复杂度阶数越低，算法的峰值内存需求越容易控制在安全范围内。
