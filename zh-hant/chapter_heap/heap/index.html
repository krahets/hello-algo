8.1   堆積¶

堆積（heap）是符合特定條件的完全二元樹，主要分為以下兩種，如圖 8-1 所示。

  • 最小堆積（min heap）：任一節點的值 \(\leq\) 其子節點的值。
  • 最大堆積（max heap）：任一節點的值 \(\geq\) 其子節點的值。

圖 8-1   最小堆積與最大堆積

圖解 8-1：最小堆積與最大堆積的結構及大小關係

左邊的最小堆積與右邊的最大堆積樹形相同，父子節點之間的大小關係正好相反。

兩棵樹都是有 12 個節點的完全二元樹。前三層已填滿，第四層從最左邊起連續放了 5 個節點。下表由上而下逐層列出數值，每層都由左至右讀取。層號依位置編排，圖中沒有標示層號。

兩棵樹中，節點相連的位置相同。根有兩個子節點，第二層的每個節點也各有兩個子節點。第三層由左至右，前兩個節點各有兩個子節點，第三個節點只有左子節點，第四個是葉節點。對照下表即可確定每一對父子節點。

圖下方分別註明：在最小堆積中，父節點的值小於或等於子節點的值；在最大堆積中，父節點的值大於或等於子節點的值。節點值可以相等，例如最小堆積第二層右邊的節點與其左子節點的值都是 2。同一層由左至右不必排序，兄弟節點之間也沒有大小限制。

逐層比較父子節點，就能看出最小堆積的根節點值 1 是整個堆積的最小值，最大堆積的根節點值 9 則是整個堆積的最大值。

堆積是完全二元樹的一種特例，具有以下特性。

  • 最底層的節點從左往右依序填入，其餘各層皆已填滿。
  • 我們稱二元樹的根節點為「堆積頂端」，最底層最右側的節點為「堆積底端」。
  • 在最大堆積（最小堆積）中，頂端元素也就是根節點，其值是整個堆積中的最大值（最小值）。

8.1.1   堆積的常用操作¶

許多程式語言提供的是優先佇列（priority queue）。這種抽象資料結構是一個依元素優先順序排列的佇列。

實際上，優先佇列通常以堆積實作。最大堆積相當於依元素值由大到小取出元素的優先佇列。從使用者的角度來看，可以將「優先佇列」和「堆積」視為等價的資料結構。因此，本書統稱兩者為「堆積」。

表 8-1 列出堆積的常用操作，實際的方法名稱依程式語言而定。

表 8-1   堆積的操作效率

方法名稱 說明 時間複雜度
push() 將元素加入堆積 \(O(\log n)\)
pop() 取出堆積頂端元素 \(O(\log n)\)
peek() 讀取堆積頂端元素（最大堆積為最大值，最小堆積為最小值） \(O(1)\)
size() 取得堆積中的元素個數 \(O(1)\)
isEmpty() 判斷堆積是否為空 \(O(1)\)

實際應用時，可以直接使用程式語言提供的堆積類別（或優先佇列類別）。

就像排序演算法可以「由小到大」或「由大到小」排列，我們可以設定 flag 或修改 Comparator，在最小堆積與最大堆積之間切換。程式碼如下：

heap.go
// 在 Go 中可以實作 heap.Interface 來建立整數最大堆積
// 實作 heap.Interface 時也要實作 sort.Interface
type intHeap []any

// Push 是 heap.Interface 的方法，負責將元素加入堆積
func (h *intHeap) Push(x any) {
    // Push 和 Pop 都使用指標接收者（pointer receiver）
    // 因為這兩個方法除了調整切片的內容，也會改變切片的長度。
    *h = append(*h, x.(int))
}

// Pop 是 heap.Interface 的方法，取出切片的最後一個元素（heap.Pop 已將頂端元素換到尾端）
func (h *intHeap) Pop() any {
    // 待取出的元素位於尾端
    last := (*h)[len(*h)-1]
    *h = (*h)[:len(*h)-1]
    return last
}

// Len 是 sort.Interface 的方法
func (h *intHeap) Len() int {
    return len(*h)
}

// Less 是 sort.Interface 的方法
func (h *intHeap) Less(i, j int) bool {
    // 若要實作最小堆積，這裡應改用小於符號
    return (*h)[i].(int) > (*h)[j].(int)
}

// Swap 是 sort.Interface 的方法
func (h *intHeap) Swap(i, j int) {
    (*h)[i], (*h)[j] = (*h)[j], (*h)[i]
}

// Top 取得堆積頂端元素
func (h *intHeap) Top() any {
    return (*h)[0]
}

func TestHeap(t *testing.T) {
    /* 初始化堆積 */
    // 初始化最大堆積
    maxHeap := &intHeap{}
    heap.Init(maxHeap)
    /* 將元素加入堆積 */
    // 呼叫 heap.Interface 的方法以加入元素
    heap.Push(maxHeap, 1)
    heap.Push(maxHeap, 3)
    heap.Push(maxHeap, 2)
    heap.Push(maxHeap, 5)
    heap.Push(maxHeap, 4)

    /* 取得堆積頂端元素 */
    top := maxHeap.Top()
    fmt.Printf("堆積頂端元素為 %d\n", top)

    /* 取出堆積頂端元素 */
    // 呼叫 heap.Interface 的方法以移除元素
    fmt.Printf("從堆積取出的元素為 %d\n", heap.Pop(maxHeap)) // 5
    fmt.Printf("從堆積取出的元素為 %d\n", heap.Pop(maxHeap)) // 4
    fmt.Printf("從堆積取出的元素為 %d\n", heap.Pop(maxHeap)) // 3
    fmt.Printf("從堆積取出的元素為 %d\n", heap.Pop(maxHeap)) // 2
    fmt.Printf("從堆積取出的元素為 %d\n", heap.Pop(maxHeap)) // 1

    /* 取得堆積大小 */
    size := len(*maxHeap)
    fmt.Printf("堆積中的元素個數為 %d\n", size)

    /* 判斷堆積是否為空 */
    isEmpty := len(*maxHeap) == 0
    fmt.Printf("堆積是否為空 %t\n", isEmpty)
}

1.   堆積的儲存與表示法¶

「二元樹」一章提過，完全二元樹很適合用陣列表示。堆積正是一種完全二元樹，因此我們用陣列來儲存堆積。

用陣列表示二元樹時，元素代表節點值，索引代表節點在樹中的位置。節點指標可透過索引之間的對應公式來實作。

如圖 8-2 所示，給定索引 \(i\)，其左子節點的索引為 \(2i + 1\)，右子節點的索引為 \(2i + 2\)，父節點的索引為 \((i - 1) / 2\)（向下取整的整數除法）。若索引超出範圍，表示該位置為空或節點不存在。

圖 8-2   堆積的表示與儲存

圖解 8-2：堆積的陣列表示法

同一個堆積可以畫成完全二元樹，也可以依層序存入陣列。兩種表示法透過索引公式相互對應。

圖上方的左側標示「堆積的邏輯結構（『堆積』是一棵『完全二元樹』）」，右側標示「堆積的實體結構（底層儲存方式，以『陣列』表示『完全二元樹』）」。右側的陣列水平排列，索引由左到右遞增。12 個元素依層序存放為 [9, 8, 6, 6, 7, 5, 2, 1, 4, 3, 6, 2]，索引從 0 到 11。

左側完全二元樹的每個節點圓圈下方都標有陣列索引。根節點的值為 9（索引 0），左、右子節點的值分別為 8（索引 1）、6（索引 2）。索引 1 的左、右子節點是索引 3（值 6）、4（值 7）；索引 2 的左、右子節點是索引 5（值 5）、6（值 2）；索引 3 的左、右子節點是索引 7（值 1）、8（值 4）；索引 4 的左、右子節點是索引 9（值 3）、10（值 6）；索引 5 只有左子節點，在索引 11（值 2）。

若算出的子節點索引超出陣列範圍，表示該子節點不存在。根節點（索引 0）沒有父節點。完全二元樹的節點依層序緊密排列，因此即使節點的值相等（例如多個 6 和 2），也能以各自唯一的索引加以區分。

以緊密排列的陣列表示完全二元樹，可以省去額外的父子節點指標欄位，在 O(1) 時間內算出父節點及左右子節點的位置，並檢查這些節點是否存在。

3.   將元素加入堆積¶

給定元素 val，先將它加到堆積底端。加入後，val 可能大於堆積中的其他元素，使堆積不再符合原本的性質。因此，必須沿著插入節點到根節點的路徑調整節點，這項操作稱為堆積化（heapify）。

從新加入的節點開始，由下往上調整堆積。如圖 8-3 所示，比較插入節點與父節點的值，若插入節點的值較大，就交換兩者。反覆執行這個操作，由下往上調整，直到越過根節點或遇到無須交換的節點為止。

本例一開始有 12 個元素，根節點索引 0 的值為 9，這次要插入的新元素為 7。索引 4 原有的另一個 7 始終停在原處，表中以角色欄區分這兩個元素。

樹和陣列呈現同一份資料。陣列按層序排列，由上到下，同一層由左到右，索引從 0 起算。非根節點 i 的父節點索引是 (i−1)/2 向下取整，左、右子節點的索引分別是 2i+1、2i+2。若索引超出範圍，表示沒有該子節點。值相同的元素以索引區分。

my_heap.py
def push(self, val: int):
    """將元素加入堆積"""
    # 新增節點
    self.max_heap.append(val)
    # 由下往上調整堆積
    self.sift_up(self.size() - 1)

def sift_up(self, i: int):
    """從節點 i 開始向上調整堆積"""
    while True:
        # 取得節點 i 的父節點
        p = self.parent(i)
        # 若已越過根節點，或節點已符合堆積性質，就結束調整
        if p < 0 or self.max_heap[i] <= self.max_heap[p]:
            break
        # 交換兩個節點
        self.swap(i, p)
        # 繼續向上調整堆積
        i = p

4.   取出堆積頂端元素¶

堆積頂端元素是二元樹的根節點，也就是串列的第一個元素。如果直接刪除串列開頭的元素，樹中所有剩餘節點的索引都會改變，後續就難以透過調整來恢復堆積性質。為了盡量減少索引變動，我們採用以下步驟。

  1. 交換堆積頂端與底端的元素（交換根節點與最右側的葉節點）。
  2. 交換後，從串列尾端刪除堆積底端的元素（注意，因為已經交換過，實際刪除的是原本的頂端元素）。
  3. 從根節點開始，由上往下調整堆積。

如圖 8-4 所示，「由上往下調整堆積」與「由下往上調整堆積」的方向相反。比較根節點與兩個子節點的值，若子節點的值較大，就將其中較大的那個與根節點交換。反覆執行這個操作，直到越過葉節點或遇到無須交換的節點。

取出最大值後，從根開始向下與值較大的子節點交換，恢復最大堆積的性質。

本例一開始有 13 個元素，根節點（索引 0）是最大值 9，尾端元素（索引 12）是 5。最大堆積要求每個父節點的值都不小於其子節點的值。

樹和陣列呈現同一份資料。陣列按層序排列，由上到下，同一層由左到右，索引從 0 起算。非根節點 i 的父節點索引是 (i−1)/2 向下取整，左、右子節點的索引分別是 2i+1、2i+2。若索引超出範圍，表示沒有該子節點。值相同的元素以索引區分。

取出頂端元素時，先將堆積頂端（索引 0）與尾端元素（索引 12）交換，再從陣列尾端刪除原本的頂端元素。這樣就不必因刪除第一個元素而將後續元素全部前移。接著從根節點開始向下調整：每一步都從目前節點及其左右子節點中找出最大值。若子節點的值較大，就與值較大的那個子節點交換。只有讓較大的子節點上移，才能確保新的父節點也不小於另一個子節點。當目前節點的值已不小於其子節點，或已抵達葉節點時，就停止下沉。

def pop(self) -> int:
    """從堆積取出元素"""
    # 檢查堆積是否為空
    if self.is_empty():
        raise IndexError("堆積為空")
    # 交換根節點與最右側的葉節點（即首尾兩個元素）
    self.swap(0, self.size() - 1)
    # 刪除節點
    val = self.max_heap.pop()
    # 由上往下調整堆積
    self.sift_down(0)
    # 回傳堆積頂端元素
    return val

def sift_down(self, i: int):
    """從節點 i 開始向下調整堆積"""
    while True:
        # 找出節點 i、l、r 中值最大的節點，記為 ma
        l, r, ma = self.left(i), self.right(i), i
        if l < self.size() and self.max_heap[l] > self.max_heap[ma]:
            ma = l
        if r < self.size() and self.max_heap[r] > self.max_heap[ma]:
            ma = r
        # 若節點 i 的值最大，或子節點索引 l、r 均超出範圍，即可結束調整，跳出迴圈
        if ma == i:
            break
        # 交換兩個節點
        self.swap(i, ma)
        # 繼續向下調整堆積
        i = ma

8.1.3   堆積的常見應用¶

  • 優先佇列：堆積通常是實作優先佇列的首選資料結構。加入和取出元素的時間複雜度皆為 \(O(\log n)\)，建立堆積則為 \(O(n)\)，這些操作都很有效率。
  • 堆積排序：給定一組資料，可以先用它們建立堆積，再反覆取出頂端元素，就能得到排序好的資料。不過，我們通常會用更簡潔的方式實作堆積排序，詳見「堆積排序」一章。
  • 取得最大的 \(k\) 個元素：這是經典的演算法問題，也是堆積的典型應用。例如選取熱門程度前 10 名的新聞作為微博熱搜，或選出銷量前 10 名的商品。
