# 序

幾年前，我在力扣上分享了《劍指 Offer》系列的解題筆記，得到許多讀者的鼓勵與支持。和讀者交流時，我最常聽到的一個問題是：「演算法該怎麼入門？」久而久之，我自己也對這個問題產生了濃厚的興趣。

埋頭刷題似乎是最受歡迎的做法，簡單、直接又有效。不過，刷題有點像玩「踩地雷」：擅長自學的人能順利排除一顆顆地雷，基礎還沒打穩的人卻可能被炸得滿頭包，遇到挫折便一步步退縮。從頭到尾讀完一本教科書也是常見的做法，但對正在求職的人來說，光是寫畢業論文、投履歷、準備筆試與面試，就已經耗去大半精力，要再讀完一本厚重的書，往往相當吃力。

如果你也有類似的困擾，很高興這本書「找」到了你。這是我對那個問題的回答，即使不是最佳解，至少也是一次認真的嘗試。這本書雖然不足以直接幫你拿到錄取通知，但會帶你探索資料結構與演算法的「知識地圖」，認識各種「地雷」的形狀、大小與分布位置，也學會各種「排雷方法」。有了這些本領，相信你能更自在地練習解題、閱讀文獻，一步步建立完整的知識體系。

我很認同費曼教授的一句話：「Knowledge isn't free. You have to pay attention.」從這個角度來看，這本書也不是完全「免費」的。為了不辜負你付給這本書的寶貴「注意力」，我也會盡我所能，把最大的「注意力」投入寫作。

我深知自己所學有限，書中內容雖經多次琢磨，一定仍有不少錯誤，懇請各位老師與同學不吝指正。

電腦的問世為世界帶來巨大改變。高速運算能力與出色的可程式化特性，讓電腦成為執行演算法、處理資料的理想工具。從電玩遊戲的逼真畫面、自動駕駛的智慧決策，到 AlphaGo 的精采棋局、ChatGPT 的自然對話，都是演算法在電腦上的巧妙應用。

其實早在電腦問世以前，演算法與資料結構就已存在於世界各個角落。早期的演算法較為簡單，例如古人的計數方法、製作工具的步驟。隨著文明發展，演算法也變得更精細、更複雜。從巧奪天工的工藝、提高生產力的工業產品，到描述宇宙運行的科學定律，幾乎每一件平凡或令人驚嘆的事物背後，都藏著精妙的演算法思維。

資料結構同樣無所不在。大至社會網絡，小至捷運路線，許多系統都能以「圖」建模；大至國家，小至家庭，社會的主要組織形式常呈現「樹」的特徵。冬天穿的層層衣物就像「堆疊」，最先穿上的要最後才能脫下；羽球筒則像「佇列」，從一端放入、另一端取出；字典就像「雜湊表」，可以快速查到想找的詞條。

本書以容易理解的動畫圖解與可執行的程式範例，幫助讀者掌握演算法與資料結構的核心概念，並學會自己動手實作。在此基礎上，本書也希望帶你看見演算法如何生動地體現在複雜的世界裡，體會其中的美。希望這本書能幫上你的忙！
