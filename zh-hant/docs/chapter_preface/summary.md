# 0.3 &nbsp; 本章小結

### 1. &nbsp; 重點回顧

- 這本書主要寫給演算法初學者。如果你已經有些基礎，可以用它來有系統地複習演算法知識，也可以把書中的原始碼當作「解題工具庫」。
- 本書主要分為複雜度分析、資料結構與演算法三大部分，涵蓋這個領域的大多數主題。
- 對剛開始學演算法的人來說，先讀一本入門書很重要，可以少走許多冤枉路。
- 書中的動畫圖解通常用來介紹重點與較難的概念，閱讀時值得多花些心思。
- 動手實作是學習程式設計的最佳途徑。強烈建議你執行原始碼，並親自把程式碼寫一遍。
- 本書網頁版的每個章節都有留言區，歡迎隨時分享你的問題與見解。
