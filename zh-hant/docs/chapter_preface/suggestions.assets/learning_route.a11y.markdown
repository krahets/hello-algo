學習路線分為三個階段：階段一透過演算法入門書完成基礎入門，隨後單向進入階段二；階段二透過刷演算法題提升熟練度，並配以“週期性回顧”（隔段時間多次刷同一道題，形成長期記憶並加深理解）；階段三閱讀演算法專欄、解題框架與演算法教材以搭建知識體系，並配以“主動總結”（梳理內容、發現規律、搭建完整知識體系）。圖中階段二與階段三之間為雙向箭頭，表明進入專題學習後仍需返回刷題練習，讓解題實踐與知識整理相互促進。

## 結果

階段二透過週期性回顧多次重做同題以形成長期記憶，階段三透過主動總結梳理規律以搭建完整知識體系；兩階段往返配合。
