# 0.1 &nbsp; 關於本書

本專案希望打造一本開源、免費，適合初學者的資料結構與演算法入門書。

- 全書採用動畫圖解，讓內容清楚易懂，帶領初學者循序漸進地探索資料結構與演算法的知識地圖。
- 原始碼只要按一下就能執行，讀者可以一邊練習程式設計，一邊了解演算法的運作原理與資料結構的底層實作。
- 我們鼓勵讀者互相學習，歡迎在留言區提問、分享見解，一起從討論中進步。

## 0.1.1 &nbsp; 適合哪些讀者

如果你剛入門，從沒接觸過演算法，或是已經做過一些題目，卻對資料結構與演算法仍似懂非懂，時而覺得自己會了，時而又沒把握，那麼這本書就是為你寫的！

如果你已經做過不少題目，對多數題型都很熟悉，本書可以幫你回顧並整理演算法知識。程式碼儲存庫也可以當作「解題工具庫」或「演算法字典」來使用。

如果你是演算法高手，我們期待收到你的寶貴建議，也歡迎你[一起參與創作](../chapter_appendix/contribution.md)。

!!! success "先備知識"

    你至少需要具備一種語言的程式設計基礎，能讀懂並撰寫簡單的程式碼。

## 0.1.2 &nbsp; 內容架構

本書的主要內容如圖 0-1 所示。

- **複雜度分析**：評估資料結構與演算法的面向和方法，以及時間複雜度與空間複雜度的推算方法、常見類型和範例。
- **資料結構**：基本資料型別與資料結構的分類方式，以及陣列、鏈結串列、堆疊、佇列、雜湊表、樹、堆積、圖等結構的定義、優缺點、常用操作、常見類型、典型應用及實作方式。
- **演算法**：搜尋、排序、分治、回溯、動態規劃、貪婪法等演算法的定義、優缺點、效率、適用情境、解題步驟與例題。
