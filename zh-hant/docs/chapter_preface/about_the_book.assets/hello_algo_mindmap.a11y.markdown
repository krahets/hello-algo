# 全書知識地圖

按資料結構、複雜度分析與演算法三個板塊，折返查詢全書 16 個主題與典型問題。

## 問題與輸入

全書思維導圖分為資料結構（7 個主題分支）、複雜度分析（3 個主題分支）和演算法（6 個主題分支）三個板塊，共 16 個一級主題分支。各分支表示主題迴屬，不要求按單一固定順序閱讀；下文每段以“板塊／主題”短名開頭，便於按主題檢索。

## 結構與關係

資料結構／資料結構：邏輯結構與物理結構；基本資料型別、數字編碼與字元編碼。

資料結構／陣列與鏈結串列：連續儲存與分散儲存方式、操作方法與優缺點對比、基於動態陣列實現串列、計算機記憶體與快取。

資料結構／堆疊與佇列：先入後出堆疊、先入先出佇列、雙向佇列，以及基於陣列與鏈結串列實現堆疊和佇列。

資料結構／雜湊表：工作原理與基於陣列實現；雜湊衝突與鏈式位址、開放定址；雜湊演算法用途與設計目標。

資料結構／樹：完美、完全、完滿與平衡二元樹；鏈結串列與陣列表示對比；層序、前序、中序與後序走訪；二元搜尋樹與 AVL 樹。

資料結構／堆積：小頂堆積、大頂堆積與優先佇列；基於陣列實現堆積與建堆積操作；Top-k 問題。

資料結構／圖：有向圖、連通圖與有權圖；鄰接表與鄰接矩陣表示對比；廣度優先走訪與深度優先走訪。

複雜度分析／迭代與遞迴：for 迴圈、while 迴圈與巢狀迴圈；遞迴呼叫堆疊、尾遞迴與遞迴樹；迭代與遞迴對比。

複雜度分析／時間複雜度：函式漸近上界；推算方法與常見型別；最差、最佳與平均時間複雜度。

複雜度分析／空間複雜度：推算方法與常見型別；權衡時間與空間。

演算法／搜尋：暴力搜尋（線性搜尋、廣度與深度優先搜尋）；高效搜尋（二分搜尋、雜湊查詢、樹查詢）；搜尋演算法的選取。

演算法／排序：評價維度包括就地性、穩定性、自適應性、是否基於比較；按原圖分支依次迴入“走訪”（選擇排序、泡沫排序、插入排序）、“分治”（快速排序、合併排序、堆積排序）和“非比較”（桶排序、計數排序、基數排序）。

演算法／分治：問題特性與判斷方法；例題包括二分、構建樹、河內塔。

演算法／回溯：問題特性與框架程式碼；例題包括全排列、子集和、n 皇后。

演算法／動態規劃：暴力搜尋、記憶化遞迴與遞推；重疊子問題、最優子結構與無後效性；問題判斷方法與求解步驟；例題包括 0-1 背包、完全背包、編輯距離。

演算法／貪婪：問題特性與解題步驟；例題包括分數背包、最大容量、最大切分乘積。
