# 雜湊表的鍵值對映與查詢

## 結構與關係

與需要從頭逐個比對的陣列或鏈結串列線性查詢（O(n)）不同，雜湊表直接透過鍵定位對應的值，圖中橫向排列順序僅作展示，並不要求學號按大小排序。

這裡的 O(1) 表示雜湊分佈良好且負載適當時的理想或平均查詢效率；嚴重衝突時，查詢仍可能退化到 O(n)。
