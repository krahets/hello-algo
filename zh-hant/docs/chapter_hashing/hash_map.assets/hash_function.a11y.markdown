# 雜湊函式將輸入 key 對映為桶陣列索引

以雜湊函式 key % 100 將學號轉換為容量 100 的陣列桶索引，演示 13276、12836、16750 三條查詢路徑如何分別定位到 76、36、50 號桶並取出姓名。

## 問題與輸入

畫面從左到右分為四個部分：“輸入 key”列、“雜湊函式 key % 100”計算框、“索引”與“陣列（每個桶內儲存一個鍵值對）”列，以及最右側的“輸出 value”列。

底層陣列容量為 100，雜湊函式定義為 index = key % 100，即直接擷取五位學號的後兩位數字作為陣列桶索引。

## 結構與關係

陣列列共畫出 5 個非空雜湊桶（見表 1），其餘位置用省略號“…”略去。左側“輸入 key”列從上到下給出三個待查詢學號：橙色 13276、藍色 12836、綠色 16750（見表 2）。

由於左側輸入學號未按後兩位從小到大排列，而中間陣列按桶索引 36、37、50、76、83 升序排列，三條彩色查詢曲線在穿過“雜湊函式 key % 100”時發生了視覺交叉：頂部橙色 13276 對映到下方索引 76 並輸出底部橙色“小法”；中部藍色 12836 對映到上方索引 36 並輸出頂部藍色“小哈”；底部綠色 16750 對映到中部索引 50 並輸出中部綠色“小算”。

## 透過 key % 100 定位桶索引的三條查詢路徑

三條同色有向曲線完整展示了雜湊查詢的兩步過程：橙色路徑輸入 13276，計算 13276 % 100 = 76，定位到 76 號桶 (13276, “小法”) 並輸出“小法”；藍色路徑輸入 12836，計算 12836 % 100 = 36，定位到 36 號桶 (12836, “小哈”) 並輸出“小哈”；綠色路徑輸入 16750，計算 16750 % 100 = 50，定位到 50 號桶 (16750, “小算”) 並輸出“小算”。陣列中一併畫出的 37 號桶 (15937, “小囉”) 和 83 號桶 (10583, “小鴨”) 未參與本次三條查詢。

## 結果

雜湊函式在輸入 key 與底層陣列桶索引之間架起確定性橋樑：先由 key % 100 算出桶索引，再直接訪問該桶取出對應的 value。
