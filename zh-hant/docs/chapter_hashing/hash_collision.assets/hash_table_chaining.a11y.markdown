# 鏈式位址雜湊表：用桶內單向鏈結串列收納衝突元素

每個雜湊桶對應一條儲存鍵值對節點的單向鏈結串列；當多個 key 對 100 取餘落入同一桶時，依次串聯在該桶鏈結串列中。

## 問題與輸入

畫面左側說明框給出核心定義：“鏈式位址：每個桶儲存一個鏈結串列，其中包含所有衝突元素”，下方註明“雜湊函式 key % 100；後兩位相同的 key 會發生雜湊衝突”。

右側主體由三列標題構成：“索引”列、淺藍色“陣列”列，以及向右延伸的淺綠色“鏈結串列（節點為鍵值對）”區域。藍色陣列列存放每條非空鏈結串列的頭節點，後續衝突節點透過向右的單向箭頭依次串聯。

## 結構與關係

圖中一共展示了 00、37、50、76、83 五個非空桶，共包含 13 個鍵值對節點，各桶從鏈頭到鏈尾的完整節點順序見下表。

在鏈式位址雜湊表中查詢或修改某個 key 時，先用 key % 100 定位到對應的桶索引，再從該桶的鏈結串列頭節點出發，沿箭頭從左往右逐一比對節點的 key，直到找到完全匹配的鍵值對或到達鏈結串列末尾。

## 五個雜湊桶各自的衝突鏈結串列

由於雜湊函式為 key % 100，凡是後兩位相同的鍵都會進入同一條橫向鏈結串列：例如 200、500、300 後兩位均為 00，依次串在 00 號桶；937、637、437、237 後兩位均為 37，依次串在 37 號桶。若要查詢 key = 437，程式先算得 437 % 100 = 37 進入 37 號桶，再沿鏈結串列依次檢查頭節點 937、第二節點 637，在第 3 個節點匹配到 437 並取出值 K。

## 結果

鏈式位址透過“桶陣列 + 鏈結串列”的組合結構，允許任意多個後兩位相同的衝突 key 共存於同一桶對應的鏈結串列內，不會相互覆蓋。
