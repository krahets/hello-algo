# 圖的深度優先走訪

從起點出發沿未訪問鄰居遞迴深入，無路可走時回溯到上一層頂點，繼續探索剩餘分支。

## 問題與輸入

無向連通圖包含頂點 0 至 6，共 6 條無向邊：0—1、0—3、1—2、2—5、4—5、5—6。走訪從起點 0 出發；本例在頂點 0 處按先 1 後 3 的次序檢查鄰居，在頂點 5 處按先 4 後 6 的次序檢查鄰居。

## 深度優先走訪概覽

總覽圖彙總了全部 14 個遞迴事件：從 0 依次深入 1、2、5、4（事件 1 至 5），4 無新鄰居而返回 5（事件 6）；再由 5 深入 6 並返回 5（事件 7、8），隨後沿 5→2→1→0 連續返回起點 0（事件 9 至 11）；最後從 0 深入 3（事件 12），再經 3 返回 0 及起始呼叫返回（事件 13、14）。每次回溯只退回上層呼叫，不重複記入 res。

## 結果

最終首次訪問序列為 res = \[0, 1, 2, 5, 4, 6, 3\]，每個頂點僅在首次到達時記錄一次，回溯返回不會再次寫入 res。即使 7 個頂點已全部訪問，仍需依次結束剩餘遞迴呼叫才算完成走訪；若改變同一圖中鄰居的檢查次序，所得 DFS 序列也會隨之改變。
