# 圖的廣度優先走訪

從左上角起點 0 出發，藉助先進先出佇列與去重集合，按距離由近及遠逐層走訪各頂點。

## 問題與輸入

待走訪的無向圖有 9 個頂點，編號為 0 至 8，按三行三列網格排列：三行依次為 0、1、2；3、4、5；6、7、8。圖中只在水平或豎直相鄰的頂點之間連線無向邊，共 12 條邊，沒有對角邊；各頂點的鄰居列在鄰接表中。

res 是按出隊順序記錄的走訪序列；que 是先進先出的待處理佇列，下文均按從佇列首到佇列尾的順序寫出；visited 是記錄已發現頂點的雜湊集合。注意頂點在入列時就立即記入 visited，因此即使某頂點仍在佇列中等待出列，後續遇到它時也不會再次入列。

## 結構與關係

每輪迴圈從佇列 que 佇列首取出一個頂點並追加到 res，隨後檢查它的所有鄰接頂點：將尚未出現在 visited 中的新鄰居依次加入 que 佇列尾，並同步記入 visited。先進先出佇列保證了同一距離層的頂點先於更遠層的頂點被處理。圖中佇列槽位左側的空白格表示此前元素出列後留下的位置，並非空元素；visited 的橫向排列也不代表集合內部有序。
