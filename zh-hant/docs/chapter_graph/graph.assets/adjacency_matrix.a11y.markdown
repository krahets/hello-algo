# 無向圖的鄰接矩陣

頂點串列按 1、3、2、5、4 排列；七條無向邊在 5×5 鄰接矩陣中各對應兩個關於主對角線對稱的 1。

## 問題與輸入

圖的頂點串列為 V=\[1, 3, 2, 5, 4\]，按此順序對應矩陣的行、列索引 0 至 4。注意頂點編號與矩陣索引不完全相同：頂點 1、2、4 恰好位於索引 0、2、4，而頂點 3 位於索引 1、頂點 5 位於索引 3。表頭同時列出索引與頂點編號，查詢時須先按頂點找到對應索引。

## 結構與關係

鄰接矩陣元素 M\[i, j\]=1 表示索引 i 的頂點 V\[i\] 與索引 j 的頂點 V\[j\] 之間有邊相連，M\[i, j\]=0 表示無邊。由於無向圖的每條邊在兩個方向上等價，同一條無向連線會同時在 M\[i, j\] 和 M\[j, i\] 兩處記為 1，使矩陣關於主對角線對稱；本圖無自環，主對角線 M\[i, i\] 全為 0。

圖中用顏色高亮標出三組無向邊與矩陣對稱單元的對應：邊 1—2（索引 0 與 2）對應 M\[0, 2\]=1 與 M\[2, 0\]=1；邊 3—2（索引 1 與 2）對應 M\[1, 2\]=1 與 M\[2, 1\]=1；邊 5—4（索引 3 與 4）對應 M\[3, 4\]=1 與 M\[4, 3\]=1。完整 5×5 矩陣見資料表。

查邊時先將兩個頂點換算為 V=\[1, 3, 2, 5, 4\] 中的行列索引，再讀取交叉單元：例如查頂點 3（索引 1）與頂點 2（索引 2），M\[1, 2\] 與對稱位置 M\[2, 1\] 均為 1，說明兩點有邊；若查頂點 3（索引 1）與頂點 4（索引 4），M\[1, 4\]=0，說明兩點無邊。

## 結果

五個頂點構成 5×5 鄰接矩陣，七條無向邊在主對角線兩側對稱產生 14 個值為 1 的矩陣元素，主對角線元素全為 0。
