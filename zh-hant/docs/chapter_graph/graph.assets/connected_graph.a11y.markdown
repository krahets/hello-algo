# 連通圖與非連通圖：所有頂點皆可達與存在孤立頂點

左圖五個頂點透過七條邊彼此全部可達；右圖去掉與頂點 4 相連的兩條邊後，頂點 4 孤立，形成非連通圖。

## 問題與輸入

左右兩幅圖均為包含頂點 1、2、3、4、5 的無向圖。無向圖的“連通”是指從任意頂點出發，都能沿一條或多條邊組成的路徑到達其餘任意頂點，不要求每對頂點之間都有直接相連的邊。

## 結構與關係

左側為“連通圖（所有頂點皆可達）”：共有七條無向邊 1—2、1—3、1—5、2—3、2—4、2—5、4—5。即使像頂點 3 與頂點 4 之間沒有直接邊，也能透過路徑 3—2—4 或 3—1—5—4 互相到達，因此五個頂點構成單一連通整體。

右側為“非連通圖（存在頂點不可達）”：保留了左側四個頂點之間的五條無向邊 1—2、1—3、1—5、2—3、2—5，但刪去了連線頂點 4 的兩條邊 2—4 和 4—5。此時頂點 1、2、3、5 內部依然彼此可達，但沒有任何路徑能夠通往右側孤立的頂點 4。

圖左右對比“連通圖（所有頂點皆可達）”與“非連通圖（存在頂點不可達）”：兩圖的唯一結構差異在於頂點 4——左圖中頂點 4 透過邊 2—4 和 4—5 接入網路，五點全連通；右圖去掉這兩條邊後，頂點 4 成為沒有任何邊的孤立頂點，其餘四個頂點無法到達 4。

## 結果

只要無向圖中存在至少一對頂點無法透過路徑互相到達（如右圖中孤立的 {4} 與連通子集 {1, 2, 3, 5}），該圖就屬於非連通圖。
