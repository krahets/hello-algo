# 鏈結串列、樹與圖的連線關係

用同樣的五個節點比較線性後繼、樹形層級與允許交叉和環路的網路關係。

## 問題與輸入

三幅子圖均使用編號 1 至 5 的五個節點：鏈結串列與樹的箭頭表示有向引用，無向圖的線段表示雙向鄰接。三者是並列的結構對比，而非將同一結構逐步變形的演算法過程。

## 結構與關係

按連線約束從嚴到寬對比：單向鏈結串列要求每個非尾節點僅有一個後繼，呈單一線性鏈；樹允許一個父節點分出多個子節點，形成自根向下的層級分支，但每個非根節點只有一個父節點且不能跨分支或成環；圖則解除根與層級限制，任意兩個頂點之間均可按關係建立連線，並允許出現環路。

本例無向圖中包含 1—2—3—1、2—4—5—2 等環路，共連線 7 條邊，但並非每對頂點之間都有邊（例如 3 與 4、3 與 5 未相連，不是完全圖）。圖下方標註的“邏輯自由度最高”是指連線約束最少，而非比較某次演算法執行的複雜度。

單向鏈結串列將連線限制為單線後繼；樹放寬為一對多的單向層級分支；圖進一步允許跨分支連線與環路。相同的 5 個節點在不同連線約束下呈現出線性、層級與網路三類結構。

## 結果

把節點視作頂點、引用視作邊，鏈結串列與樹都能從圖的角度理解。一般圖容許更廣泛的連線方式；本圖展示的是結構關係的拓展。
