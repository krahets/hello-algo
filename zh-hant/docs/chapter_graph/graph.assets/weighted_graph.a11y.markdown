# 無權圖與有權圖：為邊附加權重數值屬性

左右兩圖具有完全相同的五個頂點與七條無向邊；右圖在每條邊旁標註 0.2 至 1.0 的小數作為邊的權重。

## 問題與輸入

左右兩幅圖均為無向圖，頂點同為 1 至 5，七條無向邊同為 1—2、1—3、1—5、2—3、2—4、2—5、4—5。左圖僅表達頂點間是否存在連線，右圖進一步為每條邊賦予一個數值權重。

## 結構與關係

左側為“無權圖（所有邊等價）”：七條邊上沒有任何數值標註，所謂“所有邊等價”是指已存在的這七條邊在圖模型中地位相同、不區分強弱或長短，並非指所有頂點兩兩之間都有邊。

右側為“有權圖（邊具有權重屬性）”：在完全相同的七條無向邊旁分別標出小數權重——上方的邊 1—5 為 0.25，左側豎邊 1—3 為 0.2，中間斜邊 1—2 為 0.5，下方橫邊 2—3 為 0.3，中間豎邊 2—5 為 0.7，右上斜邊 4—5 為 0.88，右下斜邊 2—4 為 1.0。全部邊與權重的對應關係列於資料表。

邊權在不同應用場景中可代表距離、耗費、親密度等量化屬性；圖本身只給出純數值，未繫結具體物理單位。

圖左右對比“無權圖（所有邊等價）”與“有權圖（邊具有權重屬性）”：兩圖擁有完全一致的五頂點、七無向邊結構，右圖在每條邊旁附加上小數權重（1—2 為 0.5，1—3 為 0.2，1—5 為 0.25，2—3 為 0.3，2—4 為 1.0，2—5 為 0.7，4—5 為 0.88）。

## 結果

向邊引入權重屬性後，無權圖即擴展為有權圖：底層頂點與邊的拓撲連線不變，但每條邊多了一維可用於最短路徑、最小生成樹等圖計算的量化資訊。
