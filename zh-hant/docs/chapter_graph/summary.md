# 9.4 &nbsp; 小結

### 1. &nbsp; 重點回顧

- 圖由頂點和邊組成，可以用一個頂點集合與一個邊集合來表示。
- 相較於線性關係（鏈結串列）與分治關係（樹），網路關係（圖）的連接方式更自由，因此也更複雜。
- 有向圖的邊具有方向，連通圖中的任意兩個頂點彼此可達，加權圖的每條邊都有權重。
- 鄰接矩陣用矩陣來表示圖，每個橫列與每個直行各代表一個頂點，矩陣元素則代表邊，以 $1$ 或 $0$ 表示兩個頂點之間有邊或無邊。使用鄰接矩陣新增、刪除、查詢和修改邊都很有效率，但佔用的空間較多。
- 鄰接串列用多條鏈結串列來表示圖，第 $i$ 條串列對應頂點 $i$，存放與該頂點相鄰的所有頂點。鄰接串列比鄰接矩陣省空間，但查詢邊時必須走訪鏈結串列，因此較耗時。
- 當鄰接串列中的鏈結串列過長時，可以改用紅黑樹或雜湊表，以提升查詢效率。
- 從演算法設計的觀點來看，鄰接矩陣是「以空間換取時間」，鄰接串列則是「以時間換取空間」。
- 許多真實系統都可以用圖來描述，例如社群網路、捷運路線等。
- 樹是圖的一種特例，樹的走訪也是圖的走訪的一種特例。
- 圖的廣度優先走訪是一種由近而遠、逐層向外擴展的搜尋方式，通常使用佇列實作。
- 圖的深度優先走訪會沿一條路走到底，無路可走時再回溯，通常以遞迴實作。

### 2. &nbsp; Q & A

**Q**：路徑的定義是頂點序列還是邊序列？

維基百科不同語言版本的定義有所不同：英文版寫的是「路徑是邊的序列」，中文版則寫「路徑是頂點的序列」。以下是英文版原文：In graph theory, a path in a graph is a finite or infinite sequence of edges which joins a sequence of vertices.

本文將路徑視為邊的序列，而非頂點的序列。因為兩個頂點之間可能有多條邊相連，這時每條邊都對應一條路徑。

**Q**：在非連通圖中，會有無法走訪到的頂點嗎？

在非連通圖中，從某個頂點出發，至少有一個頂點無法抵達。要走訪非連通圖的所有連通分量，必須設定多個起點。

**Q**：在鄰接串列中，「與該頂點相連的所有頂點」有順序上的限制嗎？

可以採用任意順序。但在實際應用中，有時需要依指定規則排序，例如依頂點加入的順序或頂點值的大小排列，以便快速找出具有某種極值的頂點。
