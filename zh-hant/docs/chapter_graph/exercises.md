## 觀念複習

### 用兩種方式表示同一張圖

某個無向圖有 4 個頂點 `A、B、C、D`，邊為
`A-B、A-C、B-C、C-D`。

<!-- numbered-subquestions -->

1. 寫出這張圖的鄰接串列。
2. 填寫這張圖的鄰接矩陣，其中只能填入 0 或 1。
3. 若要判斷 `A` 和 `D` 之間是否有邊直接相連，使用哪種表示法只需查看一個項目？
4. 如果圖中的頂點很多、邊卻很少，哪種表示法通常比較節省記憶體空間？

??? success "參考答案"

    1. 鄰接串列如下：

        ```text
        A: B, C
        B: A, C
        C: A, B, D
        D: C
        ```

    2. 鄰接矩陣如下：

        | | A | B | C | D |
        | --- | --- | --- | --- | --- |
        | A | 0 | 1 | 1 | 0 |
        | B | 1 | 0 | 1 | 0 |
        | C | 1 | 1 | 0 | 1 |
        | D | 0 | 0 | 1 | 0 |

    3. 在鄰接矩陣中，可以直接查看 `A` 所在的橫列與 `D` 所在的直行交會處的值，因此很適合用來判斷任意兩個頂點之間是否有邊直接相連。

    4. 當頂點很多、邊卻很少時，鄰接串列只記錄實際存在的邊，通常比為每一對頂點都預留空間的鄰接矩陣更節省記憶體。

### 廣度優先搜尋與深度優先搜尋的走訪順序

某個無向圖的頂點為 `A、B、C、D、E`，邊為
`A-B、A-C、B-D、C-D、D-E`。

從 A 出發。若有多個尚未走訪的相鄰頂點可選，請依字母順序選擇。

<!-- numbered-subquestions -->

1. 寫出廣度優先搜尋（BFS）走訪頂點的順序。
2. 寫出遞迴深度優先搜尋（DFS）走訪頂點的順序。
3. 為什麼這兩種搜尋都需要記錄已經走訪過的頂點？

??? success "參考答案"

    1. BFS 的走訪順序為 `A, B, C, D, E`。先走訪與 A 相距一條邊的 B 和 C，
        再走訪距離較遠的 D 和 E。

    2. DFS 的走訪順序為 `A, B, D, C, E`。從目前的頂點出發，依序深入尚未走訪的相鄰頂點，
        所以一開始會沿著 `A → B → D → C` 前進。到了 C，已經沒有尚未走訪的相鄰頂點，於是回到 D，再走訪 E。

    3. 圖中有環，例如 `A-B-D-C-A`。如果沒有記錄已走訪的頂點，
        搜尋時就可能沿著環反覆走訪同一批頂點，無法結束。

### 一次 BFS 能走訪整張圖嗎？

某個無向圖的頂點為 `A、B、C、D、E、F`，邊只有
`A-B、B-C、D-E`。

<!-- numbered-subquestions -->

1. 從 A 開始做一次 BFS，可以走訪哪些頂點？
2. 根據第 1 題的結果，這次 BFS 走訪了圖中所有的頂點嗎？為什麼？
3. 如果依字母順序檢查所有頂點，每遇到一個尚未走訪的頂點，就從該頂點重新開始 BFS，
    那麼每次 BFS 的起點分別是哪個頂點？這張圖可以分成幾個彼此不相連的部分（連通分量）？

??? success "參考答案"

    1. 從 A 出發只能走訪 `A、B、C`。

    2. 這次 BFS 沒有走訪所有頂點。`D、E` 彼此相連，構成另一個連通分量，而 F 是孤立頂點。
        A 與這三個頂點之間都沒有路徑，因此從 A 出發無法到達其中任何一個。

    3. 三次 BFS 的起點依序為 `A、D、F`，各次走訪的頂點集合分別為
        `{A, B, C}`、`{D, E}` 和 `{F}`。因此，這張圖共有 3 個連通分量。

## 程式設計練習

### 判斷無向圖中的兩點之間是否有路徑

給定一張有 $n$ 個頂點的無向圖，頂點編號從 $0$ 到 $n-1$。陣列 `edges` 中的每一項 `[u, v]` 代表頂點 `u` 和 `v` 之間有一條無向邊。

另給定起點 `source` 和終點 `destination`。請先根據 `edges` 建立鄰接串列，再用 BFS 或 DFS
判斷是否有一條從 `source` 到 `destination` 的路徑。有就回傳 `true`，否則回傳 `false`。
圖中可能有環，也可能不連通。

??? tip "解題提示"

    1. 每條無向邊都要記錄兩個方向
    2. 圖中可能有環，必須記錄已走訪的頂點
    3. 從 source 出發，遇到 destination 就回傳 true，走訪完仍未遇到就回傳 false
