# 二元樹的插入與摘除

透過改連左子節點引用，在完整保留節點 2 子樹的前提下插入或摘除中間節點 P。

<a id="source-91"></a>

預先用 n2 儲存節點 2 的引用。插入時執行 n1.left = P 與 P.left = n2，把原邊 1 → 2 改連為 1 → P(0) → 2，節點 2 的左右連線仍為 4、5，整棵子樹得以接回。摘除時執行 n1.left = n2，繞過 P 直接恢復 1 → 2。

## 結果

摘除後恢復原樹連線，僅能斷言從根節點不再能到達 P，不能據此斷言 P 的物件記憶體已被釋放，也不表示刪去了整棵左子樹。

## 二元樹的插入與摘除：動畫

透過改連左子節點引用，在完整保留節點 2 子樹的前提下插入或摘除中間節點 P。

n1 指向值為 1 的根節點，n2 保留值為 2 的原左子節點引用；待插入節點 P 的值為 0。

### 第 1 步：準備插入 P

在改寫 n1.left 之前，先由引用 n2 指向節點 2，以便後續把以 2 為根的原左子樹接回新節點 P 下方。

<details><summary>本步完整狀態</summary><p>根節點 1（n1）的左子節點為 2（n2）、右子節點為 3；節點 2 的左右子節點為 4、5；3、4、5 為葉節點。值為 0 的節點 P 獨立於樹外，左右子節點均為空。</p></details>

### 第 2 步：將 P 插入左連線

依次執行 n1.left = P 與 P.left = n2：因 n2 保留了節點 2 的引用，P.left = n2 能將整棵原左子樹接回 P 下方，節點 2 的左右連線仍為 4、5，不會丟失子樹。

<details><summary>本步完整狀態</summary><p>根節點 1（n1）的左子節點改為 P（值為 0）、右子節點仍為 3；P 的左子節點為 2（n2）、右子節點為空；節點 2 的左右子節點仍為 4、5；3、4、5 為葉節點。</p></details>

### 第 3 步：繞過 P 接回原子樹

執行賦值 n1.left = n2，令根節點 1 繞過 P 直接連回節點 2，恢復原左子樹連線；這只是把 P 從根可達路徑中摘除，不表示刪去整棵子樹或已釋放 P 的記憶體。

<details><summary>本步完整狀態</summary><p>根節點 1（n1）的左子節點恢復為 2（n2）、右子節點為 3；節點 2 的左右子節點為 4、5；3、4、5 為葉節點。節點 P 已無法從根節點到達；僅憑此狀態不能斷言 P 的記憶體已釋放。</p></details>

### 結果

摘除後恢復原樹連線，僅能斷言從根節點不再能到達 P，不能據此斷言 P 的物件記憶體已被釋放，也不表示刪去了整棵左子樹。
