# 二元樹的根、葉、深度與高度

以一棵四層二元樹為例，展示根節點、葉節點，以及節點 2 的深度 1、高度 2 和整棵樹的高度 3。

## 結構與關係

圖中是一棵四層二元樹，綠色圓圈內為節點值，灰色箭頭從父節點指向左、右子節點。頂層的 1 是根節點；1 的左、右子節點是 2、3；2 的左、右子節點是 4、5；3 的左、右子節點是 6、7；4 的左、右子節點是 8、9；6 只有左子節點 12；7 的左、右子節點是 14、15。

每條有向連線代表一條邊。頂部的“根節點”標註指向最上方沒有父節點的 1；底部的“葉節點”透過六條引線指向 8、9、5、12、14、15。這六個節點都沒有子節點，其中 5 位於第 3 層，其餘五個位於第 4 層，說明葉節點不必處在同一層。

兩側標尺按經過的邊數度量深度與高度：左側上方標尺從根 1 量到節點 2，經過 1 條邊，標明“節點 2 深度 = 1”；左側下方標尺從節點 2 量到其最遠葉節點 8、9，經過 2 條邊，標明“節點 2 高度 = 2”。右側長標尺從根 1 量到底層最遠葉節點，經過 3 條邊，標明“二元樹高度 = 3”。

左側上下兩段標尺以水平虛線對齊各層，分別標出節點 2 從根向下計算的深度 1，以及從節點 2 到最遠葉節點 8、9 的高度 2；右側貫通頂層與底層的標尺標出整棵二元樹的高度 3。

## 結果

本圖以經過的邊數定義深度和高度：節點 2 的深度為 1、高度為 2，四層二元樹的高度為 3 而非 4。
