# 完全二元樹：末層從左到右連續填充

前三層全部填滿，第四層從左起連續佔滿五個位置，僅最右側三個位置留空。

## 結構與關係

左側四層無數值標籤的二元樹中，前三層全部填滿，分別有 1、2、4 個節點。第三層從左往右數：第一、第二個節點各有左、右兩個子節點；第三個節點只有左子節點；第四個節點沒有子節點。因此第四層共有五個節點，連續佔據最左側的五個位置。

右側標出“完全二元樹”與英文“complete binary tree”。樹底部有一條指向左側的長箭頭，配合灰色說明框“最底層節點靠左填充，其他層節點全被填滿”，強調末層節點必須緊靠左側連續排列，中間不能出現空缺。

前三層依次填滿 1、2、4 個節點，第四層從左到右連續排列五個節點且中間無空位，底部向左的箭頭標明最底層靠左連續填充。

## 結果

圖中二元樹高度為 3，共有 12 個節點，符合完全二元樹定義；因第四層右側仍有三個空位未填滿，它不是完美二元樹。
