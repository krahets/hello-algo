# 完滿二元樹：所有節點的度都為 0 或 2

四層共 7 個節點，每個節點要麼是度為 0 的葉節點，要麼是度為 2 的雙子節點。

## 結構與關係

左側無數值標籤的二元樹分佈在四層，共 7 個節點：第一層根節點有左、右兩個子節點；第二層右側節點是葉節點，左側節點又有左、右兩個子節點；第三層左側節點是葉節點，右側節點繼續分出第四層的左、右兩個葉節點。

節點的“度”即它擁有的子節點數量。右側標出“完滿二元樹（full binary tree）”，底部灰色說明框寫著“所有節點的度都為 0 或 2”：圖中三個非葉節點的度全為 2，4 個葉節點的度全為 0，不存在度為 1 的單子節點；同時葉節點分佈在不用填滿的第二、第三、第四層。

圖中三個分叉節點都成對擁有左、右子節點（度為 2），其餘 4 個節點均為無子節點的葉節點（度為 0），沒有任何節點只帶單個子節點。

## 結果

完滿二元樹只要求每個節點有 0 個或 2 個子節點，不要求每一層填滿或所有葉節點處於同一層。
