# 完美二元樹：每一層都完全填滿

四層二元樹的節點數從上到下依次為 1、2、4、8，所有層全部填滿，共 15 個節點。

## 結構與關係

左側是一棵四層無數值標籤的二元樹：第一層有 1 個根節點；第二層有 2 個節點；第三層有 4 個節點；第四層有 8 個葉節點。樹下方的灰色說明框寫著“所有層的節點都被填滿”。

圖中每個非葉節點都同時擁有左、右兩個子節點，全部 8 個葉節點都整齊排列在最底部的第四層。右側標題標出“完美二元樹”、英文“perfect binary tree”，並註明“（也被稱為滿二元樹）”。

<a id="source-92"></a>

從第一層到第四層每層節點數依次翻倍為 1、2、4、8，沒有任何空缺位置，展示“所有層的節點都被填滿”的完美二元樹（滿二元樹）形態。

## 結果

這棵四層完美二元樹按邊數計算的高度為 3，共有 15 個節點；一般地，高度為 h 的完美二元樹共有 2^(h+1) − 1 個節點。
