# 平衡二元樹：任意節點的左右子樹高度差不超過 1

八個節點旁分別標出左右子樹高度差 d，所有節點的 d 均在 −1、0、1 之間，滿足 \|d\| ≤ 1。

## 問題與輸入

右側說明框給出定義：“設節點的 左子樹高度 – 右子樹高度 = d，則平衡二元樹中所有節點都滿足 \|d\| ≤ 1。”按邊數計高度時，葉節點高度為 0，空子樹高度記為 −1；這裡的 d 表示左右子樹高度差，不是節點的度。

## 結構與關係

左側是一棵四層共 8 個無數值標籤節點的二元樹：第一層根節點有左、右兩個子節點；第二層左節點只有左子節點（位於第三層的葉節點）；第二層右節點有左、右兩個子節點（位於第三層），其中左節點又分出第四層的兩個葉節點，右節點本身是葉節點。

每個節點旁都標有高度差 d：第一層根節點的左子樹比右子樹低一層，故標為 d = −1；第二層左節點只有左葉節點而無右子樹，標為 d = 1；第二層右節點的左子樹比右葉節點高一層，也標為 d = 1。

第三層中間那個帶兩個葉節點的內部節點，左右子樹高度同為 0，標為 d = 0；其餘四個葉節點（第三層兩個、第四層兩個）左右均為空子樹，也都標為 d = 0。全樹 8 個節點的 \|d\| 都不超過 1。

## 結果

判斷平衡二元樹必須核驗樹中的每一個節點，所有節點的左右子樹高度差絕對值都至多為 1。
