# 二元樹的層序走訪

按從頂層到底層、同一層內從左到右的次序逐層訪問二元樹節點。

## 問題與輸入

示例二元樹共三層 7 個節點：根節點為 1；1 的左、右子節點分別為 2、3；2 的左、右子節點分別為 4、5；3 的左、右子節點分別為 6、7。其中 4、5、6、7 為葉節點。

走訪按層推進：先訪問第 1 層的根 1，再從左到右訪問第 2 層的 2、3；第 2 層完成後轉入第 3 層最左側的節點 4，再依次訪問同層的 5、6、7，因此訪問 3 之後是 4。圖中灰色實線箭頭表示父子關係，串聯各節點底部藍點的虛線箭頭僅表示訪問先後次序——例如 4 的父節點是 2，從 3 指向 4 的斜向虛線只表示從第 2 層末尾進入第 3 層首節點，不表示 3 是 4 的父節點。

## 結果

層序走訪序列為 \[1, 2, 3, 4, 5, 6, 7\]，每個節點恰好訪問一次。
