# 7.6 &nbsp; 小結

### 1. &nbsp; 重點回顧

- 二元樹是一種非線性資料結構，體現了「一分為二」的分治想法。每個二元樹節點包含一個值和兩個指標，分別指向它的左子節點與右子節點。
- 在二元樹中，一個節點的左子節點連同其所有後代形成該節點的左子樹；右子節點及其所有後代則形成右子樹。
- 二元樹的相關術語包括根節點、葉節點、層、分支度、邊、高度與深度。
- 二元樹的初始化、節點插入與節點刪除方式，都和鏈結串列的相應操作類似。
- 常見的二元樹類型包括完美二元樹、完全二元樹、完滿二元樹與平衡二元樹。完美二元樹是最理想的狀態，退化成鏈結串列則是最差的狀態。
- 二元樹可以用陣列表示。將節點值和空位依層序走訪的順序排列，再利用父子節點之間的索引對應關係，就能達到指標的作用。
- 二元樹的層序走訪屬於廣度優先搜尋，像一圈一圈向外擴展般逐層走訪，通常用佇列來實作。
- 前序、中序與後序走訪都屬於深度優先搜尋，做法是先沿一條路徑走到底，再回溯繼續走訪，通常用遞迴來實作。
- 二元搜尋樹是能有效率地搜尋元素的資料結構，搜尋、插入與刪除的時間複雜度都是 $O(\log n)$。當二元搜尋樹退化為鏈結串列時，這些操作的時間複雜度都會變差為 $O(n)$。
- AVL 樹是一種平衡二元搜尋樹。即使持續插入或刪除節點，它也能透過旋轉維持平衡。
- AVL 樹的旋轉方式包括右旋、左旋、先右旋再左旋，以及先左旋再右旋。插入或刪除節點後，AVL 樹會由下往上進行旋轉，使樹恢復平衡。

### 2. &nbsp; Q & A

**Q**：如果二元樹只有一個節點，樹高和根節點的深度都是 $0$ 嗎？

是的，因為高度和深度通常都是以沿途經過的邊數來定義。

**Q**：在二元樹中插入與刪除節點通常要搭配「一系列操作」，這是指哪些操作？可以理解為釋放子節點所占用的資源嗎？

以二元搜尋樹為例，刪除節點要分三種情況處理，每一種都需要分好幾個步驟操作節點。

**Q**：為什麼用 DFS 走訪二元樹有前序、中序與後序三種順序？各有什麼用途？

就像陣列可以正向或反向走訪，二元樹也可以用前序、中序、後序三種方式走訪，取得特定順序的結果。例如，在二元搜尋樹中，節點值滿足 `左子節點值 < 根節點值 < 右子節點值`，因此只要依「左 $\rightarrow$ 根 $\rightarrow$ 右」的順序走訪，就能取得排序好的節點序列。

**Q**：右旋處理的是失衡節點 `node`、`child` 和 `grand_child` 之間的關係。那麼，`node` 的父節點與 `node` 原有的連線不用維護嗎？右旋之後，這條連線不就斷了嗎？

可以從遞迴的角度來看。傳給右旋操作 `right_rotate(root)` 的是子樹的根節點，最後 `return child` 會回傳旋轉後的子樹根節點。等函式返回，才將子樹的根接回父節點，這個連接步驟不在右旋操作內。

**Q**：在 C++ 中，將函式分別放在 `private` 和 `public` 有什麼考量？為什麼把 `height()` 函式和 `updateHeight()` 函式分別放在 `public` 和 `private` 中？

主要取決於方法的使用範圍。若只在類別內部使用，就設為 `private`。例如，單獨呼叫 `updateHeight()` 對使用者沒有意義，因為它只是插入或刪除操作中的一個步驟。`height()` 則用來取得節點高度，類似 `vector.size()`，因此設為 `public` 以方便使用。

**Q**：如何用一組輸入資料建立二元搜尋樹？根節點的選擇很重要嗎？

是的。建立樹的方法可見二元搜尋樹程式碼中的 `build_tree()` 方法。至於根節點的選擇，通常會先將輸入資料排序，取中間的元素作為根，再遞迴建立左右子樹。這樣最能讓樹保持平衡。

**Q**：在 Java 中比較字串，一定要使用 `equals()` 方法嗎？

在 Java 中，對於基本資料型別，可以用 `==` 比較兩個變數的值是否相等。如果是參照型別，以下兩種寫法的作用不同。

- `==`：比較兩個變數是否指向同一個物件，也就是它們指向的記憶體位置是否相同。
- `equals()`：比較兩個物件的值是否相等。

因此，若要比較值，應使用 `equals()`。不過，用 `String a = "hi"; String b = "hi";` 初始化的兩個字串都存放在字串常值池中，指向同一個物件，因此在這個例子裡也可以用 `a == b` 比較兩個字串的內容。

**Q**：廣度優先走訪即將處理最底層時，佇列裡有 $2^h$ 個節點嗎？

是的。以高度為 $h = 2$ 的滿二元樹為例，其節點總數為 $n = 7$，最底層的節點數為 $4 = 2^h = (n + 1) / 2$。
