# 二元搜尋樹的中序走訪

## 問題與輸入

本書二元搜尋樹不存重複值；每個節點的左子樹所有值小於該節點值，右子樹所有值大於該節點值。

每個節點都先遞迴走訪比它小的左子樹，再記錄自身，最後走訪比它大的右子樹。根 8 的左子樹先輸出 2、4、6，隨後記錄根 8，右子樹再輸出 10、12、14，由此得到嚴格遞增序列；圖中藍點標記記錄各節點的時機。
