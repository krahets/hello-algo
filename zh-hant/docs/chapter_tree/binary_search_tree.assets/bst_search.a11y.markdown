# 在二元搜尋樹中查詢節點 7

## 問題與輸入

二元搜尋樹中，任意節點的左子樹所有節點值小於該節點值，右子樹所有節點值大於該節點值。連線箭頭從父節點指向子節點。

四層完美二元搜尋樹含節點 1 至 15：根為 8，左、右子節點為 4、12；4 的左、右子節點為 2、6；12 的左、右子節點為 10、14；2 的子節點為 1、3，6 的子節點為 5、7，10 的子節點為 9、11，14 的子節點為 13、15。
