# AVL 樹先右旋後左旋

針對先向右再向左彎折的路徑 3 → 5 → 4，先對 child（5）執行右旋，再對 node（3）執行左旋，使 4 成為區域性新根。

## 問題與輸入

外層根節點為 2，左子節點為 1，右子節點為失衡節點 3；節點 3 只有右子節點 5，節點 5 只有左子節點 4。圖中將失衡節點 3 記為 node，其右子節點 5 記為 child。

## 結構與關係

第一步對 child（節點 5）執行右旋：節點 4 上升為這棵小子樹的根，節點 5 降為 4 的右子節點，節點 3 的右子節點隨之變為 4。如中間子圖所示，原本彎折的路徑被拉直為連續向右傾斜的路徑 3 → 4 → 5。

第二步對原失衡節點 node（節點 3）執行左旋：節點 4 繼續上升為區域性子樹的根，節點 3 降為 4 的左子節點，節點 5 保持為 4 的右子節點。外層父節點 2 的右子節點更新為 4，左子節點 1 保持不變。

這一過程與“先左旋後右旋”互為映象：先糾正子節點子樹的反向彎折，使其與失衡方向一致，再旋轉失衡節點，即可在恢復平衡的同時保持所有節點的大小次序。

## 結果

雙旋完成後，外層根 2 的左、右子節點分別為 1 和 4，節點 4 的左、右子節點分別為 3 和 5；區域性子樹恢復平衡，整棵樹的中序走訪序列保持為 \[1, 2, 3, 4, 5\]。
