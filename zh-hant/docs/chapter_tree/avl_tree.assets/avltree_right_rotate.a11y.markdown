# AVL 樹右旋

對首個失衡節點執行右旋，先重連區域性子樹的父子指標，再將新子樹根接回上層父節點。

## 問題與輸入

初始樹根為 4，左右子節點為 3、5；3 只有左子節點 1，1 只有左子節點 0；0、5 為葉節點。

平衡因子定義為左子樹高度減右子樹高度；高度按邊數計，葉節點高度為 0，空子樹高度為 −1。自底向上檢查時，首個失衡節點是 3，記為 node；其左子節點 1 記為 child。

## 結構與關係

本例中 child（1）的右子樹為空，右旋時 node（3）的左指標因而改為空。若一般情形下 child 帶有非空右子樹 grand\_child，實現中會將它改接到 node 的左側；本組不包含這一非空中間子樹。

## 第 1 步：找到首個失衡節點 3

各節點下方標註平衡因子：葉節點 0、5 為 0，節點 1 為 1，節點 3 與根 4 均為 2。沿左分支自底向上檢查，首先超出平衡範圍的是節點 3，因此優先修復以 3 為根的子樹。

<details><summary>本步完整狀態</summary><p>右旋第 1 步（定位失衡節點）：根 4 的左右子節點為 3、5；3 只有左子節點 1，1 只有左子節點 0。各節點平衡因子依次為：0 為 0，1 為 1，3 為 2，4 為 2，5 為 0。</p></details>

<a id="source-131"></a>

## 第 2 步：標記旋轉的兩個節點

將失衡子樹根 3 記為 node，其左子節點 1 記為 child。本例 child 的右子樹為空，因此旋轉後 node 的左子樹也為空。

<details><summary>本步完整狀態</summary><p>右旋第 2 步（標記旋轉節點）：根 4 的左右子節點仍為 3、5；node 指向 3，child 指向 1，3.left 為 1，1.left 為 0，1.right 為空，樹連線尚未改變。</p></details>

<a id="source-132"></a>

## 第 3 步：形成以 1 為根的區域性子樹

以 child（1）為原點將 node（3）向右旋轉：令 child.right 指向 node（3），並把 node.left 改為原 child.right（本例為空），使 1 的左右子節點分別為 0、3。此時區域性子樹雖已形成，但圖中父節點 4 還未接到新根 1，整次旋轉尚未完成。

<details><summary>本步完整狀態</summary><p>右旋第 3 步（區域性子樹已形成、未接回父節點）：區域性子樹根已是 child（1），1 的左子節點為 0、右子節點為 node（3），0 和 3 為葉節點；但圖中父節點 4 僅連著右子節點 5，還未接到新根 1。原 3 位置處的虛線輪廓僅示意旋轉前的舊位置。</p></details>

<a id="source-133"></a>

## 第 4 步：將新子樹根接回父節點

最後用新子樹根 child（1）替換原 node（3）在父節點 4 下的位置，最後使 4.left 指向 1，完成整次右旋。該子樹高度下降 1，根 4 的左右子樹高度差也恢復到 1 以內。

<details><summary>本步完整狀態</summary><p>右旋第 4 步（接回父節點、旋轉完成）：根為 4；4 左為 1、右為 5，1 左為 0、右為 3，0、3、5 均為葉節點。全樹滿足二元搜尋樹順序與 AVL 平衡條件，中序序列為 [0, 1, 3, 4, 5]。</p></details>

## 結果

旋轉完成後，根為 4；4 左為 1、右為 5，1 左為 0、右為 3，0、3、5 均為葉節點。區域性子樹與整棵樹均恢復平衡，中序序列仍為 \[0, 1, 3, 4, 5\]。
