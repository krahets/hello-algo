# 刪除導致搜尋樹退化

對二元搜尋樹連續刪除一側節點而不做平衡維護，會使子樹高度差超限並退化為單側鏈。

<a id="source-128"></a>

初始根 4 的左右子節點為 2、5，2 的左右子節點為 1、3。先刪去右葉節點 5 後，根 4 的左子樹高度為 1，右子樹為空、高度為 −1，平衡因子為 1 − (−1) = 2，此時即已失衡。再刪去節點 2 的右葉節點 3，便只剩 4 → 2 → 1 的全左鏈。

## 結果

刪除後搜尋樹的數值大小順序仍成立，但樹形會退化為鏈結串列。本圖透過未做旋轉維護的退化過程說明平衡維護的必要性，不代表 AVL 樹完成維護後仍允許失衡。

## 刪除導致搜尋樹退化：動畫

對二元搜尋樹連續刪除一側節點而不做平衡維護，會使子樹高度差超限並退化為單側鏈。

對普通二元搜尋樹依次刪除 5、3，本演示不執行平衡旋轉。節點高度按邊數計，葉節點高度為 0、空子樹高度為 −1；平衡條件要求任意節點左右子樹高度差的絕對值不超過 1。

### 第 1 步：初始平衡樹

根 4 的左、右子樹高度分別為 1、0，平衡因子為 1；節點 2 的左右子樹高度均為 0，全樹各處均平衡。

### 第 2 步：刪除右葉節點 5

刪去 5 後，根 4 的左子樹高度為 1，右子樹為空為 −1，平衡因子變為 1 − (−1) = 2，超出平衡範圍。

### 第 3 步：刪除節點 3 後只剩左鏈

繼續刪去節點 2 的右葉節點 3，使剩餘非葉節點每層都只有左子節點，樹形退化為單側鏈。
