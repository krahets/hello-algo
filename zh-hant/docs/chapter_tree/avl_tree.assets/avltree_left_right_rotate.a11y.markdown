# AVL 樹先左旋後右旋

針對先向左再向右彎折的路徑 3 → 1 → 2，先對 child（1）執行左旋，再對 node（3）執行右旋，使 2 成為區域性新根。

## 問題與輸入

外層根節點為 4，右子節點為 5，左子節點為失衡節點 3；節點 3 只有左子節點 1，節點 1 只有右子節點 2。圖中將失衡節點 3 記為 node，其左子節點 1 記為 child。

## 結構與關係

第一步對 child（節點 1）執行左旋：節點 2 上升為這棵小子樹的根，節點 1 降為 2 的左子節點，節點 3 的左子節點隨之變為 2。如中間子圖所示，原本彎折的路徑被拉直為連續向左傾斜的路徑 3 → 2 → 1。

第二步對原失衡節點 node（節點 3）執行右旋：節點 2 繼續上升為區域性子樹的根，節點 3 降為 2 的右子節點，節點 1 保持為 2 的左子節點。外層父節點 4 的左子節點更新為 2，右子節點 5 保持不變。

對於這種“左-右”彎折形態，若直接對節點 3 做單次右旋，仍會留下新的失衡；只有先透過左旋把區域性形態轉化為“左-左”同向傾斜，再執行右旋，才能讓節點 1、2、3 均勻分佈在兩側。

## 結果

雙旋完成後，外層根 4 的左、右子節點分別為 2 和 5，節點 2 的左、右子節點分別為 1 和 3；區域性子樹恢復平衡，整棵樹的中序走訪序列保持為 \[1, 2, 3, 4, 5\]。

## AVL 樹先左旋後右旋：動畫

當失衡節點 node 的左子樹更高，但左子節點 child 自身的優勢分支卻在右側時，單次右旋無法消除失衡，需要採用“先對 child 左旋、再對 node 右旋”的雙旋操作來恢復平衡。

初始整樹根為 4，左子節點為 3、右子節點為 5；節點 3 的左子節點為 1，節點 1 的右子節點為 2。指標 node 指向失衡節點 3，指標 child 指向其左子節點 1，區域性構成 3→1→2 的折線結構。

動畫分三步展現雙旋全過程：第一步識別 3→1→2 的“左—右”折線形失衡；第二步先在區域性對 child（節點 1）執行左旋，將綠色孫節點 2 提升為 3 的左子節點，把折線轉化為單純左傾鏈 3→2→1；第三步再對 node（節點 3）執行右旋，使節點 2 成為子樹新根。

整個過程中根節點 4 與右子節點 5 保持不動，雙旋重連左子樹內部的父子指標，並將根節點 4 的左子指標接到新子樹根 2，不改變五個節點的中序排列。
