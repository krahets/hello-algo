# AVL 樹的四種失衡形狀與旋轉選擇

左左偏斜用右旋，左右彎折用先左旋後右旋，右左彎折用先右旋後左旋，右右偏斜用左旋。

## 問題與輸入

四幅子圖中，橙色節點 3 均為待修復的失衡節點，藍色節點是它較高一側的子節點，綠色節點標示子樹繼續延伸的方向；灰色圓角背景框圈出需要旋轉調整的區域性失衡子樹。

## 結構與關係

從左到右排列四個旋轉前案例：前兩幅圖的外層根節點均為 4、右子節點為 5，左側掛著以 3 為根的失衡子樹；後兩幅圖的外層根節點均為 2、左子節點為 1，右側掛著以 3 為根的失衡子樹。四種區域性連線形態及下方標註的旋轉方法彙總於資料表。

結合正文選擇規則，設平衡因子 f 為左子樹高度減去右子樹高度：當失衡節點 f &gt; 1（左偏樹）時檢查左子節點，若左子節點 f ≥ 0 則直接右旋，若 f &lt; 0 則先左旋後右旋；當失衡節點 f &lt; −1（右偏樹）時檢查右子節點，若右子節點 f ≤ 0 則直接左旋，若 f &gt; 0 則先右旋後左旋。其中子節點平衡因子等於 0 的情形屬於通用判定條件的一部分（例如刪除節點後可能出現），並非指圖中四個具體子節點的平衡因子都等於 0。

## 結果

先根據失衡節點的平衡因子符號判斷偏向哪一側，再看較高一側子節點是否同向傾斜，即可在單旋與雙旋之間唯一確定修復操作，且旋轉後中序次序不變。
