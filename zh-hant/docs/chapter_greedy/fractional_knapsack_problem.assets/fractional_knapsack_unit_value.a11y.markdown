# 物品在單位重量下的價值

單位價值等於物品價值除以重量；選取其中重量為 w 的一部分時，背包增加的價值為 w 乘以該物品的單位價值。

## 問題與輸入

由於分數背包允許對物品任意切分，衡量一件物品價效比的核心指標不再是整件總價值，而是它在單位重量下的價值（簡稱單位價值）。5 件物品的重量仍為 10、20、30、40、50，價值仍為 50、120、150、210、240。

## 結構與關係

畫面左側為四串列格，在前三列（編號 i、重量 wgt\[i-1\]、價值 val\[i-1\]）右側新增了第 4 列“單位價值 val\[i-1\] / wgt\[i-1\]”；畫面右側給出按所取重量 w 計算背包內增加價值的代數關係式。

左側表格逐行用價值除以重量算出 5 件物品的單位價值：1 號蘋果 50 / 10 = 5，2 號香蕉 120 / 20 = 6，3 號葡萄 150 / 30 = 5，4 號菠蘿 210 / 40 = 5.25，5 號西瓜 240 / 50 = 4.8。右側公式表明：若從第 i 件物品中切取重量 w 放入背包，則“背包內的增加價值 = 當前物品選取重量 w × 當前物品單位價值 (val\[i-1\] / wgt\[i-1\])”。

## 結果

透過單位價值可以直接比較各物品每佔用 1 單位背包容量所帶來的收益：2 號香蕉最高（6），4 號菠蘿次之（5.25），1 號蘋果與 3 號葡萄並列第三（5），5 號西瓜最低（4.8）。
