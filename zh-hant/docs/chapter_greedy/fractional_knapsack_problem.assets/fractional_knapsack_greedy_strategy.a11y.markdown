# 分數背包問題的貪婪策略

將五件物品按單位價值從高到低重排為香蕉（6）、菠蘿（5.25）、蘋果（5）、葡萄（5）、西瓜（4.8），確立優先選取高單位價值物品的貪婪次序。

## 問題與輸入

最大化限定容量下的背包總價值，本質上是讓每一單位背包容量儘可能裝入單位價值最高的物品。因此，分數背包的貪婪策略需要先對所有候選物品按單位價值降序排序。

經過按單位價值降序排序，表格自上而下的物品順序由原編號 1、2、3、4、5 變為 2 號香蕉（重 20、價值 120、單位價值 6）、4 號菠蘿（重 40、價值 210、單位價值 5.25）、1 號蘋果（重 10、價值 50、單位價值 5）、3 號葡萄（重 30、價值 150、單位價值 5）、5 號西瓜（重 50、價值 240、單位價值 4.8）。走訪時每輪優先拿取當前單位價值最高的物品，若剩餘容量不足以裝下整件，則切取一部分將背包填滿。

## 結果

按排定的優先順序 \[2 號香蕉, 4 號菠蘿, 1 號蘋果, 3 號葡萄, 5 號西瓜\] 依次貪婪裝包：在容量 50 的例項中，先全取排名第一的香蕉（重 20），再取排名第二的菠蘿的一部分（重 30）填滿剩餘容量，即可直接求得全域性最大價值 277.5。
