# 切分可使乘積不減

當整數因子 n ≥ 4 時，將其切分為 2 和 n - 2 後的乘積滿足 2(n - 2) ≥ n（n = 4 時相等，n &gt; 4 時嚴格變大），說明所有大於等於 4 的因子都可繼續切分。

## 問題與輸入

給定整數 n ≥ 2，將其切分為至少兩個正整數之和，並在總和固定為 n 的條件下最大化各段的乘積。

為確定最大切分乘積的貪婪策略，首先考察：一個較大的正整數因子是否應該繼續切分？為此比較原整數 n 與從中切出一個因子 2 後的乘積 2(n - 2)。

## 結構與關係

畫面上方為表示長度 n 的灰色長條；下方等長條在左側切出一段綠色短條“2”，右側剩餘藍色長條標註“n - 2”，分界處有豎直虛線對齊；圖下方給出推導結論：“當 n ≥ 4 時，恆有 2(n - 2) ≥ n，因此最終切分方案只應存在 1, 2, 3 因子”。

把長度為 n 的整數條切分為長度 2 和長度 n - 2 兩段後，比較切分前後的數值：由不等式 2(n - 2) ≥ n 解得 n ≥ 4。注意在邊界 n = 4 時，2 × (4 - 2) = 4，切分前後乘積相等；當 n &gt; 4 時，2(n - 2) &gt; n，切分後乘積嚴格變大。因此任何大於等於 4 的因子都可以繼續向下切分而不損失乘積，直至所有因子均屬於 {1, 2, 3}。

## 結果

只要切分方案中存在大於等於 4 的因子，就總能將其拆成 2 和 n - 2 而使乘積不減（n = 4 時乘積保持 4 不變，n &gt; 4 時乘積嚴格增大），因此必然存在僅由 1、2、3 三種因子組成的最優切分方案。
