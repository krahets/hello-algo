# 最大切分乘積的問題定義

將正整數 n 切分為至少兩個正整數因子之和（n₁ + n₂ + … + nₘ = n），在總和固定為 n 的條件下求所有因子乘積的最大值。

## 問題與輸入

最大切分乘積問題要求：給定一個正整數 n（n ≥ 2），將其拆分為 m 個（m ≥ 2）正整數的和 n = n₁ + n₂ + … + nₘ，最大化這 m 個切分因子的乘積 n₁ × n₂ × … × nₘ。

上方完整灰條代表待切分的正整數 n，下方等長條被切分為 m 個正整數因子 n₁、n₂、n₃、…、nₘ₋₂、nₘ₋₁、nₘ（中間省略號代表任意切分段數）。因為各段首尾相連後的總長度與上方 n 完全對齊，即加和恆為 n，在此約束下求解乘積 n₁ × n₂ × … × nₘ 的最大值。

## 結果

問題需要在滿足 n₁ + n₂ + … + nₘ = n（m ≥ 2）的前提下，同時決定切分段數 m 與每一段的正整數大小 nᵢ，使各段連乘積達到最大（本圖為通用符號定義，未指定具體的 n 數值）。
