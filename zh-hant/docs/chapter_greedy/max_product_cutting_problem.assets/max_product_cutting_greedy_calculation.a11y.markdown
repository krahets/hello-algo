# 最大切分乘積的計算方法

透過整除與取模將 n 寫成 3×a+b 並按餘數分類調整切分；邊界 n=2、3 須單獨滿足至少切分為兩段的要求。

## 問題與輸入

給定整數 n ≥ 2，要求將其切分為至少兩個正整數之和，並在總和固定為 n 的條件下最大化各段乘積。

既然貪婪最優策略是儘可能多地切出因子 3，程式碼實現便無需迴圈逐段切分，而是直接利用向下整除 a = n // 3 與取模 b = n % 3，一步算出可切出的 3 的個數 a 與餘數 b。

## 結構與關係

圖中把總長為 n 的整條分解為 a 個長度為 3 的段與一段“餘數 b”，下方給出代數恆等式 n = 3 × a + b（其中 a = n // 3，b = n % 3，餘數 b 只可能是 0、1、2）。注意圖中將“餘數 b”畫在左側僅作符號分解示意，並未指定具體 n 或 b 的數值，也不代表按從左到右順序執行切分。

結合正文與程式碼的分類規則，首先單獨處理必須“至少切分為兩段”的邊界情況：n = 2 只能切為 1 + 1（乘積 1），n = 3 的最優切分為 1 + 2（乘積 2），即 n ≤ 3 時直接返回 1 × (n - 1)。當 n ≥ 4 時按餘數 b 分為三類：若 b = 0，全部使用 a 個因子 3，乘積為 3^a；若 b = 2，保留餘數 2 不再拆分，乘積為 3^a × 2；若 b = 1，由於 1 × 3 = 3 &lt; 2 × 2 = 4，需退回一個 3 與餘數 1 重組為 2 + 2。

在餘數 b = 1 的重組中，將“一個 3 與餘數 1”改為“2 + 2”後，該部分長度總和仍為 4（全段總和保持 n 不變），區域性乘積從 3 提升到 4，而因子 3 的個數從 a 減少 1 個變為 a−1，故最大乘積公式為 3^(a−1) × 2 × 2。表中彙總了邊界與三種餘數的完整計算規則。

## 用商 a 與餘數 b 直接分類計算最大切分乘積

圖面建立 n = 3 × a + b 的通用商餘分解；結合正文規則，邊界 n = 2、3 單獨滿足至少兩段限制，n ≥ 4 且餘數 b = 1 時將最後一個 3 與 1 重組為 2 + 2。

## 結果

先判斷邊界 n = 2（返回 1）與 n = 3（返回 2）；當 n ≥ 4 時由 a = n // 3、b = n % 3 按餘數查表：b = 0 返回 3^a，b = 1 將一個 3 與 1 重組為 2 + 2 返回 3^(a−1) × 2 × 2，b = 2 返回 3^a × 2。
