# 15.5 &nbsp; 小結

### 1. &nbsp; 重點回顧

- 貪婪演算法通常用來解決最佳化問題。它在每個決策階段做出局部最佳的選擇，希望藉此得到全域最佳解。
- 貪婪演算法反覆進行貪婪選擇，每一輪都將問題化為規模更小的子問題，直到解決整個問題。
- 貪婪演算法不但容易實作，解題效率也很高，時間複雜度通常比動態規劃更低。
- 在零錢兌換問題中，有些硬幣面額組合能保證用貪婪演算法找到最佳解；換成其他組合時，貪婪演算法卻可能得到很差的解。
- 適合用貪婪演算法求解的問題具備兩項性質：貪婪選擇性質與最佳子結構。具備貪婪選擇性質，表示貪婪策略有效。
- 對某些複雜問題來說，要證明貪婪選擇性質成立並不簡單。相比之下，舉反例推翻它比較容易，零錢兌換就是一例。
- 用貪婪法解題主要分三步：分析問題、決定貪婪策略，以及證明正確性。決定策略是核心步驟，證明正確性往往最難。
- 分數背包問題延伸自 0-1 背包問題，允許只取物品的一部分，因此可以用貪婪演算法求解。這個貪婪策略的正確性可以用反證法證明。
- 最大容量問題可以用列舉法求解，時間複雜度為 $O(n^2)$。若採用貪婪策略，每一輪都將較矮隔板的指標往內移，就能將時間複雜度降到 $O(n)$。
- 在最大切分乘積問題中，我們先後推導出兩個貪婪策略：$\geq 4$ 的整數都應繼續切分，最佳切分因子為 $3$。程式碼使用了次方運算，因此時間複雜度取決於次方運算的實作方式，通常為 $O(1)$ 或 $O(\log n)$。
