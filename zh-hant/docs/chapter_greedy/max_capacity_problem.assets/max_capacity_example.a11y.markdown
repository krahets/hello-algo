# 兩根隔板的最大容量

選擇兩根隔板組成容器，容量由較短隔板的高度與兩板間距的乘積決定，目標是找到容量最大的組合。

## 問題與輸入

最大容量問題給定長度為 8 的垂直隔板高度陣列 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]（索引 0 至 7）。任選兩根隔板 \[i, j\] 圍成容器時，容器寬度為兩板索引之差 j - i，盛水高度由兩板中較短的那根決定（即 min(ht\[i\], ht\[j\])，中間隔板不會阻擋或縮減該定義下的盛水面積）。

## 結構與關係

畫面縱軸標示隔板高度 0 至 8，橫軸標示陣列索引 0 至 7，各索引位置立有對應高度的柱狀隔板。其中索引 1（高 8）和索引 5（高 7）兩根隔板及底部橫軸區間被深色高亮，兩板之間高為 7、寬為 4 的矩形盛水區域以淺藍色半透明填充，左側縱軸高度 7 處以藍紫色“短板”文字和水平虛線標出水位上限。

在 8 根隔板 ht = \[3, 8, 5, 2, 7, 7, 3, 4\] 中，選中索引 1（高度 8）作為左壁、索引 5（高度 7）作為右壁：兩板間距寬度為 5 - 1 = 4，盛水高度受較矮的右壁（短板）限制為 min(8, 7) = 7，因此淺藍色盛水區域的容量達到最大值 (5 - 1) × 7 = 28。

## 結果

該示例陣列的最大盛水容量為 (5 - 1) × 7 = 28，由索引 1 和索引 5 兩根隔板圍成。
