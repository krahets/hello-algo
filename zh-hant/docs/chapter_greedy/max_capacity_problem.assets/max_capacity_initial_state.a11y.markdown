# 容器雙指標的初始狀態

雙指標初始分列陣列兩端 i = 0（短板高 3）和 j = 7（長板高 4），圍成的初始容器寬度為 7、水位高為 3，當前容量為 21。

## 問題與輸入

為探究雙指標貪婪策略的移動方向，對同一高度陣列 ht = \[3, 8, 5, 2, 7, 7, 3, 4\] 考察兩指標分別位於左右兩端的初始狀態 \[i, j\] = \[0, 7\]，用作後續比較“向內移動長板”與“向內移動短板”的基準。

## 結構與關係

畫面索引 0 的隔板上方標有左指標 i，對應隔板高度 ht\[0\] = 3；索引 7 的隔板上方標有右指標 j，對應隔板高度 ht\[7\] = 4。兩端的隔板高亮，橫跨索引 0 至 7、高度齊平左端短板 3 的淺藍色矩形表示當前盛水區域，圖下方標註“i 為短板，j 為長板”及當前容量算式。

<a id="source-466"></a>

左指標 i = 0 指向高度 3 的隔板，右指標 j = 7 指向高度 4 的隔板；由於 ht\[0\] = 3 &lt; ht\[7\] = 4，左板 i 為決定水位上限的短板，右板 j 為長板。此時容器寬度為 7 - 0 = 7，有效水高為 min(3, 4) = 3，算得當前容量 cap = min(3, 4) × (7 - 0) = 21。

## 結果

初始狀態 \[0, 7\] 的容器容量為 min(3, 4) × (7 - 0) = 21；這是雙指標搜尋的起點狀態，而非全陣列的最大容量。
