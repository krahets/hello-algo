# 最大容量：雙指標貪婪

雙指標從陣列兩端 \[0, 7\] 出發，每輪計算當前容器容量並更新歷史最大值 res，隨後向內移動短板指標，直至兩指標在索引 1 相遇並返回最大容量 28。

## 問題與輸入

給定高度陣列 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]（索引 0 至 7），容器容量為 cap\[i, j\] = min(ht\[i\], ht\[j\]) × (j - i)。

雙指標貪婪演算法初始化左指標 i = 0、右指標 j = 7、最大容量記錄 res = 0。當 i &lt; j 時迴圈執行：先計算當前容量 cap 並用 res = max(res, cap) 更新全域性最大值，然後比較左右兩板高度，將較短一側的指標向內移動一格，直到 i 與 j 相遇時跳出迴圈。
