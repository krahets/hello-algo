# 容器向內移動長板

保持短板不動而將長板向內移動，只會縮短容器寬度且無法提高水位上限，容量不能增大；本例容量從 21 降至 18。

## 問題與輸入

高度陣列為 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]。初始狀態 i = 0（短板高 3）、j = 7（長板高 4），容量為 21。本圖在保持左端短板不動的前提下，將右端長板向內移動一格，考察這一區域性操作為何不能改善當前容量。

## 結構與關係

畫面中左指標仍停在 i = 0（高度 3），右指標由索引 7 向左移動一格至 j = 6（高度 ht\[6\] = 3，原索引 7 的隔板變回普通未選中灰柱）。淺藍色盛水區域隨之縮窄為橫跨索引 0 至 6、高度為 3 的矩形，圖下方標註“向內移動長板，容量一定減小”及更新後的容量算式。

將右側長板指標 j 從索引 7 左移到索引 6 後，新右板高度為 ht\[6\] = 3，與左端短板 ht\[0\] = 3 相等。此時有效水位高度 min(3, 3) = 3 並未突破原短板上界，但容器底寬已從 7 - 0 = 7 縮短為 6 - 0 = 6，導致當前容量變為 cap = min(3, 3) × (6 - 0) = 18，比移動前的 21 減少了 3。

## 結果

向內移動長板 j 後，容器寬度必然嚴格減小（從 7 減為 6），而盛水高度仍受原地未動的左端短板 ht\[0\] = 3 限制（至多不變或變得更矮），因此容量由 21 下降到 18。因此，保留當前短板並只內移另一端，不能得到比當前狀態更大的容量；貪婪搜尋可捨棄保留此短板的這些狀態，轉而內移短板。此處 18 是區域性比較值，不是全陣列最終最優值。
