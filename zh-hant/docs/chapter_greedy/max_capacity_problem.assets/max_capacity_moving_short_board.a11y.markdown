# 容器向內移動短板

向內移動短板可能提高容器高度，從而增大容量；本例容量從 21 增至 24。

## 問題與輸入

在高度陣列 ht = \[3, 8, 5, 2, 7, 7, 3, 4\]（索引 0 至 7）中，容器容量定義為 cap\[i, j\] = min(ht\[i\], ht\[j\]) × (j - i)。

與前文從初始狀態 \[0, 7\]（端板高 3 和 4，容量 21）向內移動長板導致容量必然減小相對照，本圖演示從同一初始狀態出發向內移動短板指標 i 後的單步狀態變化。

## 結構與關係

畫面中右指標保持在 j = 7（高度 4），左指標從索引 0 向右移動一格至 i = 1（高度 ht\[1\] = 8，原索引 0 的隔板恢復為未選中灰柱）。此時左板高度 8 超過右板高度 4，新的短板轉移到右端 j = 7；橫跨索引 1 至 7、高度齊平右板 4 的淺藍色矩形表示更新後的盛水區域，圖下方標註“向內移動短板，容量可能增大”及當前容量算式。

將左端原短板指標 i 從索引 0（高度 3）右移至索引 1（高度 8），右指標仍為 j = 7（高度 4）。此時容器寬度由 7 - 0 = 7 縮窄為 7 - 1 = 6，但決定水位的短板高度由 min(3, 4) = 3 上升為 min(8, 4) = 4，高度增益超過了寬度損失，算得當前容量 cap = min(8, 4) × (7 - 1) = 24，高於初始狀態的 21。

## 結果

向內移動短板後，雖然容器寬度縮減了 1（從 7 變為 6），但由於新換入的左板高度達到 8，有效盛水高度由 3 提升至 4，使本例容量從 21 增大到 24。需注意這隻說明向內移動短板“有可能”使容量變大（並非每次移動短板都會增大），且 24 也還不是全陣列的最終最大容量 28。
