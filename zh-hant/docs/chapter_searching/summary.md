# 10.6 &nbsp; 小結

### 1. &nbsp; 重點回顧

- 二分搜尋利用資料已排序的特性，每一輪將搜尋區間縮小一半，逐步找出目標。輸入資料必須已排序，而且這種方法只適用於陣列或以陣列實作的資料結構。
- 暴力搜尋藉由走訪資料結構來找出資料。循序搜尋適用於陣列和鏈結串列，廣度優先搜尋和深度優先搜尋則適用於圖和樹。這類演算法適用範圍廣，無須事先處理資料，但時間複雜度 $O(n)$ 較高。
- 雜湊搜尋、樹搜尋和二分搜尋都能在特定資料結構中快速找出目標元素。這類演算法效率高，時間複雜度可達 $O(\log n)$，甚至是 $O(1)$，但通常需要額外的資料結構。
- 實際選擇搜尋方法時，應考量資料量、搜尋效能需求，以及查詢和更新資料的頻率等因素。
- 循序搜尋適合資料量小或經常更新的情況。二分搜尋適合大量且已排序的資料。雜湊搜尋適合要求查詢效率且無須範圍查詢的情況。若資料量大、會動態更新，且需要維持順序並支援範圍查詢，則適合採用樹搜尋。
- 以雜湊搜尋取代循序搜尋，是縮短執行時間的常見策略，可以將時間複雜度從 $O(n)$ 降為 $O(1)$。
