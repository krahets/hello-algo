# 二分搜尋

在升序陣列中查詢目標值 6，每輪比較中點元素後排除不可能包含目標的一半區間。

## 問題與輸入

輸入為含 10 個互異元素的升序陣列 \[1, 3, 6, 8, 12, 15, 23, 26, 31, 35\]，索引為 0 至 9，查詢目標值 target = 6；各索引與元素值的對應關係見輸入表。

指標 i、j 分別表示當前搜尋閉區間 \[i, j\] 的左、右邊界（兩端點均包含在搜尋範圍內）；m 表示區間中點索引，按 (i + j) / 2 向下取整計算。每輪先計算中點 m，再比較 nums\[m\] 與目標值。
