# 二分搜尋的區間約定

右邊界指標 j 是否包含在搜尋區間內，直接決定 j 的初始值、迴圈終止條件以及向左收縮時的賦值方式。

## 問題與輸入

示意升序陣列包含 n = 10 個元素，索引為 0 至 9；指標 i、j 分別標識當前搜尋區間的左、右邊界，m 表示當前折半中點索引。圖中柱高僅示意元素單調遞增，未標註具體元素數值。

## 結構與關係

左半幅展示“雙閉區間 \[i, j\]”（左右邊界都包含自身）：初始化指標為 i = 0, j = n - 1（即 j = 9，指向最後一根柱子）；當 i = j 時區間內仍含一個待查元素，直到 i &gt; j 時搜尋區間才為空。

右半幅展示“左閉右開區間 \[i, j)”（左邊界包含自身、右邊界不包含自身）：初始化指標為 i = 0, j = n（即 j = 10，指向陣列最右端外側的排除位置）；當 i = j 時區間已經為空，因此迴圈終止條件為 i ≥ j。

在縮小區間操作上：若中點值小於目標，兩種寫法都已排除 m 及其左側，左邊界均更新為 i = m + 1；若中點值大於目標，雙閉區間需將右邊界設為包含在內的 j = m − 1，而左閉右開區間由於本身不包含右端點 j，需將右邊界設為 j = m。完整對照見附表。

## 雙閉區間與左閉右開區間

左右兩圖的藍色虛線框都恰好框住索引 0 至 9 的十個元素，但左圖雙閉區間的右指標 j 指向索引 9（包含該位置），右圖左閉右開區間的右指標 j 指向越界的索引 10（排除該位置），下方四行文字逐項列出由此決定的演算法規則差異。

## 結果

雙閉區間 \[i, j\] 與左閉右開區間 \[i, j) 都能正確實現二分搜尋，但初始化指標、迴圈終止條件與縮小區間操作必須嚴格配套使用；雙閉區間左右收縮對稱（i = m + 1 與 j = m − 1），通常更不易出錯。
