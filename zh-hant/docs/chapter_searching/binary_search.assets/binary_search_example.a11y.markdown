# 二分搜尋示例資料：在十個升序元素中定位 target = 6

有序陣列 nums 從 1 嚴格遞增到 35，目標值 target = 6 位於索引 2。

## 問題與輸入

給定嚴格遞增的有序陣列 nums = \[1, 3, 6, 8, 12, 15, 23, 26, 31, 35\]，索引從 0 到 9，查詢目標元素 target = 6。

## 結構與關係

畫面上半部分“使用柱狀圖表示陣列”：從左到右排列十根高度遞增的豎柱，每根柱子頂部標出對應元素值；柱狀圖下方標出從 0 到 9 的“索引”；下半部分用十個橫向連續的陣列方格展示同一陣列。上下兩部分之間由雙向箭頭連線，表明柱狀圖與一維陣列完全等價。

位於索引 2 的元素 6 在上方柱狀圖和下方陣列方格中都用青色高亮標出：其左側是索引 0、1 的較小元素 1、3，右側依次是索引 3 至 9 的較大元素 8、12、15、23、26、31、35。本圖僅定義輸入資料與查詢目標，尚未展開二分折半步驟。

## 用柱狀圖與陣列方格對照展示二分搜尋輸入

上方柱狀圖透過柱高直觀反映陣列單調遞增，柱狀圖下方給出 0 至 9 的索引，下半部分用陣列方格顯示對應元素；兩處同步用青色突出索引 2 的目標元素 target = 6。

## 結果

目標元素 target = 6 在有序陣列中的位置索引為 2，二分搜尋成功後應返回索引 2。
