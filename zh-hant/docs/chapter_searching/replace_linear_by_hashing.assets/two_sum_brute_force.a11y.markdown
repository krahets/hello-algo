# 線性查詢求解兩數之和：兩層迴圈列舉不同索引組合

對陣列 nums = \[2, 7, 11, 15\] 與 target = 13，列舉不同位置的配對，由 2 + 11 = 13 找到索引組合 \[0, 2\]。

## 問題與輸入

給定整數陣列 nums = \[2, 7, 11, 15\]（索引從 0 到 3）與目標和 target = 13。

題目要求找出和為 target 的兩個不同陣列位置並返回它們的索引（同一個位置的元素不能重複使用兩次）。暴力解法透過外層索引 i 與內層索引 j（j &gt; i）開啟兩層迴圈，逐對檢查兩數之和。

## 結構與關係

畫面下方的四行四列矩陣以行頭和列頭分別列出 2、7、11、15，僅在主對角線右上方的上三角區域填入六個候選和：既排除了主對角線上同一位置與自身相加的情況，也省去了左下角交換相加次序的重複配對。六組候選和見附表。

矩陣中第 0 行（元素 2）與第 2 列（元素 11）交叉處的單元格 13 用紫藍色文字標出。按照程式碼從左到右的列舉順序，外層固定 i = 0（元素 2）後，內層先算 2 + 7 = 9，緊接著算到 2 + 11 = 13 即命中目標並直接返回 \[0, 2\]；圖中將其餘候選和一併畫出僅用於展示完整的組合空間，並不代表命中後仍需繼續算完後續組合。

## 走訪兩數配對的上三角表，定位 2 + 11 = 13

上三角矩陣展示六個不重複位置配對的求和結果，其中元素 2（索引 0）與元素 11（索引 2）交叉處的和為 13（紫藍色文字），滿足 target = 13。

## 結果

命中 2 + 11 = 13，返回索引組合 \[0, 2\]。兩層迴圈暴力列舉的時間複雜度為 O(n²)，空間複雜度為 O(1)，屬於“以時間換空間”的解法。
