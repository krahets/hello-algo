# 用半整數查詢左右邊界

在有序整數陣列中，分別查詢整數 target 減 0.5 與加 0.5 對應的半整數，由查詢結束時的指標 i、j 定位左右邊界；返回前須確認索引有效且對應元素等於 target。

## 問題與輸入

有序整數陣列為 nums = \[1, 3, 6, 6, 6, 6, 6, 10, 12, 15\]，目標元素 target = 6（佔據索引 2 至 6）。由於陣列中全是整數，構造出的半整數 target - 0.5 = 5.5 與 target + 0.5 = 6.5 必然不在陣列中。

## 結構與關係

當使用雙閉區間二分搜尋一個陣列中不存在的目標值時，迴圈無需處理相等分支，最終搜尋區間為空時，指標 i 必指向首個大於該目標的元素，指標 j 必指向最右一個小於該目標的元素。若不存在更大的元素，i = n；若不存在更小的元素，j = −1，此時對應指標位於陣列外。

畫面左側展示“查詢最左一個 target”等價於“查詢 target - 0.5”（即 5.5）：查詢結束時 j = 1（指向 3），i = 2（指向首個大於 5.5 的元素，即最左一個 6），返回 i = 2 即得左邊界。畫面右側展示“查詢最右一個 target”等價於“查詢 target + 0.5”（即 6.5）：查詢結束時 j = 6（指向最右一個小於 6.5 的元素，即最右一個 6），i = 7（指向 10），返回 j = 6 即得右邊界。

該方法依賴輸入陣列僅含整數的前提（若原陣列本身包含小數，則 ±0.5 可能與已有元素碰撞而失效）；通用實現中若原陣列可能不含 target，返回前仍需校驗索引不越界且對應元素值等於 target。

## 結果

對整數陣列分別查詢 5.5 和 6.5，迴圈結束時取左圖的 i = 2 與右圖的 j = 6，即可得到重複元素 6 的左邊界 2 與右邊界 6。
