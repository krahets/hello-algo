# 硬碟、記憶體和快取之間的資料流通

硬碟、記憶體與快取分層協作以兼顧儲存容量和訪問速度：執行所需資料從硬碟讀入記憶體，再由快取為處理器提供更快的訪問。

## 問題與輸入

圖從左到右依次排列 CPU、記憶體和硬碟。左側綠色圓角框代表 CPU，內部左側是“處理器”圖示，右側是“快取”圖示。處理器與快取之間、快取與記憶體之間、記憶體與硬碟之間，都畫有一左一右兩條反向的平行箭頭，表示雙向資料讀寫。

## 結構與關係

在 CPU 框上方，還有兩條跨過快取的折線箭頭直接連線“處理器”與“記憶體”（一條由處理器指向記憶體，一條由記憶體指向處理器），表明處理器既可透過快取高速訪問資料，也可與記憶體直接互動。

結合正文，程式執行時資料從硬碟讀入記憶體；快取位於 CPU 內，從記憶體載入常訪問的資料和指令供處理器高速讀寫，從而減少直接訪問較慢記憶體的次數。

## 結果

硬碟負責長期儲存，記憶體承載執行中的資料，CPU 內的快取為處理器提供高速資料緩衝，三者協同完成資料流通。
