# 計算機儲存系統的金字塔層級

從頂到底依次為 CPU 內的 L1、L2、L3 快取，以及記憶體（RAM）和硬碟（HDD/SSD），體現速度與容量、成本的權衡。

## 問題與輸入

中央金字塔從上到下由窄變寬，共分五層：前三層為 L1 Cache、L2 Cache、L3 Cache，左側迴類別為“快取”，上方由綠色邊框迴入“CPU”內部；第四層為 RAM，左側標為“記憶體”；最底層為 HDD/SSD，左側標為“硬碟”。

## 結構與關係

金字塔右側有兩條方向相反的縱向箭頭：向上箭頭旁標“速度、價格”，表示越靠近頂端的儲存層級，訪問速度越快、單位容量價格越高；向下箭頭旁標“容量、永續性”，表示越靠近底端的儲存層級，容量越大，且到底層硬碟（HDD/SSD）具備斷電後長期儲存資料的永續性（快取與記憶體屬於易失性儲存，斷電後資料會丟失）。

金字塔從頂到底由窄變寬分為五層：位於 CPU 綠色框內的 L1 Cache、L2 Cache、L3 Cache（左側統稱“快取”），其下的 RAM（“記憶體”），以及最底層的 HDD/SSD（“硬碟”）。右側向上箭頭標“速度、價格”，說明越往上訪問越快、單位容量成本越高；向下箭頭標“容量、永續性”，說明越往下容量越大，且底層硬碟能夠在斷電後持久儲存資料，而上方的快取和記憶體斷電後資料會丟失。

## 結果

多層級儲存結構在高速低容量的快取、中等速度與容量的記憶體、大容量可持久化的硬碟之間取得速度、容量與成本的平衡。
