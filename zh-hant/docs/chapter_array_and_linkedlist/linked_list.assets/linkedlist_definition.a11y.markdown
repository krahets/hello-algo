# 鏈結串列的節點與連線

節點用引用連線成序列，儲存位置無須連續。

## 結構與關係

邏輯檢視與記憶體網格展示的是同一條鏈結串列，並非兩份獨立資料。網格中每個節點佔相鄰兩格，分別存放節點值與後繼引用（指標），其餘淺色格為可用空間；格子大小僅為示意。

<a id="source-50"></a>

鏈結串列從頭節點 1 沿 next 引用依次連線到 3、2、5、4，尾節點 4 指向 None。每個節點包含值和指向下一節點的引用，例如節點 3 的值為 3，其 next 指向節點 2。記憶體示意中，節點 4 位於上方，而排在它前面的節點 2 和 5 位於下方，說明走訪順序由 next 引用決定，與物理儲存位置無關。

## 結果

鏈結串列節點可分散存放，依靠 next 引用保持邏輯順序；每個節點需要額外的引用儲存空間。
