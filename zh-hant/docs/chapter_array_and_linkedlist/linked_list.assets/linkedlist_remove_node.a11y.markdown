# 鏈結串列刪除節點

修改前驅節點的後繼引用，繞過待刪除節點。

<a id="source-52"></a>

已知前驅節點 n0（值為 1）、待刪節點 P（值為 0）及後繼節點 n1（值為 3），原連線為 n0 → P → n1 → 後續節點。執行 n0.next = n1 後，從入口 n0 出發會直接到達 n1，從而繞過 P。此時 P.next 雖仍指向 n1，但從鏈結串列入口已無法訪問 P；圖中保留 P 的虛線框僅作對比示意，不表示它仍在鏈結串列中，也未展示記憶體釋放。

## 鏈結串列刪除節點：動畫

修改前驅節點的後繼引用，繞過待刪除節點。

區域性鏈結串列為 n0(1) → P(0) → n1(3) → …；已知前驅節點 n0，目標是刪除節點 P。

刪除操作透過改變前驅引用使目標節點從入口不可達。節點 P 自身的 next 引用仍可指向 n1，不能據此認為 P 仍在鏈結串列中；圖中未展示記憶體釋放。

### 第 1 步：刪除前：n0 → P → n1

初始狀態下 n0.next 指向 P，P.next 指向 n1，從 n0 出發需經過 P 才能到達 n1。接下來準備將 n0.next 改指 n1。

<details><summary>本步完整狀態</summary><p>當前區域性鏈結串列為 n0(1) → P(0) → n1(3) → 後續節點；n0.next 指向 P，P.next 指向 n1，n0、P、n1 均從入口 n0 可達。</p></details>

### 第 2 步：改接引用：n0.next = n1

將前驅 n0 的後繼引用直接指向 n1，主鏈隨即跳過 P。此時 P.next 雖仍指向 n1，但從入口 n0 已無法訪問 P，邏輯刪除完成。

<details><summary>本步完整狀態</summary><p>已執行 n0.next = n1，主鏈變為 n0(1) → n1(3) → 後續節點；節點 P(0) 的 P.next 仍指向 n1，但 P 已從入口 n0 不可達（已知前驅 n0 時改接為 O(1)）。</p></details>

### 結果

在已知前驅節點 n0 的前提下，僅需 O(1) 時間改接一次引用即可完成刪除，其餘節點無須移動；查詢前驅的耗時不計入此步。圖中未清空 P.next，也未展示記憶體釋放。
