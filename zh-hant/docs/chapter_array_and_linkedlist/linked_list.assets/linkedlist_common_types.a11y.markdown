# 三種常見鏈結串列型別

以同一組節點 1、3、2、5、4 對比單向鏈結串列、環形鏈結串列和雙向鏈結串列的連線方式。

## 問題與輸入

畫面從上到下分三行對比三種常見鏈結串列結構，每一行都包含按相同順序排列的五個節點 1、3、2、5、4，區別僅在於節點間及首尾兩端的引用連線方式。

## 結構與關係

上方為“單向鏈結串列（singly linked list）”：節點依次為 1 → 3 → 2 → 5 → 4 → None。每對相鄰節點之間只有一條向右的後繼箭頭，尾節點 4 指向空值 None，只能從頭到尾單向走訪。

中間為“環形鏈結串列（circular linked list）”：節點同樣依次為 1 → 3 → 2 → 5 → 4，但尾節點 4 的箭頭不再指向 None，而是經下方折線回到首個節點 1，形成首尾相接的閉環。在環形鏈結串列中，任意節點都可視作頭節點。

下方為“雙向鏈結串列（doubly linked list）”：表示為 None ← 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4 → None。每對相鄰節點之間都有向右（next，指向後繼）和向左（prev，指向前驅）兩條方向相反的箭頭，頭節點 1 的前驅指向左側 None，尾節點 4 的後繼指向右側 None，支持向前和向後雙向走訪。

圖從上到下用節點 1、3、2、5、4 對比三種鏈結串列：上方單向鏈結串列為 1 → 3 → 2 → 5 → 4 → None，僅含向後的單向箭頭，尾節點指向 None；中間環形鏈結串列為 1 → 3 → 2 → 5 → 4，並由尾節點 4 的折線箭頭連回節點 1，實現首尾相接；下方雙向鏈結串列為 None ← 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4 → None，相鄰節點間同時具有向前和向後的雙向箭頭，頭節點 1 的前驅與尾節點 4 的後繼均指向 None。

## 結果

單向鏈結串列單向連線至 None，環形鏈結串列首尾相接成環，雙向鏈結串列同時維護前驅與後繼引用以支持雙向走訪。
