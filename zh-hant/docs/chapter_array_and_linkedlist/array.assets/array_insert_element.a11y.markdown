# 在陣列中插入元素

在索引 1 處插入元素 3：先從末端開始將原有元素依次向右複製一位，再寫入新元素。

## 問題與輸入

陣列 nums 共有 5 個槽位，索引為 0 至 4。初始儲存為 \[1, 2, 5, 4, 0\]，其中只有前 4 個元素 \[1, 2, 5, 4\] 有效，末尾索引 4 的 0 是無意義的佔位值。目標是在索引 1 處插入 3，並保持原有有效元素的相對順序。

為騰出索引 1，演算法從有效序列末端開始倒序複製：先把索引 3 的 4 複製到索引 4（nums\[4\] = nums\[3\]），再把索引 2 的 5 複製到索引 3（nums\[3\] = nums\[2\]），最後把索引 1 的 2 複製到索引 2（nums\[2\] = nums\[1\]）；隨後在索引 1 寫入 3（nums\[1\] = 3）。從末端向插入點倒序複製，能保證每個即將被覆蓋、仍需保留的有效元素都已提前複製到右側相鄰格，避免從左向右移動時覆蓋尚未儲存的元素。賦值操作不會清空源槽位，因此過程中會暫時出現重複數值。在陣列中間插入平均需移動 O(n) 個元素；若原本 5 個槽位全部有效，這種定長覆蓋會丟失末尾有效元素，需先擴容或拒絕插入。

## 結果

插入完成後陣列為 \[1, 3, 2, 5, 4\]，有效元素數量由 4 增至 5。被覆蓋的是末尾無意義的佔位值 0，四個原有有效元素均未丟失。

陣列 nums 共有 5 個槽位，索引為 0 至 4。初始儲存為 \[1, 2, 5, 4, 0\]，其中只有前 4 個元素 \[1, 2, 5, 4\] 有效，末尾索引 4 的 0 是無意義的佔位值。目標是在索引 1 處插入 3，並保持原有有效元素的相對順序。

先從最右端的有效元素開始向右複製，再逐步推進到插入位置，避免覆蓋尚未備份的資料。賦值複製不會清空源槽位，因此中間狀態會暫時出現重複數值。

### 第 1 步：準備插入

索引 1 當前存放有效元素 2，若直接寫入 3 會將其覆蓋丟失，因此需先把索引 1 至 3 的有效元素依次向右複製一位。

### 第 2 步：複製末尾的 4

執行 nums\[4\] = nums\[3\]，把索引 3 的 4 複製到末尾索引 4，覆蓋原本無意義的 0。此時索引 3 的 4 已備份到索引 4，下一步可以安全覆蓋索引 3。

### 第 3 步：複製 5

執行 nums\[3\] = nums\[2\]，把索引 2 的 5 複製到索引 3。原索引 3 的 4 已在上一步儲存到索引 4，因此不會丟失。

### 第 4 步：複製 2

執行 nums\[2\] = nums\[1\]，把索引 1 的 2 複製到索引 2。至此，原有的 2、5、4 已分別儲存到索引 2、3、4，索引 1 可以安全寫入新元素。

### 第 5 步：寫入 3

執行 nums\[1\] = 3，將新元素 3 寫入索引 1。插入完成，有效元素數量由 4 增至 5，五個槽位全部有效。
