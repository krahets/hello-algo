# 4.6 &nbsp; 練習

## 4.6.1 &nbsp; 觀念複習

### 1. &nbsp; 陣列和鏈結串列如何找到元素

陣列和單向鏈結串列都依序存放了 `[A, B, C, D, E]`。現在要讀取第 4 個元素 `D`：

<!-- numbered-subquestions -->

1. 在陣列中可以直接使用哪個索引？
2. 在單向鏈結串列中，從頭節點 `A` 出發，沿著 `next` 會依序經過哪些節點？
3. 當要讀取的元素越靠近尾端，這兩種結構所需的步數會如何變化？哪一種較適合反覆依位置讀取元素？為什麼？

??? success "參考答案"

    1. 若索引從 0 開始，第 4 個元素的索引就是 3，可以直接讀取陣列中的 `arr[3]`。

    2. 在單向鏈結串列中必須從頭開始，依 `A → B → C → D` 的順序走訪，沿著 `next` 前進 3 次。

    3. 陣列可以根據起始位址和索引直接定位元素，依位置存取的時間複雜度為 $O(1)$。
        要存取單向鏈結串列的第 $k$ 個節點，必須從頭節點出發，沿著 `next` 前進 $k-1$ 次，
        最壞情況下需要 $O(n)$ 的時間。

        這裡只比較依位置讀取元素的效率，不能據此推論鏈結串列的所有操作都比較慢。

### 2. &nbsp; 陣列和鏈結串列如何插入元素

陣列和單向鏈結串列都存放了 `A、B、C、D`。現在要在 `B` 後面插入 `X`：

- 陣列的容量是 5，目前的狀態為 `[A, B, C, D, _]`；
- 鏈結串列為 `A → B → C → D`，而且已取得指向節點 `B` 的參照。

<!-- numbered-subquestions -->

1. 陣列需要移動哪些元素？寫出插入後的陣列。
2. 在鏈結串列中，應依什麼順序修改 `X.next` 和 `B.next`？寫出插入後的鏈結串列。
3. 比較插入效率時，為什麼要特別說明「已取得節點 B 的參照」？

??? success "參考答案"

    1. 在陣列中，先將 `D` 右移一格，再將 `C` 右移一格，最後將 `X` 放在索引 2 的位置，
        得到 `[A, B, X, C, D]`。

    2. `B.next` 原本指向 `C`。應先令 `X.next = B.next`，讓 `X` 指向 `C`；
        再令 `B.next = X`。結果為 `A → B → X → C → D`。
        若先覆寫 `B.next`，又沒有保留原來的連結，就可能找不到 `C`。

    3. 已知 `B` 的位置時，在鏈結串列中插入節點只需修改兩個連結，可在 $O(1)$ 時間內完成。
        若還得從頭尋找 `B`，光是尋找就可能需要 $O(n)$ 的時間。

### 3. &nbsp; 列表的容量如何增加

一個以陣列實作的列表目前的內容為 `[A, B, C]`，長度為 `size = 3`，容量為 `capacity = 4`。
規定容量不足時，新陣列的容量為原來的 2 倍。

<!-- numbered-subquestions -->

1. 在尾端加入 `D` 後，列表的長度和容量各是多少？需要擴充容量嗎？
2. 接著在尾端加入 `E` 時，容量會變成多少？要複製幾個原有的元素？
3. 底層陣列的長度固定，為什麼列表的容量看起來卻可以增加？

??? success "參考答案"

    1. `D` 可以放進最後一個空位。此時內容為 `[A, B, C, D]`，
        `size = 4`、`capacity = 4`，無須擴充容量。

    2. 再於尾端加入 `E` 時，陣列已沒有空位，因此需要建立容量為 8 的新陣列，
        將 `A、B、C、D` 這 4 個原有的元素複製過去，再加入 `E`。
        此時 `size = 5`、`capacity = 8`。

    3. 原本的陣列並沒有變長。列表會建立一個更大的陣列，將原有的元素複製過去，
        再改用新陣列儲存元素，因此使用者看到的容量增加了。

## 4.6.2 &nbsp; 程式設計練習

### 1. &nbsp; 用陣列表示的大整數加一

陣列 `digits` 由左至右依序存放一個非負整數的各位數字，例如 `[3, 0, 8]` 表示 308。
數字 0 以 `[0]` 表示；其餘輸入的首位數字都不是 0。

請模擬一次十進位直式加法，將這個整數加 1，再以相同的陣列格式回傳結果。
可以直接修改 `digits`；若最高位產生進位，可以回傳較長的陣列。

??? tip "解題提示"

    1. 像做直式加法一樣，從陣列的最後一位開始
    2. 若目前這一位小於 9，加一後就能回傳結果
    3. 若目前這一位是 9，就將它改成 0；若每一位都是 9，就要在最前面補上 1

### 2. &nbsp; 反轉單向鏈結串列

給定單向鏈結串列的頭節點 `head`。每個節點都包含一個值，以及指向下一個節點的 `next`。

請以迭代方式反轉所有節點之間的連結，並回傳反轉後的頭節點。
過程中不得建立新的鏈結串列節點。

??? tip "解題提示"

    1. 先在紙上畫出三個相連的節點，以及 prev 和 cur 兩個指標
    2. 改寫 cur.next 之前，必須先用 nxt 記住原本的下一個節點
    3. 反轉 cur.next 後，先令 prev = cur，再令 cur = nxt，繼續處理原串列中的下一個節點
