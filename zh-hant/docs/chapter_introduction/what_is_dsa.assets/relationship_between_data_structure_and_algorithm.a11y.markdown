# 資料結構與演算法的關係

演算法透過操作指令將輸入轉換為輸出，資料結構為輸入、演算法處理和輸出全程提供儲存與操作支撐。

<a id="source-17"></a>

圖中上方處理流按“輸入（input）→ 演算法（algorithm，一系列操作指令）→ 輸出（output）”從左到右推進。下方“資料結構（data structure，提供結構化儲存的資料及對應操作方法）”並非只在演算法開始前儲存輸入，而是同時指向並支撐輸入、演算法、輸出三個環節：組織輸入資料、在演算法執行期間提供讀寫操作，並承載最終輸出結果。

## 結果

資料結構與演算法緊密配合：資料結構組織資料並提供讀寫操作方法，演算法呼叫這些操作將輸入轉換為輸出。
