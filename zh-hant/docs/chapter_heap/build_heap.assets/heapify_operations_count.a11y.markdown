# 建堆積的分層工作量

高度為 h 的完美二元樹中，從根層到葉節點層，單層節點數按 2^0, 2^1, …, 2^h 翻倍，而節點高度（最多下沉層數）按 h, h−1, …, 0 遞減。

## 問題與輸入

圖中以高度為 h 的完美二元樹分析自下而上建堆積的時間複雜度。節點高度為該節點到最深葉節點的邊數：葉節點高度為 0，根節點高度為 h。一個節點最多向下交換的層數等於其高度；這不包含程式碼迴圈最後一次判斷並停止的檢查。

## 結構與關係

若把全部 n 個節點都按根節點的最大下沉層數 h 估算，會顯著高估工作量：完美二元樹越靠近底部，單層節點數越多，但每個節點還能向下交換的層數越短；最底部的葉層佔約一半節點，卻完全無須下沉。

設深度 d 從根層 0 計到葉層 h。第 d 層有 2^d 個節點，每個節點高度為 h−d（即最多下沉 h−d 層），因此該層下沉次數上界為 2^d×(h−d)；到葉層 d=h 時，2^h 個葉節點高度為 0，下沉次數為 0。圖中縱向省略號代表中間各層，並非固定只有四層。

按層加權求和得總上界 T(h) = 2^0×h + 2^1×(h−1) + … + 2^(h−1)×1 + 2^h×0；由正文錯位相減化簡可得 T(h) = 2^(h+1) − h − 2。該式是建堆積累計下沉次數的理論上界，實際建堆積時若提前滿足堆積序還會更早停止。

根節點最多下沉 h 層但只有 2^0=1 個；倒數第二層有 2^(h−1) 個節點、每個最多下沉 1 層；最底葉層有 2^h 個節點、下沉 0 層。按深度分別將“節點數”與“最多下沉層數”相乘再求和，即可緊緻推導出 O(n) 的線性建堆積上界。

## 結果

高度為 h 的完美二元樹有 n = 2^(h+1) − 1 個節點，累計下沉次數上界 T(h) = 2^(h+1) − h − 2 屬於 O(2^h) = O(n)。加上各節點的檢查等線性開銷，自下而上建堆積的時間複雜度為 O(n)。
