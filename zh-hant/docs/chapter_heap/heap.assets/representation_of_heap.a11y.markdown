# 堆積的陣列表示

堆積按層序存入陣列後，可直接透過索引換算定位父子節點；例如索引 i = 4 的父節點索引為 ⌊(i − 1)/2⌋ = 1（向下取整），左、右子節點索引分別為 9 和 10。

## 問題與輸入

圖上方標註：左側為“堆積的邏輯結構（‘堆積’是一棵‘完全二元樹’）”，右側為“堆積的物理結構（底層儲存，使用‘陣列’表示‘完全二元樹’）”。陣列按層序存放 12 個元素 \[9, 8, 6, 6, 7, 5, 2, 1, 4, 3, 6, 2\]，索引從 0 到 11。

## 結構與關係

左側完全二元樹在每個節點圓圈下方標出對應的陣列索引：根節點值 9（索引 0）的左、右子節點為值 8（索引 1）和值 6（索引 2）；索引 1 的左、右子節點為索引 3（值 6）和索引 4（值 7）；索引 2 的左、右子節點為索引 5（值 5）和索引 6（值 2）；索引 3 的左、右子節點為索引 7（值 1）和索引 8（值 4）；索引 4 的左、右子節點為索引 9（值 3）和索引 10（值 6）；索引 5 只有左子節點索引 11（值 2）。

右側陣列展示了“透過索引對映實現節點指標”的公式：給定節點索引 i，其父節點索引為 ⌊(i−1)/2⌋（向下整除），左子節點索引為 2i+1，右子節點索引為 2i+2。圖中以青色高亮索引 i=4（值為 7）的節點：指向橙色高亮父節點的灰色箭頭對應父節點索引 ⌊(4−1)/2⌋ = 1（值為 8），向右的兩條箭頭分別對應藍色左子節點索引 2×4+1 = 9（值為 3）與紫藍色右子節點索引 2×4+2 = 10（值為 6）。樹與陣列中的同色高亮一一對應。

當計算出的子節點索引超出陣列長度範圍時，表示該子節點不存在；根節點（索引 0）沒有父節點。藉助緊湊的完全二元樹層序排列，數值相等的不同節點（如多個 6 和 2）也能由各自的唯一索引準確區分。

## 結果

完全二元樹無需額外儲存左右指標欄位，直接利用陣列下標算術對映即可在 O(1) 時間內定位任意節點的父節點與左、右子節點。
