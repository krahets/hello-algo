# 8.4 &nbsp; 小結

### 1. &nbsp; 重點回顧

- 堆積是一棵完全二元樹，依父子節點間的大小關係可分為最大堆積與最小堆積。最大堆積的頂端是最大值，最小堆積的頂端則是最小值。
- 優先佇列中的元素依優先順序取出，通常以堆積實作。
- 堆積的常用操作與時間複雜度包括：加入元素 $O(\log n)$、取出頂端元素 $O(\log n)$，以及讀取頂端元素 $O(1)$。
- 完全二元樹很適合用陣列表示，因此我們通常用陣列儲存堆積。
- 調整堆積能維持堆積的性質，加入元素和取出元素時都會用到這項操作。
- 以 $n$ 個輸入元素建立堆積，時間複雜度可降至 $O(n)$，效率很高。
- Top-k 是經典的演算法問題，使用堆積就能有效率地解決，時間複雜度為 $O(n \log k)$。

### 2. &nbsp; Q & A

**Q**：資料結構中的「堆積」和記憶體管理中的「堆積」是同一個概念嗎？

兩者只是剛好同名，指的是不同概念。電腦系統記憶體中的堆積是動態配置記憶體的一部分，程式可以在執行時用它來儲存資料。程式可要求配置一定大小的堆積記憶體，以存放物件、陣列等複合結構。不再需要這些資料時，程式必須釋放記憶體，以免發生記憶體洩漏。相較於堆疊記憶體，管理與使用堆積記憶體要更謹慎，使用不當可能造成記憶體洩漏、無效指標等問題。
