# 方法二（排序）：先升序排序，再返回最右 k 個元素

將 nums = \[1, 7, 6, 3, 2\] 升序排序為 \[1, 2, 3, 6, 7\]，直接擷取最右側的 k = 3 個元素 \[3, 6, 7\]。

## 問題與輸入

給定無序陣列 nums = \[1, 7, 6, 3, 2\] 和參數 k = 3，任務是找出其中最大的三個元素。

## 結構與關係

第一行展示原始無序陣列 nums = \[1, 7, 6, 3, 2\]。經第一個向下箭頭“對陣列進行排序”後，第二行得到升序排列的 \[1, 2, 3, 6, 7\]，其中最右側的三個元素 3、6、7 用藍色邊框與下方花括號標出。

經第二個向下箭頭“返回最右 k 個元素”後，第三行單獨列出提取出的結果 \[3, 6, 7\]，較小的 1 和 2 被捨棄。

圖自上而下分三行展示排序法求 Top-k：先將原陣列 \[1, 7, 6, 3, 2\] 整體升序排序為 \[1, 2, 3, 6, 7\]，由於升序陣列右側元素更大，直接擷取最右邊的 k = 3 個元素即可得到 \[3, 6, 7\]。

## 結果

升序排序後最大的 k 個元素必然集中在陣列末尾，直接切片返回 \[3, 6, 7\] 即可。使用 O(n log n) 的排序演算法時，該方法的時間複雜度為 O(n log n)，但也對無需返回的其餘元素做了排序。
