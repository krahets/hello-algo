# 走訪選擇 Top-k

對 nums = \[1, 7, 6, 3, 2\] 與 k = 3，每輪從未選元素中找出最大值，三輪依次提取 7、6、3。

## 問題與輸入

給定無序陣列 nums = \[1, 7, 6, 3, 2\] 和參數 k = 3，任務是透過“走訪搜尋最大元素”找出其中最大的三個元素。

## 結構與關係

第一輪走訪全部五個元素 \[1, 7, 6, 3, 2\]，找到第 1 大元素 7；曲線箭頭將 7 抽離到右側藍框結果區 \[7\]，左側待選區剩下 \[1, 6, 3, 2\]。

第二輪在剩餘的 \[1, 6, 3, 2\] 中繼續走訪，找到第 2 大元素 6 並移入右側結果區，此時待選區變為 \[1, 3, 2\]，右側結果區顯示 \[6, 7\]。

第三輪在剩餘的 \[1, 3, 2\] 中找到第 3 大元素 3 並移入結果區，待選區只剩 \[1, 2\]，右側結果區匯聚為三個藍框元素 \[3, 6, 7\]。圖中向下的灰色粗箭頭表示輪次推進，曲線細箭頭標示每輪被提取的最大值。

## 結果

經過 k = 3 輪走訪，依次選出第 1、2、3 大元素 7、6、3（圖中結果區展示為 \[3, 6, 7\]）。對長度為 n 的陣列執行 k 輪線性掃描，總時間複雜度為 O(nk)。

## 走訪選擇 Top-k：動畫

Top-K 問題要求從給定陣列中找出最大的 k 個元素；本動畫輸入陣列為 nums = \[1, 7, 6, 3, 2\]，目標參數 k = 3，採用走訪選擇法共執行 3 輪掃描，每一輪從未被選出的候選元素中找出最大值並將其移入結果區，已選出的元素不再參與後續輪次的比較。
