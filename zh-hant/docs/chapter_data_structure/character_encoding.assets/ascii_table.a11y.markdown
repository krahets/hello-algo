# ASCII 字元與編碼對照

按十進位制編碼或字元查閱對應的二進位制表示，區分控制字元與可列印字元。

## 問題與輸入

ASCII 使用 7 位二進位制數表示 128 個字元，十進位制編碼範圍為 0 至 127。圖中按單位元組 8 位展示二進位制，每 4 位以空格分組，最高位恆為 0。下方資料表已將原圖四列面板合併為按十進位制 0 至 127 遞增的完整對照表，可按行列檢索。

## 結構與關係

按編碼區間劃分：0 至 31 與 127 為控制字元；32 為空格（SP）；48 至 57 為數字字元 0 至 9；65 至 90 為大寫字母 A 至 Z；97 至 122 為小寫字母 a 至 z；其餘可列印標點與符號分佈在 33 至 47、58 至 64、91 至 96 以及 123 至 126。

表中“含義（圖中註明）”列保留原圖註文，閱讀時需注意其與現代通用術語的差異：編碼 14 的 SO（Shift Out）與 15 的 SI（Shift In）分別表示移出切換與移入切換；編碼 27 的 ESC（Escape）表示轉義，原圖註文“換碼(溢位)”中的“溢位”並非算術溢位；編碼 10（LF）、12（FF）、13（CR）分別控制換行、換頁與回車，原圖帶有的“鍵”字僅作功能提示，不代表必須對應實體按鍵。

表中同一行的十進位制碼、8 位二進位制與字元一一對應。數字字元 0 至 9 位於十進位制 48 至 57，二進位制高四位恆為 0011，低四位恰為對應數值 0000 至 1001。同一字母的大小寫編碼相差 32，8 位二進位制僅右起第 6 位（權重 32 的位）不同：例如大寫 A 為 65（0100 0001），小寫 a 為 97（0110 0001）；換行 LF 為 10（0000 1010）。

## 結果

字元字面與編碼數值不同：數字字元 0 的編碼是 48（0011 0000），而編碼 0 對應空字元 NUL（0000 0000）；大寫 A 編碼為 65，小寫 a 編碼為 97；空字元 NUL（0）、空格 SP（32）與刪除字元 DEL（127）也各自對應不同編碼。
