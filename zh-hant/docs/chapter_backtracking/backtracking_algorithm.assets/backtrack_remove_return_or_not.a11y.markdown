# 記錄解後是否繼續搜尋

當目標節點的後代中仍可能存在合法解時，記錄解後立即返回會漏掉深層解，需刪除該提前 return 以繼續搜尋。

## 問題與輸入

任務是尋找從根節點出發、終點值為 7 且路徑不含 3 的所有路徑。圖中二元樹共有 8 個節點：根為 1，左、右子節點為 7 和 3；左側 7 的左、右子節點為 4 和 5，且 4 下方還有一個左子節點 7；3 的左、右子節點為 6 和右側 7。

這裡對比的是“記錄解之後是否立即執行 return 結束當前遞迴分支”。遇到節點 3 時停止深入的剪枝，以及走訪完子節點後的正常回退，在兩種做法中均保留不變；框架程式碼透過拒絕值為 3 的選擇來實現這項剪枝。

左圖保留記錄解後的 return：訪問根的左子節點 7 並記錄 \[1, 7\] 後立即停止當前分支，剪掉了其下方的節點 4、5 及 4 的左子節點 7，從而漏掉深層解。右圖刪除該提前 return：記錄淺層解 \[1, 7\] 後繼續遞迴訪問子節點 4 及其左子節點 7，成功找到第二條合法路徑 \[1, 7, 4, 7\]。左右兩圖在右分支遇到紅色節點 3 時均執行剪枝，不會進入 6 和右側 7。注意本圖比前文例題及配套 Python 程式碼的七節點樹多畫了節點 4 下方的深層左子節點 7，第二條解 \[1, 7, 4, 7\] 按圖中八節點樹得出。

## 結果

在這棵八節點樹上，保留記錄解後的提前 return 只能找到 \[\[1, 7\]\]；刪除該提前 return 後可完整找到 \[\[1, 7\], \[1, 7, 4, 7\]\]。
