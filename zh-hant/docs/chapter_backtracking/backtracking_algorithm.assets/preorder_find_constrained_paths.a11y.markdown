# 根據路徑不含 3 的約束條件剪枝

搜尋根節點到 7 且不含 3 的路徑時，在節點 3 處提前返回並剪去其子樹，跳過節點 6 和右側 7。

## 問題與輸入

二元樹共七個節點：根節點為 1，其左、右子節點分別為 7 和 3；左側節點 7 的左、右子節點為 4 和 5；節點 3 的左、右子節點為 6 和另一個 7；節點 4、5、6 與右側 7 均為葉節點。

例題要求找出從根節點到所有值為 7 節點的路徑，且路徑中不能包含值為 3 的節點。一旦當前路徑經過節點 3，其下方所有延伸路徑都必然違反約束。

## 結構與關係

左子樹不包含 3，前序訪問左側節點 7 時記錄合法路徑 \[1, 7\]，並繼續檢查其子節點 4 和 5。

當搜尋到達根的右子節點 3 時觸發約束條件，演算法立即提前返回，不再遞迴進入其子節點 6 和右側 7。圖中將節點 3 標為紅色，並用剪刀圖示與半透明虛化子樹表示跳過該搜尋分支，樹節點本身並未從資料結構中刪除。

## 在節點 3 處提前返回以剪除無效搜尋分支

遇到節點 3 時即可判定其整棵子樹不可能產生合法解，因為後續任何延伸路徑都會包含 3。在此處直接返回可省去對節點 6 和右側 7 的無意義訪問。

## 結果

唯一滿足約束的路徑為 \[1, 7\]。右側葉節點 7 雖然節點值等於目標 7，但從根到達它的路徑 \[1, 3, 7\] 經過了被禁止的節點 3，因此在剪枝階段被排除。
