# 嘗試與回退：儲存到達 7 的路徑

## 問題與輸入

二元樹共 7 個節點：根節點為 1，左、右子節點分別為左側 7 和節點 3；左側 7 的左、右子節點為 4、5；節點 3 的左、右子節點為 6 和右側 7；4、5、6 與右側 7 為葉節點。

本例對應不帶節點 3 剪枝約束的全量搜尋：按“根 → 左 → 右”的前序順序走訪整棵樹，找出從根節點 1 到所有值為 7 節點的路徑。

狀態串列 path 即時維護從根到當前節點的活躍路徑，結果串列 res 儲存每次命中 7 時的路徑副本。圖中以節點值簡寫 path 與 res，配套程式碼實際儲存節點物件及串列複製 list(path)，左、右兩個值為 7 的節點是不同物件。

## 結構與關係

每次向前“嘗試”進入節點時將其追加到 path 末尾；若當前節點值為 7，則複製當前 path 的副本加入 res；離開節點“回退”前將其從 path 末尾彈出，恢復進入該節點前的路徑。

本組沒有禁止經過節點 3 的約束：命中左側 7 後仍繼續訪問其子節點 4、5，後續也會經過節點 3 找到右側 7。由於命中時向 res 儲存的是 path 的獨立副本，後續回退彈出只修改當前 path，不會改變 res 中已儲存的兩條路徑。
