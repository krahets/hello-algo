# 在前序走訪中搜索並記錄所有值為 7 的節點

按根、左、右的前序順序走訪七個節點，依次命中並記錄根的左子節點 7 與節點 3 的右子節點 7。

## 問題與輸入

二元樹共七個節點：根節點為 1，其左、右子節點分別為 7 和 3；左側節點 7 的左、右子節點為 4 和 5；節點 3 的左、右子節點為 6 和另一個 7；節點 4、5、6 與右側 7 均為葉節點。

例題要求搜尋並記錄樹中所有值為 7 的節點，而非找到第一個就停止。圖中兩個青色高亮的 7 位於不同分支，代表兩個獨立的節點物件。

## 結構與關係

綠色虛線箭頭沿二元樹外圍勾勒深度優先走訪軌跡，每個節點左側的橙色圓點標示前序訪問時機：進入節點時立即檢查節點值，隨後再依次遞迴左子樹和右子樹。

全樹前序訪問序列為 \[1, 7, 4, 5, 3, 6, 7\]。每當遇到值為 7 的節點便將其加入結果串列，之後繼續走訪剩餘分支；因此命中左側節點 7 後仍會繼續訪問其子節點 4 和 5。

## 在前序訪問時機檢查並記錄目標節點

橙色圓點標出首次進入每個節點時的前序檢查點，青色填充標出兩個值為 7 的命中節點。搜尋軌跡穿過左側命中節點繼續深入其子樹，確保整棵樹的所有節點都被逐一檢查。

## 結果

搜尋共記錄兩個節點，按命中先後依次為根的左子節點 7 和節點 3 的右子節點 7；若按節點值展示為 \[7, 7\]，對應樹上兩個不同位置的節點。
