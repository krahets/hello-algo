# 相等元素使全排列重複

把兩個值為 1 的元素當作不同候選展開，會產生六條路徑但只有三種不同的數值排列。

## 問題與輸入

輸入陣列為 \[1, 1, 2\]，圖中用 1̂ 標記第二個 1 的元素身份，其實際數值仍為 1。在每個索引最多使用一次的前提下，僅依靠 selected 限制同一索引重用，還不足以排除因相等數值交換位置而造成的重複排列。

## 結構與關係

頂部列出初始狀態 state 的三個空槽與候選陣列 choices=\[1, 1̂, 2\]。三輪選擇展開為六個葉節點，其中藍色方塊表示第一個 1、青色方塊表示第二個 1（即 1̂）、紫色方塊表示 2。底部第 3、第 4、第 6 個葉節點加有橙色邊框，並彙總指向下方“應當去除的重複排列”說明。

第一輪分別嘗試選 1、1̂、2，得到 \[1\]、\[1̂\]、\[2\] 三個分支；第二輪在每個分支下分別選取剩餘兩個索引之一，第三輪填入最後一個未用索引，共形成表中所列的六個葉節點。其中橙框標出的 \[1̂, 1, 2\]、\[1̂, 2, 1\] 和 \[2, 1̂, 1\]，分別只是將 \[1, 1̂, 2\]、\[1, 2, 1̂\] 和 \[2, 1, 1̂\] 中兩個值為 1 的元素互換了位置，並未產生新的數值排列。

## 結果

忽略區分元素身份的標記後，六個葉節點只對應 \[1, 1, 2\]、\[1, 2, 1\]、\[2, 1, 1\] 三種不重複的數值排列。
