# 雙向鏈結串列實現雙向佇列

維護頭尾節點及雙向引用，在兩端增刪時保持中間節點不動。

## 問題與輸入

每個節點同時儲存前驅引用 prev 和後繼引用 next，鏈結串列頭、尾節點分別作為佇列首和佇列尾。初始鏈結串列為 3 ⇄ 2 ⇄ 5（頭為 3、尾為 5），序列按佇列首到佇列尾書寫。

## 結構與關係

五幀連續演示：初始狀態、佇列尾加入 4、佇列首加入 1、佇列尾取出 4、佇列首取出 1。每次操作僅修改頭尾引用及端點處的相鄰 prev/next 引用；圖中邏輯佇列與底層雙向鏈結串列是同一份資料的兩種檢視。

在已維護頭尾節點引用的前提下，兩端入列與出列均為 O(1)：佇列尾出列可直接透過尾節點的 prev 找到新佇列尾，無須從頭走訪。

## 第 1 步：初始雙向佇列

初始鏈結串列為 3 ⇄ 2 ⇄ 5，相鄰節點透過 prev 和 next 雙向連線，頭、尾引用分別指向節點 3 和節點 5。

<details><summary>本步完整狀態</summary><p>當前有效佇列按佇列首到佇列尾為 [3, 2, 5]，底層雙向鏈結串列為 3 ⇄ 2 ⇄ 5，頭節點為 3、尾節點為 5；無返回值。</p></details>

<a id="source-72"></a>

## 第 2 步：佇列尾加入4

在原尾節點 5 後接入新節點 4，令 5.next 指向 4、4.prev 指向 5，並將尾引用更新為 4；頭引用仍為 3。

<details><summary>本步完整狀態</summary><p>執行佇列尾入列後，當前有效佇列為 [3, 2, 5, 4]，底層雙向鏈結串列為 3 ⇄ 2 ⇄ 5 ⇄ 4，頭節點為 3、尾節點更新為 4；無返回值。</p></details>

<a id="source-73"></a>

## 第 3 步：佇列首加入1

在原頭節點 3 前接入新節點 1，令 1.next 指向 3、3.prev 指向 1，並將頭引用更新為 1；尾引用仍為 4。

<details><summary>本步完整狀態</summary><p>執行佇列首入列後，當前有效佇列為 [1, 3, 2, 5, 4]，底層雙向鏈結串列為 1 ⇄ 3 ⇄ 2 ⇄ 5 ⇄ 4，頭節點更新為 1、尾節點為 4；無返回值。</p></details>

<a id="source-74"></a>

## 第 4 步：佇列尾取出4

透過原尾節點 4 的 prev 引用直接定位前驅節點 5，將尾引用回退為 5，斷開 5 與 4 之間的雙向連線並返回 4。

<details><summary>本步完整狀態</summary><p>執行佇列尾出列後，當前有效佇列為 [1, 3, 2, 5]，底層雙向鏈結串列為 1 ⇄ 3 ⇄ 2 ⇄ 5，頭節點為 1、尾節點恢復為 5；本次從佇列尾返回 4。</p></details>

<a id="source-75"></a>

## 第 5 步：佇列首取出1

透過原頭節點 1 的 next 引用定位後繼節點 3，將頭引用推進為 3，斷開 1 與 3 之間的雙向連線並返回 1。

<details><summary>本步完整狀態</summary><p>執行佇列首出列後，當前有效佇列恢復為 [3, 2, 5]，底層雙向鏈結串列為 3 ⇄ 2 ⇄ 5，頭節點恢復為 3、尾節點為 5；本次從佇列首返回 1。</p></details>

## 結果

經四次連續操作後，先從佇列尾返回 4，再從佇列首返回 1，鏈結串列恢復為 3 ⇄ 2 ⇄ 5（頭為 3、尾為 5）。
