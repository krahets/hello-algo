# 堆疊的入出操作

在堆疊頂同一端壓入和彈出，體現後進先出。

## 問題與輸入

所有序列按堆疊底到堆疊頂書寫。push 向堆疊頂壓入元素，pop 移除並返回堆疊頂元素。

初始堆疊為 \[1, 3, 2\]（堆疊頂為 2）。先依次執行 push(5) 和 push(4)，每次壓入的新元素都成為新的堆疊頂；再連續執行兩次 pop()，後壓入的 4 先彈出，隨後 5 彈出，體現後進先出。

## 堆疊的入出操作：動畫

在堆疊頂同一端壓入和彈出，體現後進先出。

所有序列按堆疊底到堆疊頂書寫。push 向堆疊頂壓入元素，pop 移除並返回堆疊頂元素。

本例初始堆疊為 \[1, 3, 2\]。

虛線方塊僅示意元素操作前的舊位置，不重複計入當前堆疊；移出容器外的實心方塊表示本次 pop 的返回值。

### 第 1 步：初始

初始堆疊包含 3 個元素，堆疊底為 1，堆疊頂為 2。

### 第 2 步：push(5)

將 5 壓入堆疊頂，原有元素次序不變，5 成為新堆疊頂。

<details><summary>本步完整狀態</summary><p>執行 push(5) 後，當前堆疊按堆疊底到堆疊頂為 [1, 3, 2, 5]，共 4 個元素，堆疊底為 1、堆疊頂為 5；無返回值。</p></details>

### 第 3 步：push(4)

將 4 壓入堆疊頂，壓在 5 之上成為新堆疊頂。

<details><summary>本步完整狀態</summary><p>執行 push(4) 後，當前堆疊按堆疊底到堆疊頂為 [1, 3, 2, 5, 4]，共 5 個元素，堆疊底為 1、堆疊頂為 4；無返回值。</p></details>

### 第 4 步：第一次pop()

移除並返回當前堆疊頂 4，下方的 5 重新成為堆疊頂。

<details><summary>本步完整狀態</summary><p>第一次執行 pop() 後，當前堆疊按堆疊底到堆疊頂為 [1, 3, 2, 5]，共 4 個元素，堆疊底為 1、堆疊頂為 5；本次返回 4（已移出堆疊外）。</p></details>

### 第 5 步：第二次pop()

繼續移除並返回堆疊頂 5，堆疊頂恢復為 2。

<details><summary>本步完整狀態</summary><p>第二次執行 pop() 後，當前堆疊按堆疊底到堆疊頂為 [1, 3, 2]，共 3 個元素，堆疊底為 1、堆疊頂為 2；本次返回 5（已移出堆疊外）。</p></details>

### 結果

連續兩次出堆疊依次返回 4、5，堆疊恢復為 \[1, 3, 2\]。
