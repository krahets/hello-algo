# 基於陣列實現堆疊的入堆疊與出堆疊

將陣列尾部作為堆疊頂、首部作為堆疊底：在陣列尾部追加 4 完成入堆疊，刪除陣列尾元素 4 完成出堆疊。

## 問題與輸入

每幀左側展示對外表現的堆疊（上為堆疊頂、下為堆疊底），右側展示底層豎直繪製的陣列（下方為“首元素”，上方有效末端為“尾元素”，更上方灰色虛線格和豎排省略號表示“陣列剩餘空位”），中間標註“底層實現是陣列，對外表現為堆疊”。

## 結構與關係

陣列從首元素到尾元素的順序與堆疊從堆疊底到堆疊頂的順序一致。下面三幀依次展示初始狀態（\[1, 3, 2, 5\]）、執行 push(4) 在陣列尾部新增元素，以及執行 pop() 刪除陣列尾元素。

## 第 1 步：初始堆疊：陣列尾元素 5 為堆疊頂

初始時，左側堆疊從堆疊底到堆疊頂依次為 \[1, 3, 2, 5\]。右側陣列有效元素自下而上（從首元素到尾元素）同樣為 \[1, 3, 2, 5\]：底部首元素 1 對應堆疊底，頂部尾元素 5 對應堆疊頂；5 上方畫有兩個灰色虛線空位和省略號，括注為“陣列剩餘空位”。

## 第 2 步：在陣列尾部入堆疊 4

左側標註“入堆疊 push(4)”，右側標註“將元素 4 新增至陣列尾部”。青色元素 4 寫入原尾元素 5 上方的第一個空位，“尾元素”標記隨之上移到 4。此時有效陣列從首到尾變為 \[1, 3, 2, 5, 4\]，左側堆疊從堆疊底到堆疊頂也變為 \[1, 3, 2, 5, 4\]，堆疊頂更新為 4。

## 第 3 步：在陣列尾部出堆疊 4

左側標註“出堆疊 pop()”，右側標註“刪除陣列尾元素”。移除上一步追加在陣列尾部的元素 4，原來 4 所在的單元格恢復為灰色虛線空位，“尾元素”標記下移回 5。有效陣列與堆疊從底到頂均恢復為 \[1, 3, 2, 5\]，堆疊頂回到 5。

## 結果

基於陣列實現堆疊時，入堆疊和出堆疊分別對應在陣列尾部追加和刪除元素，未觸發擴容時時間複雜度均為 O(1)，已有元素無須搬移。
