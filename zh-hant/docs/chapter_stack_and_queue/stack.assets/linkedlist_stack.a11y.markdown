# 基於鏈結串列實現堆疊的入堆疊與出堆疊

將鏈結串列頭節點作為堆疊頂、尾節點作為堆疊底：頭插節點 4 完成入堆疊，刪除頭節點 4 完成出堆疊。

## 問題與輸入

每幀左側展示對外表現的堆疊（上為堆疊頂、下為堆疊底），右側展示底層豎直繪製的單向鏈結串列（上為頭節點、下為尾節點，箭頭向下指向 next），中間以向左箭頭標註“底層實現是鏈結串列，對外表現為堆疊”。

## 結構與關係

堆疊頂對應鏈結串列頭節點，堆疊底對應鏈結串列尾節點。下面三幀依次展示初始狀態（\[1, 3, 2, 5\]）、執行 push(4) 頭插法入堆疊，以及執行 pop() 刪除頭節點出堆疊。

## 第 1 步：初始堆疊：頭節點 5 為堆疊頂

初始時，左側堆疊從堆疊底到堆疊頂依次為 \[1, 3, 2, 5\]，堆疊頂開口處標有入堆疊（向下）和出堆疊（向上）箭頭。右側單向鏈結串列從上到下依次為 5 → 2 → 3 → 1，上方頭節點 5 對應堆疊頂，下方尾節點 1 對應堆疊底。

## 第 2 步：在鏈結串列頭部入堆疊 4

左側標註“入堆疊 push(4)”，右側標註“將節點 4 新增至鏈結串列頭部”。青色新節點 4 採用頭插法插入在原頭節點 5 上方並指向 5，成為新的頭節點。此時鏈結串列從頭到尾變為 4 → 5 → 2 → 3 → 1，左側堆疊從堆疊底到堆疊頂變為 \[1, 3, 2, 5, 4\]，堆疊頂更新為 4。

## 第 3 步：在鏈結串列頭部出堆疊 4

左側標註“出堆疊 pop()”，右側標註“刪除頭節點”。移除上一步位於鏈結串列頭部的節點 4，使其後繼節點 5 重新成為頭節點。右側鏈表恢復為 5 → 2 → 3 → 1，左側堆疊從堆疊底到堆疊頂也恢復為 \[1, 3, 2, 5\]，堆疊頂回到 5。

## 結果

基於鏈結串列實現堆疊時，入堆疊和出堆疊都只在鏈結串列頭部增刪節點，時間複雜度均為 O(1)。
