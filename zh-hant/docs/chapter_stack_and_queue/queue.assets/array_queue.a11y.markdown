# 基於陣列實現佇列的入列與出列

在未跨越陣列末端的前提下，用 front 標記佇列首、size 記錄佇列長度，透過 rear = front + size 定位入列寫入位置，並在出列時僅移動 front、減小 size。

## 問題與輸入

每幀左側展示對外表現的佇列（上為佇列首、下為佇列尾），右側展示底層豎直繪製的陣列（有效元素自上而下按佇列首到佇列尾排列，兩端畫有灰色虛線空位和豎排省略號），中間標註“底層實現是陣列，對外表現為佇列”。

## 結構與關係

變數 front 指向佇列首元素，size 記錄佇列長度；在不越過陣列末端時，由公式 rear = front + size 計算佇列尾元素之後的下一個位置（即有效區間為 \[front, rear - 1\]）。下面三幀依次展示初始狀態（\[1, 3, 2, 5\]）、執行 push(4) 入列和執行 pop() 出列。

## 第 2 步：在 rear 位置入列 4

左側標註“入列 push(4)”，右上角說明框列出三步：“1. 計算尾指標 rear；2. 將元素新增至 rear 處；3. 將 size 自增 1”。程式先按入列前的 front 和 size = 4 算出尾指標 rear（即步驟 1 中 5 下方的空位），將青色元素 4 寫入該 rear 位置，再將佇列長度更新為 size = 5。此時佇列變為 \[1, 3, 2, 5, 4\]，front 仍指向 1；圖中 rear 箭頭停留在剛寫入的 4 處，標示本次入列步驟 1、2 所使用的寫入位置（若按更新後的 size = 5 重新代入 front + size，下一個尾後空位則在 4 的下方一格）。

## 第 3 步：移動 front，佇列首 1 出列

左側標註“出列 pop()”，右上角說明框列出兩步：“1. 將 front 自增 1；2. 將 size 自減 1”。橙色指標 front 向下移動一格，從原佇列首 1 的位置移到元素 3，同時佇列長度更新為 size = 4。原來存放 1 的單元格不再屬於有效區間，在圖中變為灰色虛線空位；其餘有效元素 \[3, 2, 5, 4\] 保持原陣列位置不動，無須整體前移。由於出列操作不計算尾指標，此幀未繪製 rear 標記。這裡的空位表示該槽已退出佇列有效區間，不表示程式碼把槽內原值清零。

## 結果

入列只需在 rear 處寫入元素並將 size 加 1，出列只需將 front 加 1 並將 size 減 1，避免了每次出列搬移剩餘元素，時間複雜度均為 O(1)。
