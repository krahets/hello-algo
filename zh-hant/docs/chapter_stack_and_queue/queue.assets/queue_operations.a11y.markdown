## 佇列的入出操作：動畫

佇列尾加入、佇列首取出，體現先入先出。

所有序列按佇列首到佇列尾書寫。圖中 push 向佇列尾入列，pop 從佇列首出列並返回該元素。

本例初始佇列為 \[1, 3, 2\]。

虛線方塊僅示意元素操作前的舊位置，不重複計入當前佇列；移出容器外的實心方塊表示本次 pop 的返回值。

### 第 1 步：初始

初始佇列包含 3 個元素，佇列首為 1，佇列尾為 2。

### 第 2 步：push(5)

將 5 加入列尾，原有元素先後次序不變，5 成為新佇列尾。

<details><summary>本步完整狀態</summary><p>執行 push(5) 後，當前佇列按佇列首到佇列尾為 [1, 3, 2, 5]，共 4 個元素，佇列首為 1、佇列尾為 5；無返回值。</p></details>

### 第 3 步：push(4)

將 4 加入列尾，排在 5 之後成為新佇列尾。

<details><summary>本步完整狀態</summary><p>執行 push(4) 後，當前佇列按佇列首到佇列尾為 [1, 3, 2, 5, 4]，共 5 個元素，佇列首為 1、佇列尾為 4；無返回值。</p></details>

### 第 4 步：第一次pop()

移除並返回佇列首 1，緊隨其後的 3 成為新佇列首。

<details><summary>本步完整狀態</summary><p>第一次執行 pop() 後，當前佇列按佇列首到佇列尾為 [3, 2, 5, 4]，共 4 個元素，佇列首為 3、佇列尾為 4；本次返回 1（已移出佇列）。</p></details>

### 第 5 步：第二次pop()

繼續移除並返回佇列首 3，2 成為新佇列首。

<details><summary>本步完整狀態</summary><p>第二次執行 pop() 後，當前佇列按佇列首到佇列尾為 [2, 5, 4]，共 3 個元素，佇列首為 2、佇列尾為 4；本次返回 3（已移出佇列）。</p></details>

### 結果

連續兩次出列依次返回最早進入的 1、3，剩餘佇列為 \[2, 5, 4\]。
