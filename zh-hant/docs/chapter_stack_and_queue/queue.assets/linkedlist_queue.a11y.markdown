# 基於鏈結串列實現佇列的入列與出列

將鏈結串列頭節點作為佇列首、尾節點作為佇列尾：在鏈結串列尾部追加 4 完成入列，刪除鏈結串列頭節點 1 完成出列。

## 問題與輸入

每幀左側展示對外表現的佇列（上為佇列首、下為佇列尾），右側展示底層豎直繪製的單向鏈結串列（上為頭節點、下為尾節點，箭頭向下指向 next），中間標註“底層實現是鏈結串列，對外表現為佇列”。

## 結構與關係

鏈結串列從頭節點到尾節點的順序與佇列從佇列首到佇列尾的順序完全一致，規定僅在鏈結串列尾部新增節點（入列）、僅在鏈結串列頭部刪除節點（出列）。下面三幀依次展示初始狀態（\[1, 3, 2, 5\]）、執行 push(4) 入列和執行 pop() 出列。

## 第 1 步：初始佇列：頭出尾入

初始時，左側佇列從佇列首（上）到佇列尾（下）依次為 \[1, 3, 2, 5\]，佇列首旁標有向上的出列箭頭，佇列尾旁標有向上的入列箭頭。右側單向鏈結串列從上到下依次為 1 → 3 → 2 → 5，頭節點 1 對應佇列首，尾節點 5 對應佇列尾。

## 第 2 步：在鏈結串列尾部入列 4

左側標註“入列 push(4)”，右側標註“將節點 4 新增至鏈結串列尾部”。青色新節點 4 接在原尾節點 5 的下方，並使“尾節點”標記下移到 4。此時右側鏈表從頭到尾變為 1 → 3 → 2 → 5 → 4，左側佇列從佇列首到佇列尾變為 \[1, 3, 2, 5, 4\]，頭節點與佇列首仍為 1，尾節點與佇列尾更新為 4。

## 第 3 步：在鏈結串列頭部出列 1

左側標註“出列 pop()”，右側標註“刪除頭節點”。移除原頭節點 1，“頭節點”標記下移到其後繼節點 3。此時右側鏈表變為 3 → 2 → 5 → 4，左側佇列從佇列首到佇列尾變為 \[3, 2, 5, 4\]，新佇列首為 3，尾節點和佇列尾仍為青色節點 4。

## 結果

基於鏈結串列實現佇列時，尾節點入列與頭節點出隊均只需修改區域性引用，時間複雜度均為 O(1)；本例最終佇列為 \[3, 2, 5, 4\]。
