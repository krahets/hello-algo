# 小結

### 重點回顧

- 堆疊是遵循先進後出原則的資料結構，可以用陣列或鏈結串列實作。
- 就時間效率而言，以陣列實作的堆疊平均效率較高，但若需擴充容量，推入一個元素的時間複雜度就會升至 $O(n)$。以鏈結串列實作的堆疊，執行效率則較穩定。
- 就空間效率而言，以陣列實作的堆疊可能會浪費部分空間。不過，鏈結串列中每個節點占用的記憶體空間，也比陣列中每個元素來得大。
- 佇列是遵循先進先出原則的資料結構，也可以用陣列或鏈結串列實作。就這兩種實作的時間效率和空間效率而言，佇列和堆疊的比較結果相似。
- 雙端佇列的操作更有彈性，兩端都可以加入或刪除元素。

### Q & A

**Q**：瀏覽器的上一頁、下一頁功能是用雙向鏈結串列實作的嗎？

瀏覽器的上一頁、下一頁功能體現了堆疊的運作方式。當使用者開啟新網頁時，該網頁會被推入堆疊頂端。當使用者按一下「上一頁」按鈕，該網頁就會從頂端彈出。使用雙端佇列，還能方便地支援一些額外的操作，詳見〈雙端佇列〉一節。

**Q**：從堆疊彈出節點後，需要釋放該節點占用的記憶體嗎？

如果之後還會使用彈出的節點，就不需要釋放記憶體。如果之後用不到，`Java` 和 `Python` 等語言有自動垃圾回收機制，無須手動釋放記憶體。在 `C` 和 `C++` 中則需要手動釋放。

**Q**：雙端佇列看起來像兩個堆疊接在一起。它有什麼用途？

雙端佇列像是堆疊與佇列的組合，也可以想成兩個堆疊接在一起。它兼具堆疊和佇列的操作方式，因此凡是堆疊或佇列能做到的應用，雙端佇列都能實現，而且用法更靈活。

**Q**：如何實作「復原」（undo）和「重做」（redo）？

使用兩個堆疊。堆疊 `A` 用於復原，堆疊 `B` 用於重做。

1. 每當使用者執行一項操作，就把這項操作推入堆疊 `A`，並清空堆疊 `B`。
2. 當使用者執行「復原」時，從堆疊 `A` 彈出最近的一項操作，再將它推入堆疊 `B`。
3. 當使用者執行「重做」時，從堆疊 `B` 彈出最近的一項操作，再將它推入堆疊 `A`。
