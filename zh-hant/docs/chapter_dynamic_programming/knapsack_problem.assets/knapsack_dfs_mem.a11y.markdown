# 0-1 背包的記憶化搜尋

右分支再次遇到 dp\[1, 10\] 時直接讀取快取返回有效值 60，省去重複子樹，並與超重剪枝區分。

## 問題與輸入

0-1 背包中每件物品最多選擇一次。本圖使用與前圖相同的獨立 3 物品、容量 cap = 30 示例：重量依次為 10、20、20，價值依次為 60、110、120（見表）。dp\[i, c\] 表示前 i 件物品在可用容量 c 下的最大價值；圖中表頭寫 wgt\[i\]、val\[i\]（i 從 1 到 3），正文程式碼用下標 i-1 訪問陣列。

噹噹前物品裝得下時，比較不選它的 dp\[i-1, c\] 與選它的 dp\[i-1, c-wgt\[i-1\]\] + val\[i-1\]，取較大值；裝不下時只取不選分支。無物品（i = 0）或容量為 0（c = 0）時返回 0。圖中的負容量節點僅示意被排除的選擇，程式碼在遞迴前判斷超重，不實際呼叫負容量狀態。

## 結構與關係

從根 dp\[3, 30\] 依次對物品 3、2、1 決策時，由於物品 2（西瓜）和物品 3（菠蘿）的重量同為 20，走“不選物品 3、再選物品 2”或“選物品 3、再不選物品 2”這兩條路線都會剩下容量 10、待選範圍只剩物品 1（蘋果，重 10、價值 60），從而匯合到同一個狀態 dp\[1, 10\]。

左子樹首次訪問 dp\[1, 10\]（路線“不選3→選2”）時，展開比較 dp\[0, 10\] 與 dp\[0, 0\] + 60 並把結果存入快取；當右子樹在 dp\[2, 10\] 下選擇不放物品 2、再次遇到 dp\[1, 10\]（路線“選3→不選2”）時，觸發“剪枝：找到記錄”，直接讀取快取返回，不再重複展開兩個葉節點。由物品 1 重 10、價值 60 可推知該快取返回值為 60，這一數值由輸入表推導而來，並非節點上的原標數字。

在右子樹 dp\[2, 10\] 處，兩個分支雖都帶有剪刀標記，但停止原因完全不同：左分支 dp\[1, 10\] 是命中快取、直接返回合法子問題的有效解 60；右分支 dp\[1, -10\]（“剪枝：物品重量 &gt; 背包容量”）則是因為物品 2 重量 20 超過當前剩餘容量 10 而被排除的非法示意節點，程式在遞迴前已判斷超重，只調用不選分支 dp\[1, 10\]，不會實際呼叫 dp\[1, -10\]。

## 快取命中複用 dp\[1, 10\] 並與超重剪枝區分

左子樹首次求出 dp\[1, 10\] = 60 後寫入快取；右子樹在 dp\[2, 10\] 下再次請求 dp\[1, 10\] 時直接讀取快取值 60 返回，省去兩個基例葉節點的展開，而旁邊的 dp\[1, -10\] 則是因物品 2 超重被排除的示意分支。

## 結果

引入記憶化快取後，第二處 dp\[1, 10\] 直接複用已算出的有效返回值 60，使圖中 i = 0 的基例葉節點由 6 個減少為 4 個（全樹共 11 個節點）；按圖中輸入推算，全域性最大價值仍為選物品 1 和物品 3 所得的 180（60 與 180 均為根據輸入推導的數值）。
