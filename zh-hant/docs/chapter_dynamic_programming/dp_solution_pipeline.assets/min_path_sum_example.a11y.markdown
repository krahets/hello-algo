# 四乘四網格的最小路徑和

在 4×4 代價網格中從左上角只向右或向下走到右下角，綠色最優路徑的七格總和為 13。

## 問題與輸入

給定一個 4×4 的非負整數網格 grid，每個單元格的數值代表經過該格所需支付的代價。從左上角起點 \[0, 0\] 出發，每次只能向右或向下移動一格，直至到達右下角終點 \[3, 3\]，起點和終點的數值均計入路徑總和（行列索引從 0 開始）。

## 結構與關係

左側展示完整的 4×4 輸入網格，並在左上角標註“起點”、右下角標註“終點”；中央向右箭頭指向右側同一個 4×4 網格，其中一條從左上到右下的七格折線路徑以綠色高亮，圖下方標註“最小路徑和為 13，對應最佳方案為 1→2→2→3→2→1→2”。

如表中所示，網格四行數值依次為 \[1, 3, 1, 5\]、\[2, 2, 4, 2\]、\[5, 3, 2, 1\]、\[4, 3, 5, 2\]。右側綠色最優路徑從起點 \[0, 0\]（值為 1）出發，先向下到 \[1, 0\]（值為 2），再向右到 \[1, 1\]（值為 2），接著向下到 \[2, 1\]（值為 3），隨後連續兩次向右經過 \[2, 2\]（值為 2）和 \[2, 3\]（值為 1），最後向下到達終點 \[3, 3\]（值為 2），沿途代價相加為 1+2+2+3+2+1+2=13。

## 結果

該 4×4 網格的最小路徑和為 13，對應綠色高亮路徑所經過的七個單元格代價之和。
