# 把網格位置定義為二維 dp 狀態

用行列座標 \[i, j\] 定義狀態，建立同尺寸 4×4 二維 dp 表對應從起點到各格的最小路徑和子問題。

## 問題與輸入

輸入為 4×4 非負代價網格 grid（行列索引 0 至 3 的完整數值見表），從左上角起點 \[0, 0\] 出發每次只能向右或向下走一格，起點與終點均計入路徑和。本圖對比原網格 grid 與動態規劃表 dp 的狀態定義。

## 結構與關係

首先區分兩個 4×4 矩陣的含義：grid\[i, j\] 僅記錄經過單個格子的代價，而 dp\[i, j\] 記錄從左上角起點 \[0, 0\] 走到格子 \[i, j\]（含首尾兩格）的累計最小路徑和。例如 grid\[1, 1\] = 2 只代表該格自身的單格代價，不能直接當作累計路徑和 dp\[1, 1\]（後者還包含從起點到達該格的路徑代價）。

圖中在 grid 旁標出行索引 i、i+1 與列索引 j、j+1，並以當前格 \[1, 1\]（代價 2）演示每輪移動決策：向右走一格列索引加 1，到達 \[1, 2\]（即 \[i, j+1\]），該格代價為 4；向下走一格行索引加 1，到達 \[2, 1\]（即 \[i+1, j\]），該格代價為 3。每次移動只改變行或列中的一個座標，因此用二維行列索引 \[i, j\] 定義狀態。

右側 dp 表是與 grid 尺寸相同的 4×4 矩陣，行列索引均為 0 至 3，單元格依次記作 dp\[0, 0\] 至 dp\[3, 3\]，分別對應到達各格的最小路徑和子問題。本圖只建立狀態定義與座標對映，尚未計算和填寫具體路徑和數值。

## 單格代價 grid 與累計狀態 dp\[i, j\] 的對應關係

按底部四項建模定義：每輪決策向右或向下走一格，將行列索引 \[i, j\] 定義為狀態（從 \[1, 1\] 向右到 \[1, 2\]、向下到 \[2, 1\]），並用同尺寸 4×4 的 dp 表記錄從左上角到各格 \[i, j\] 的最小路徑和。

## 結果

每輪向右或向下移動分別對應座標 \[i, j\] 到 \[i, j+1\] 或 \[i+1, j\] 的狀態轉移，16 個二維狀態與 4×4 的 dp 表單元格一一對應；右側 dp 表僅展示符號狀態名 dp\[0, 0\] 至 dp\[3, 3\]，不含已算出的路徑和數值。
