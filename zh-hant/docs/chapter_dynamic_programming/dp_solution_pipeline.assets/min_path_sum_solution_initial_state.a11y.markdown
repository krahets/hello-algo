# 最小路徑和的邊界與填表順序

先設定起點並沿首行向右、首列向下累加初始化邊界，再按從上到下、從左到右的正序走訪內部格。

## 問題與輸入

在非負數字網格中從 \[0, 0\] 出發只能向右或向下移動，起點與終點均計入路徑和，dp\[i, j\] 表示到達第 i 行、第 j 列的最小路徑和（行列索引 0 至 3）。本圖用左右兩個 4×4 符號 dp 表分別說明“邊界條件：初始化首行首列”與“狀態轉移順序：正序走訪矩陣”，不展示具體網格數值。

## 結構與關係

第一步初始化左上角起點 \[0, 0\]：路徑和包含起點自身的代價，故直接設 dp\[0, 0\] = grid\[0, 0\]。

第二步按左圖初始化首行與首列邊界：處在首行的狀態 \[0, j\]（j = 1、2、3）只能從左鄰一路向右到達，故按 dp\[0, j\] = dp\[0, j-1\] + grid\[0, j\] 從左向右依次累加；處在首列的狀態 \[i, 0\]（i = 1、2、3）只能從上鄰一路向下到達，故按 dp\[i, 0\] = dp\[i-1, 0\] + grid\[i, 0\] 從上向下依次累加。

第三步按右圖逐行正序填寫內部九格：外層按行索引 i = 1、2、3 從上到下，內層按列索引 j = 1、2、3 從左到右依次推進。計算當前格 dp\[i, j\] 時，上方前驅 dp\[i-1, j\] 已在前一行算好，左方前驅 dp\[i, j-1\] 已在本行左側算好，直接按 dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\] 取較小前驅加當前格代價。

## 先初始化首行首列邊界，再按行優先正序填表

左圖先由起點 dp\[0, 0\] 沿首行向右、沿首列向下單向累加得出邊界；右圖在邊界就緒後按先行後列的正序走訪內部九格，確保每格所需的上方與左方前驅在計算前均已求出。

## 結果

先完成起點 \[0, 0\] 以及首行、首列的單向累加，再從第 1 行到第 3 行、每行從第 1 列到第 3 列正序填表，就能保證求解每個內部狀態時其上方和左方前驅均已就緒，最終在右下角得到 dp\[3, 3\]。
