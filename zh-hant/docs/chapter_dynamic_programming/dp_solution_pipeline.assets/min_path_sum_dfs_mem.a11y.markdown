# 最小路徑和的記憶化遞迴

右子樹再次遇到 dp\[1, 0\] 時直接讀取快取返回有效路徑和，不再展開子節點，並與越界返回正無窮區分。

## 問題與輸入

在非負數字網格中從 \[0, 0\] 出發只能向右或向下移動，dp\[i, j\] 表示到達第 i 行、第 j 列的最小路徑和（索引從 0 開始）。本圖同樣以 dp\[2, 1\] 為搜尋根，展示引入記憶化快取 mem 後對重疊子問題的剪枝效果，不展示具體網格權重。

有效內部狀態取兩個前驅返回值的較小值，再加當前格代價：dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\]。起點返回 grid\[0, 0\]，負索引越界時返回正無窮。

## 結構與關係

從根狀態 dp\[2, 1\] 反向查詢“上一行”與“上一列”前驅時，同樣有兩條呼叫路線到達同一個子問題 dp\[1, 0\]：先查上一行到 dp\[1, 1\] 再查上一列（路線“上→左”），或先查上一列到 dp\[2, 0\] 再查上一行（路線“左→上”）。

遞迴先走訪左子樹：首次訪問 dp\[1, 0\]（路線“上→左”）時向下展開求出其最小路徑和並寫入快取；隨後右子樹從 dp\[2, 0\] 再次請求 dp\[1, 0\]（路線“左→上”）時觸發“剪枝：已有記錄”，直接返回快取結果，不再展開下方的 dp\[0, 0\] 與 dp\[1, -1\]。需區分右子樹中兩處停止展開的語義：dp\[1, 0\] 命中快取返回的是有效最小路徑和，而右鄰 dp\[2, -1\] 觸發“剪枝：索引越界”返回的是正無窮，二者不能混同。

到達起點 dp\[0, 0\] 時返回基例值 grid\[0, 0\]；出現負索引（dp\[-1, 1\]、dp\[1, -1\]、dp\[2, -1\]）時返回正無窮，使不可行的前驅不會被最小值選中。整棵樹涉及 4×4 網格中的六種有效狀態 \[0, 0\]、\[0, 1\]、\[1, 0\]、\[1, 1\]、\[2, 0\]、\[2, 1\]；由於僅剪去了第二次 dp\[1, 0\] 的子樹，左子樹的 dp\[0, 1\] 與 dp\[1, 0\] 下方仍保留 2 個起點葉節點 dp\[0, 0\]。

## 命中快取直接複用 dp\[1, 0\] 並區分越界剪枝

左子樹首次解出 dp\[1, 0\] 後存入快取；右子樹在 dp\[2, 0\] 下再次請求 dp\[1, 0\] 時直接讀取快取的有效路徑和參與最小值比較，省去重複子樹展開，而同層的 dp\[2, -1\] 則因列索引越界返回正無窮。

## 結果

記憶化搜尋在首次算出 dp\[1, 0\] 後將其快取，右子樹第二次訪問時直接複用已求出的有效最小路徑和，省去了兩個子節點的重複展開，使全樹節點由 13 個減少為 11 個。
