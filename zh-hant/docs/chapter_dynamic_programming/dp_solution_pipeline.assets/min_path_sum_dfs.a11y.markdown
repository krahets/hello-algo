# 最小路徑和的重複遞迴

從目標 dp\[2, 1\] 向前回溯上方與左方前驅時，兩條呼叫路線匯合到 dp\[1, 0\] 並將其子樹重複展開兩次。

## 問題與輸入

在非負數字網格中從 \[0, 0\] 出發只能向右或向下移動，dp\[i, j\] 表示到達第 i 行、第 j 列的最小路徑和（索引從 0 開始）。本圖以 dp\[2, 1\] 為根節點展示自頂向下的暴力搜尋遞迴樹，不給出具體網格權重；注意遞迴是反向查詢“上一行”與“上一列”前驅，方向與實際行走時的向下、向右相反。

有效內部狀態取兩個前驅返回值的較小值，再加當前格代價：dp\[i, j\] = min(dp\[i-1, j\], dp\[i, j-1\]) + grid\[i, j\]。起點返回 grid\[0, 0\]，負索引越界時返回正無窮。

## 結構與關係

從根狀態 dp\[2, 1\] 反向查詢“上一行”和“上一列”前驅時，有兩條不同調用路線都會到達 dp\[1, 0\]：一條先查上一行到 dp\[1, 1\]、再查上一列到 dp\[1, 0\]（路線“上→左”）；另一條先查上一列到 dp\[2, 0\]、再查上一行到 dp\[1, 0\]（路線“左→上”）。正如右下方說明所指出的，“重疊子問題來源：dp\[i+1, j\] 和 dp\[i, j+1\] 都依賴 dp\[i, j\]”。

暴力搜尋不記錄已解狀態，因此第二次遇到 dp\[1, 0\]（路線“左→上”）時會像第一次（路線“上→左”）一樣，再次向下展開其上一行子節點 dp\[0, 0\] 與上一列越界節點 dp\[1, -1\]。加上左子樹“上→上→左”路線下的 dp\[0, 0\]，整棵 13 節點遞迴樹中起點 dp\[0, 0\] 共出現 3 次。

遞迴到達起點 dp\[0, 0\] 時返回基例值 grid\[0, 0\]；當行或列索引小於 0（圖中 dp\[-1, 1\]、兩處 dp\[1, -1\] 及 dp\[2, -1\]）時觸發“剪枝：索引越界”，按程式碼返回正無窮，使非法前驅在最小值比較中被自動排除。下方 4×4 符號 dp 表標出了本次搜尋涉及的六種有效狀態：\[0, 0\]、\[0, 1\]、\[1, 0\]、\[1, 1\]、\[2, 0\]、\[2, 1\]。

## 兩條回溯路線重複展開子問題 dp\[1, 0\]

從根 dp\[2, 1\] 經 dp\[1, 1\] 或 dp\[2, 0\] 回溯都會請求 dp\[1, 0\]；暴力搜尋將兩處 dp\[1, 0\] 各自展開為起點 dp\[0, 0\] 與越界節點 dp\[1, -1\]，造成同一子問題被重複求解。

## 結果

由於任意狀態 dp\[i, j\] 同時是下方狀態 dp\[i+1, j\] 和右方狀態 dp\[i, j+1\] 的前驅，暴力遞迴會產生大量重疊子問題；僅從 dp\[2, 1\] 回溯就把 dp\[1, 0\] 重複展開了兩次。
