# 14.8 &nbsp; 練習

## 14.8.1 &nbsp; 觀念複習

### 1. &nbsp; 什麼時候適合使用動態規劃

一位同學說：「只要能寫出遞迴關係式，就應該使用動態規劃。」
請判斷以下三個任務各適合用動態規劃、回溯法，還是直接用迴圈或數學公式求解而不建立 `dp` 表，並各寫出一項主要理由。

<!-- numbered-subquestions -->

1. 用面額為 `[1, 3, 4]` 的硬幣湊出金額 6，求最少需要幾枚硬幣。每種硬幣都可以重複使用；
2. 輸出 `[1, 2, 3]` 的所有排列；
3. 計算 $1 + 2 + \dots + n$。

    對於你認為適合使用動態規劃的任務，請再說明 `dp[i]` 的意義。

??? success "參考答案"

    1. 適合使用動態規劃。令 `dp[i]` 表示湊出金額 `i` 所需的最少硬幣數。
        對於每枚面額不超過 `i` 的硬幣 `c`，都可以把 `dp[i-c] + 1` 列為候選答案，
        再從中取最小值。做出不同選擇時，會反覆遇到相同的金額，而較大金額的最佳解也能由較小金額的最佳解構成。
        金額為 6 時，答案是 2，也就是 `3 + 3`。

    2. 應使用回溯法。題目要求逐一產生全部 6 個排列。回溯法可以有系統地嘗試一個選擇，繼續搜尋，
        再撤銷選擇，嘗試其他分支。無論採用哪種方法，要實際輸出所有排列，就得逐一列舉。

    3. 使用迴圈或等差級數公式即可。雖然能寫出 `S(i) = S(i-1) + i`，但計算 `S(i)` 只需要一個較小的 `S(i-1)`，
        每個部分和只需算一次，沒有重複的子問題，因此無須建立 `dp` 表。「能寫出遞迴關係式」不等於「需要動態規劃」。

### 2. &nbsp; 如何算出背包問題表格中某一格的值

0-1 背包問題中，物品重量為 `wgt = [1, 2, 3]`，價值為 `val = [5, 11, 15]`，背包容量為 4。
`dp[i][c]` 表示只考慮前 $i$ 件物品且背包容量上限為 $c$ 時，可取得的最大價值；
背包不必剛好裝滿。

現在只計算狀態 `dp[3][4]`。已知 `dp[2][4] = 16`、`dp[2][1] = 5`：

<!-- numbered-subquestions -->

1. 若不選第 3 件物品，候選價值是多少？
2. 若選第 3 件物品，還剩多少容量？候選價值是多少？
3. `dp[3][4]` 應取多少？這個值對應到哪些物品？

??? success "參考答案"

    1. 若不選第 3 件物品，就沿用前兩件物品的結果，候選價值為 `dp[2][4] = 16`。

    2. 第 3 件物品的重量為 3，放入後剩餘容量為 $4-3=1$，候選價值為
        `dp[2][1] + 15 = 5 + 15 = 20`。

    3. 比較 16 與 20，得到 `dp[3][4] = 20`。這個值對應到第 1、3 件物品，
        總重量為 $1+3=4$，總價值為 $5+15=20$。

        計算這個狀態時，就做了一次 0-1 背包問題中「選或不選」的比較。

### 3. &nbsp; 背包容量應依什麼順序更新

一道 0-1 背包問題只有一件物品，重量為 2，價值為 5，背包容量為 4。
每件物品最多選一次，一維陣列的初始值為 `dp = [0, 0, 0, 0, 0]`。

一位同學處理這件物品時，依容量由 2 到 4 的順序更新：

- 更新 `dp[2]` 後得到 5；
- 更新 `dp[3]` 後也得到 5；
- 更新 `dp[4]` 時又用到剛算出的 `dp[2]`，於是得到 `dp[4] = 10`。

<!-- numbered-subquestions -->

1. `dp[4] = 10` 這個結果正確嗎？為什麼？
2. 根據「每件物品最多選一次」的條件，`dp[4]` 應為多少？
3. 處理每件物品時，應依容量由大到小還是由小到大的順序更新？這樣可以避免什麼問題？

??? success "參考答案"

    1. 這個結果有誤。價值 10 相當於把這件價值為 5 的物品放入兩次，
        違反了「每件物品最多選一次」的條件。

    2. 背包最多只能放入這一件物品，因此 `dp[4]` 的正確值是 5。

    3. 容量應由大到小更新，也就是依序處理 4、3、2。
        這樣在計算 `dp[c]` 時，讀取的 `dp[c-2]` 仍是處理這件物品之前的結果，
        同一輪就不會重複使用這件物品。

## 14.8.2 &nbsp; 程式設計練習

### 1. &nbsp; 爬樓梯有幾種走法

一段樓梯共有 `n` 階。每一步只能往上走 1 階或 2 階，最後必須剛好走到第 `n` 階。
請算出共有幾種走法。已知 `n >= 1`，走法只依每一步跨 1 階或 2 階來區分。
請使用一維動態規劃陣列解題，先保留整張表，暫不採用只保留兩個狀態的空間最佳化寫法。

??? tip "解題提示"

    1. 到達第 i 階的最後一步，只可能跨 1 階或 2 階
    2. 因此有 dp[i] = dp[i-1] + dp[i-2]
    3. 先處理 n 為 1 和 2 的情況，再從第 3 階開始填表

### 2. &nbsp; 0-1 背包

給定長度相同的陣列 `wgt` 和 `val`，第 `i` 件物品的重量為正整數 `wgt[i]`，價值為非負整數 `val[i]`，
背包容量 `cap` 為非負整數。每件物品最多選一次，請在總重量不超過 `cap` 的條件下，
求出可裝入背包的最大總價值。請用一維動態規劃實作。

??? tip "解題提示"

    1. 建立長度為 cap + 1 的陣列 dp，其中 dp[c] 表示容量上限為 c 時可取得的最大價值
    2. 處理物品 i 時，比較「不選」的 dp[c] 與「選取」的 dp[c-wgt[i]] + val[i]
    3. 容量必須由大到小更新，才能避免在同一輪重複選取這件物品
