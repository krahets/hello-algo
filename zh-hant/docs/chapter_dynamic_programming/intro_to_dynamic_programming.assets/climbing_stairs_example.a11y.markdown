# 爬到第三階的三種方案

每次可上 1 階或 2 階，從地面 0 爬到第 3 階共有三種不同的走法。

## 問題與輸入

設地面起點編號為 0，每一步可以選擇向上爬 1 階或 2 階，目標是恰好爬上第 3 階樓梯。

## 結構與關係

圖中樓梯輪廓從 0 畫到第 6 階，其中目標第 3 階的踏面以綠色高亮。樓梯上方用青色實線、藍色點線和橙色虛線畫出三條從 0 到 3 的跳躍弧線，圖下方文字依次列出這三種方案經過的臺階編號。

<a id="source-367"></a>

青色實線方案按臺階編號 0→1→2→3 前進，即連續三次各上 1 階；藍色點線方案按 0→2→3 前進，即先上 2 階到第 2 階、再上 1 階到第 3 階；橙色虛線方案按 0→1→3 前進，即先上 1 階到第 1 階、再上 2 階到第 3 階。三條路線都從地面 0 出發並恰好停在綠色高亮的第 3 階。

## 結果

爬上第 3 階共有 3 種方案；每步跨 1 階與跨 2 階的先後順序不同（如先 2 後 1 與先 1 後 2），經過的臺階序列不同，計為不同方案。
