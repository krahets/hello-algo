# 禁止連續兩次上 1 階後的第三階走法

加上不能連續兩輪跳 1 階的限制後，0→1→2→3 被捨棄，到達第 3 階只剩 2 種方案。

## 問題與輸入

從地面 0 出發，每步仍可上 1 階或 2 階，目標是爬上第 3 階樓梯，但新增約束條件：不能連續兩輪都跳 1 階。

## 結構與關係

樓梯輪廓畫至第 6 階，目標第 3 階踏面為綠色。原 0→1→2→3 路線改為灰色點線，並在上方標註“由於不能連續兩輪跳 1 階，因此方案 0→1→2→3 被捨棄”；藍色實線 0→2→3 與橙色實線 0→1→3 保持彩色高亮，底部彙總剩餘的 2 種方案。

<a id="source-374"></a>

方案 0→1→2→3 需要連續三次各跳 1 階，在前兩步就已經違反了“不能連續兩輪跳 1 階”的限制，因此被置灰捨棄。藍色方案 0→2→3 先跳 2 階再跳 1 階，橙色方案 0→1→3 先跳 1 階再跳 2 階，兩者都沒有出現相鄰兩次 1 階跳躍，因此均合法保留。

## 結果

在禁止連續兩步跳 1 階的約束下，爬上第 3 階的合法方案減少為 2 種。
