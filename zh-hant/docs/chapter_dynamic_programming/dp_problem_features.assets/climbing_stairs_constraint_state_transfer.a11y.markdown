# 用上一步步長擴展動態規劃狀態

將最後一步跳了 1 階還是 2 階納入二維狀態 dp\[i, j\]，即可在轉移時排除連續兩次跳 1 階。

## 問題與輸入

每步可上 1 階或 2 階，但不能連續兩輪跳 1 階。由於當前能否跳 1 階取決於上一輪的步長，需要將狀態擴展為二維 dp\[i, j\]，表示爬到第 i 階且上一輪跳了 j 階（j 取 1 或 2）的方案數。

## 結構與關係

圖中在最高一階標出兩個目標狀態：青色 dp\[i, 1\] 與藍色 dp\[i, 2\]；在前一階標出青色 dp\[i-1, 2\] 與灰色 dp\[i-1, 1\]；在前兩階標出藍色 dp\[i-2, 1\] 與藍色 dp\[i-2, 2\]。從 dp\[i-1, 2\] 有一條青色實線跨 1 階指向 dp\[i, 1\]，而從灰色 dp\[i-1, 1\] 引出的灰色點線旁註明“不能連續兩輪跳 1 階，因此該項被捨去”；從 dp\[i-2, 1\] 和 dp\[i-2, 2\] 各有一條藍色實線跨 2 階匯入 dp\[i, 2\]。

分析到達第 i 階的兩類狀態：第一類是最後一步跳 1 階到達 dp\[i, 1\]，此時上一步位於第 i-1 階，且再上一步決不能也是 1 階，因此只能從 dp\[i-1, 2\] 轉移而來，即 dp\[i, 1\]=dp\[i-1, 2\]，而 dp\[i-1, 1\] 因會導致連續兩輪跳 1 階被捨去；第二類別是最後一步跳 2 階到達 dp\[i, 2\]，此時上一步位於第 i-2 階，無論前一步是跳 1 階還是跳 2 階都不違背約束，因此 dp\[i, 2\]=dp\[i-2, 1\]+dp\[i-2, 2\]。結合表中給出的正文程式碼第 1、第 2 階初始狀態即可順序遞推。

## 結果

擴展狀態後問題重新滿足無後效性，狀態轉移方程為 dp\[i, 1\]=dp\[i-1, 2\] 與 dp\[i, 2\]=dp\[i-2, 1\]+dp\[i-2, 2\]，爬到第 n 階的總方案數為 dp\[n, 1\]+dp\[n, 2\]。
