# 三階樓梯的最小代價

當各階代價為 0、1、10、1 時，跨過代價高昂的第 2 階，走 0→1→3 可得最小總代價 2。

## 問題與輸入

每步可以上 1 階或 2 階，每踏上第 n 階樓梯都需要支付該階對應的代價 cost\[n\]。地面起點代價為 cost\[0\]=0，本題目標是踏上第 3 階並支付第 3 階的代價（不同於越過第 3 階免付末階費用的變體）。

## 結構與關係

樓梯下方依次對齊列出樓梯階數 n=0、1、2、3 與代價 cost\[n\]=0、1、10、1；其中第 2 階的踏面與數字 10 用紅色突出顯示，目標第 3 階的踏面用綠色突出顯示。樓梯上方用青色實線、藍色點線和橙色虛線畫出三條走法，底部列出三種方案並指出最優方案。

三條到達第 3 階的方案費用如下：青色實線 0→1→2→3 依次踏上第 1、第 2、第 3 階，支付 1+10+1=12；藍色點線 0→2→3 踏上第 2、第 3 階，支付 10+1=11；橙色虛線 0→1→3 踏上第 1、第 3 階，直接跨過了代價為 10 的紅色第 2 階，只需支付 1+1=2。比較可知 0→1→3 的總代價最小。

## 結果

到達第 3 階的最小總代價為 2，對應先上 1 階、再上 2 階的路徑 0→1→3。
