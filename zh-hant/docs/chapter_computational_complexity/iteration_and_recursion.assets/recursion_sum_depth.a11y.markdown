# 遞迴求和的遞迴深度

在普通遞迴求和圖的基礎上將右側返回過程淡化，用左側大括號框出從 recur(n) 到 recur(1) 的整列向下呼叫鏈，標明其“遞迴深度 n”。

## 問題與輸入

正文以正整數 n 為輸入、計算 1 + 2 + … + n 的 recur(n) 為例，說明遞迴的呼叫堆疊：每次遞迴呼叫但尚未返回的函式都會佔用堆疊幀空間，因此需要度量同時存在的最大呼叫層數，即“遞迴深度”。

## 結構與關係

畫面沿用了普通遞迴求和的左右雙列布局，右側 return 表示式、大括號與返回箭頭均被淡化；左右列標題及底部“觸發遞迴終止條件”文字和向右箭頭仍清晰可見。視覺焦點集中在左側“向下‘遞’”呼叫列，從 recur(n)、recur(n-1)、… 到 recur(4)、recur(3)、recur(2)、recur(1)；其左側設有貫穿首尾的縱向大括號，大括號左側的灰色標籤標註“遞迴深度 n”。

畫面透過淡化右側“向上‘迴’”部分，突顯左側“向下‘遞’”階段在觸底前累積的呼叫鏈：從頂層 recur(n) 依次向下呼叫 recur(n-1)、…、recur(4)、recur(3)、recur(2) 直至底層 recur(1)，左側縱向大括號將這串連續巢狀的呼叫整體括起並標註“遞迴深度 n”，直觀展示到達 recur(1) 時，包括頂層在內共有 n 層呼叫尚未返回。在 recur(1) 處觸發終止條件後返回 1，再沿被淡化的右列逐層加上當前層參數，最終返回 1 到 n 的總和。

## 結果

從 recur(n) 到 recur(1)，包括頂層在內共 n 層巢狀呼叫；最深時呼叫堆疊上同時存在 n 個尚未返回的堆疊幀。因此該函式的遞迴深度為 n，空間複雜度為 O(n)。
