# 五種常見時間複雜度的增長趨勢

對比常數階、對數階、線性階、平方階和指數階五條曲線：隨輸入規模 n 增大，不同複雜度階數的操作數量增長差距急劇拉開。

## 結構與關係

座標圖橫軸表示輸入資料大小 n，刻度從 1 到 14；縱軸表示計算操作數量 T(n)。圖中透過五條示意曲線對比不同時間複雜度的漸近增長趨勢，而非報告某段具體程式的精確執行次數。

五條曲線按不同顏色區分：綠色常數階 O(1) 為水平直線，操作數量不隨 n 變化；青色對數階 O(log n) 隨 n 增大而緩步上升，斜率逐漸減小、走勢趨於平緩；藍色線性階 O(n) 以恆定斜率呈直線穩定上升；橙色平方階 O(n²) 呈向上彎曲趨勢，增長速度不斷加快；紅色指數階 O(2ⁿ) 在前段貼近底部、變化平緩，進入後段則陡峭攀升。

圖右側配有向上的箭頭，標註“從低至高、從優至差”。在輸入規模接近 14 的右側末端，五條曲線由下到上依次為常數階 O(1)、對數階 O(log n)、線性階 O(n)、平方階 O(n²) 和指數階 O(2ⁿ)，體現大規模輸入下的增長快慢排序；前段示意曲線的交點僅用於展示趨勢，不能當作複雜度優劣切換的精確規模閾值。

## 結果

圖中五種常見時間複雜度的增長速度由慢到快依次為：常數階 O(1)、對數階 O(log n)、線性階 O(n)、平方階 O(n²)、指數階 O(2ⁿ)。時間複雜度的階數越低，當輸入規模充分增大時，操作數量的增長越平緩，演算法漸近效率越優。
