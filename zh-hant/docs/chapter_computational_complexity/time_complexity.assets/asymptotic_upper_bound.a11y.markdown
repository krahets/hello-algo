# 漸近上界：越過閾值後的大小關係

當輸入規模 n 超過閾值 n₀ 後，正常數倍函式 c·f(n) 始終不低於操作數量 T(n)，據此將 f(n) 定義為 T(n) 的漸近上界 O(f(n))。

## 問題與輸入

座標圖橫軸表示輸入資料大小 n，標有刻度 0 至 14 及向右箭頭；縱軸表示函式值，配有向上箭頭，未標出可見數值刻度。

藍色曲線表示演算法的操作數量函式 T(n)，橙色曲線表示候選函式 f(n) 乘以正常數係數 c 後的函式 c·f(n)。圖中曲線用於闡釋漸近上界的數學關係，未繫結特定的代數公式。

## 結構與關係

綠色豎直虛線標出閾值 n₀，位置緊靠橫軸刻度 7 右側（位於 7 與 8 之間的兩線交點處）。在虛線 n₀ 左側的小規模區間內，藍色 T(n) 曲線有小幅起伏，並在刻度 1 至 7 之間高於橙色 c·f(n) 曲線；越過虛線 n₀ 之後，橙色 c·f(n) 曲線始終位於藍色 T(n) 曲線上方，且兩條曲線隨 n 增大一同向上攀升。

圖下方說明框總結定義：當 n &gt; n₀ 時，始終有 c·f(n) ≥ T(n)，此時可認為 f(n) 是 T(n) 的一個漸近上界，記為 T(n) = O(f(n))。

<a id="source-26"></a>

漸近上界關注的是輸入規模 n 趨向無窮大時的增長級別。即使在 n 較小時（n ≤ n₀）操作數量 T(n) 一度超過 c·f(n)，只要越過閾值 n₀ 後 c·f(n) 始終能夠覆蓋 T(n)，f(n) 就給出了 T(n) 的有效漸近上界。

## 結果

判定 T(n) = O(f(n)) 只要求存在正實數 c 和閾值 n₀，使所有大於 n₀ 的輸入規模都滿足 T(n) ≤ c·f(n)；並不要求兩條曲線在所有輸入規模下處處相等，也不受閾值 n₀ 之前區域性大小關係的影響。
