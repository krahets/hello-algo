# 每層一分為二的遞迴樹

遞迴樹從根節點開始每往下一層節點數翻倍，共 n 層的節點總數為 2⁰ + 2¹ + … + 2ⁿ⁻¹ = 2ⁿ - 1，對應指數階時間複雜度 O(2ⁿ)。

## 問題與輸入

每個綠色圓角小方塊代表 1 個遞迴呼叫節點（即 1 個計算操作）。樹頂標題為“遞迴樹 每層一分為二”，右側列標題為“各層的節點數量”；根節點計為第 1 層，右側大括號標明整棵遞迴樹共 n 層。

## 結構與關係

從上到下，第 1 層畫出 1 個根節點，右側標註 2⁰（即 1）；該節點向下分出 2 個箭頭，指向第 2 層的 2 個節點，右側標註 2¹（即 2）；第 2 層每個節點再各分出 2 個箭頭，指向第 3 層的 4 個節點，右側標註 2²（即 4）。

第 3 層下方用 8 個向下箭頭和省略號表示中間繼續按一分為二規律展開的各層；最底層（第 n 層）並排畫出 8 個帶省略號間隔的綠色節點，右側標註 2ⁿ⁻¹（即 2 的 n - 1 次方）。底部說明框列出公式：計算操作總數（即遞迴樹的節點總數）為 2⁰ + 2¹ + 2² + … + 2ⁿ⁻¹ = 2ⁿ - 1，右側箭頭指向結論“時間複雜度 指數階 O(2ⁿ)”。

統計整個過程的計算操作總數，需要將全部 n 層的節點數按等比數列求和：1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ - 1。注意區分兩種計數口徑：正文中“1 個細胞分裂 n 輪後變為 2ⁿ 個細胞”指的是經過 n 次分裂後的末態數量；而本圖與程式碼中的參數 n 表示包含起始根層在內的總層數（共分裂 n - 1 輪），末層節點數為 2ⁿ⁻¹，全樹累計節點總數為 2ⁿ - 1。

## 結果

每增加一層遞迴，新增的操作數量就翻一倍；包含根層在內的 n 層節點總數按 2ⁿ - 1 呈指數級增長，忽略常數項後時間複雜度為指數階 O(2ⁿ)。
