# 全排列的逐層選擇與階乘增長

生成 n 個不重複元素的全排列時，各層分支數從 n 依次遞減到 1，第 n 層共產生 n! 個完整排列葉節點，按圖中每個遞迴節點僅做常數工作的計數模型，對應階乘階時間複雜度 O(n!)。

## 問題與輸入

圖對應全排列的遞迴展開過程：最上方居中的單個灰色小方塊代表尚未做出任何選擇的起始根節點；往下每一層代表為排列的下一個位置挑選一個尚未使用的元素。

畫面左列標題為“各層的分裂數量”，右列標題為“各層的節點數量”；右側大括號標註“共 n 層”，範圍覆蓋根節點下方的 n 個選擇層（不含最頂部的起始根節點）。

## 結構與關係

從頂部起始節點向下，第 1 個虛線框層分裂出 n 個灰色節點（中間用省略號表示其餘分支），左列分裂數量標註 n，右列節點數量標註 n。第 2 個虛線框層中，上一層的每個節點各分裂出 n - 1 個子節點，左列標註 n - 1，右列標註 n(n - 1)。第 3 個虛線框層中，每個節點再各分裂出 n - 2 個子節點，左列標註 n - 2，右列標註 n(n - 1)(n - 2)。

第 4 個虛線框層用省略號表示中間繼續遞減的各層；最底層（第 n 層）的左列分裂數量標註 1，框內畫出綠色的葉節點方塊，右列節點數量標註 n!。底部說明框寫出：全排列的方案數（即最底層的節點數量）為 n × (n - 1) × (n - 2) × … × 2 × 1 = n!，右側箭頭指向“時間複雜度 階乘階 O(n!)”。

<a id="source-32"></a>

在第 1 層有 n 種選擇，第 2 層對每種已選字首各有 n - 1 種剩餘選擇，依此類推，到第 n 層只剩最後 1 個可選元素並停止分裂。將各層分裂數量連乘得到的 n × (n - 1) × (n - 2) × … × 2 × 1 = n!，準確對應最底層的綠色葉節點數量（即全部排列方案數，也等於程式碼 factorial\_recur 累加返回的基例計數），而非把樹中所有中間層節點也加在一起的總節點數。

## 結果

隨著元素個數 n 增大，全排列方案數按 n! 呈階乘級急劇增長；當 n ≥ 4 時恆有 n! &gt; 2ⁿ，階乘階 O(n!) 比指數階 O(2ⁿ) 的增長還要快得多。
