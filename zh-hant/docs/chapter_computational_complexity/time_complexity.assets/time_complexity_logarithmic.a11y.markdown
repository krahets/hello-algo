# 每次保留一半的對數增長

長度為 n 的陣列每層刪減一半，最終縮減至長度 1；圖中包含長度為 1 的末層在內共 log₂n + 1 層，每層 1 個計算操作，對應對數階時間複雜度 O(log n)。

## 問題與輸入

畫面分為左、中、右三列，頂部標題依次為“剩餘陣列長度”、“輸入陣列長度為 n 每層刪減一半”和“每層包含 1 個計算操作”。陣列行中，深綠色格子並加綠色外框表示當前保留的區間，淺灰色格子表示已被排除的區間。

## 結構與關係

三列頂部均以豎向省略號開頭，表示從一般規模 n 持續減半的前序過程；其下具體畫出最後 4 層（對應從長度 8 縮減到 1 的過程），各層之間用向下的灰色箭頭銜接。這 4 層的左側“剩餘陣列長度”依次標註 8、4、2、1；中間 8 格陣列依次保留全部 8 格、最右側 4 格、最右側 2 格和最右側 1 格；右側每層各畫出 1 個淺綠色計算操作方塊，由向下箭頭串聯。

最右側大括號跨越從頂部省略號到末尾長度 1 的全部層級，標註“共 log₂n + 1 層”。底部說明框寫出：計算操作總數為 log₂n + 1，箭頭指向“時間複雜度 對數階 O(log n)”。

設 n 為 2 的整數次冪，需要區分“減半動作的次數”與“圖中畫出的陣列層數”：從長度 n 連續除以 2 直到變為 1，共執行 log₂n 次減半（對應程式碼 while n &gt; 1 迴圈體執行的次數）；而圖示把起始狀態和末尾長度為 1 的狀態都作為獨立的一層畫出，因此總層數為 log₂n + 1。以圖中具體畫出的後四行 8、4、2、1 為例，共經歷了 3 次減半，但包含首尾共有 4 層。

## 結果

當資料規模每輪縮減為原來的一半時，執行層數僅隨輸入規模 n 按對數級別緩慢增長；忽略常數項 +1 與對數底數後，時間複雜度記為對數階 O(log n)。
