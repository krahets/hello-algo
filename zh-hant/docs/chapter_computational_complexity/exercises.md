## 觀念複習

### 迭代與遞迴所需的時間和空間

下列兩段程式碼都用來計算 $1 + 2 + \dots + n$（設 $n \ge 1$）。請將 `n` 設為 4，
依程式實際執行的順序回答問題，再比較兩種寫法的效率。

```src
[file]{complexity_exercises}-[class]{}-[func]{sum_iter}
```

<!-- numbered-subquestions -->

1. 以 `n = 4` 為輸入執行迭代函式時，每次迴圈結束後，累加變數 `res` 的值分別是多少？
2. 以 `n = 4` 為輸入執行遞迴函式時，參數 `n` 依序取哪些值？從最深一層開始回傳時，各層如何算出結果？
3. 兩種寫法的時間複雜度與空間複雜度各是多少？請根據第 1、2 題的執行過程說明理由。

??? success "參考答案"

    1. 迴圈變數 `i` 依序為 `1、2、3、4`，每次迴圈結束後，`res` 的值依序為
        `1、3、6、10`，因此迭代函式回傳 10。

    2. 參數 `n` 的值依序為 `4 → 3 → 2 → 1`。
        最深一層回傳 1，接下來各層依序算出 `2 + 1 = 3`、`3 + 3 = 6`、`4 + 6 = 10`。
        執行到最深一層時，4 次函式呼叫都還沒結束。

    3. 兩段程式碼的迴圈次數或呼叫次數都與 $n$ 成正比，因此時間複雜度都是 $O(n)$。
        兩者的空間複雜度不同。迭代版只用到固定數量的變數，空間複雜度為 $O(1)$。
        遞迴版在達到終止條件前，先前的函式呼叫都要等候回傳結果，因此呼叫堆疊最多同時保留 $n$ 次呼叫，
        空間複雜度為 $O(n)$。

        分析空間複雜度時，除了程式碼中的變數，也要考慮遞迴呼叫占用的空間。

### 三段程式碼的時間複雜度

以下三段程式碼的輸入都是正整數 $n$。請按時間複雜度由低到高排列，並寫出各段的複雜度。

```src
[file]{complexity_exercises}-[class]{}-[func]{linear_loop}
```

??? success "參考答案"

    由低到高依序為片段三 $O(\log n)$、片段一 $O(n)$、片段二 $O(n^2)$。
    片段三每次迴圈都把 $n$ 減半，約執行 $\log_2 n$ 次。
    片段一的迴圈恰好執行 $n$ 次。片段二的內層迴圈依序執行
    $n,n-1,\dots,1$ 次，合計 $n(n+1)/2$ 次，因此是平方階。

### 哪種反轉方式較省空間

要將陣列 `nums` 的所有元素順序反轉，有兩種做法：

<!-- numbered-subquestions -->

1. 建立一個同樣長的陣列 `res`，依相反順序複製元素，再回傳新陣列；
2. 讓索引 `i` 和 `j` 分別從頭、尾往中間移動，逐對交換 `nums[i]` 與 `nums[j]`。

    兩種做法的空間複雜度各是多少？哪一種屬於「原地」操作？

??? success "參考答案"

    1. 需要與輸入等長的輔助陣列，空間複雜度為 $O(n)$。

    2. 只用到兩個索引變數，
        空間複雜度為 $O(1)$，屬於原地操作。

        請留意，原地反轉會修改輸入陣列，
        只有在允許修改輸入時才應優先採用。如果需要保留原陣列，就無法省去第一種做法的複製成本。

## 程式設計練習

### 費氏數

費氏數列滿足 $F(0)=0$、$F(1)=1$，且當 $n\ge2$ 時，
$F(n)=F(n-1)+F(n-2)$。

給定非負整數 `n`，請用迴圈計算並回傳 $F(n)$，不可使用遞迴。

??? tip "解題提示"

    1. 先分別處理 n 為 0 和 1 的情況
    2. 計算下一項只需要前兩項，不必儲存整個數列
    3. 更新兩個變數時，留意哪些舊值還會用到，以免太早覆寫
