# 空間複雜度通常統計哪些空間

演算法執行涉及的記憶體分為輸入空間、暫存空間和輸出空間三類；空間複雜度通常統計暫存空間與輸出空間，且實際分析中一般忽略指令空間。

## 問題與輸入

畫面自左向右依次排列三個圓角矩形框：“輸入空間”、“暫存空間”和“輸出空間”，框間用向右的灰色粗箭頭連線，表示演算法接收輸入、藉助暫存區完成計算併產生輸出的過程。

## 結構與關係

左側綠色框為“輸入空間”，正下方標註“輸入資料”；中間藍色框為“暫存空間”，正下方分三行依次列出“暫存資料”、“堆疊幀空間”和“指令空間”；右側青色框為“輸出空間”，正下方標註“輸出資料”。

圖上方有一道水平大括號，僅跨過中間的“暫存空間”和右側的“輸出空間”，未包含左側的“輸入空間”，大括號上方標註“通常情況下空間複雜度的統計範圍”。

暫存空間中的三個子項各有職責：暫存資料用於儲存執行過程中的常數、變數和物件；堆疊幀空間用於儲存函式呼叫的上下文資料（每次呼叫入堆疊、返回後釋放）；指令空間用於儲存編譯後的程式指令。圖中的向右箭頭表示演算法的資料處理流程，並不表示這三類記憶體會依次自動釋放。

## 結果

在推算一段程式的空間複雜度時，輸入資料本身佔用的輸入空間不計入額外開銷，編譯後的指令空間在實際統計中也通常忽略不計；重點統計的是暫存資料、堆疊幀空間和輸出資料三部分。
