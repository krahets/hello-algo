# 常見空間複雜度的增長趨勢

對比常數階 O(1)、對數階 O(log n)、線性階 O(n)、平方階 O(n²) 和指數階 O(2ⁿ) 五條曲線，展示記憶體需求隨輸入規模 n 增大的增長快慢排序。

## 問題與輸入

座標圖橫軸表示輸入資料大小 n，可見刻度為 1 至 14；縱軸表示記憶體空間大小，未標出可見的具體容量數值。圖中曲線用於對比不同空間複雜度的漸近增長趨勢，而非某段具體程式碼的實測位元組數。

## 結構與關係

圖中繪有五條不同顏色的示意曲線：綠色常數階 O(1) 是緊貼橫軸上方的水平直線，記憶體佔用不隨 n 變化；青色對數階 O(log n) 隨 n 增大而緩步上升，斜率逐漸變緩；藍色線性階 O(n) 是以恆定斜率向上延伸的直線；橙色平方階 O(n²) 呈向上彎曲的拋物線走勢，斜率越來越陡；紅色指數階 O(2ⁿ) 在刻度 1 至 8 之間貼近底部，進入後段則急劇陡峭攀升。

在橫軸末端 n = 14 右側，五條曲線的終點由下到上依次對齊標註“常數階 O(1)”、“對數階 O(log n)”、“線性階 O(n)”、“平方階 O(n²)”和“指數階 O(2ⁿ)”；最右側配有向上的灰色粗箭頭，內寫“從低至高、從優至差”。

右側向上箭頭“從低至高、從優至差”反映的是當 n 足夠大時的漸近增長階排序（注意圖中只包含這五種常見空間複雜度，未繪製時間複雜度圖中的線性對數階或階乘階）。在小規模區間內，示意曲線之間存在交叉（例如青色對數曲線在刻度 2 至 6 之間略高於藍色線性直線，紅色指數曲線在前段低於其他曲線），這些交點僅作趨勢示意，不能當作具體記憶體大小或複雜度優劣切換的精確閾值。

## 結果

常見空間複雜度的漸近增長速度由慢到快依次為：常數階 O(1) &lt; 對數階 O(log n) &lt; 線性階 O(n) &lt; 平方階 O(n²) &lt; 指數階 O(2ⁿ)。當輸入資料規模足夠大時，空間複雜度階數越低，演算法的峰值記憶體需求越容易控制在安全範圍內。
