# 遞迴各層保留陣列形成平方空間

遞迴函式 quadratic\_recur 在參數從 n 到 1 的 n 個呼叫層分別建立並保留長度為 n、n - 1、…、2、1 的陣列，峰值陣列總長度為 n(n + 1)/2，空間複雜度為平方階 O(n²)。

## 問題與輸入

畫面自左向右分為三列，頂部標題依次為“陣列 nums 長度”、“向下‘遞’”和“向上‘迴’”。函式在參數為正數的每一層遞迴中都會初始化一個長度等於當前參數值的區域性陣列 nums，再發起下一層遞迴呼叫。

## 結構與關係

中間“向下‘遞’”列自上而下由向下箭頭連線 quadratic\_recur(n)、quadratic\_recur(n-1)、省略號、quadratic\_recur(2) 和 quadratic\_recur(1)；左列“陣列 nums 長度”以藍色字型對應標註 n、n-1、省略號、2、1，並透過帶圓點的水平線段與各層呼叫框相連。最左側大括號覆蓋從 n 到 1 的這 n 層，標註“遞迴深度 n”。

在最底層的 quadratic\_recur(1) 右側，水平向右箭頭標註“觸發遞迴終止條件”，指向右列底部的“return 0”，隨後由向上箭頭串聯各層“return 0”向上返回。底部說明框寫出：“在每個遞迴函式中都初始化了一個陣列，總長度為 1 + 2 + … + (n-1) + n = n(n+1)/2”，右側箭頭指向“空間複雜度 平方階 O(n²)”。

在上層函式等待下層遞迴返回期間，上層建立的陣列 nums 始終保留在記憶體中無法釋放。到達遞迴最深處時，記憶體中同時存在長度為 n、n - 1、…、2、1 的 n 個陣列，按等差數列求和得到總長度 n(n + 1)/2 = (n² + n)/2（圖中將末端的終止與返回簡化畫在參數 1 這一行，準確覆蓋了分配陣列的全部 n 層；Python 程式碼還會呼叫參數 0，在該層直接返回且不分配陣列）。因此，峰值空間由平方階 O(n²) 的陣列總長度主導，遠大於呼叫堆疊本身的 O(n) 堆疊幀開銷。

## 結果

當遞迴函式在每一層堆疊幀內還額外分配了與當前參數成正比的資料結構時，峰值記憶體需要將該呼叫鏈上所有未返回層的區域性資料結構一併累加；此處 n 層陣列的總長度為 n(n + 1)/2，主導項決定了最差空間複雜度為平方階 O(n²)。
