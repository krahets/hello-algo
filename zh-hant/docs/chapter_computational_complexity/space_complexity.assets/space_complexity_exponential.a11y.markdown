# 儲存 n 層滿二元樹所需的空間

構建並儲存一棵 n 層滿二元樹時，各層節點數從 2⁰ 翻倍至 2ⁿ⁻¹，記憶體中同時保留全部 2ⁿ - 1 個節點，對應指數階空間複雜度 O(2ⁿ)。

## 問題與輸入

圖對應遞迴構建滿二元樹（build\_tree）完成後在記憶體中儲存的樹結構：每個帶雙層邊框的綠色圓圈代表 1 個樹節點物件（佔用固定大小的記憶體空間），有向箭頭從父節點指向左、右子節點。右側列標題為“各層的節點總數”，大括號標明整棵樹“共 n 層”。

## 結構與關係

從上到下，第 1 層畫出 1 個綠色根節點，右側標註 2⁰（即 1）；根節點向左下、右下各伸出 1 條箭頭，指向第 2 層的 2 個節點，右側標註 2¹（即 2）；第 2 層每個節點再各伸出 2 條箭頭，指向第 3 層的 4 個節點，右側標註 2²（即 4）。

第 3 層的 4 個節點下方共伸出 8 條向下箭頭指向省略號，表示樹繼續按滿二元樹規律向下展開直至第 n 層；右列在省略號下方標註第 n 層的節點總數 2ⁿ⁻¹（即 2 的 n - 1 次方）。底部說明框寫出：“所有節點數量 2⁰ + 2¹ + 2² + … + 2ⁿ⁻¹ = 2ⁿ - 1”，右側箭頭指向“空間複雜度 指數階 O(2ⁿ)”。

注意區分“遞迴呼叫堆疊深度”與“持久化的樹節點總數”：構建這棵 n 層滿二元樹時，單條從根到葉路徑上的遞迴呼叫堆疊深度雖然只有 O(n)，但每次呼叫建立的樹節點都會透過左右指標掛載到樹上並長期保留。因此峰值記憶體必須統計整棵樹同時存在的所有節點：將第 1 層至第 n 層的節點數相加得到 1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ - 1，每個節點佔用常數空間，總空間複雜度即為指數階 O(2ⁿ)。

## 結果

當演算法需要在記憶體中完整儲存一棵層數為 n 的滿二元樹時，所有新建立的節點物件都不會隨遞迴返回而銷燬；節點總數 2ⁿ - 1 決定了其佔用的儲存空間呈指數級增長，空間複雜度為指數階 O(2ⁿ)。
