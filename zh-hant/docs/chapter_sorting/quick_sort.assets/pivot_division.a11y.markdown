# 以 2 為基準的一次哨兵劃分

雙指標將 \[2,4,1,0,3,5\] 劃分為 \[1,0\]、基準 2 與 \[4,3,5\]，兩側仍待遞迴排序。

## 問題與輸入

初始陣列為 nums = \[2, 4, 1, 0, 3, 5\]，索引從 0 到 5，當前處理區間為 left = 0、right = 5，選取最左端元素 nums\[left\] = 2 作為基準數。

左指標 i 從左向右尋找首個大於基準數的元素，右指標 j 從右向左尋找首個小於基準數的元素。本實現每輪迴圈先移動 j、再移動 i，且移動條件均要求 i &lt; j；當兩端都找到放錯分割槽的元素後便交換它們，直到兩指標相遇，最後將基準數交換到相遇位置。

## 結構與關係

畫面上方展示陣列 nums、基準數標記以及區間邊界指標 left、right 與掃描指標 i、j；下方展示 partition 函式程式碼，並以灰色高亮標出當前步驟執行的語句。在最終將基準數交換到分界位置之前，基準數 2 一直儲存在索引 0 處，不會隨指標 i 向右掃描而改變位置。

## 第 1 步：初始化邊界、基準數與雙指標

區間邊界為 left = 0、right = 5，選取索引 0 的最左端元素 2 作為基準數；程式碼高亮初始化語句 i, j = left, right，令指標 i = 0、j = 5 分別指向陣列兩端的值 2 和 5，此時尚未開始掃描或交換。

<a id="source-264"></a>

## 第 2 步：指標 j 從右向左找到小於基準數的 0

每輪先移動右指標 j：索引 5 的元素 5 和索引 4 的元素 3 均不小於基準數 2，因此 j 依次向左跳過它們；移至索引 3 時遇到元素 0，因 0 &lt; 2 滿足小於基準數的條件而停止。左指標 i 仍停在索引 0。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 4, 1, 0, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 0，j = 3。</p></details>

<a id="source-265"></a>

## 第 3 步：指標 i 從左向右找到大於基準數的 4

接著從索引 0 開始向右移動左指標 i：索引 0 的基準數 2 不大於自身，i 越過索引 0；移至索引 1 時遇到元素 4，因 4 &gt; 2 滿足大於基準數的條件而停止。此時 i 指向偏大的元素 4，j 指向偏小的元素 0。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 4, 1, 0, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 1，j = 3。</p></details>

## 第 4 步：交換元素 4 與 0

執行交換語句，將索引 1 的元素 4 與索引 3 的元素 0 互換，陣列變為 \[2, 0, 1, 4, 3, 5\]。交換後，小於基準數的 0 被移到左側，大於基準數的 4 被移到右側；指標仍為 i = 1、j = 3，基準數 2 仍留在索引 0。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 0, 1, 4, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 1，j = 3。</p></details>

<a id="source-267"></a>

## 第 5 步：指標 j 繼續向左找到小於基準數的 1

進入下一輪迴圈，繼續先移動右指標 j：當前索引 3 的元素 4 滿足 4 ≥ 2，j 向左移至索引 2；索引 2 的元素為 1，因 1 &lt; 2 滿足小於基準數的條件而停止。左指標 i 仍停在索引 1，指向元素 0。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 0, 1, 4, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 1，j = 2。</p></details>

<a id="source-268"></a>

## 第 6 步：指標 i 右移並與指標 j 相遇

接著移動左指標 i：當前索引 1 的元素 0 滿足 0 ≤ 2，i 向右移至索引 2。此時 i = j = 2，內層掃描因兩指標相遇（i &lt; j 不再成立）而停止；注意相遇處的元素 1 並不大於基準數 2，此處停下是因為雙指標相遇，而非找到了第二個偏大元素。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 0, 1, 4, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 2，j = 2。</p></details>

<a id="source-269"></a>

## 第 7 步：相遇位置的自交換不改變陣列

程式碼繼續執行本輪末尾的 nums\[i\], nums\[j\] 交換語句，但由於 i 與 j 同為 2，相當於將索引 2 的元素 1 與自身交換，陣列內容保持不變。隨後外層迴圈條件 i &lt; j 不成立，退出掃描迴圈。

<details><summary>本步完整狀態</summary><p>陣列為 [2, 0, 1, 4, 3, 5]，索引 0 至 5；基準數 2 位於索引 0。left = 0，right = 5，i = 2，j = 2。</p></details>

## 第 8 步：將基準數 2 交換到分界索引 2

執行迴圈後的基準迴位語句，交換 nums\[left\] 與 nums\[i\]，即將索引 0 的基準數 2 與索引 2 的元素 1 互換。陣列變為 \[1, 0, 2, 4, 3, 5\]，基準數 2 到達左右分割槽的分界位置；區間邊界 left = 0、right = 5 保持不變。

## 第 9 步：完成一次劃分，保留左右子陣列子問題

函式執行 return i 返回基準數索引 2。最終畫面隱去指標，用大括號標出基準數 2 兩側的子區間：左子陣列為索引 0、1 的 \[1, 0\]，右子陣列為索引 3 至 5 的 \[4, 3, 5\]。此時僅基準數 2 的最終位置已確定，左側的 1、0 與右側的 4、3 仍未排好順序。

## 結果

單次哨兵劃分結果為 \[1, 0, 2, 4, 3, 5\]，並返回基準數最終所在的索引 2。此時左側子陣列 \[1, 0\] 的所有元素均滿足 ≤ 2，右側子陣列 \[4, 3, 5\] 的所有元素均滿足 ≥ 2；但左右兩個子陣列內部仍處於無序狀態，完成整個陣列的快速排序還需分別對它們遞迴執行哨兵劃分。
