# 快速排序遞迴概覽

每輪哨兵劃分先將基準數固定到最終位置，再對左右子陣列遞迴劃分，直至子區間長度不超過 1。

## 問題與輸入

輸入陣列為 \[2, 4, 1, 0, 3, 5\]，索引為 0 至 5。每次劃分取當前子陣列最左端元素作為基準數，重排後使基準左側元素均不大於基準、右側元素均不小於基準，基準數隨即落入最終有序位置。

## 結構與關係

第一層對全區間 \[0, 5\] 取最左元素 2 為基準進行劃分，得到 \[1, 0, 2, 4, 3, 5\]：基準 2 固定在索引 2，留下左子區間 \[0, 1\]（子陣列 \[1, 0\]）與右子區間 \[3, 5\]（子陣列 \[4, 3, 5\]）。

下一層對兩個子區間分別劃分：左子區間 \[0, 1\] 以 1 為基準劃分為 \[0, 1\]，基準 1 固定在索引 1；右子區間 \[3, 5\] 以 4 為基準劃分為 \[3, 4, 5\]，基準 4 固定在索引 4。此時僅剩 \[0, 0\]、\[3, 3\]、\[5, 5\] 三個單元素子區間（以及空區間），均滿足遞迴終止條件，無需繼續劃分。

全過程共包含三次非平凡劃分：首層以 2 劃分全陣列 \[0, 5\]，第二層對左子區間 \[0, 1\] 以 1 劃分、對右子區間 \[3, 5\] 以 4 劃分。圖中藍色格標出各層已迴位的基準數，向下箭頭指示拆分出的子區間，到達單元素區間 \[0, 0\]、\[3, 3\]、\[5, 5\] 時直接終止。

## 結果

最終有序陣列為 \[0, 1, 2, 3, 4, 5\]。快速排序在自頂向下的每次劃分中直接確定基準數的最終索引，遞迴基終止時整個陣列已經有序，無需像合併排序那樣在回溯階段執行合併操作。
