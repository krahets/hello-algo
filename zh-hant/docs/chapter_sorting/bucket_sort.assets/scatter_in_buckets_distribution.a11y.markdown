# 按價格分佈劃分桶

根據商品價格的機率分佈設定分界點，使落入各桶的資料機率儘量接近，避免資料集中擠入少數桶。

## 問題與輸入

圖中橫軸表示商品價格，從左到右依次標出 0、3、10、25、80、200、+∞；縱軸表示機率密度，刻度為 0.0 至 0.4。灰色鐘形曲線在價格 25 附近達到峰值，僅作分佈形態示意，圖中未給出分佈函式參數或各桶的精確機率數值。

## 結構與關係

需要特別注意橫軸是非線性示意座標：相鄰刻度之間的價格差（如 0 到 3 相差 3，80 到 200 相差 120）與圖上的水平畫素寬度不成比例。因此，不能根據圖上各桶的視覺寬度判斷真實價格跨度，也不能直接量取畫面中的曲線下面積來推算精確入桶機率。

分桶設計的目標是依據真實價格分佈的區間機率選擇分界點，使各桶的期望資料量大致接近；本圖未給出精確區間機率，也未證明六桶已嚴格等機率。
