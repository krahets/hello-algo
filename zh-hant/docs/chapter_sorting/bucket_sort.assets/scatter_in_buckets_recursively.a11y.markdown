# 遞迴拆分資料過多的價格桶

先將商品粗分為三個價格桶，再遞迴拆分佔比 65% 與 35% 的密集桶，得到七個較均衡的葉桶。

## 問題與輸入

每個桶標註的“資料佔比”均指佔全部商品資料的百分比，而非佔其父桶的比例。圖中僅給出價格區間簡寫與資料佔比，未指定商品總數、貨幣單位或邊界點的開閉迴屬。

## 結構與關係

第一層粗分將商品資料劃分為三個價格桶：&lt;100 佔 65%，100–500 佔 20%，&gt;500 佔 15%。由於 &lt;100 桶集中了 65% 的資料，繼續將該桶向下細分為三個子桶。

第二層將 &lt;100 桶拆分為：&lt;10 佔 18%，10–50 佔 35%，50–100 佔 12%，三項之和恰好等於父桶的 65%。其中 10–50 桶佔比仍明顯偏高（35%），因此再向下一層細分為 10–20 佔 13%、20–35 佔 12%、35–50 佔 10%，三項之和等於 35%。

畫面右側“資料劃分結果”彙總了遞迴樹的七個葉節點桶（詳見附表），各葉桶佔比分佈在 10% 至 20% 之間，顯著比初始的 65%、20%、15% 更均衡。中間層的 65% 和 35% 屬於已被拆開的父桶彙總，不再計入最終結果桶。

## 針對高佔比桶按需遞迴細分

從頂部“商品資料”出發的分支箭頭表示對高密度價格桶的遞迴拆解：先拆開佔 65% 的 &lt;100 桶，再拆開其中佔 35% 的 10–50 桶，其餘佔比適中的桶則直接作為葉節點保留。

## 結果

最終保留的七個葉桶佔比合計為 100%，透過按需遞迴細分密集區間，使各桶的資料量趨於均勻。圖中價格區間採用簡寫形式，實際編碼時仍需明確區間端點的開閉約定。
