# 第 11 章 &nbsp; 排序

![排序](../assets/covers/chapter_sorting.svg){ class="cover-image" }

!!! abstract

    排序就像一把魔法鑰匙，能讓雜亂的資料井然有序，讓我們更有效率地理解與處理資料。

    無論是簡單地由小到大排列，還是依複雜規則分類排序，都能讓我們看見資料排列的和諧之美。
