# 原地堆積排序：把最大值逐個放入陣列右端

建立大頂堆積後，反覆交換堆積頂與有效堆積尾並縮小堆積範圍，將六個元素排成 \[1, 1, 2, 3, 4, 5\]。

## 問題與輸入

本組第一幀已完成初始建堆積，陣列為 \[5, 4, 3, 1, 1, 2\]。大頂堆積要求任意父節點的值不小於其子節點的值，因此建堆積或堆積化修復完成後，堆積頂根節點是當前有效堆積中的最大元素。

左側上方的二元樹與其下方陣列按層序一一對應，索引從 0 開始；索引 i 的左右子節點分別位於 2i+1 與 2i+2，且只有落在當前有效區間內的索引才屬於堆積。圖中綠色節點表示堆積的有效區間，灰色節點表示右側已排序區間。

## 結構與關係

每輪提取操作先將堆積頂元素與當前有效堆積的堆積底（最右端）元素交換，使當前最大值迴入右側灰色的已排序字尾；隨後僅在縮短後的綠色有效字首內從頂至底執行堆積化（sift down）。

當節點變為灰色迴入已排序區間後，左側二元樹中連向它的樹邊會隱去，代表它不再參與後續堆積化比較；但該元素始終原地儲存在下方陣列中，有效堆積縮短並非從陣列中刪除元素。
