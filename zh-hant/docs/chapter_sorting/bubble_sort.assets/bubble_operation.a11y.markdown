# 一輪冒泡操作

對 \[4, 1, 3, 1, 5, 2\] 從左向右依次比較五對相鄰“泡泡”，執行四次交換、一次保持不變，將最大元素 5 浮到最右端索引 5。

## 問題與輸入

輸入陣列為 nums = \[4, 1, 3, 1, 5, 2\]，索引從 0 到 5。單輪冒泡從最左端開始向右走訪，每次比較相鄰兩個元素：若“左邊元素 &gt; 右邊元素”則交換二者，若“左邊元素 ≤ 右邊元素”則維持不變。

畫面將陣列元素形象地畫成一排圓球“泡泡”，元素數值越大則泡泡體積越大；陣列左端對應“水底”，右端對應“水面”。每步用淺綠色方框圈出當前比較的相鄰位置對，淺框內位於泡泡上、下方的交換弧線表示該對剛剛完成了交換。

## 結構與關係

七幅分步畫面完整演示第一輪冒泡：第 1 步將六個陣列方格對映為六個大小成正比的泡泡；第 2 至第 6 步依次檢查索引 (0, 1)、(1, 2)、(2, 3)、(3, 4)、(4, 5) 五對相鄰位置（其中第 2、3、4、6 步展示已完成相鄰交換後的結果，第 5 步因 4 ≤ 5 維持原位不交換）；第 7 步展示最大泡泡 5 到達右端“水面”就位，剩餘左側前 n − 1 = 5 個元素留待後續輪次繼續冒泡。
