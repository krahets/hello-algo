# 合併排序的劃分與合併

先按位置中點將陣列遞迴拆分為單元素子陣列，再逐層將相鄰有序子陣列合併為完整有序陣列。

## 問題與輸入

輸入陣列為 \[7, 3, 2, 6, 0, 1, 5, 4\]。劃分階段只按位置中點將陣列不斷對半切分，不按數值大小分組；當子陣列長度為 1 時停止劃分，因為單元素子陣列天然有序。

上半部分經過三層對半劃分，拆解為 8 個單元素子陣列（觸發遞迴終止條件）；下半部分自底向上逐層兩兩合併。每次合併的兩個輸入子陣列都已各自升序排列：演算法比較兩側尚未取出的首元素，先將較小者放入結果區間，待一側取盡後直接追加另一側的剩餘元素，從而保證每次合併的結果依然有序。圖中下半部分的交叉箭頭用於追蹤各元素進入下一層合併結果的目標位置，不表示兩兩原地交換。

## 結果

經過三層中點劃分與三層有序合併，最終得到升序陣列 \[0, 1, 2, 3, 4, 5, 6, 7\]。圖按遞迴樹層級並列展示資料依賴關係；實際後序遞迴執行時，會先完整處理完左分支、再處理右分支，最後合併左右結果。
