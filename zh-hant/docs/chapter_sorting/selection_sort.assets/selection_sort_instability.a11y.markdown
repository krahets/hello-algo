# 選擇排序中的跨位置交換

觀察首輪跨位置交換如何打亂兩個相等元素 4 的相對次序，並區分單輪中間狀態與完整排序的最終穩定性。

## 問題與輸入

初始陣列為 \[4A, 4B, 3, 1, 5, 2\]，索引從 0 到 5。其中 4A 表示初始位於索引 0 的藍色 4，4B 表示初始位於索引 1 的紫色 4；字母 A、B 僅為說明中區分兩個相等元素身份的輔助標記，原圖方塊內均印數字 4。

選擇排序每一輪在未排序區間中找出最小元素，與該區間的首個元素直接交換。排序演算法的穩定性，則是按全部輪次結束後的最終輸出中相等元素是否保持初始先後次序來判定的。

首輪在未排序區間 \[0, 5\] 內定位最小元素 1（索引 3），與索引 0 的 4A 交換。交換後 1 在索引 0 迴位，未排序區間縮為 \[1, 5\]；而原本在索引 0 的 4A 直接跨過索引 1 的 4B 落到索引 3，使兩個 4 在首輪後出現中間逆序。圖中僅展示這第一輪，未畫出後續輪次。

## 結果

第一輪交換後陣列變為 \[1, 4B, 3, 4A, 5, 2\]，4B 排在 4A 之前，直觀展示了跨位置交換可能跨越其它相等元素。但這只是第一輪中間狀態，不能單獨證明該具體輸入在最終輸出中也逆序：按正文嚴格小於的比較規則繼續，第二輪將索引 1 的 4B 與索引 5 的 2 交換，最終排序結果中 4A 仍排在 4B 之前。選擇排序在一般意義上是不穩定排序，並不等於對任意輸入都會產生最終逆序。

## 選擇排序中的跨位置交換：動畫

初始陣列為 \[4A, 4B, 3, 1, 5, 2\]，索引從 0 到 5。其中 4A 表示初始位於索引 0 的藍色 4，4B 表示初始位於索引 1 的紫色 4；字母 A、B 僅為說明中區分兩個相等元素身份的輔助標記，原圖方塊內均印數字 4。

### 第 1 步：定位最小值與兩個相等元素 4

初始狀態下索引 0 至 5 全部處於未排序區間，藍色 4A（索引 0）排在紫色 4B（索引 1）之前。掃描區間找到最小元素 1 位於索引 3，準備將它與區間首元素 4A 交換。

交換索引 0 的 4A 與索引 3 的 1 後，最小元素 1 在索引 0 迴位，而 4A 跨過索引 1 的 4B 落到索引 3，導致兩個 4 在首輪後暫時逆序。這只是第一輪結果，剩餘未排序區間 \[1, 5\] 在後續輪次中還會繼續交換。
