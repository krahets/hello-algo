# 選擇排序

每輪在未排序區間中選出最小元素 nums\[k\] 並與區間首元素 nums\[i\] 交換，經五輪將 \[4, 1, 3, 1, 5, 2\] 排為 \[1, 1, 2, 3, 4, 5\]。

## 問題與輸入

待排序陣列為 nums = \[4, 1, 3, 1, 5, 2\]，共 6 個元素，索引從 0 到 5，目標是按非遞減順序完成排序。

每輪由指標 i 指向當前“未排序區間”的首個元素，由指標 k 記錄從該未排序區間中選出的最小元素索引。左側灰色方格表示已排好序的字首，上方花括號標出當前“未排序區間”；選定 k 後，將最小元素 nums\[k\] 與區間首元素 nums\[i\] 交換，使已排序字首向右擴展一位。

## 結構與關係

本組共十一幅畫面：前十幅按五輪選擇展開，每輪包含兩步——第一步“走訪未排序區間，選擇最小元素 nums\[k\]”（直接展示本輪內迴圈掃描完成後的指標 k，不逐格展開內迴圈比較過程），第二步“交換最小元素 nums\[k\] 和未排序區間的首個元素 nums\[i\]”（展示交換完成後的陣列狀態，並用陣列上、下方的交換弧線標出剛完成交換的兩個位置）；第十一幅展示僅剩末尾一個元素時無需再排、排序完成的狀態。
