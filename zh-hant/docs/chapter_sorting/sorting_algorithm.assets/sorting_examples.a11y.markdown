# 排序演算法的資料型別與判斷規則示例：數值大小、字典序與自定義等級

分三行展示整數按數值升序、英文姓名按字典序、等級字串按自定義優先順序 D 至 A+ 排序的前後對比。

## 問題與輸入

排序演算法不僅適用於不同資料型別，還需要明確的先後判斷規則。畫面分三行展示三組資料：每行左側為無序輸入，經中間標註排序規則的向右箭頭後，右側給出排序完成的結果（不涉及具體排序演算法的內部交換步驟）。

## 結構與關係

第一行“按照數字大小排序整數”：將八個無序整數 \[7, 3, 2, 6, 0, 1, 5, 4\] 按從小到大的數值順序排列為 \[0, 1, 2, 3, 4, 5, 6, 7\]。

第二行“按照字典序排序字串”：將五個英文姓名字串 \[Kobe, Durant, Curry, Lebron, Harden\] 按首字母字典序排列為 \[Curry, Durant, Harden, Kobe, Lebron\]（完全保留原圖拼寫與大小寫）。

第三行“按照自定義規則排序字串”：針對七個等級標識 \[B-, A+, B, B+, A, D, C\]，並非按普通 ASCII 字典序排列，而是按等級從低到高的自定義規則 D &lt; C &lt; B- &lt; B &lt; B+ &lt; A &lt; A+ 排列為 \[D, C, B-, B, B+, A, A+\]（注意 B-、B、B+ 是三個彼此獨立的等級）。

## 三組資料分別按數值大小、字典序與自定義規則排序

三行依次對比整數 \[7, 3, 2, 6, 0, 1, 5, 4\] 排為 \[0, 1, 2, 3, 4, 5, 6, 7\]、姓名 \[Kobe, Durant, Curry, Lebron, Harden\] 排為 \[Curry, Durant, Harden, Kobe, Lebron\]，以及等級 \[B-, A+, B, B+, A, D, C\] 按自定義高低次序排為 \[D, C, B-, B, B+, A, A+\]。

## 結果

排序只改變原有元素的排列次序；輸出順序由所選定的比較判斷規則（數值大小、ASCII 字典序或業務自定義規則）決定。
