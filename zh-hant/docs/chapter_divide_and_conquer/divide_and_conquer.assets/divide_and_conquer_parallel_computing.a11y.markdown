# 桶排序的平行計算結構

將無序資料分配到六個桶中，交由六個計算單元並行排序，再按序彙集為有序資料。

## 問題與輸入

這是一張展示分治並行化的結構示意圖，未指定具體陣列元素、桶邊界數值或執行耗時。畫面自上而下依次排列頂部的“無序資料”、中間的六個“桶”與六個“計算單元”，以及底部的“有序資料”。

## 結構與關係

頂部的無序資料沿六條向下分支箭頭分配到六個桶中；每個桶各透過一條豎直虛線對應下方的計算單元，表示六個桶的內部排序任務彼此獨立、互不依賴，可分發給不同計算單元同時並行處理。

六個計算單元完成各自桶內排序後，輸出箭頭彙總到底部的有序資料。在按數值範圍有序劃分的桶排序中，各計算單元排好本桶資料後，還需按桶的範圍先後順序依次收集，才能拼出全域性有序結果。

本圖旨在說明分治產生的獨立子問題有利於多核或多處理器並行加速，並未展示各桶的資料量分佈或通訊合併開銷，因此不能由圖中畫出六個計算單元直接推斷執行速度必定提升六倍。

六條“無序資料分桶 → 計算單元獨立排序 → 彙總為有序資料”的並行支路，展示瞭如何將互不依賴的分治子問題對映到多計算單元同時求解。

## 結果

分治策略將原排序問題拆解為互不重疊的多個桶內排序子問題，使多個計算單元得以並行執行，最後再合併各子問題的解。
