# 用合併排序理解“分”與“治”

將八元素排序問題逐層分解至單元素最小子問題，再自底向上合併有序結果，得到 0 至 7 的升序陣列。

## 問題與輸入

輸入陣列為 \[7, 3, 2, 6, 0, 1, 5, 4\]。分治策略包含兩個核心步驟：“分（劃分階段）”遞迴地將原問題拆解為規模更小、互不重疊的子問題，直至到達最小子問題；“治（合併階段）”從已知解的最小子問題出發，自底向上將子問題的解合併為原問題的解。

## 結構與關係

不斷把當前陣列對半劃分，直到每個子問題只含一個元素。左右兩部分互不重疊，可各自求解；單元素無需比較就是有序結果。

返回時將相鄰的兩個有序結果合併。每次比較兩邊首個尚未取出的元素，取較小者；一邊取完後接上另一邊的剩餘元素。逐層合併後解決完整八元素問題。

## 結果

由於子問題與原問題同屬陣列排序、左右子陣列相互獨立，且兩個有序子陣列可以高效合併為一個有序陣列，合併排序完整體現了分治策略的三大要素。
