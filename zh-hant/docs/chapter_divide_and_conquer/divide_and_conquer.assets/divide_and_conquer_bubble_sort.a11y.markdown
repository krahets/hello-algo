# 把一次泡沫排序拆成兩個較小排序任務

對比直接泡沫排序八個元素與先二分再分別泡沫排序後合併，二者結果相同，且單次劃分後仍為平方階。

## 問題與輸入

左右兩條對比路線的共同輸入為 \[7, 3, 2, 6, 0, 1, 5, 4\]，共同排序目標為 \[0, 1, 2, 3, 4, 5, 6, 7\]。設陣列長度為 n，本圖透過複雜度表示式對比劃分前後的操作量構成，並未提供實測耗時資料。

## 結構與關係

左側路線直接對長度為 n 的完整陣列執行泡沫排序，標註時間開銷為 O(n²)，底部輸出升序陣列 \[0, 1, 2, 3, 4, 5, 6, 7\]。

右側路線先將原陣列從中點劃分為左半 \[7, 3, 2, 6\] 和右半 \[0, 1, 5, 4\]，圖中標註“劃分 O(n)”；隨後對兩個長度為 n/2 的子陣列分別執行泡沫排序，各自標註“泡沫排序 O((n/2)²)”，得到有序左半 \[2, 3, 6, 7\] 與有序右半 \[0, 1, 4, 5\]；最後執行“合併 O(n)”，交錯取出兩側較小元素合成 \[0, 1, 2, 3, 4, 5, 6, 7\]。

右側合併階段的交叉箭頭表明兩個有序半區的元素需按大小穿插合併，而非簡單前後拼接。畫面底部將右側總複雜度彙總為“總體 O(n²/2 + 2n)”，對應兩次半規模泡沫排序加上線性劃分與合併。

右側路線用額外的線性劃分 O(n) 與合併 O(n) 換取兩次半規模的泡沫排序 O((n/2)²)，直觀解釋了將大問題拆分為小問題為何可能減少操作數量。

## 結果

在圖中用於比較工作量的簡化表示式中，單次中點劃分將平方項寫為 n²/2，並增加 2n 的劃分與合併項，說明分解子問題可能縮減平方主導項的常數係數；但由於只劃分了一次，O(n²/2 + 2n) 在漸近意義下仍屬於 O(n²)，不能據此聲稱已降至 O(n log n)，也不能將漸近記號當作精確操作次數或保證實際耗時減半。
