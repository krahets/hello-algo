# 由前序與中序序列重建五節點二元樹

由前序 \[3,9,2,1,7\] 與中序 \[9,3,1,2,7\]，唯一重建以 3 為根的五節點二元樹。

## 問題與輸入

已知一棵二元樹的前序走訪序列 preorder = \[3, 9, 2, 1, 7\] 和中序走訪序列 inorder = \[9, 3, 1, 2, 7\]，且樹中所有節點的值互不重複。

前序走訪遵循“根 → 左子樹 → 右子樹”的訪問順序，中序走訪遵循“左子樹 → 根 → 右子樹”的訪問順序。利用兩條序列的互補位置關係，可以從中唯一還原整棵二元樹。

## 結構與關係

畫面左側展示待重建的目標二元樹：根節點為 3，其左子節點為 9、右子節點為 2；節點 2 的左子節點為 1、右子節點為 7；節點 9、1、7 均為葉節點。

畫面右側上下排列前序走訪 \[3, 9, 2, 1, 7\] 與中序走訪 \[9, 3, 1, 2, 7\]，並透過向左的箭頭“重建二元樹”指向左側樹結構：前序首元素 3 確定整棵樹的根；在中序中，3 左側僅有 9，說明左子樹只含節點 9；3 右側為 \[1, 2, 7\]，對應前序後三項 \[2, 1, 7\]，說明右子樹以 2 為根、以 1 和 7 為左右子節點。

注意這是一棵普通二元樹而非二元搜尋樹，節點位置由走訪次序決定，並不要求左子節點的值小於父節點（例如左子節點 9 大於根節點 3）。

右側的前序走訪序列負責定位各子樹的根節點，中序走訪序列負責劃分左右子樹的成員範圍，二者結合即可重建左側的五節點二元樹。

## 結果

在節點值互不重複的前提下，前序走訪與中序走訪共同唯一確定了這棵包含 3、9、2、1、7 五個節點的二元樹。
