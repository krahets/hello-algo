# 用 i、l、m、r 表示構樹遞迴的索引區間

左子樹根的前序索引為 i+1，右子樹根的前序索引為 i+1+(m−l)，其中 m−l 為左子樹節點數。

## 問題與輸入

輸入為前序走訪 preorder = \[3, 9, 2, 1, 7\] 與中序走訪 inorder = \[9, 3, 1, 2, 7\]，節點值互不重複。

陣列索引從 0 開始：i 表示當前子樹根節點在 preorder 中的索引；\[l, r\] 表示當前子樹在 inorder 中的閉區間；m 表示當前子樹根節點在 inorder 中的索引。注意 m 是透過根的值在 inorder（或雜湊表）中查表得到的索引，並非區間 \[l, r\] 的幾何中點。

## 結構與關係

畫面以整棵樹的頂層呼叫為例標出各指標位置：當前根節點 3 在前序中的索引為 i = 0，整棵樹在中序中的閉區間為 \[l, r\] = \[0, 4\]，根節點 3 在中序中的索引為 m = 1，因此左子樹的節點數量為 m − l = 1。

由此可直接推導出左右子樹的遞迴參數（通用公式見附表）：左子樹根節點緊跟在當前根之後，其前序索引為 i + 1 = 1（對應元素 9），中序閉區間為 \[l, m − 1\] = \[0, 0\]；右子樹根節點需跳過當前根和全部 m − l 個左子樹節點，其前序索引為 i + 1 + (m − l) = 2（對應元素 2），中序閉區間為 \[m + 1, r\] = \[2, 4\]（對應 \[1, 2, 7\]）。

遞迴過程中只需傳遞前序根索引與中序閉區間端點，當遇到 l &gt; r 的空區間時直接返回空子樹。畫面左側同步展示對應的五節點樹：根節點 3 的左子節點為 9、右子節點為 2，2 的左右子節點分別為 1 和 7。

在前序走訪中定位右子樹根節點時，必須從當前根索引 i 出發跳過當前根（+1）以及左子樹的全部節點（m − l），因此右子樹根的前序索引為 i + 1 + (m − l)。

## 結果

藉助指標變數 i、l、m、r 的代數關係，每次遞迴呼叫僅需傳遞整數索引即可精確界定左右子樹，無需切片複製子陣列。
