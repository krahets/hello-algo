# 逐個子問題檢視前序與中序的劃分

根 3 拆出左葉 9 與以 2 為根的右子樹，節點 2 再拆出左右葉 1、7；各節點旁標出對應的走訪有效區間。

## 問題與輸入

輸入為前序走訪 preorder = \[3, 9, 2, 1, 7\] 與中序走訪 inorder = \[9, 3, 1, 2, 7\]，節點值互不重複。

重建出的二元樹以 3 為根，左子節點為 9，右子節點為 2；節點 2 的左右子節點分別為 1 和 7；節點 9、1、7 均為葉節點。

## 結構與關係

畫面在樹的五個節點旁各畫出一組完整長度的 preorder 和 inorder 陣列，僅將屬於當前遞迴子問題的區間著色，其餘無關位置置為淺灰色。在每個子問題中，青色代表當前子樹的根節點，藍色代表其左子樹區間，紫色代表其右子樹區間（完整劃分見附表）。

在頂層根節點 3 處，前序劃分為 3 \| \[9\] \| \[2, 1, 7\]，中序劃分為 \[9\] \| 3 \| \[1, 2, 7\]；在左子節點 9 處，前序與中序的有效區間均僅剩青色單元素 \[9\]，其左右子樹均為空。

在右子樹根節點 2 處，前序有效段劃分為 2 \| \[1\] \| \[7\]，中序有效段劃分為 \[1\] \| 2 \| \[7\]；在其下方的葉節點 1 和 7 處，前序與中序的有效區間又分別縮減為單元素 \[1\] 和 \[7\]，不再有非空子節點。

同一個節點值在不同遞迴子問題的陣列中承擔不同的顏色角色：例如元素 2 在根 3 的頂層陣列中屬於紫色右子樹區間，而在以 2 自身為根的子問題陣列中則變為青色根元素。圖中樹的五個圓形節點本身均為綠色。

## 結果

五個節點的遞迴呼叫遵循完全相同的分治規則：在各自的有效區間內由前序首元素定根、由中序切分左右子樹，直至單節點葉子的左右空區間返回空引用。
