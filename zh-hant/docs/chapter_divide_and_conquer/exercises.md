# 練習

## 觀念複習

### 哪些任務適合使用分治法

一位同學想用「先分成兩半，各自求解，再合併結果」的方法完成以下任務。
請逐一判斷各項任務屬於「適合分治」、「可以分治，但無法減少總工作量」或「兩半無法獨立求解」，並說明理由。

<!-- numbered-subquestions -->

1. 將未排序的陣列排好順序。
2. 找出陣列中的最大值。
3. 依序執行一連串 `push(x)`、`pop()` 堆疊操作，並輸出每次 `pop()` 取得的元素。

??? success "參考答案"

    1. 適合分治。將陣列對半分，各自排序，再以 $O(n)$ 的時間合併，這正是合併排序法。
    2. 可以分治，但無法減少總工作量。左右兩半合計仍須檢查全部 $n$ 個元素，
        和直接掃描一樣，都需要 $O(n)$ 的時間。
    3. 兩半無法獨立求解。後半段開始時，堆疊的內容取決於前半段的執行結果，
        因此兩半無法在不知道對方結果的情況下獨立完成。

### 快速冪如何減少計算量

以下遞迴函式使用分治法計算 $x^n$：

```src
[file]{fast_power}-[class]{}-[func]{fast_pow}
```

令 `x = 3`、`n = 5`，並用這個函式計算：

<!-- numbered-subquestions -->

1. 每次遞迴呼叫時，參數 `n` 依序有哪些值？
2. 從最深層逐層返回時，各層依序回傳什麼值？
3. 為什麼要先將遞迴結果存為 `half`？如果在乘法的兩側各呼叫一次相同的子問題，會有什麼影響？

??? success "參考答案"

    1. 參數依序為 `5 → 2 → 1 → 0`，每次都將指數減半，直到滿足終止條件。

    2. `n = 0` 時回傳 1，`n = 1` 時回傳 $1×1×3=3$；
        `n = 2` 時回傳 $3×3=9$，`n = 5` 時回傳 $9×9×3=243$。

    3. 如果在乘法兩側各呼叫一次相同的子問題，這兩次遞迴就會執行完全相同的計算。
        先將結果存為 `half`，每層就只需遞迴一次，遞迴深度約為 $\log n$；
        呼叫兩次則會造成大量重複計算。

### 從走訪序列拆出左右子樹

一棵節點值皆相異的二元樹，其前序與中序走訪結果如下：

- 前序走訪：`[A, B, D, E, C]`
- 中序走訪：`[D, B, E, A, C]`

只需在根節點這一層拆分，無須繼續遞迴，也不用畫出整棵樹：

<!-- numbered-subquestions -->

1. 根節點是哪個節點？
2. 中序走訪中的哪兩段分別對應左、右子樹？
3. 前序走訪中的哪兩段分別對應左、右子樹？根節點的直接子節點有哪些？

??? success "參考答案"

    1. 前序走訪的第一個節點就是根節點，因此根節點為 `A`。

    2. `A` 將中序走訪序列分成兩部分，左子樹為 `[D, B, E]`，右子樹為 `[C]`。

    3. 左子樹有 3 個節點，因此前序序列中緊接在根節點 `A` 後面的 3 個元素屬於左子樹，
        也就是 `[B, D, E]`，剩下的 `[C]` 則屬於右子樹。
        所以根節點的左子節點是 `B`，右子節點是 `C`。

## 程式設計練習

### 快速冪

給定實數 `x` 和整數 `n`，請計算 $x^n$，且不得呼叫程式語言內建的冪次函式。
請使用遞迴分治法，每次將指數減半，並重複利用已算出的子問題結果。
本題規定 $x^0=1$，即使 `x = 0` 也一樣。當 `n < 0` 時，保證 `x != 0`，此時可將答案改寫為 $(1/x)^{-n}$。

??? tip "解題提示"

    1. n 等於 0 時，答案是 1
    2. 算出 x 的 n // 2 次方後，將結果存為 half，無須再次呼叫遞迴函式
    3. 當 n < 0 時，先將 x 改為 1 / x，再將 n 改為 -n。使用 C++ 或 Java 時，可先將 n 轉成 64 位元整數，避免對最小的 32 位元整數取相反數時發生溢位
