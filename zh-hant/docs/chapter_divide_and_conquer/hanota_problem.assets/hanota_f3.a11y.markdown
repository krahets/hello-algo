# 三盤河內塔的分治

先將頂部兩盤遷到 B，再把最大盤移到 C，最後把兩盤從 B 遷到 C；三個階段共含七次單盤移動。

## 問題與輸入

圖中從左到右為三根柱子 A、B、C，目標是把柱 A 上的三個圓盤移到柱 C。每次只能移動柱頂的一個圓盤，且大盤不能壓在小盤之上；下文柱上圓盤均按從下到上的順序表述。

三隻圓盤從大到小依次為綠色大盤、藍色中盤、橙色小盤，初始全部疊在柱 A。青色實線輪廓將上方的中盤與小盤圈作一個規模為 f(2) 的遞迴子問題。

將兩盤看作整體只是分治遞迴的抽象表示，並不代表物理上同時端起兩個圓盤；兩個 f(2) 子問題各自需要展開為三次合法的單盤移動，加上中間最大盤的一次移動，共執行七次單盤移動。

## 結構與關係

四幀依次展示初始劃分狀態以及三個子階段的完成終點，未逐幀展開 f(2) 子問題內部的三次單盤移動細節。
