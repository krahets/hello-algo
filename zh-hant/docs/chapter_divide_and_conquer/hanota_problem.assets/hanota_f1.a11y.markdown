# 一個圓盤的河內塔（f(1)）

將柱 A 上的唯一圓盤直接移到目標柱 C，一次單盤移動即完成。

## 問題與輸入

圖中從左到右共有三根柱子 A、B、C，目標是把柱 A 上的圓盤移動到柱 C。移動規則為每次只能移動柱頂的一個圓盤，且大盤不能壓在小盤之上；下文柱上圓盤均按從下到上的順序表述。

規模 f(1) 表示只需遷移一個圓盤，代表河內塔遞迴分解的基本情況。

## 結構與關係

本組用綠色圓角矩形表示唯一圓盤，兩幀分別展示移動前的初始狀態與直接移入柱 C 後的完成狀態。

## 第 1 步：唯一圓盤位於柱 A
