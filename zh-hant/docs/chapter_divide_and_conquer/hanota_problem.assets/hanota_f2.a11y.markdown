# 兩個圓盤藉助緩衝柱 B 完成移動

先把小盤暫存到柱 B，再把大盤移到柱 C，最後把小盤疊到大盤上，共三次移動。

## 問題與輸入

圖中從左到右為三根柱子 A、B、C，目標是把柱 A 上的兩個圓盤全部移到柱 C。每次只能移動柱頂的一個圓盤，且大盤不能壓在小盤之上；下文柱上圓盤均按從下到上的順序表述。

綠色圓盤為大盤，藍色圓盤為小盤；初始時柱 A 從下到上依次疊放大盤和小盤，柱 B 與柱 C 為空。
