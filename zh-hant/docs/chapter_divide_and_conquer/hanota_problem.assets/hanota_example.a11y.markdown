# 河內塔問題示例：將六張圓盤從 A 移至 C

初始狀態下六張圓盤按上小下大疊在柱 A，目標是藉助柱 B 將它們全部移至柱 C 並保持原有順序。

## 問題與輸入

河內塔移動規則要求：每次只能移動一張圓盤，且只能從一根柱子的頂部拿出、放入另一根柱子的頂部；在移動全過程中，小圓盤必須時刻位於大圓盤之上。

## 結構與關係

畫面上半部分展示起始狀態：三根柱子從左到右依次標記為 A、B、C，柱 A 上從上到下按從小到大的順序疊放著六張不同顏色的圓盤，柱 B 與柱 C 均為空。

畫面下半部分展示目標狀態：柱 A 與柱 B 變為空柱，全部六張圓盤已移至最右側的柱 C 上，且依然保持最小盤在頂、最大盤在底的原有順序。中間向下的箭頭“將所有圓盤從 A 移動至 C”概括整個問題的總體任務，並非表示可以一次性搬移整疊圓盤。
