# 河內塔遞迴樹：兩個較小任務加一次單盤移動

每個 f(n) 拆分為左 f(n−1)、中 f(1)、右 f(n−1)，逐層展開至單盤移動 f(1)，總時間呈指數增長。

## 問題與輸入

節點 f(k) 表示移動 k 張圓盤的子問題規模。每個規模大於 1 的問題都拆解為：先移走上方 k−1 張盤、再移動底部 1 張最大盤、最後將 k−1 張盤移到目標柱。圖中節點僅標註問題規模，未標出各子問題不同的起始柱、緩衝柱和目標柱。

## 結構與關係

遞迴樹頂部為原問題 f(n)，向下一層從左到右分出三個子節點：f(n−1)、f(1)、f(n−1)。其中左右兩個綠色節點 f(n−1) 各自再向下分出 f(n−2)、f(1)、f(n−2)，而中間的青色節點 f(1) 已是隻需一次單盤移動的最小子問題，不再向下拆分。

圖中綠色方框代表仍需繼續遞迴拆解的子問題，青色方框代表直接執行單盤移動的基例 f(1)。中間層以省略號“…”概括，底層全部迴結為青色節點 f(1)；注意本圖是任意規模 n 的結構示意，不能直接清點圖上畫出的青色框個數當作某個具體 n 的總移動次數。

按遞推關係 T(1) = 1、T(n) = 2T(n−1) + 1 展開，單盤移動總次數為 2^n − 1，因此時間複雜度為 O(2^n)；而同一時刻處於活動狀態的遞迴呼叫鏈最長沿 f(n) → f(n−1) → … → f(1) 深入 n 層，因此堆疊幀空間複雜度為 O(n)。

還需注意，圖中每一層中間畫出的青色節點 f(1) 代表概念上的單盤移動子任務；在配套程式碼實現中，這一步直接呼叫 move 函式移動圓盤，並未額外發起一次 dfs(1) 遞迴呼叫，因此本圖展示的是問題分解樹而非逐條函式呼叫的精確堆疊追蹤。

每一層非基本子問題都向下分裂出左右兩個規模減 1 的子問題和中間一次單盤移動 f(1)，直觀展現 O(2^n) 時間複雜度與 O(n) 遞迴深度的來源。

## 結果

由於每次分解都會產生兩個規模僅減 1 的子問題，河內塔的遞迴樹節點總數以 O(2^n) 指數級增長，但遞迴堆疊深度始終保持為線性的 O(n)。
