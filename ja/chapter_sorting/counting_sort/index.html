11.9   カウントソート¶

カウントソート（counting sort）は要素の出現回数を数えて並べ替える方法で、通常は整数の配列に使います。

11.9.1   簡易版の実装¶

簡単な例を見てみましょう。長さ \(n\) の配列 nums があり、要素はすべて非負整数とします。図 11-16 にカウントソートの流れを示します。

  1. 配列を走査して最大値 \(m\) を求め、長さ \(m + 1\) の補助配列 counter を作成します。
  2. counter を使って nums の各数値の出現回数を数えます。counter[num] は数値 num の出現回数です。数え方は簡単です。nums を走査し（現在の値を num とします）、各回で counter[num] を \(1\) 増やすだけです。
  3. counter のインデックスは初めから順に並んでいるため、すべての値はすでに整列したも同然です。あとは counter を走査し、小さい値から順に、出現回数だけ nums に書き込みます。

図 11-16   カウントソートの流れ

図解 11-16：各整数の出現回数を数え、その回数だけ書き戻す

値そのものをインデックスにして出現回数を数え、小さい値から順に書き戻します。

対象の配列は nums = [1, 0, 1, 2, 0, 4, 0, 2, 2, 4] です。すべての要素が非負整数で最大値が 4 なので、インデックス 0～4 の 5 マスのカウント配列 counter を作ります。counter[num] は num の出現回数です。インデックスは元の配列の位置ではなく、値そのものに対応します。

counter[3] = 0 は入力に 3 がないことを示します。インデックス 0～4 の出現回数を順に読み、0 を 3 個、1 を 2 個、2 を 3 個、4 を 2 個書き出します。下の 3 表は、元の入力、各数値の出現回数、書き戻した結果です。

この簡易版は出現回数から整数列を作り直すので、値が等しい入力要素を個別に識別できません。他の属性を持つオブジェクトを安定にソートするには、オブジェクトを個別に保持し、書き込み位置を決める必要があります。

コードを次に示します。

counting_sort.py
def counting_sort_naive(nums: list[int]):
    """カウントソート"""
    # 簡易版。オブジェクトのソートには使えない
    # 1. 配列の最大値 m を求める
    m = max(nums)
    # 2. 各数値の出現回数を数える
    # counter[num] は num の出現回数を表す
    counter = [0] * (m + 1)
    for num in nums:
        counter[num] += 1
    # 3. counter を走査し、各要素を元の配列 nums に書き込む
    i = 0
    for num in range(m + 1):
        for _ in range(counter[num]):
            nums[i] = num
            i += 1

void countingSortNaive(vector<int> &nums) {
    // 1. 配列の最大値 m を求める
    int m = 0;
    for (int num : nums) {
        m = max(m, num);
    }
    // 2. 各数値の出現回数を数える

            nums[i] = num;
        }
    }
}

func countingSortNaive(nums []int) {
    // 1. 配列の最大値 m を求める
    m := 0
    for _, num := range nums {
        if num > m {
            m = num
        }

    for i, num := 0, 0; num < m+1; num++ {

        }
    }
}

/* カウントソート */
// 簡易版。オブジェクトのソートには使えない
fn counting_sort_naive(nums: &mut [i32]) {
    // 1. 配列の最大値 m を求める
    let m = *nums.iter().max().unwrap();
    // 2. 各数値の出現回数を数える
    // counter[num] は num の出現回数を表す
    let mut counter = vec![0; m as usize + 1];
    for &num in nums.iter() {
        counter[num as usize] += 1;
    }
    // 3. counter を走査し、各要素を元の配列 nums に書き込む
    let mut i = 0;
    for num in 0..m + 1 {
        for _ in 0..counter[num as usize] {
            nums[i] = num;
            i += 1;
        }
    }
}
counting_sort.c
/* カウントソート */
// 簡易版。オブジェクトのソートには使えない
void countingSortNaive(int nums[], int size) {
    // 1. 配列の最大値 m を求める
    int m = 0;
    for (int i = 0; i < size; i++) {
        if (nums[i] > m) {
            m = nums[i];
        }
    }
    // 2. 各数値の出現回数を数える
    // counter[num] は num の出現回数を表す
    int *counter = calloc(m + 1, sizeof(int));
    for (int i = 0; i < size; i++) {
        counter[nums[i]]++;
    }
    // 3. counter を走査し、各要素を元の配列 nums に書き込む
    int i = 0;
    for (int num = 0; num < m + 1; num++) {
        for (int j = 0; j < counter[num]; j++, i++) {
            nums[i] = num;
        }
    }
    // 4. メモリを解放
    free(counter);
}

### カウントソート ###
def counting_sort_naive(nums)
  # 簡易版。オブジェクトのソートには使えない
  # 1. 配列の最大値 m を求める
  m = 0
  nums.each { |num| m = [m, num].max }

  # counter[num] は num の出現回数を表す
  counter = Array.new(m + 1, 0)

  i = 0
  for num in 0...(m + 1)
    (0...counter[num]).each do
      nums[i] = num
      i += 1
    end
  end
end

カウントソートとバケットソートの関係

バケットソートの観点から見ると、カウント配列 counter の各インデックスが 1 個のバケットにあたり、出現回数を数える操作は各要素を対応するバケットに振り分けることにあたります。つまり、カウントソートは整数データに対するバケットソートの特殊な場合です。

11.9.2   完全版の実装¶

お気づきかもしれませんが、入力データがオブジェクトの場合、先ほどのステップ 3. は使えません。たとえば商品オブジェクトを価格（クラスのメンバー変数）で並べ替えたいとします。先ほどのアルゴリズムで得られるのは、価格だけを並べ替えた結果です。

元のデータそのものを並べ替えるにはどうすればよいでしょうか。まず counter の「累積和」を求めます。インデックス i の累積和 prefix[i] は、配列の先頭から i + 1 個の要素を足したものです。

\[ \text{prefix}[i] = \sum_{j=0}^i \text{counter[j]} \]

この累積和から、要素 num が結果配列 res 内で最後に現れるインデックスは prefix[num] - 1 だとわかります。これで各要素の書き込み先が決まります。次に元の配列 nums の要素 num を逆順に走査し、各回で次の 2 つの操作を行います。

  1. num を配列 res のインデックス prefix[num] - 1 に書き込みます。
  2. 累積和 prefix[num] を \(1\) 減らして、次に num を置くインデックスを求めます。

走査が終わると、配列 res に整列済みの結果が入っています。最後に res で元の配列 nums を上書きします。図 11-17 にカウントソートの手順全体を示します。

図 11-17   カウントソートの手順

図解 11-17：累積和を使ったカウントソートの安定な書き込み

出現回数の累積和から書き込み先のインデックスを求めます。元の配列を逆順に走査し、res に書き込むたびにカウントを減らし、最後に nums を上書きします。

元の配列は nums = [1, 0, 1, 2, 0, 4, 0, 2, 2, 4]（インデックス 0～9）で、値の範囲は 0～4、出現回数の配列は counter = [3, 2, 3, 0, 2] です。

counter の累積和を求めると初期値は prefix = [3, 5, 8, 8, 10] になります。初期の prefix[num] は num 以下の要素の総数です。実際に現れる値 num について、prefix[num] - 1 は結果配列 res 内で num が最後に現れるインデックスです。図では累積和の配列を prefix と呼びますが、本文のコードでは counter 内で加算し、累積和で元の値を上書きします。

結果配列 res には 10 個のマスがあります。コードでは res を 0 で初期化しますが、図では「まだ要素を置いていないマス」と「値 0 を書き込んだマス」を区別するため、未記入のマスを空白で示します。

nums を右から左へ走査し、現在の値 num を res[prefix[num] − 1] に書き込んで、prefix[num] を 1 減らします。同じ値が後から現れたときは、減算後の prefix[num] − 1 が次の書き込み先です。このように prefix は書き込みのたびに変化し、初期の累積和とは異なる値になります。

元の配列を逆順に読み、結果の各区間を右から左に埋めます。値が等しい要素のうち、元の配列で右にあるものを先に右側に置き、左にあるものを後で左側に置くので、安定性が保たれます。図はまず元のインデックス 9、8、7、6 からの書き込みを示します。その後の 6 回の書き込みは省略して走査終了時に進み、最後に res で nums を上書きします。

counting_sort.py
def counting_sort(nums: list[int]):
    """カウントソート"""
    # 完全版。オブジェクトもソートでき、安定性を保つ
    # 1. 配列の最大値 m を求める
    m = max(nums)
    # 2. 各数値の出現回数を数える
    # counter[num] は num の出現回数を表す
    counter = [0] * (m + 1)
    for num in nums:
        counter[num] += 1
    # 3. counter の累積和を求め、出現回数から各値の末尾位置を求められるようにする
    # つまり counter[num]-1 は res 内で num が最後に現れるインデックス
    for i in range(m):
        counter[i + 1] += counter[i]
    # 4. nums を逆順に走査し、各要素を結果配列 res に書き込む
    # 結果を格納する配列 res を初期化
    n = len(nums)
    res = [0] * n
    for i in range(n - 1, -1, -1):
        num = nums[i]
        res[counter[num] - 1] = num  # num を対応するインデックスに配置
        counter[num] -= 1  # 累積和を 1 減らして、次に num を置く位置を求める
    # 結果配列 res で元の配列 nums を上書き
    for i in range(n):
        nums[i] = res[i]

    // 1. 配列の最大値 m を求める
    int m = 0;
    for (int num : nums) {
        m = max(m, num);
    }

    // counter[num] は num の出現回数を表す

    }

            m = num
        }
    }

func countingSort(nums: inout [Int]) {
    // 1. 配列の最大値 m を求める
    let m = nums.max()!
    // 2. 各数値の出現回数を数える
    // counter[num] は num の出現回数を表す
    var counter = Array(repeating: 0, count: m + 1)
    for num in nums {
        counter[num] += 1
    }
    // 3. counter の累積和を求め、出現回数から各値の末尾位置を求められるようにする
    // つまり counter[num]-1 は res 内で num が最後に現れるインデックス
    for i in 0 ..< m {
        counter[i + 1] += counter[i]
    }

    // 結果を格納する配列 res を初期化
    var res = Array(repeating: 0, count: nums.count)

    for i in nums.indices {
        nums[i] = res[i]
    }

    res[counter[_num] - 1] = _num; // _num を対応するインデックスに配置
    counter[_num]--; // 累積和を 1 減らし、次に _num を置くインデックスを求める
  }
  // 結果配列 res で元の配列 nums を上書き
  nums.setAll(0, res);
}

fn counting_sort(nums: &mut [i32]) {
    // 1. 配列の最大値 m を求める
    let m = *nums.iter().max().unwrap() as usize;
    // 2. 各数値の出現回数を数える
    // counter[num] は num の出現回数を表す
    let mut counter = vec![0; m + 1];
    for &num in nums.iter() {
        counter[num as usize] += 1;
    }
    // 3. counter の累積和を求め、出現回数から各値の末尾位置を求められるようにする
    // つまり counter[num]-1 は res 内で num が最後に現れるインデックス
    for i in 0..m {
        counter[i + 1] += counter[i];
    }
    // 4. nums を逆順に走査し、各要素を結果配列 res に書き込む
    // 結果を格納する配列 res を初期化
    let n = nums.len();
    let mut res = vec![0; n];
    for i in (0..n).rev() {
        let num = nums[i];
        res[counter[num as usize] - 1] = num; // num を対応するインデックスに配置
        counter[num as usize] -= 1; // 累積和を 1 減らして、次に num を置く位置を求める
    }
    // 結果配列 res で元の配列 nums を上書き
    nums.copy_from_slice(&res)
}

void countingSort(int nums[], int size) {
    // 1. 配列の最大値 m を求める
    int m = 0;
    for (int i = 0; i < size; i++) {
        if (nums[i] > m) {
            m = nums[i];
        }
    }
    // 2. 各数値の出現回数を数える
    // counter[num] は num の出現回数を表す
    int *counter = calloc(m + 1, sizeof(int));
    for (int i = 0; i < size; i++) {
        counter[nums[i]]++;
    }
    // 3. counter の累積和を求め、出現回数から各値の末尾位置を求められるようにする
    // つまり counter[num]-1 は res 内で num が最後に現れるインデックス
    for (int i = 0; i < m; i++) {
        counter[i + 1] += counter[i];
    }
    // 4. nums を逆順に走査し、各要素を結果配列 res に書き込む
    // 結果を格納する配列 res を初期化
    int *res = malloc(sizeof(int) * size);
    for (int i = size - 1; i >= 0; i--) {
        int num = nums[i];
        res[counter[num] - 1] = num; // num を対応するインデックスに配置
        counter[num]--;              // 累積和を 1 減らして、次に num を置く位置を求める
    }
    // 結果配列 res で元の配列 nums を上書き
    memcpy(nums, res, size * sizeof(int));
    // 5. メモリを解放
    free(res);
    free(counter);
}

11.9.3   アルゴリズムの特性¶

  • 時間計算量は \(O(n + m)\)、非適応的なソート。nums の走査にも counter の走査にも線形時間がかかります。通常は \(n \gg m\) なので、時間計算量は \(O(n)\) に近づきます。
  • 空間計算量は \(O(n + m)\)、インプレースではないソート。長さがそれぞれ \(n\) と \(m\) の配列 res と counter を使います。
  • 安定ソート。res には右から左へ要素を書き込むため、nums を逆順に走査すれば値が等しい要素の相対順序を保てます。nums を先頭から走査しても値は正しい順に並びますが、その場合は安定性が失われます。

11.9.4   制約¶

カウントソートでは、出現回数を数えるだけで効率よくソートできます。ただし、利用できる条件は比較的限られています。

カウントソートを直接適用できるのは非負整数だけです。他の種類のデータに使うには、要素間の大小関係を変えずに非負整数に変換できることが必要です。たとえば負数を含む整数配列なら、すべての値に同じ定数を加えて正の数にし、ソート後に元に戻せます。

カウントソートは、データ数が多く、値の範囲が狭い場合に適しています。先ほどの例では、\(m\) が大きすぎると領域を使いすぎます。また \(n \ll m\) のときは \(O(m)\) の時間がかかり、\(O(n \log n)\) のソートアルゴリズムより遅くなることもあります。
