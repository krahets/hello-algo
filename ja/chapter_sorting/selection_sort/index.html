11.2   選択ソート¶

選択ソート（selection sort）の仕組みは簡単です。ループの各回で未整列区間の最小要素を選び、整列済み区間の末尾に加えます。

配列の長さを \(n\) とします。図 11-2 に選択ソートの手順を示します。

  1. 初めは全要素が未整列なので、未整列のインデックス区間は \([0, n-1]\) です。
  2. 区間 \([0, n-1]\) の最小要素を選び、インデックス \(0\) の要素と交換します。これで配列の先頭の 1 要素が整列します。
  3. 区間 \([1, n-1]\) の最小要素を選び、インデックス \(1\) の要素と交換します。これで配列の先頭の 2 要素が整列します。
  4. これを繰り返します。\(n - 1\) 回の選択と交換が終わると、先頭の \(n - 1\) 要素が整列します。
  5. 残りの 1 要素は必ず最大なので、並べ替える必要はありません。これで配列のソートは完了です。

図 11-2   選択ソートの手順

図解 11-2：選択ソート

毎回、未整列区間の最小要素を選んで区間の先頭要素と交換し、先頭の整列済み区間を 1 要素分広げます。

対象の配列は nums = [4, 1, 3, 1, 5, 2] です。6 要素のインデックスは 0～5 で、非減少順に並べ替えます。

各回で i は現在の未整列区間の先頭要素を指し、k は区間の最小要素のインデックスを記録します。緑は未整列部分、左の灰色のマスは先頭の整列済み区間で、上の波括弧は現在の未整列区間を示します。k を決めたら最小要素 nums[k] と先頭要素 nums[i] を交換し、整列済み区間を右へ 1 マス広げます。

全 11 枚のうち最初の 10 枚は、5 回分の選択と交換の図です。選択の図は走査後の i と k を示し、内側のループの比較は 1 マスずつは描きません。交換の図は操作後の配列を示し、交換した位置に上下の弧を付け、i と k の文字を隠します。11 枚目では末尾に 1 要素だけが残り、6 回目の処理は不要です。

  1. インデックス 1 の最小値 1 を選ぶ

    1 回目の選択です。現在は nums = [4, 1, 3, 1, 5, 2] です。未整列区間 [0, 5] を走査すると、i = 0 は先頭の 4、k = 1 は最小値 1 を指します。2 つの 1 はインデックス 1 と 3 にあります。厳密に小さいときだけ更新するので左の k = 1 が残ります。整列済み区間はまだありません。交換はまだです。

  2. インデックス 0 と 1 を交換

    1 回目の交換です。未整列区間 [0, 5] の最小値 1（インデックス 1）と先頭の 4（インデックス 0）を交換します。現在は nums = [1, 4, 3, 1, 5, 2] です。灰色の整列済み区間はインデックス 0 で値は [1]、未整列のインデックス区間は [1, 5] で値は [4, 3, 1, 5, 2] です。

  3. インデックス 3 の最小値 1 を選ぶ

    2 回目の選択です。現在は nums = [1, 4, 3, 1, 5, 2] です。未整列区間 [1, 5] を走査すると、i = 1 は先頭の 4、k = 3 は最小値 1 を指します。整列済み区間はインデックス 0 で、値は [1] です。交換はまだです。

  4. インデックス 1 と 3 を交換

    2 回目の交換です。未整列区間 [1, 5] の最小値 1（インデックス 3）と先頭の 4（インデックス 1）を交換します。現在は nums = [1, 1, 3, 4, 5, 2] です。灰色の整列済み区間はインデックス 0～1 で値は [1, 1]、未整列のインデックス区間は [2, 5] で値は [3, 4, 5, 2] です。

  5. インデックス 5 の最小値 2 を選ぶ

    3 回目の選択です。現在は nums = [1, 1, 3, 4, 5, 2] です。未整列区間 [2, 5] を走査すると、i = 2 は先頭の 3、k = 5 は最小値 2 を指します。整列済み区間はインデックス 0～1 で、値は [1, 1] です。交換はまだです。

  6. インデックス 2 と 5 を交換

    3 回目の交換です。未整列区間 [2, 5] の最小値 2（インデックス 5）と先頭の 3（インデックス 2）を交換します。現在は nums = [1, 1, 2, 4, 5, 3] です。灰色の整列済み区間はインデックス 0～2 で値は [1, 1, 2]、未整列のインデックス区間は [3, 5] で値は [4, 5, 3] です。

  7. インデックス 5 の最小値 3 を選ぶ

    4 回目の選択です。現在は nums = [1, 1, 2, 4, 5, 3] です。未整列区間 [3, 5] を走査すると、i = 3 は先頭の 4、k = 5 は最小値 3 を指します。整列済み区間はインデックス 0～2 で、値は [1, 1, 2] です。交換はまだです。

  8. インデックス 3 と 5 を交換

    4 回目の交換です。未整列区間 [3, 5] の最小値 3（インデックス 5）と先頭の 4（インデックス 3）を交換します。現在は nums = [1, 1, 2, 3, 5, 4] です。灰色の整列済み区間はインデックス 0～3 で値は [1, 1, 2, 3]、未整列のインデックス区間は [4, 5] で値は [5, 4] です。

  9. インデックス 5 の最小値 4 を選ぶ

    5 回目の選択です。現在は nums = [1, 1, 2, 3, 5, 4] です。未整列区間 [4, 5] を走査すると、i = 4 は先頭の 5、k = 5 は最小値 4 を指します。整列済み区間はインデックス 0～3 で、値は [1, 1, 2, 3] です。交換はまだです。

  10. インデックス 4 と 5 を交換

    5 回目の交換です。未整列区間 [4, 5] の最小値 4（インデックス 5）と先頭の 5（インデックス 4）を交換します。現在は nums = [1, 1, 2, 3, 4, 5] です。灰色の整列済み区間はインデックス 0～4 で値は [1, 1, 2, 3, 4]、未整列のインデックス区間は [5, 5] で値は [5] です。

  11. ソート完了

    5 回の走査後、nums = [1, 1, 2, 3, 4, 5] です。インデックス 0～4 は灰色の整列済み区間です。インデックス 5 の緑色の 5 は、まだ単一要素の未整列区間 [5, 5] に表示されていますが、必ず最大値であり、すでに正しい位置にあります。図には「ソート完了（残りは 1 要素なのでソート不要）」とあり、i、k はどちらも非表示です。

コードでは、\(k\) を使って未整列区間の最小要素の位置を記録します。

selection_sort.py
def selection_sort(nums: list[int]):
    """選択ソート"""
    n = len(nums)
    # 外側のループ：未整列区間は [i, n-1]
    for i in range(n - 1):
        # 内側のループ：未整列区間の最小要素を探す
        k = i
        for j in range(i + 1, n):
            if nums[j] < nums[k]:
                k = j  # 最小要素のインデックスを記録
        # その最小要素と未整列区間の先頭要素を交換
        nums[i], nums[k] = nums[k], nums[i]

/* 選択ソート */
void selectionSort(vector<int> &nums) {
    int n = nums.size();
    // 外側のループ：未整列区間は [i, n-1]
    for (int i = 0; i < n - 1; i++) {
        // 内側のループ：未整列区間の最小要素を探す

    }
}

selection_sort.swift
/* 選択ソート */
func selectionSort(nums: inout [Int]) {
    // 外側のループ：未整列区間は [i, n-1]
    for i in nums.indices.dropLast() {
        // 内側のループ：未整列区間の最小要素を探す
        var k = i
        for j in nums.indices.dropFirst(i + 1) {
            if nums[j] < nums[k] {
                k = j // 最小要素のインデックスを記録
            }
        }
        // その最小要素と未整列区間の先頭要素を交換
        nums.swapAt(i, k)
    }
}

selection_sort.rs
/* 選択ソート */
fn selection_sort(nums: &mut [i32]) {
    if nums.is_empty() {
        return;
    }
    let n = nums.len();
    // 外側のループ：未整列区間は [i, n-1]
    for i in 0..n - 1 {
        // 内側のループ：未整列区間の最小要素を探す
        let mut k = i;
        for j in i + 1..n {
            if nums[j] < nums[k] {
                k = j; // 最小要素のインデックスを記録
            }
        }
        // その最小要素と未整列区間の先頭要素を交換
        nums.swap(i, k);
    }
}

11.2.1   アルゴリズムの特性¶

  • 時間計算量は \(O(n^2)\)、非適応的なソート。外側のループは \(n - 1\) 回で、内側のループは最初の回に \(n - 1\) 回、最後の回に \(1\) 回実行します。各回の実行回数は順に \(n - 1\)、\(n - 2\)、\(\dots\)、\(2\)、\(1\) で、合計は \(\frac{n(n - 1)}{2}\) です。
  • 空間計算量は \(O(1)\)、インプレースソート。ポインタ \(i\) と \(j\) が使う追加領域は一定です。
  • 不安定なソート。図 11-3 のように、要素 nums[i] が交換によって等しい要素の右側に移り、相対順序が変わることがあります。

図 11-3   選択ソートで等しい要素の順序が変わる例

図解 11-3：選択ソートで離れた位置の要素を交換

最初の交換で離れた位置の要素を入れ替えると、値が等しい 2 つの 4 の順序がどう変わるかを見ます。1 回の途中状態と、ソート全体の結果から判断する安定性を区別します。

初期配列は [4A, 4B, 3, 1, 5, 2] で、インデックスは 0～5 です。4A は初めにインデックス 0 にある青色の 4、4B はインデックス 1 にある紫色の 4 です。A、B は同じ値の 2 要素を説明で区別するための記号で、元の図のマスにはどちらも 4 と書かれています。

選択ソートでは毎回、未整列区間の最小要素を見つけ、同区間の先頭要素と直接交換します。ソートの安定性は、すべての回が終わったときの出力で、等しい要素が初めの順序を保っているかどうかで判断します。

最初の走査で未整列区間 [0, 5] の最小要素 1（インデックス 3）を選び、インデックス 0 の 4A と交換します。1 がインデックス 0 に確定し、未整列区間は [1, 5] に縮みます。元のインデックス 0 の 4A はインデックス 1 の 4B を飛び越えてインデックス 3 に移り、一時的に 2 つの 4 が逆順になります。図には最初の走査だけを示し、以降の回は描いていません。

図で最初の交換後に順序が逆になるのは途中の状態です。この節のコードの「厳密に小さい」という比較条件で続けると、2 回目にはインデックス 1 の 4B とインデックス 5 の 2 を交換します。最終結果は [1, 2, 3, 4A, 4B, 5] で、2 つの 4 は初めの順序に戻ります。図でわかるのは離れた位置の交換の仕組みで、この入力の最終結果でも逆順になるとはいえません。図とは別の反例を挙げます。[4A, 4B, 1] は 1 回目に [1, 4B, 4A] となります。2 回目は 2 つの 4 が等しく、厳密に小さいという条件を満たさないので、異なる位置の交換は起きません。最終結果も [1, 4B, 4A] です。このような入力が 1 つあれば、選択ソートが不安定であることがわかります。
