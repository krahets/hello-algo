# 第 3 章 &nbsp; データ構造

![データ構造](../assets/covers/chapter_data_structure.svg){ class="cover-image" }

!!! abstract "概要"

    データ構造は、さまざまな形を取る頑丈な骨組みのようなものです。
    
    その骨組みがデータを整然と組み立てるための設計図となり、その上でアルゴリズムが生き生きと動き出します。
