# 3.6 &nbsp; 練習問題

## 3.6.1 &nbsp; 理解を確かめる問題

### 1. &nbsp; 身近な場面に見られるデータ間の関係

次の 3 つの場面について、データ間の関係に合うものを「線形構造、木構造、ネットワーク構造」から選び、理由を説明してください。

<!-- numbered-subquestions -->

1. 生徒が一列に並び、それぞれが自分の前後の人だけに注目しています。
2. 学校では「学校 → 学年 → 学級」という階層に沿って管理しています。
3. 街の道路は複数の交差点を結んでいます。1 つの交差点からほかの複数の交差点に通じており、経路が輪になることもあります。

??? success "解答例"

    1. 線形構造です。先頭と末尾を除くと、各人が隣り合う相手は前後に 1 人ずつで、関係が 1 本の線に沿って続きます。

    2. 木構造です。各学級は 1 つの学年に属し、各学年は学校に属します。上から下へ階層をなす関係です。

    3. ネットワーク構造です。1 つの交差点が複数の交差点とつながり、経路が輪になることもあるため、単一の順序や厳密な階層には並べられません。

        構造を判断するときは、メモリをどれだけ使うかを考える前に、要素どうしの関係を観察しましょう。

### 2. &nbsp; 論理的な順序をメモリに格納する方法

論理的な順序 `A → B → C` を保存するために、メモリへの配置を単純化した次の 2 つの案を考えます。

- 案 A：`A、B、C` を、それぞれ番号 `20、21、22` のメモリ区画に置きます。
- 案 B：`A、B、C` を、それぞれ番号 `20、7、31` のメモリ区画に置き、`A` には `B` の位置を、`B` には `C` の位置を記録します。

<!-- numbered-subquestions -->

1. 連続した領域に格納するのはどちらの案ですか。分散した領域に格納するのはどちらですか。
2. それぞれの案は、配列と連結リストのどちらに近いでしょうか。
3. 案 B のメモリ区画の番号は大きさの順に並んでいません。それでも `A → B → C` という論理的な順序を表せるのはなぜでしょうか。

??? success "解答例"

    1. 案 A は隣り合うメモリ区画を使うので、連続した領域に格納しています。案 B はノードが異なる位置に散らばっているので、分散した領域に格納しています。

    2. 案 A は配列に、案 B は連結リストに近い形です。

    3. 論理的な順序はメモリ区画の番号の大小によらず、各ノードが記録しているリンクによって決まります。
        `A` が記録した位置から `B` が見つかり、次に `B` が記録した位置から `C` が見つかるので、`A、B、C` の順にアクセスできます。

        この例からも、論理構造と物理構造は同じデータを異なる 2 つの観点から見たものだとわかります。

### 3. &nbsp; 宿題の記録に使うデータ型と構造

ある学習グループで、4 人が宿題を提出したかどうかを座席順に記録したところ、次のようになりました。

`[true, false, true, true]`

<!-- numbered-subquestions -->

1. 各要素にはどの基本データ型が適していますか。
2. 4 つの要素を座席順に一列に並べると、どのような論理構造になりますか。
3. 後で各人の宿題の点数 `[90, 0, 85, 100]` を記録することにした場合、変わるのはデータの「内容の型」と「整理の仕方」のどちらですか。理由を説明してください。

??? success "解答例"

    1. 各要素が表すのは「はい」か「いいえ」だけなので、ブール型 `bool` が適しています。

    2. これらの要素は座席順に並んで線形構造をなすので、配列に格納できます。

    3. 変わるのは内容の型です。要素がブール値から整数に変わります。整理の仕方は同じです。
        データは引き続き座席順に一列に並ぶので、配列という線形構造をそのまま使えます。

        基本データ型は「何を格納するか」を表し、データ構造は「データをどう整理するか」を表します。

## 3.6.2 &nbsp; プログラミング問題

### 1. &nbsp; 二進表現に含まれる 1 の個数

非負整数 `n` が与えられます。その二進表現に含まれる 1 の個数を求めてください。

ビット演算を使ってください。二進表現を文字列に変換したり、1 の個数を直接数える組み込み関数を使ったりしてはいけません。

??? tip "解き方のヒント"

    1. n & 1 で n の一番右のビットを取り出し、そのビットが 1 かどうか判定できます。
    2. 1 ビット右にシフトすると、一番右のビットが取り除かれます。多くの言語で使う演算子は >> です。
    3. 各ビットを調べて右にシフトする方法ができたら、n & (n - 1) に注目しましょう。n の一番右にある 1 が 0 に変わります。
