# 第 5 章 &nbsp; スタックとキュー

![スタックとキュー](../assets/covers/chapter_stack_and_queue.svg){ class="cover-image" }

!!! abstract "概要"

    スタックは猫たちが上へ上へと重なった姿に、キューは猫たちが一列に並んだ姿に似ています。
    
    スタックは後入れ先出し、キューは先入れ先出しの仕組みを表しています。
