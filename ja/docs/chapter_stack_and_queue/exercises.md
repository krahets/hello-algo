# 5.5 &nbsp; 練習問題

## 5.5.1 &nbsp; 理解を確かめる問題

### 1. &nbsp; スタックとキューで最初に取り出す要素はどれか

空のスタック`S`と空のキュー`Q`を用意し、それぞれに次の操作を同じ順序で行います。

手順1：`A`を追加します。
手順2：`B`を追加します。
手順3：要素を1つ取り出し、その値を記録します。
手順4：`C`を追加します。
手順5：空になるまで要素を1つずつ取り出し、そのたびに値を記録します。

`S`と`Q`のそれぞれについて、要素を取り出した順序を書いてください。それぞれが「後入れ先出し」と「先入れ先出し」のどちらに当たるかを示し、順序が異なる理由を説明してください。

??? success "解答例"

    スタック`S`から要素を取り出す順序は`B、C、A`です。`A、B`の順に追加した後、最後に追加した`B`を取り出します。次に`C`を追加します。
    その後は`C、A`の順に取り出します。これが「後入れ先出し」です。

    キュー`Q`から要素を取り出す順序は`A、B、C`です。`A、B`の順に追加した後、最初に追加した`A`を取り出します。
    次に`C`を追加し、`B、C`の順に取り出します。これが「先入れ先出し」です。

### 2. &nbsp; キューの末尾が配列の末尾を越えるとき

長さ5の循環配列を使ってキューを実装します。配列のインデックスの範囲は`0〜4`です。
現在は`front = 3`、`size = 2`で、キューの要素`A、B`はそれぞれインデックス3、4にあります。

<!-- numbered-subquestions -->

1. `C`をエンキューするとき、`C`をどのインデックスに格納しますか。エンキュー後の`size`はいくつですか。
2. 続いて1回デキューすると、どの要素が取り出されますか。デキュー後の`front`と`size`はそれぞれいくつですか。
3. この時点で、要素はキューの先頭から末尾まで論理的にどのような順序で並んでいますか。デキューするとき、配列内のほかの要素を移動する必要はありますか。理由も説明してください。

??? success "解答例"

    1. 新しい要素を格納するインデックスは、次の式で求められます。
        `(front + size) % 5 = (3 + 2) % 5 = 0`。
        したがって、`C`をインデックス0に格納します。エンキュー後は`size = 3`です。

    2. デキューすると、現在キューの先頭にある`A`が取り出されます。新しい先頭インデックスは次のように求められます。
        `(3 + 1) % 5 = 4`。したがって、`front = 4`、`size = 2`となります。

    3. キューに残っている要素の論理的な順序は`B、C`です。配列内では、`B`はインデックス4に、`C`はインデックス0にあります。
        デキューするときは、`front`を1つ進めて`size`を更新するだけです。循環配列では剰余を使ってインデックスを計算するので、末尾の次は先頭に戻ります。
        そのため、ほかの要素をまとめて前にずらす必要はありません。

### 3. &nbsp; 両端キューの先頭と末尾での操作

ここでは、`push_first` は先頭への追加、`push_last` は末尾への追加を表します。
`pop_first` は先頭からの取り出し、`pop_last` は末尾からの取り出しを表します。

空の両端キュー `deq` に、次の操作を順に行います。

1. `push_last(A)`
2. `push_last(B)`
3. `push_first(C)`
4. `pop_last()`
5. `push_last(D)`
6. `pop_first()`

<!-- numbered-subquestions -->

1. 1 回目と 2 回目に取り出される要素は、それぞれ何ですか。
2. すべての操作が終わったとき、先頭から末尾に向かって、どの要素がどの順に残っていますか。
3. この 6 つの操作を見てみましょう。末尾への追加と先頭からの削除だけができるキューで、すべての操作を行えますか。できない場合は、どの操作ができないかを挙げてください。次に、両端キューではすべての操作ができるかどうかを、理由とともに説明してください。

??? success "解答例"

    最初の 3 つの操作を終えると、両端キューの要素は先頭から末尾の順に `[C, A, B]` となります。

    <!-- numbered-subquestions -->

    1. `pop_last()` で `B` を取り出します。次に `D` を追加すると、キューは `[C, A, D]` になります。
        続いて `pop_first()` で `C` を取り出します。

    2. 最後に残るのは `[A, D]` です。

    3. 末尾への追加と先頭からの削除だけができるキューでは、すべての操作を行うことはできません。
        手順 3 の `push_first(C)` では先頭への追加、手順 4 の `pop_last()` では末尾からの削除が必要です。どちらもこのキューではできません。
        両端キューはどちらの端でも追加と削除ができるので、この 6 つの操作をすべて行えます。

## 5.5.2 &nbsp; プログラミング問題

### 1. &nbsp; 括弧の並びを検証する

`()`、`[]`、`{}` の 3 種類の括弧だけを含む文字列 `s` が与えられます。スタックを使って、括弧の並びが正しいか判定してください。

正しい並びには、次の 2 つの条件が両方とも必要です。どの閉じ括弧も、その時点でまだ対になっていない直近の開き括弧と種類が一致しなければなりません。
また、最後まで調べたとき、対になっていない開き括弧が残っていてはいけません。判定結果を真偽値で返してください。

??? tip "解き方のヒント"

    1. 閉じ括弧をキー、対応する開き括弧を値とする対応表を作れます。
    2. 閉じ括弧が現れたら、まずスタックが空かどうかを確認し、次にトップの括弧と対応するかを調べましょう。
    3. 最後まで調べた時点で、スタックも空になっている必要があります。
