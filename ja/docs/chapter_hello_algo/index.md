# 序文

数年前、私は LeetCode で『剣指 Offer』シリーズの解説を公開し、多くの読者から励ましと応援をいただきました。読者とやり取りする中で最もよく聞かれたのは、「アルゴリズムはどう学び始めたらよいか」という質問でした。いつしか私自身も、この問いに強くひかれるようになりました。

よくわからないままとにかく問題を解くというのが、いちばん人気のある方法のようです。簡単で直接的ですし、効果もあります。ただ、これは「マインスイーパー」で遊ぶのに似ています。独学が得意な人は地雷を一つずつ取り除いて進めますが、基礎が足りない人は何度も爆発に遭い、そのたびに一歩ずつ後ずさりしかねません。教科書を通読するのもよくある方法ですが、就職を目指す人は、卒業論文や応募書類、筆記試験や面接の準備にすでに力の大半を使っています。そのうえ分厚い本を読みこなすのは大仕事です。

同じことで悩んでいるなら、この本があなたを「見つけて」くれて幸いです。本書はこの問いに対する私なりの答えです。最適解とまではいかなくても、一歩を踏み出す試みではあります。この本だけで内定が手に入るわけではありませんが、データ構造とアルゴリズムの「知識の地図」を一緒に歩き、「地雷」の形や大きさ、どこに分布しているかを知り、さまざまな「地雷の取り除き方」を身に付けられるようにしました。その力があれば、もっと自在に問題に取り組み、文献を読み、少しずつ知識の全体像を組み立てていけると信じています。

ファインマン先生の「Knowledge isn't free. You have to pay attention.」という言葉に、私は深く共感します。その意味で、本書も完全に「無料」ではありません。読者が注いでくださる貴重な「注意」に応えられるよう、私も最大限の「注意」と力を注いで本書を執筆します。

私自身、学ぶべきことはまだたくさんあります。本書の内容は時間をかけて磨いてきましたが、なお多くの誤りが残っていることでしょう。先生方、そして学習中の皆さんにも、ご指摘、ご訂正をいただければ幸いです。

コンピュータの登場は世界を大きく変えました。高速な計算能力と優れたプログラム可能性を兼ね備え、アルゴリズムを実行し、データを処理する理想的な手段となりました。ビデオゲームの写実的な映像、自動運転の賢い判断、AlphaGo の見事な一局、ChatGPT との自然な対話。いずれも、コンピュータ上でアルゴリズムが巧みに働く姿です。

実は、アルゴリズムとデータ構造は、コンピュータが生まれる前から世界のあちこちにありました。初期のアルゴリズムは、古代の数え方や道具を作る手順など、比較的単純なものでした。文明の進歩とともに、仕組みは精緻に、複雑になってきました。目を見張る職人の技、生産力を解き放った工業製品、宇宙の運行を支える科学の法則に至るまで、ありふれたものにも驚くべきものにも、その背後には巧みなアルゴリズムの発想が隠れています。

データ構造も至るところにあります。社会のネットワークから地下鉄の路線に至るまで、多くのシステムは「グラフ」として表せます。国家から家庭まで、社会の主な組織形態には「木」の特徴があります。冬の重ね着は「スタック」のようで、最初に着た服を脱ぐのは最後です。バドミントンのシャトルの筒は、一方の端から入れて反対の端から取り出す「キュー」に似ています。辞書は、目的の項目をすばやく探せる「ハッシュテーブル」のようです。

本書の目的は、わかりやすいアニメーション図解と実行できるコード例を通じて、アルゴリズムとデータ構造の中心となる考え方を理解し、自分でプログラムにできるようになっていただくことです。そのうえで、複雑な世界の中に息づくアルゴリズムの姿を紹介し、その美しさを伝えたいと思います。本書が皆さんの役に立てば幸いです。
