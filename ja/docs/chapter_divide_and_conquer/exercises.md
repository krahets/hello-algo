# 練習問題

## 理解を確かめる問題

### 分割統治法に向いているのはどの課題か

ある学生が、次の課題を「半分に分け、それぞれを解いてから結果をまとめる」という方法で解こうとしています。
それぞれについて「分割統治法に向いている」「分割統治法は使えるが、全体の作業量は減らない」「二つに分けても独立に解けない」のいずれに当てはまるか、理由とともに説明してください。

<!-- numbered-subquestions -->

1. 未整列の配列をソートする。
2. 配列の最大値を求める。
3. 一連のスタック操作 `push(x)` と `pop()` を順番に実行し、`pop()` のたびに取り出した要素を出力する。

??? success "解答例"

    1. 分割統治法に向いています。半分に分けてそれぞれを独立にソートし、$O(n)$ でマージするのが、まさにマージソートです。
    2. 分割統治法は使えますが、全体の作業量は減りません。左右合わせて $n$ 個の要素をすべて調べる必要があり、
        そのまま走査する場合と同じく、時間計算量は $O(n)$ です。
    3. 二つに分けても独立には解けません。後半の開始時点でのスタックの中身は、前半の操作の結果によって決まるため、
        互いの結果が分からないまま、両方を独立に処理することはできません。

### 繰り返し二乗法はどのように計算を減らすか

次の再帰関数は、分割統治法で $x^n$ を計算します。

```src
[file]{fast_power}-[class]{}-[func]{fast_pow}
```

`x = 3`、`n = 5` として、この関数で計算します。

<!-- numbered-subquestions -->

1. 再帰呼び出しで、引数 `n` は順にどのような値になりますか。
2. 最も深い階層から順に、それぞれの階層でどの値が返りますか。
3. 掛け算の両側で同じ部分問題を 1 回ずつ呼び出さず、再帰の結果を先に `half` に保存するのはなぜですか。

??? success "解答例"

    1. 引数は順に `5 → 2 → 1 → 0` となります。終了条件に達するまで、毎回指数を半分にします。

    2. `n = 0` のときは 1 を、`n = 1` のときは $1×1×3=3$ を返します。
        `n = 2` のときは $3×3=9$ を、`n = 5` のときは $9×9×3=243$ を返します。

    3. 掛け算の両側で同じ部分問題を 1 回ずつ呼び出すと、2 回の再帰でまったく同じ計算を行います。
        先に結果を `half` に保存すれば、各階層での再帰呼び出しは 1 回で済み、再帰の深さはおよそ $\log n$ です。
        2 回ずつ呼び出すと、同じ計算が何度も繰り返されます。

### 走査順から左右の部分木を切り分ける

ノードの値に重複のない二分木の行きがけ順と通りがけ順の走査列を次に示します。

- 行きがけ順：`[A, B, D, E, C]`
- 通りがけ順：`[D, B, E, A, C]`

根ノードの階層での分割だけを考えます。それ以上再帰を進めたり、木全体を描いたりする必要はありません。

<!-- numbered-subquestions -->

1. 根ノードはどれですか。
2. 通りがけ順のどの部分が、それぞれ左部分木と右部分木に対応しますか。
3. 行きがけ順のどの部分が、それぞれ左部分木と右部分木に対応しますか。根ノードの直接の子はどれですか。

??? success "解答例"

    1. 行きがけ順の先頭が根ノードなので、根ノードは `A` です。

    2. `A` が通りがけ順の列を二つに分けます。左部分木は `[D, B, E]`、右部分木は `[C]` です。

    3. 左部分木には 3 個のノードがあるため、行きがけ順で根ノード `A` に続く 3 個の要素が左部分木に属します。
        つまり、左部分木は `[B, D, E]` で、残りの `[C]` が右部分木に属します。
        したがって、根ノードの左の子は `B`、右の子は `C` です。

## プログラミング問題

### 繰り返し二乗法

実数 `x` と整数 `n` が与えられます。言語組み込みのべき乗関数を使わずに $x^n$ を求めてください。
再帰による分割統治法を使い、毎回指数を半分にして、計算済みの部分問題の結果を再利用してください。
この問題では `x = 0` の場合も含めて $x^0=1$ と定めます。`n < 0` のときは `x != 0` が保証され、求める値は $(1/x)^{-n}$ と書き換えられます。

??? tip "解き方のヒント"

    1. n が 0 のとき、答えは 1 です
    2. x の n // 2 乗を計算したら half に保存し、同じ再帰呼び出しを繰り返さないようにします
    3. n < 0 のときは、まず x を 1 / x にしてから n を -n にします。C++ や Java では、先に n を 64 ビット整数に変換すれば、32 ビット整数の最小値の符号を反転するときのオーバーフローを防げます
