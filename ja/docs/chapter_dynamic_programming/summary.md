# 14.7 &nbsp; まとめ

### 1. &nbsp; 要点の振り返り

- 動的計画法は問題を部分問題に分け、その解を保存して重複計算を避けることで、効率よく解を求めます。
- 時間を考慮しなければ、動的計画法で解ける問題はすべてバックトラック（全探索）でも解けます。ただし、再帰木には部分問題の重複が多く、非常に非効率です。メモ用配列に計算済みの部分問題の解をすべて記録すれば、重複する各部分問題を 1 回だけ計算すれば済みます。
- メモ化探索はトップダウンの再帰的な解法です。これに対応する動的計画法はボトムアップの解法で、表を埋めるように漸化式で順に解を求めます。現在の状態が近くのいくつかの状態だけに依存する場合は、$dp$ テーブルの次元を 1 つ減らし、空間計算量を削減できます。
- 部分問題への分解は広く使われる考え方で、分割統治法、動的計画法、バックトラックではそれぞれ異なる性質を持ちます。
- 動的計画法に適した問題の 3 つの特徴は、部分問題の重複、最適部分構造、過去の経緯に依存しないことです。
- 部分問題の最適解から元の問題の最適解を構成できるとき、その問題は最適部分構造を持ちます。
- 過去の経緯に依存しないとは、ある状態から先の展開がその状態だけで決まり、それまでにどの状態を経たかには左右されないことです。多くの組合せ最適化問題にはこの性質がなく、動的計画法では高速に解けません。

**ナップサック問題**

- ナップサック問題は動的計画法の代表例で、0-1 型、個数制限なし、個数制限付きなどの変種があります。
- 0-1 ナップサック問題では、最初の $i$ 個の品物から選んで容量 $c$ のナップサックに入れられる最大価値を状態の値とします。入れない場合と入れる場合から最適部分構造が得られ、状態遷移式を導けます。使用メモリを削減する際は、各状態が真上と左上の状態に依存するので、左上の値を上書きしないよう配列を降順に走査します。
- 個数制限なしナップサック問題では同じ品物を何個でも選べるため、品物を入れる場合の状態遷移が 0-1 ナップサック問題とは異なります。各状態は真上と左の状態に依存するので、使用メモリを削減した場合は昇順に走査します。
- 硬貨の両替問題は個数制限なしナップサック問題の変種です。「最大」の価値から「最少」の硬貨枚数へと目的が変わるため、状態遷移式の $\max()$ を $\min()$ に変えます。また、容量を「超えない」ことから、目標金額を「ちょうど」作ることに条件が変わるため、目標金額を作れない無効な解を $amt + 1$ で表します。
- 硬貨の両替問題 II では、「硬貨の最少枚数」に代わって「硬貨の組合せ数」を求めるため、状態遷移式の $\min()$ を加算に置き換えます。

**編集距離問題**

- 編集距離（Levenshtein 距離）は、2 つの文字列の類似度を測る指標です。一方からもう一方に変換するのに必要な最少編集回数で定義され、操作には追加、削除、置換があります。
- 編集距離問題では、$s$ の先頭 $i$ 文字を $t$ の先頭 $j$ 文字に変える最少編集回数を状態の値とします。$s[i-1] \ne t[j-1]$ のときは追加、削除、置換の 3 つの選択肢があり、それぞれに残りの部分問題が対応します。そこから最適部分構造がわかり、状態遷移式を導けます。$s[i-1] = t[j-1]$ のときは、今見ている文字を編集する必要はありません。
- 編集距離では、各状態が真上、左、左上の状態に依存するため、使用メモリを削減すると、昇順でも降順でもそのままでは正しく更新できません。左上の状態を変数に一時保存すれば、個数制限なしナップサック問題と同じ状況になり、昇順に走査できます。
