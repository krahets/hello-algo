# 第 10 章 &nbsp; 探索

![探索](../assets/covers/chapter_searching.svg){ class="cover-image" }

!!! abstract "概要"

    探索は未知の世界への冒険です。不思議な空間の隅々まで歩き回ることもあれば、あっという間に目当てのものを見つけることもあります。
    
    探しものをするこの旅では、一歩踏み出すたびに、思いもよらない答えに出会えるかもしれません。
