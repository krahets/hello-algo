# まとめ

### 要点の振り返り

- 二分探索はデータが整列済みであることを利用し、探索区間を毎回半分に狭めながら探します。入力データが整列済みであることが条件で、配列または配列を使って実装したデータ構造にのみ適用できます。
- 総当たり探索はデータ構造を走査して目標のデータを見つけます。線形探索は配列や連結リストに、幅優先探索と深さ優先探索はグラフや木に適しています。これらの方法は幅広く使え、データの前処理が不要ですが、時間計算量は $O(n)$ と大きくなります。
- ハッシュ探索、木による探索、二分探索は、特定のデータ構造から目標の要素をすばやく見つける効率のよい方法です。その時間計算量は $O(\log n)$、さらには $O(1)$ にもなりますが、通常は追加のデータ構造が必要です。
- 実際には、データの規模、探索に求める性能、データの照会や更新の頻度などを具体的に検討し、適切な探索方法を選びます。
- 線形探索は小規模なデータや頻繁に更新するデータ、二分探索は大規模な整列済みデータに適しています。高速な検索が必要で範囲探索が不要ならハッシュ探索が、順序を保ちながら範囲探索を行う大規模な動的データには木による探索が適しています。
- 線形探索をハッシュ探索に置き換えるのは実行時間を短縮するためによく使う方法で、探索の時間計算量を $O(n)$ から $O(1)$ に減らせます。
