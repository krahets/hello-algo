# 10.7 &nbsp; 練習問題

## 10.7.1 &nbsp; 理解を確かめる問題

### 1. &nbsp; 二分探索で探索区間が狭まる仕組み

整列済み配列 `[2, 5, 8, 12, 16, 23, 38]` から 16 を探します。
閉区間 `[i, j]` を使い、中央のインデックスを
$m=i+(j-i)/2$（小数点以下切り捨て）で求めます。

各回の `(i, j, m)` と中央の要素を書き出し、次に区間をどう狭めるかを、
目標値が見つかるまで示してください。

??? success "解答例"

    各回の探索は次のように進みます。

    | 回 | `(i, j, m)` | 中央の要素 | 次の操作 |
    | --- | --- | --- | --- |
    | 1 | `(0, 6, 3)` | 12 | `12 < 16` なので `i = 4` とする |
    | 2 | `(4, 6, 5)` | 23 | `23 > 16` なので `j = 4` とする |
    | 3 | `(4, 4, 4)` | 16 | 目標値が見つかったのでインデックス 4 を返す |

    配列は整列済みなので、中央の値が目標値より小さければ、中央とそれより左を除外できます。
    中央の値が目標値より大きければ、中央とそれより右を除外できます。

### 2. &nbsp; 重複する要素の左端と右端

配列 `[1, 2, 2, 2, 4, 6]` から数値 2 を探します。
ある学生は、二分探索でインデックス 2 に目標値を見つけると、すぐにそのインデックスを返し、こう言いました。
「インデックス 2 が数値 2 の左端です。」

<!-- numbered-subquestions -->

1. この説明は正しいでしょうか。数値 2 の左端と右端のインデックスをそれぞれ答え、理由を説明してください。
2. 左端を探すとき、中央の要素が目標値と等しければ、次はどちら側を探しますか。
3. 右端を探すときはどちら側を探しますか。方向だけを答えてください。探索の過程をすべて書く必要はありません。

??? success "解答例"

    1. この説明は正しくありません。2 を一つ見つけてすぐに返すと、どれか一つの 2 が見つかったことしかわからず、それが左端や右端の 2 である保証はありません。
        この例では左端はインデックス 1、右端はインデックス 3 です。

    2. 左端を探すときは、中央の要素が 2 と等しくても左側の探索を続けます。
        たとえば閉区間を使う場合は `j = m - 1` とします。

    3. 右端を探すときは、中央の要素が 2 と等しければ右側の探索を続けます。
        たとえば `i = m + 1` とします。

### 3. &nbsp; データに応じた探索方法の選択

次の三つの場面に適した方法を「線形探索、二分探索、ハッシュテーブル」からそれぞれ選び、その理由を説明してください。

<!-- numbered-subquestions -->

1. 整列済みで今後も変化しない $10^7$ 個の整数を、別のデータ構造を作らずに繰り返し探索する場合。
2. 挿入と削除が頻繁に起きるデータ集合で、あるキーが存在するかを繰り返し調べる場合。順序を保つ必要はなく、範囲探索も行いません。
3. 未整列の配列から、ある値を一度だけ探す場合。

??? success "解答例"

    1. 二分探索を使います。データは整列済みで変化しないため、追加の記憶領域を使わずに $O(\log n)$ の時間で探索できます。
    2. ハッシュテーブルを使います。ハッシュ関数がキーを各バケットにほぼ均等に分散できれば、挿入、削除、キーによる探索の時間計算量はいずれも平均 $O(1)$ です。
    3. 先頭から末尾へ順に調べます。一度だけ探すなら、ソートするにもハッシュテーブルを作るにも、まず配列全体を処理する必要があり、
        この探索にかかる作業の総量は減りません。

        どの方法を選ぶかは、データが整列済みか、追加のデータ構造を使えるか、何回問い合わせるか、どのような操作が必要かによって決まります。

## 10.7.2 &nbsp; プログラミング問題

### 1. &nbsp; 整列済み配列の二分探索

狭義の単調増加順に並んだ整数配列 `nums` と目標値 `target` が与えられます。二分探索で `target` を探し、見つかれば配列内のインデックスを、見つからなければ -1 を返してください。

??? tip "解き方のヒント"

    1. 最初の区間は left = 0、right = n - 1 で、区間が空でない条件は left <= right です。
    2. mid = left + (right - left) // 2 で中央のインデックスを求めます。
    3. `nums[mid]` が `target` より小さければ左端を `mid + 1` に移し、`nums[mid]` が `target` より大きければ右端を `mid - 1` に移します。等しければ、その場でインデックスを返します。

[LeetCode](https://leetcode.com/problems/binary-search/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; 整列済み配列への挿入位置

狭義の単調増加順に並んだ整数配列 `nums` と目標値 `target` が与えられます。

配列内に `target` があればそのインデックスを返し、なければ `target` を挿入しても狭義の単調増加順が保たれる位置を返してください。答えは 0 になることも配列の長さに等しくなることもあります。二分探索を使ってください。

??? tip "解き方のヒント"

    1. 答えは 0 になることも、配列の長さ n になることもあります。
    2. 閉区間を使う場合、`nums[mid]` が `target` 以上なら `right = mid - 1` としてさらに左を調べ、それ以外なら `left = mid + 1` とします。
    3. ループが終了したときの left が挿入位置です。

[LeetCode](https://leetcode.com/problems/search-insert-position/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
