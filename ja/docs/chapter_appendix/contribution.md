# 一緒に本書を作りましょう

著者の力が及ばず、本書には見落としや誤りがあるかもしれません。どうかご了承ください。誤字脱字、リンク切れ、内容の欠落、曖昧な表現、わかりにくい説明、不適切な文章構成などに気づいたら、修正にご協力ください。読者の皆さんに、よりよい学習教材を届けることにつながります。

オープンソースコミュニティへの惜しみない貢献に感謝し、すべての[執筆協力者](https://github.com/krahets/hello-algo/graphs/contributors)の GitHub ID を、原書のリポジトリ、Web 版、および既存の PDF 版のトップページに掲載します。

!!! success "オープンソースの魅力"

    紙の書籍は次の印刷までに長い時間がかかることが多く、内容の更新が容易ではありません。
    
    一方、オープンソースである本書なら、数日、場合によっては数時間で内容を更新できます。

### 内容の小さな修正

下図のように、各ページの右上に「編集アイコン」があります。次の手順で文章やコードを修正できます。

1. 「編集アイコン」をクリックします。「このリポジトリを Fork する必要がある」という案内が表示されたら、操作に同意してください。
2. Markdown ソースファイルを編集し、内容が正しいか確認します。書式もできるだけ統一してください。
3. ページ下部に変更内容の説明を入力し、「Propose file change」ボタンをクリックします。移動先のページで「Create pull request」ボタンをクリックすると、プルリクエストを作成できます。

![ページの編集ボタン](contribution.assets/edit_markdown.png)

画像は直接編集できません。新しい [Issue](https://github.com/krahets/hello-algo/issues) を作成するか、コメントで問題をお知らせください。できるだけ早く描き直して差し替えます。

### 新しい内容の作成

コードをほかのプログラミング言語に移植したり、記事の内容を充実させたりするなど、このオープンソースプロジェクトへの参加に関心がある方は、次の Pull Request の手順に従ってください。

1. GitHub にログインし、本書の[コードリポジトリ](https://github.com/krahets/hello-algo)を自分のアカウントに Fork します。
2. Fork したリポジトリのページを開き、`git clone` コマンドでローカルにクローンします。
3. ローカルで内容を作成し、十分なテストを行ってコードの正しさを確認します。
4. ローカルの変更を Commit し、リモートリポジトリに Push します。
5. リポジトリのページを再読み込みし、「Create pull request」ボタンをクリックすると、プルリクエストを作成できます。

### Docker での起動

`hello-algo` のルートディレクトリで次の Docker スクリプトを実行すると、`http://localhost:8000/ja/` から本プロジェクトの日本語版にアクセスできます。

```shell
docker-compose up -d
```

次のコマンドで起動した環境を削除できます。

```shell
docker-compose down
```
