# 11.12 &nbsp; 練習問題

## 11.12.1 &nbsp; 理解を確かめる問題

### 1. &nbsp; 選択ソートとバブルソートの最初の数回の走査

配列 `[4, 2, 5, 1, 3]` が与えられます。以下ではいずれも昇順に並べ替えます。

<!-- numbered-subquestions -->

1. 選択ソートの最初の 2 回の走査をたどり、各回の終了時の配列と、その時点で値が確定した位置を示してください。
2. バブルソートの最初の走査をたどり、終了時の配列と交換回数を示し、どの位置の値が確定したかを答えてください。

??? success "解答例"

    1. 最初の 2 回の結果を次に示します。

        | 走査 | 配列の状態 | 説明 |
        | --- | --- | --- |
        | 1 | `[1, 2, 5, 4, 3]` | 最小の要素 1 と先頭の要素を交換します |
        | 2 | `[1, 2, 5, 4, 3]` | 値 2 はすでにインデックス 1 にあるので、交換は不要です |

        この時点で先頭の 2 要素の位置が確定します。以降は `[5, 4, 3]` の中から最小の要素を選んでいけばよいことになります。

    2. 隣り合う要素を順に比較します。4 と 2 は交換し、4 と 5 は交換せず、5 と 1、続いて 5 と 3 を交換すると、
        配列は `[2, 4, 1, 3, 5]` になります。交換は計 3 回です。最大の要素 5 が末尾に移ったので、最後の位置の値が確定します。

### 2. &nbsp; 値が等しい要素の順序は変わるか

配列 $[2_a, 2_b, 1]$ の $2_a$ と $2_b$ は値が等しく、添字で元の順序を区別しています。

<!-- numbered-subquestions -->

1. 選択ソートの最初の走査が終わった時点の配列を書いてください。$2_a$ と $2_b$ の相対的な順序は変わりましたか。
2. バブルソートの最初の走査が終わった時点の配列を書いてください。$2_a$ と $2_b$ の相対的な順序は変わりましたか。
3. 前の 2 問をもとに、値が等しい要素の元の順序を保てるかという点で、2 つのソートの違いを説明してください。

??? success "解答例"

    1. 選択ソートでは最初の走査で最小の要素 1 を選び、先頭の $2_a$ と交換します。その結果、
        配列は $[1, 2_b, 2_a]$ になります。$2_a$ が $2_b$ の後ろに移ったので、両者の相対的な順序が変わりました。

    2. バブルソートではまず $2_a$ と $2_b$ を比較します。値が等しいので交換せず、次に $2_b$ と 1 を比較して交換します。
        最初の走査が終わると配列は $[2_a, 1, 2_b]$ になります。$2_a$ は引き続き $2_b$ の前にあり、相対的な順序は変わりません。

    3. この例では、選択ソートで値が等しい要素の元の順序が変わります。バブルソートでは、左の要素が右の要素より大きいときだけ
        隣り合う要素を交換します。値が等しい要素同士は交換しないので、元の順序が保たれます。

### 3. &nbsp; カウントソートと基数ソートの比較

ある学校で、桁数が 8 桁に固定された多数の学籍番号を並べ替えます。次の問いに答えてください。

<!-- numbered-subquestions -->

1. 最下位桁から始める基数ソートでは、何回の走査が必要ですか。
2. 学籍番号をそのまま整数としてカウントソートすると、なぜ使われないカウント用の領域が大量に生じるのですか。
3. 前の 2 問をもとに、多数の 8 桁固定の学籍番号を処理するなら、カウントソートと基数ソートのどちらを選びますか。理由も説明してください。

??? success "解答例"

    1. 学籍番号は 8 桁なので、最下位桁から最上位桁まで計 8 回走査します。各回では 0～9 の数字だけでグループ分けします。

    2. 直接カウントするには、8 桁で取りうるすべての値に領域を確保する必要があります。しかし、実際の学生が使う番号はそのごく一部なので、
        大部分のカウントは 0 のままです。

    3. 基数ソートを選びます。桁数が一定で各桁の値が 10 通りしかないため、元の順序を保つグループ分けを 8 回繰り返すだけで済みます。
        カウントソートで 8 桁の学籍番号全体を整数のインデックスに使うと、実際には現れない多数の値にもカウント用の領域を確保する必要があります。

## 11.12.2 &nbsp; プログラミング問題

### 1. &nbsp; マージソートで配列を並べ替える

整数配列 `nums` が与えられます。マージソートを自分で実装し、要素を非減少順に並べ替えて返してください。言語組み込みのソート関数は使わないでください。

??? tip "解き方のヒント"

    1. 長さが 1 以下の区間はすでに整列しています
    2. 区間を中央で二分し、それぞれを再帰的にソートします
    3. 2 本のポインタを使って整列済みの左右の区間をマージし、結果を元の配列に書き戻します

[LeetCode](https://leetcode.com/problems/sort-an-array/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; カウントソートで整数配列を並べ替える

整数配列 `nums` と非負整数 $K$ が与えられます。配列の各要素は $0$ 以上 $K$ 以下です。

カウントソートを実装し、結果を非減少順に `nums` に書き戻して `nums` を返してください。
要素同士の大小比較で順序を決めたり、言語組み込みのソート関数を呼び出したりしないでください。

??? tip "解き方のヒント"

    1. 各要素は 0 以上 K 以下なので、要素の値をそのままカウント配列のインデックスに使えます
    2. まず nums を走査し、対応する位置のカウントを 1 増やします
    3. 次にカウント配列を 0 から K まで走査し、値 x の出現回数と同じ個数の x を nums に続けて書き込みます
