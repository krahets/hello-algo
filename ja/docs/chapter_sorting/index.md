# 第 11 章 &nbsp; ソート

![ソート](../assets/covers/chapter_sorting.svg){ class="cover-image" }

!!! abstract "概要"

    ソートは、ばらばらなデータに秩序を与える魔法の鍵のようなものです。データの様子がつかみやすくなり、処理も効率よく進められます。

    単純な昇順の並びから、いくつもの分類に従う複雑な並びまで、ソートを通してデータの中にある調和の美しさが見えてきます。
