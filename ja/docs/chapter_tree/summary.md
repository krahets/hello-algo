# まとめ

### 要点の振り返り

- 二分木は、一つを二つに分ける分割統治の考え方を表す非線形のデータ構造です。各ノードは値を一つと、左右の子をそれぞれ指す 2 つのポインタを持ちます。
- あるノードの左の子とその下のノードからなる木を、そのノードの左部分木と呼びます。右部分木も同様です。
- 二分木に関する用語には、根ノード、葉ノード、レベル、次数、辺、高さ、深さなどがあります。
- 二分木の初期化、ノードの挿入、ノードの削除は、連結リストでの操作と似ています。
- 代表的な二分木には、完璧二分木、完全二分木、正二分木、平衡二分木があります。完璧二分木は最も理想的な状態で、連結リストは退化した最悪の状態です。
- 二分木は配列で表せます。ノードの値と空きをレベル順に並べ、親子のインデックスの対応関係でポインタの役割を実現します。
- 二分木のレベル順走査は幅優先探索の一種で、輪を一つずつ外へ広げるように層ごとに進みます。通常はキューで実装します。
- 行きがけ順、通りがけ順、帰りがけ順の走査はいずれも深さ優先探索です。一つの経路を行き止まりまで進み、戻ってから続けます。通常は再帰で実装します。
- 二分探索木は、要素を効率よく探索できるデータ構造です。探索・挿入・削除の時間計算量はいずれも $O(\log n)$ です。木が連結リストに退化すると、各操作の時間計算量は $O(n)$ に悪化します。
- AVL 木は平衡二分探索木であり、ノードの挿入や削除を繰り返しても、回転によって平衡を保ちます。
- AVL 木の回転には、右回転、左回転、右回転してから左回転、左回転してから右回転があります。ノードの挿入や削除の後、下から上に回転を行って木の平衡を回復します。

### Q & A

**Q**：ノードが一つだけの二分木では、木の高さと根の深さはどちらも $0$ ですか。

はい。高さと深さは通常、経路に含まれる辺の本数で定義するためです。

**Q**：二分木の挿入や削除は通常「複数の操作」を組み合わせて行うとあります。これはどのような操作ですか。子ノードのリソースを解放することだと考えてよいですか。

例えば二分探索木では、ノードの削除は 3 通りに場合分けされ、いずれの場合も複数の手順でノードを操作します。

**Q**：二分木の DFS に行きがけ順、通りがけ順、帰りがけ順の 3 種類があるのはなぜですか。それぞれどのような用途がありますか。

配列を順方向や逆方向にたどるのと同様に、二分木には行きがけ順、通りがけ順、帰りがけ順という 3 つの走査方法があり、目的の順序で結果を得られます。例えば二分探索木では、値の関係が `左の子の値 < 根の値 < 右の子の値` なので、「左 $\rightarrow$ 根 $\rightarrow$ 右」の順に走査すれば、整列したノードの列が得られます。

**Q**：右回転では、平衡が崩れた `node` と、`child`、`grand_child` の関係を調整しますが、`node` の親と `node` の元の接続は管理しなくてよいのですか。右回転後に切れてしまいませんか。

再帰の視点で考えてみましょう。右回転 `right_rotate(root)` に渡すのは部分木の根で、最後に `return child` で回転後の部分木の根を返します。部分木の根を親につなぐのはこの関数から戻った後で、右回転そのものが受け持つ処理には含まれません。

**Q**：C++ ではどのように考えて関数を `private` と `public` に分けていますか。`height()` を `public` に、`updateHeight()` を `private` に置くのはなぜですか。

主な基準はメソッドをどこから使うかです。クラス内だけで使うなら `private` にします。例えば `updateHeight()` は挿入や削除の一手順でしかなく、利用者が単独で呼び出す意味はありません。一方、`height()` はノードの高さを取得するもので、`vector.size()` と同じように使えるよう `public` にしています。

**Q**：入力データから二分探索木を作るにはどうすればよいですか。根の選び方は重要ですか。

はい。木の作り方は二分探索木のコードの `build_tree()` メソッドに示しています。根を選ぶには通常、入力データをソートし、中央の要素を根にして左右の部分木を再帰的に作ります。こうすると木をできるだけ均等に保てます。

**Q**：Java で文字列を比較するときは、必ず `equals()` メソッドを使うのですか。

Java の基本データ型では、`==` は 2 つの変数の値が等しいかを比較します。参照型では、次の 2 つの比較は仕組みが異なります。

- `==` は、2 つの変数が同じオブジェクト、つまりメモリ上の同じ場所を指しているかを比較します。
- `equals()` は、2 つのオブジェクトの値が等しいかを比較します。

したがって、値を比較するには `equals()` を使います。ただし、`String a = "hi"; String b = "hi";` のように初期化した文字列は文字列定数プールに格納され、同じオブジェクトを指すので、この場合は `a == b` でも 2 つの文字列の内容を比較できます。

**Q**：幅優先走査で最下層を処理する直前、キューにあるノード数は $2^h$ ですか。

はい。例えば高さ $h = 2$ の完璧二分木ではノード総数が $n = 7$ で、最下層のノード数は $4 = 2^h = (n + 1) / 2$ です。
