# 練習問題

## 理解を確かめる問題

### 完全二分木、正二分木、完璧二分木

次の 2 つの配列は二分木をレベル順に表したものです。`None` は空の位置を示します。

- 木 A：`[1, 2, 3, 4, 5, 6]`
- 木 B：`[1, 2, 3, None, None, 6, 7]`

<!-- numbered-subquestions -->

1. どちらが完全二分木ですか。
2. どちらが正二分木ですか。正二分木では、葉以外のすべてのノードが子を 2 つ持ちます。
3. この中に完璧二分木はありますか。それぞれの木について理由を説明してください。

??? success "解答例"

    1. 木 A は完全二分木です。最下層以外はすべて埋まっており、最下層のノードは左から隙間なく並んでいます。
        木 B は完全二分木ではありません。最下層の左側に空きがあるのに、その右側にノードがあります。

    2. 木 B は正二分木です。ノード 1 とノード 3 にはそれぞれ子が 2 つあり、残りはすべて葉です。
        木 A は正二分木ではありません。ノード 3 の子は左のノード 6 だけです。

    3. どちらも最下層がすべて埋まっているわけではないので、完璧二分木ではありません。

### 同じ木を走査する 3 つの順序

配列 `[1, 2, 3, 4, 5, 6, 7]` の要素をレベル順に完全二分木に格納します。

<!-- numbered-subquestions -->

1. この木を描いてください。
2. 行きがけ順、通りがけ順、帰りがけ順でそれぞれ走査したときの値の列を書いてください。
3. 通りがけ順の列を根ノード 1 の位置で区切ると、その左側と右側の列はそれぞれ木のどの部分に対応しますか。

??? success "解答例"

    1. 木は次のようになります。

        ```text
              1
            /   \
           2     3
          / \   / \
         4   5 6   7
        ```

    2. 行きがけ順では `1, 2, 4, 5, 3, 6, 7` です。
        通りがけ順では `4, 2, 5, 1, 6, 3, 7` です。
        帰りがけ順では `4, 5, 2, 6, 7, 3, 1` です。

    3. 根ノード 1 の左側の `4, 2, 5` は、左部分木を通りがけ順に走査した列です。
        右側の `6, 3, 7` は、右部分木を通りがけ順に走査した列です。

### 2 つの二分探索木の比較

次の 2 つの列について、それぞれ空の二分探索木に左から順に値を挿入します。

- 列 A：`[4, 2, 6, 1, 3, 5, 7]`
- 列 B：`[1, 2, 3, 4, 5, 6, 7]`

<!-- numbered-subquestions -->

1. 値 7 を探索するときに通るノードを、それぞれ順に書いてください。
2. 根から最も遠い葉までの経路に含まれる辺の本数を高さとすると、2 つの木の高さはそれぞれいくつですか。
3. ここまでの 2 問を踏まえると、値 7 を探索するときの効率はどちらの木でも同じでしょうか。それぞれの木の形と探索経路に着目して理由を説明してください。

??? success "解答例"

    1. 列 A から作った木の探索経路は `4 → 6 → 7` です。
        列 B から作った木の探索経路は `1 → 2 → 3 → 4 → 5 → 6 → 7` です。

    2. 1 つ目の木はどのレベルもすべて埋まっており、高さは 2 です。2 つ目の木では子がすべて右側にあり、高さは 6 です。

    3. 7 を探索するときの効率は異なります。挿入順によって二分探索木の形と高さが変わるためです。1 つ目の木で通るノードは 3 個だけですが、
        2 つ目の木では 7 個のノードを順に通ります。木が高いほど、最悪の場合に経路上で比較するノードの数が増えます。

## プログラミング問題

### 二分木の最大深さ

二分木の根ノード `root` が与えられます。各ノードは整数値と、左右の子ノードへの参照を持ちます。

根から最も遠い葉までの経路上にある**ノードの個数**を、二分木の最大深さと呼びます。この木の最大深さを返してください。空の木の最大深さは 0 とします。
再帰を使って解いてください。

??? tip "解き方のヒント"

    1. この問題では深さをノードの個数で数えます。根しかない木の最大深さは 1 です。
    2. 現在のノードを根とする部分木の最大深さを、再帰関数の戻り値にします。
    3. 空のノードでは 0 を、それ以外では max(depth(left), depth(right)) + 1 を返します。

[LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 二分木のレベル順走査

二分木の根ノード `root` が与えられます。キューを使って、上のレベルから順にすべてのノードを訪問してください。同じレベルでは左から右へ進みます。

二次元配列を返してください。最初の部分配列には根と同じレベルのノードの値を、次の部分配列にはその次のレベルのノードの値を格納し、以降も同様にします。
木が空なら、空の配列を返してください。

??? tip "解き方のヒント"

    1. レベル順走査では先に入れたノードから訪問するので、キューを使います。
    2. 各回の開始時にキューに入っているノードは、すべて同じレベルにあります。
    3. 最初にキューの長さを記録します。その個数だけノードを取り出し、それぞれの子をキューに追加します。

[LeetCode](https://leetcode.com/problems/binary-tree-level-order-traversal/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 二分探索木で k 番目に小さい要素

ある二分探索木には `n` 個のノードがあり、値はすべて異なります。
ノードの値を小さい順に並べ、1 から順に番号を付けます。

根ノード `root` と、`1 <= k <= n` を満たす整数 `k` が与えられます。`k` 番目のノードの値を返してください。
すべての値を先に集めずに、通りがけ順走査の途中で答えを見つけてください。

??? tip "解き方のヒント"

    1. 二分探索木を通りがけ順に走査すると、ノードを値の小さい順に訪問できます。
    2. 通りがけ順走査では、左部分木、現在のノード、右部分木の順に処理します。現在のノードを訪問するときにカウンタを 1 増やします。
    3. カウンタが初めて k に達したとき、そのノードの値が答えです。それ以上走査する必要はありません。

[LeetCode](https://leetcode.com/problems/kth-smallest-element-in-a-bst/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
