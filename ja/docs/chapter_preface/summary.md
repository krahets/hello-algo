# 0.3 &nbsp; まとめ

### 1. &nbsp; 要点の振り返り

- 本書は主にアルゴリズムを初めて学ぶ方に向けています。すでに基礎を学んだ方には、知識を体系的に振り返るのに役立ちます。ソースコードは「演習用の道具箱」としても使えます。
- 内容は主に計算量解析、データ構造、アルゴリズムの 3 部にわたり、この分野の大部分のテーマを扱います。
- 初めて学ぶときは、まず入門書を 1 冊読むことが大切です。多くの回り道を避けられます。
- アニメーション図解は主に、重要な点や難しい点を説明するために使っています。読むときは特に注目してください。
- プログラミングを学ぶ最良の方法は実践です。ソースコードを実行し、自分でも入力することを強くお勧めします。
- ウェブ版の各節にはコメント欄があります。疑問や考えをいつでもお寄せください。
