# 0.3 &nbsp; まとめ

### 1. &nbsp; 要点の振り返り

- 本書は主にアルゴリズムの初学者を対象としています。すでに基礎知識がある読者にとっては、アルゴリズムを体系的に復習する助けとなり、掲載したソースコードは問題演習のための「ツール集」としても利用できます。
- 本書は主に計算量解析、データ構造、アルゴリズムの三部からなり、この分野の大部分のテーマを扱っています。
- アルゴリズムを初めて学ぶ段階では、入門書を一冊読むことが非常に重要であり、多くの遠回りを避けられます。
- 本書のアニメーション図解では、重要な内容や難しい内容を説明することが多いです。読む際は、これらに特に注意を向けてください。
- 実践はプログラミングを学ぶ最良の方法です。ソースコードを実行し、自分の手でコードを書くことを強く勧めます。
- 本書の Web 版では各節にコメント欄を設けています。疑問や考えをいつでも共有してください。
