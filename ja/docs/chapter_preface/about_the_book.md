# 本書について

このプロジェクトは、オープンソースで無料の、初めての方にも親しみやすいデータ構造とアルゴリズムの入門書を作ることを目指しています。

- 全編にアニメーション図解を取り入れ、わかりやすい内容を無理なく学べる順に並べました。データ構造とアルゴリズムの知識の地図を、初めての方もたどっていけます。
- ソースコードはワンクリックで実行できます。実際に試しながらプログラミングの腕を磨き、アルゴリズムの動作原理やデータ構造の内部実装を学べます。
- 読者同士で助け合って学ぶことを大切にしています。コメント欄で質問や考えを共有し、話し合いながら一緒に学びましょう。

## 対象読者

アルゴリズムに初めて触れる方にも、少し問題を解いた経験はあるものの、データ構造やアルゴリズムがわかったりわからなくなったりする方にも、本書はぴったりです。

ある程度の数の問題を解き、よく出る問題形式に慣れた方には、知識を振り返って整理するのに役立ちます。リポジトリのソースコードは「演習用の道具箱」や「アルゴリズム辞典」としても使えます。

すでにアルゴリズムの達人という方には、ご意見をお寄せいただいたり、[執筆に参加](../chapter_appendix/contribution.md)していただいたりできれば幸いです。

!!! success "前提知識"

    少なくとも一つの言語のプログラミングの基礎を知り、簡単なコードを読み書きできることが必要です。

## 本書の構成

本書の主な内容を次の図に示します。

- **計算量解析**：データ構造とアルゴリズムを評価する観点と方法、時間計算量と空間計算量の求め方、代表的な種類と例などを扱います。
- **データ構造**：基本データ型とデータ構造の分類方法を学びます。配列、連結リスト、スタック、キュー、ハッシュテーブル、木、ヒープ、グラフなどの定義、長所と短所、主な操作、代表的な種類、用途、実装方法を扱います。
- **アルゴリズム**：探索、ソート、分割統治、バックトラッキング、動的計画法、貪欲法などの定義、長所と短所、効率、用途、解法の手順と例題を扱います。
