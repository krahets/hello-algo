# 本書について

本プロジェクトは、オープンソースで無料、かつ初学者に親しみやすいデータ構造とアルゴリズムの入門書を作ることを目指しています。

- 全編にアニメーション図解を用い、明快な内容と緩やかな学習曲線で、初学者をデータ構造とアルゴリズムの知識の地図へと案内します。
- ソースコードはワンクリックで実行でき、実践を通してプログラミング技能を高め、アルゴリズムの仕組みやデータ構造の内部実装を理解できます。
- 読者同士が助け合って学ぶことを勧めています。コメント欄で質問や考えを共有し、対話を通して一緒に成長しましょう。

## 対象読者

アルゴリズムを初めて学ぶ人、まだ触れたことがない人、あるいは問題演習を少し経験していても、データ構造とアルゴリズムの理解が曖昧で、分かったり分からなくなったりする人に、本書はぴったりです。

すでに多くの問題を解き、大部分の問題形式になじみがある人には、知識を復習し、体系を整理する助けになります。リポジトリのソースコードは、「問題演習のツール集」や「アルゴリズム辞典」として使えます。

アルゴリズムの達人の皆さんからは、貴重なご意見をお待ちしています。[執筆への参加](../chapter_appendix/contribution.md)も歓迎します。

!!! success "前提知識"

    少なくとも一つの言語のプログラミングの基礎があり、簡単なコードを読み書きできることが必要です。

## 内容の構成

本書の主な内容を下図に示します。

- **計算量解析**：データ構造とアルゴリズムの評価の観点と方法を扱います。時間計算量と空間計算量の求め方、主な種類、例などを紹介します。
- **データ構造**：基本データ型とデータ構造の分類方法を扱います。配列、連結リスト、スタック、キュー、ハッシュテーブル、木、ヒープ、グラフなどの定義、長所と短所、主な操作、種類、代表的な用途、実装方法などを紹介します。
- **アルゴリズム**：探索、ソート、分割統治、バックトラッキング、動的計画法、貪欲法などの定義、長所と短所、効率、用途、問題を解く手順、例題などを扱います。
