# 第 15 章 &nbsp; 貪欲法

![貪欲法](../assets/covers/chapter_greedy.svg){ class="cover-image" }

!!! abstract "概要"

    ヒマワリは太陽のほうを向き、そのつど最もよく育てる向きを追い求めます。

    貪欲戦略は、単純な選択を何度も重ねながら、一歩ずつ最良の答えに近づいていきます。
