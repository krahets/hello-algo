# 練習問題

## 理解を確かめる問題

### 同じグラフを表す 2 つの方法

ある無向グラフの頂点は `A、B、C、D` の 4 つで、辺は
`A-B、A-C、B-C、C-D` です。

<!-- numbered-subquestions -->

1. このグラフの隣接リストを書いてください。
2. 0 と 1 だけを使って隣接行列を埋めてください。
3. `A` と `D` が辺で直接つながっているかどうかを、1 か所の値を調べるだけで判定できるのは、どちらの表現方法ですか。
4. グラフの頂点が多く、辺が少ないとき、通常はどちらの表現方法のほうが少ない記憶領域で済みますか。

??? success "解答例"

    1. 隣接リストは次のようになります。

        ```text
        A: B, C
        B: A, C
        C: A, B, D
        D: C
        ```

    2. 隣接行列は次のようになります。

        | | A | B | C | D |
        | --- | --- | --- | --- | --- |
        | A | 0 | 1 | 1 | 0 |
        | B | 1 | 0 | 1 | 0 |
        | C | 1 | 1 | 0 | 1 |
        | D | 0 | 0 | 1 | 0 |

    3. 隣接行列では、`A` 行 `D` 列の値を直接調べることができます。このように、任意の 2 頂点が辺で直接つながっているかどうかを判定するのに適しています。

    4. 頂点が多く、辺が少ない場合、隣接リストは実際に存在する辺だけを記録するため、すべての頂点の組に対して領域を確保する隣接行列よりも、通常は少ない記憶領域で済みます。

### 幅優先探索と深さ優先探索で頂点を訪れる順序

ある無向グラフの頂点は `A、B、C、D、E` で、辺は
`A-B、A-C、B-D、C-D、D-E` です。

A を出発点とし、未訪問の隣接頂点が複数あるときはアルファベット順に選びます。

<!-- numbered-subquestions -->

1. 幅優先探索（BFS）で頂点を訪れる順序を書いてください。
2. 再帰を使った深さ優先探索（DFS）で頂点を訪れる順序を書いてください。
3. どちらの探索でも、すでに訪れた頂点を記録しておく必要があるのはなぜですか。

??? success "解答例"

    1. BFS で頂点を訪れる順序は `A, B, C, D, E` です。まず、A から辺を 1 本たどるだけで到達できる B と C を訪れ、
        その後で、さらに遠い D と E を訪れます。

    2. DFS で頂点を訪れる順序は `A, B, D, C, E` です。その時点でいる頂点から未訪問の隣接頂点を 1 つずつ選んで進むので、
        最初に `A → B → D → C` とたどります。C には未訪問の隣接頂点が残っていないため、D に戻ってから E を訪れます。

    3. このグラフには、たとえば `A-B-D-C-A` という閉路があります。訪れた頂点を記録しておかないと、
        閉路を何度もたどって同じ頂点を繰り返し訪れ、探索が終わらなくなることがあります。

### 1 回の BFS でグラフ全体を訪れることはできるか

ある無向グラフの頂点は `A、B、C、D、E、F` で、辺は
`A-B、B-C、D-E` だけです。

<!-- numbered-subquestions -->

1. A を出発点として BFS を 1 回行うと、どの頂点を訪れることができますか。
2. 問 1 の結果から、この 1 回の BFS でグラフのすべての頂点を訪れたといえますか。理由も説明してください。
3. すべての頂点をアルファベット順に調べ、未訪問の頂点が見つかるたびに、そこから新たに BFS を始めるとします。
    各 BFS の出発点はどの頂点ですか。このグラフは、互いにつながっていないいくつの部分（連結成分）に分かれますか。

??? success "解答例"

    1. A から訪れることができる頂点は `A、B、C` だけです。

    2. すべての頂点を訪れたわけではありません。`D、E` の 2 頂点は互いにつながって別の連結成分をなし、F は孤立した頂点です。
        A からこれらのどの頂点にも道がないため、A を出発点とする探索では到達できません。

    3. 3 回の BFS の出発点は順に `A、D、F` で、それぞれが訪れる頂点の集合は
        `{A, B, C}`、`{D, E}`、`{F}` です。したがって、このグラフの連結成分は 3 つです。

## プログラミング問題

### 無向グラフで経路の有無を判定する

頂点が $n$ 個あり、$0$ から $n-1$ までの番号が付いた無向グラフが与えられます。配列 `edges` の各要素 `[u, v]` は、頂点 `u` と `v` を結ぶ無向辺を表します。

さらに始点 `source` と終点 `destination` が与えられます。まず `edges` から隣接リストを作り、次に BFS または DFS を使って、
`source` から `destination` への経路が存在するか判定してください。存在すれば `true` を、存在しなければ `false` を返します。
グラフに閉路がある場合や、グラフが連結でない場合もあります。

??? tip "解き方のヒント"

    1. 各無向辺を両方向に登録します。
    2. 閉路がある可能性があるため、訪問済みのノードを記録する必要があります。
    3. source から出発し、destination に到達したら true を返します。探索が終わっても到達しなければ false を返します。
