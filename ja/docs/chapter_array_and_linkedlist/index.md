# 第 4 章 &nbsp; 配列と連結リスト

![配列と連結リスト](../assets/covers/chapter_array_and_linkedlist.jpg){ class="cover-image" }

!!! abstract "概要"

    データ構造の世界は、分厚いレンガの壁のようです。

    配列のレンガは整然と並び、互いにぴったり接しています。連結リストのレンガはあちこちに散らばり、それらを結ぶつるがレンガの隙間を自由に行き交います。
