# 第 4 章 &nbsp; 配列と連結リスト

![配列と連結リスト](../assets/covers/chapter_array_and_linkedlist.svg){ class="cover-image" }

!!! abstract "概要"

    データ構造の世界は、厚いれんがの壁のようです。

    配列のれんがは整然と並び、隣どうしがぴったり寄り添います。連結リストのれんがはあちこちに散らばり、それらをつなぐつるがれんがの隙間を縫って伸びています。
