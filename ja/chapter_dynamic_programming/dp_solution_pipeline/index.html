14.3   動的計画法の解き方¶

前の 2 節では、動的計画法の問題の主な特徴を説明しました。ここからは、より実践的な二つの疑問を考えていきます。

  1. ある問題が動的計画法に適しているかどうかは、どのように判断するのでしょうか。
  2. 動的計画法の問題は何から手を付け、どのような手順で解けばよいのでしょうか。

14.3.1   問題の見極め¶

一般に、部分問題の重複と最適部分構造があり、後続の判断が過去の経路に依存しない問題は、動的計画法に適しています。ただし、問題文からこれらの性質を直接見抜くのは難しいため、通常は条件を緩め、まずバックトラッキング（総当たり）で解けそうかを考えます。

バックトラッキングに適した問題は、通常「決定木モデル」で表せます。木構造で記述でき、各ノードが判断を、各経路が一連の判断を表す問題です。

言い換えると、明確な選択があり、その選択を順に行って解が得られるなら、決定木モデルに当てはまり、通常はバックトラッキングで解けます。

これに加え、動的計画法の問題らしいと判断する「プラス材料」があります。

  • 最大・最小、最多・最少などの最適化を求めています。
  • 状態をリスト、多次元行列、木などで表せ、ある状態とその周囲の状態の間に漸化式があります。

反対に、次のような「マイナス材料」もあります。

  • 最適解ではなく、可能な解をすべて求めることが目標です。
  • 順列や組合せの特徴が明らかで、具体的な複数の方法を返す必要があります。

決定木モデルに当てはまり、「プラス材料」もはっきりしているなら、動的計画法の問題と仮定して取り組み、解く過程で確かめていけます。

14.3.2   問題を解く手順¶

動的計画法の手順は問題の性質や難しさによって異なりますが、通常は、選択の記述、状態の定義、\(dp\) テーブルの作成、状態遷移式の導出、境界条件の決定などの順で進めます。

手順を具体的に示すため、典型的な「経路和の最小化」問題を使います。

問題

\(n \times m\) の二次元グリッド grid が与えられます。各マスには、そのマスのコストを表す非負の整数があります。ロボットは左上のマスから出発し、毎回、下または右に 1 マスだけ進んで、右下のマスを目指します。左上から右下までの経路和の最小値を返してください。

図 14-10 のグリッドでは、経路和の最小値は \(13\) です。

第 1 段階：各回の選択を考えて状態を定義し、\(dp\) テーブルを作る

各回の選択は、現在のマスから下または右に 1 マス進むことです。現在の行と列のインデックスを \([i, j]\) とすると、移動後は \([i+1, j]\) または \([i, j+1]\) になります。したがって、状態は行と列の二つの変数を含む \([i, j]\) とします。

状態 \([i, j]\) に対応する部分問題は、開始点 \([0, 0]\) から \([i, j]\) までの経路和の最小値を求めることで、その解を \(dp[i, j]\) とします。

注記

動的計画法やバックトラッキングの過程は、一連の判断として表せます。状態はすべての判断変数で構成し、問題を解く過程の進み具合を表す変数をすべて含めます。次の状態を導くのに十分な情報を持たせる必要があります。

各状態は一つの部分問題に対応し、\(dp\) テーブルにすべての部分問題の解を保存します。状態の各独立変数が、\(dp\) テーブルの一つの次元になります。本質的には、\(dp\) テーブルは状態から部分問題の解への対応表です。

第 2 段階：最適部分構造を見つけ、状態遷移式を導く

状態 \([i, j]\) には、上のマス \([i-1, j]\) または左のマス \([i, j-1]\) からしか到達できません。したがって、最適部分構造は、\([i, j]\) までの経路和の最小値が、\([i, j-1]\) までの最小値と \([i-1, j]\) までの最小値のうち、小さい方で決まることです。

この分析から、図 14-12 の状態遷移式を導けます。

\[ dp[i, j] = \min(dp[i-1, j], dp[i, j-1]) + grid[i, j] \]

図解 14-12：経路和の最小化における状態遷移

定義した \(dp\) テーブルをもとに、元の問題と部分問題の関係を考えます。部分問題の最適解から元の問題の最適解を組み立てる方法、すなわち最適部分構造を見つけます。

最適部分構造が見つかれば、それを使って状態遷移式を組み立てられます。

第 3 段階：境界条件と状態遷移の順序を決める

この問題では、先頭行の状態には左からしか到達できず、先頭列の状態には上からしか到達できません。そのため、先頭行 \(i = 0\) と先頭列 \(j = 0\) が境界条件になります。

図 14-13 のように、各マスは左と上のマスから遷移するため、ループで行列を走査します。外側のループで行を、内側のループで列を走査します。

図 14-13   境界条件と状態遷移の順序

図解 14-13：経路和の最小化における境界条件とテーブルを埋める順序

まず始点を定め、先頭行を右へ、先頭列を下へ累積して境界を初期化してから、上から下・左から右の順方向に内部のマスを走査します。

非負の数のグリッドで [0, 0] から右または下にしか進めないとき、dp[i, j] は、始点から i 行 j 列のマスまでの経路和の最小値です。始点と到着したマスの値も含めます（行・列のインデックスは 0～3）。この図では左右 2 つの 4×4 の記号 dp テーブルを使って「境界条件：最初の行と列を初期化」と「状態遷移の順序：行列を順方向に走査」をそれぞれ説明しており、具体的なグリッドの数値は示していません。

左の図では左上の始点が緑、先頭行の残りのマスが青、先頭列の残りのマスが紫で示され、矢印は先頭行に沿って右へ、先頭列に沿って下へ向かっています。右の図の矢印は、内部のマスがすでに計算された上と左の状態に依存することを表しています。どちらの表にも dp[0,0]～dp[3,3] の記号だけが書かれています。

まず始点を初期化し、唯一の到達方向に沿って先頭行と先頭列を累積します。内部の 9 マスは、外側のループで行インデックス i = 1、2、3、内側のループで列インデックス j = 1、2、3 の順方向に埋めます。こうすると dp[i,j] を求めるときに、上の dp[i-1,j] は前の行で、左の dp[i,j-1] は同じ行の左側ですでに求まっています。下の表の計算式は図の境界と依存関係から整理したもので、図中に個別の式がすべて書かれているわけではありません。

先頭列[i,0]、i=1、2、3[i-1,0]dp[i,0]=dp[i-1,0]+grid[i,0]

先頭行と先頭列には遷移元が 1 つしかなく、上と左の 2 つの遷移元のうち小さい方を選ぶのは内部のマスだけです。

注記

境界条件は、動的計画法では \(dp\) テーブルの初期化に、探索では枝刈りに使います。

状態遷移の順序で重要なのは、現在の問題の解を計算する時点で、依存するすべての小さな部分問題の解が正しく計算済みであることです。

ここまでの分析から、動的計画法のコードを直接書けます。ただし、部分問題への分解は上から下への考え方なので、「全探索 \(\rightarrow\) メモ化探索 \(\rightarrow\) 動的計画法」の順に実装する方が、自然な思考の流れに沿っています。

1.   方法 1：全探索¶

状態 \([i, j]\) から探索を始め、より小さな状態 \([i-1, j]\) と \([i, j-1]\) へ分解していきます。再帰関数には、次の要素があります。

  • 再帰の引数：状態 \([i, j]\) です。
  • 戻り値：\([0, 0]\) から \([i, j]\) までの経路和の最小値 \(dp[i, j]\) です。
  • 終了条件：\(i = 0\) かつ \(j = 0\) なら、コスト \(grid[0, 0]\) を返します。
  • 枝刈り：\(i < 0\) または \(j < 0\) なら範囲外なので、到達不可能を表すコスト \(+\infty\) を返します。

実装は次のとおりです。

図 14-14 は、\(dp[2, 1]\) を根とする再帰木です。部分問題の重複が含まれており、グリッド grid が大きくなると、その数は急激に増えます。

部分問題が重複する本質的な理由は、左上からあるマスに到達する経路が複数あることです。

図 14-14   全探索の再帰木

図解 14-14：経路和の最小化における重複した再帰呼び出し

dp[2,1] から前の状態を探すと、2 つの呼び出し経路がともに dp[1,0] に到達し、その部分木が 2 回展開されて 2 回目が重複計算になります。

非負の数が並ぶグリッドで [0, 0] から出発して右または下にしか進めないとき、dp[i, j] は i 行 j 列（インデックスは 0 始まり）に到達する経路和の最小値を表します。この図は dp[2, 1] を根とするトップダウンの全探索の再帰木を示しており、具体的なグリッドの値は与えていません。再帰では「一つ前の行」と「一つ前の列」の前の状態を逆向きにたどるため、実際に進む下向き・右向きとは向きが逆になります。

有効な内部状態では、2 つの前の状態の戻り値のうち小さい方に現在のマスのコストを加えます（dp[i, j] = min(dp[i-1, j], dp[i, j-1]) + grid[i, j]）。開始点は grid[0, 0] を返し、負のインデックスで範囲外に出たときは正の無限大を返します。

再帰木の左の枝は一つ前の行を調べ（経路を「上」と表記）、右の枝は一つ前の列を調べます（経路を「左」と表記）。これらの「上」「左」はグリッド上で前の状態を探す向きであり、図の木における左右の配置ではありません。

根 dp[2,1] から dp[1,1] を経て dp[1,0] に至る経路は「上→左」、dp[2,0] を経て dp[1,0] に至る経路は「左→上」です。これは右下の注記「dp[i+1, j] と dp[i, j+1] はどちらも dp[i, j] に依存する」に対応しており、この例では dp[2,0] と dp[1,1] がどちらも dp[1,0] に依存しています。

全探索では解いた状態を保存しないため、2 回現れる dp[1,0] がそれぞれ子ノード dp[0,0] と dp[1,-1] を展開します。負のインデックスのノードには「枝刈り：インデックスが範囲外」と記され、コードどおり正の無限大を返すことで、最小値の比較から無効な遷移元を除外します。

下部の 4×4 の記号 dp テーブル（行・列のインデックスはともに 0～3）では、今回の探索に関わる 6 個の有効な状態 [0,0]、[0,1]、[1,0]、[1,1]、[2,0]、[2,1] が背景色で強調されています。残りの 10 マスにも dp の記号が書かれていますが、今回の探索には関わりません。下の表では、ノードに入ってから上、次に左を調べる呼び出し順に再帰木全体を並べ、重複する状態は呼び出し経路で区別しています。

2.   方法 2：メモ化探索¶

グリッド grid と同じ大きさの記録用リスト mem を導入し、各部分問題の解を保存して、重複する部分問題を枝刈りします。

図 14-15   メモ化探索の再帰木

図解 14-15：経路和の最小化におけるメモ化再帰

2 回目に dp[1,0] が呼ばれたときは記録済みの有効な経路和をそのまま読み出し、子ノードを展開しません。範囲外で正の無限大を返す処理とは区別されます。

非負の数が並ぶグリッドで [0, 0] から出発して右または下にしか進めないとき、dp[i, j] は i 行 j 列（インデックスは 0 始まり）に到達する経路和の最小値を表します。この図も dp[2, 1] を探索の根とし、メモ化用の記録リスト mem を導入して重複する部分問題を枝刈りする効果を示しており、具体的なグリッドの値は省いています。再帰では一つ前の行と一つ前の列の前の状態を逆向きにたどるため、実際に進む下向き・右向きとは向きが逆になります。

有効な内部状態では、2 つの前の状態の戻り値のうち小さい方に現在のマスのコストを加えます（dp[i, j] = min(dp[i-1, j], dp[i, j-1]) + grid[i, j]）。開始点は grid[0, 0] を返し、負のインデックスで範囲外に出たときは正の無限大を返します。

再帰木の左の枝は一つ前の行を調べ（経路を「上」と表記）、右の枝は一つ前の列を調べます（経路を「左」と表記）。これらの「上」「左」はグリッド上で前の状態を探す向きであり、図の木における左右の配置ではありません。

根 dp[2,1] から dp[1,1] を経て dp[1,0] に至る経路は「上→左」、dp[2,0] を経て dp[1,0] に至る経路は「左→上」であり、2 つの経路が同じ部分問題を求めます。

先に dp[1,1] の枝を解きます。初めて dp[1,0] に達したときは、2 つの前の状態の呼び出しが返るのを待ってこのマスの最小経路和を求め、mem[1][0] に書き込んでから dp[1,1] へ返ります。続いて dp[2,0] の枝を解き、再び dp[1,0] が呼ばれたときには「枝刈り：記録済み」に該当して記録された値をそのまま返すため、dp[0,0] と dp[1,-1] は呼び出されません。一方、dp[2,0] のもう 1 つの子ノード dp[2,-1]（経路「左→左」）はインデックスが範囲外のため正の無限大を返します。記録から読み出した値は有効な経路和であり、最小値の比較に使われます。

今回の探索は行 0～2、列 0～1 の 6 個の有効な状態 [0,0]、[0,1]、[1,0]、[1,1]、[2,0]、[2,1] を扱います。dp[0,1] と初回の dp[1,0] がそれぞれ開始点 dp[0,0] を 1 回ずつ呼び出し、経路「上→上→左」と「上→左→上」に対応します。開始点はそのまま grid[0,0] を返して mem の読み書きを行わないため、開始点の葉ノードは 2 個残ります。下の表ではノードに入ってから上、次に左を調べる呼び出し順に全呼び出しを並べています。この図にはグリッドや dp テーブルは別途描かれていません。

状態テーブル dp[i,j] は、始点 [0,0] から i 行 j 列のマスに到達する経路和の最小値を表します。テーブル作成時に入っている 0 はまだ計算していないことを表す初期のプレースホルダーであり、コスト 0 の経路が存在するという意味ではありません。

境界の初期化：始点は dp[0,0] = grid[0,0] = 1 とします。第 0 行へは左から右へ進むしかなく、第 0 列へは上から下へ進むしかないため、まず先頭行と先頭列に沿って累積し、計 7 マスの有効な境界値を得ます。

内部の漸化計算：第 1～3 行・第 1～3 列にある 9 個の内部マスについて、行ごとに左から右へ順に状態遷移式 dp[i,j] = min(dp[i-1,j], dp[i,j-1]) + grid[i,j] を計算します。これにより、どのマスを求めるときも上の dp[i-1,j] と左の dp[i,j-1] がすでに計算済みになります。各フレームの状態表には、マスの値とともに「未計算の初期値」「有効な境界値」「計算済み」のいずれかを併記しており、座標から直接確認できます。

4.   空間の最適化¶

各マスが依存するのは左と上のマスだけなので、1 行分の配列だけで \(dp\) テーブルを実装できます。

配列 dp は 1 行分の状態しか表せないため、先頭列をあらかじめ初期化することはできません。各行を走査するときに、その先頭の状態を更新することに注意してください。
