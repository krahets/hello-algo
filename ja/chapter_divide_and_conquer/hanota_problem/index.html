12.4   ハノイの塔¶

マージソートと二分木の構築では、元の問題を半分の規模の二つの部分問題に分けてきました。ハノイの塔では、これとは異なる分け方を使います。

問題

A、B、C の 3 本の棒があります。最初、棒 A には \(n\) 枚の円盤が、上から小さい順に重なっています。図 12-10 のように、\(n\) 枚すべてを元の順序のまま棒 C に移すのが課題です。円盤を移すときは、次の規則に従います。

  1. 円盤は棒の一番上から取り、別の棒の一番上に置きます。
  2. 一度に移せる円盤は 1 枚だけです。
  3. 円盤を重ねるときは、常に小さい円盤を大きい円盤の上に置きます。

図 12-10   ハノイの塔の例

図解 12-10：ハノイの塔の例：6 枚の円盤を A から C に移す

初めは棒 A に上から小さい順に 6 枚の円盤が重なっています。棒 B を使い、元の順序を保ってすべて棒 C に移します。

ハノイの塔では、一度に移せるのは 1 枚だけです。棒の一番上から取り、別の棒の一番上に置きます。移動の間も、小さい円盤は常に大きい円盤より上に重ねます。

上半分は初期状態です。棒は左から A、B、C で、A には異なる色の 6 枚の円盤が上から小さい順に重なり、B と C は空です。

下半分は目標の状態です。A と B は空で、6 枚すべてが右端の C に移り、最小の円盤が一番上、最大の円盤が一番下という元の順序を保っています。中央の下向き矢印「すべての円盤を A から C へ移す」は問題全体の課題を表し、まとめて一度に運べるという意味ではありません。

図が示すのは初期状態と目標の状態だけで、途中の手順は省略しています。規則に従って 1 枚ずつ移し、目標に到達します。

規模 \(i\) のハノイの塔の問題を \(f(i)\) と表します。たとえば \(f(3)\) は、\(3\) 枚の円盤を A から C に移す問題です。

1.   基本の場合を考える¶

図 12-11 の問題 \(f(1)\)、つまり円盤が 1 枚だけの場合は、そのまま A から C に移せば完了です。

図 12-11   規模 1 の問題の解

図解 12-11：円盤 1 枚のハノイの塔（f(1)）

棒 A の 1 枚を移動先の棒 C に直接移します。1 枚を 1 回移すだけで完了です。

棒は左から A、B、C です。一度に移せるのは棒の一番上の 1 枚だけで、小さい円盤の上に大きい円盤は置けません。f(1) は 1 枚を移す問題で、再帰的な分割の基本ケースです。

緑の角丸の長方形が唯一の円盤です。二つの画面は移動の前後を示し、実際の移動は 1 枚を移す 1 回だけです。

  1. 唯一の円盤が棒 A にある

    初めは A=[緑の円盤]、B=[]、C=[] で、まだ移していません。円盤の上に障害物はなく、移動先 C は空なので、作業用の B を使わず A から C に直接移せます。

  2. 円盤を棒 A から棒 C に直接移す

    A の一番上にある唯一の緑の円盤は取り出せて、移動先 C は空です。B を使わず A から C に直接移します。現在は A=[]、B=[]、C=[緑の円盤] です。1 枚を 1 回移して課題が完了しました。

図 12-12 の問題 \(f(2)\) では、円盤が 2 枚あります。大きい円盤の上に小さい円盤が載る順序を常に守るため、B を一時置き場に使います。

  1. まず、上の小さい円盤を A から B に移します。
  2. 次に、大きい円盤を A から C に移します。
  3. 最後に、小さい円盤を B から C に移します。

図 12-12   規模 2 の問題の解

図解 12-12：作業用の棒 B を使って 2 枚の円盤を移す

まず小さい円盤を B に仮置きし、大きい円盤を C に移してから、その上に小さい円盤を重ねます。移動は計 3 回です。

棒は左から A、B、C で、A の 2 枚を C へ移します。一度に移せるのは棒の一番上の 1 枚だけで、小さい円盤の上に大きい円盤は置けません。以下では各棒の円盤を下から上の順に表します。

緑は大きい円盤、青は小さい円盤です。

四つの画面は、初期状態と、3 回の移動を 1 枚ずつ行った後の各状態です。プレーヤーは初期画面も数えるので、手順 2、3、4 がそれぞれ 1、2、3 回目の移動後に当たります。後の三つの画面の下には実行済みの移動指示が並び、現在の指示が薄い灰色の背景で強調されます。

  1. 棒 A に 2 枚の円盤が重なっている

    初めは A=[大, 小]、B=[]、C=[] で、まだ移していません。青い小さい円盤が緑の大きい円盤の上にあるため、大きい円盤を取り出すには先に小さい円盤を作業用の B に移します。

  2. まず小さい円盤を棒 A から棒 B に移す

    1 回目の移動で青い小さい円盤を A から空の B に移し、緑の大きい円盤が棒の一番上に出ます。現在は A=[大]、B=[小]、C=[] です。

  3. 次に大きい円盤を棒 A から棒 C に移す

    2 回目の移動です。A の緑の大きい円盤の上には何もなく、C は空なので、大きい円盤を A から C に移します。現在は A=[]、B=[小]、C=[大] で、小さい円盤は B に残っています。

  4. 最後に小さい円盤を棒 B から棒 C に移す

    3 回目の移動で B の青い小さい円盤を C の緑の大きい円盤の上に置きます。小さい円盤を上に置く規則を満たしています。現在は A=[]、B=[]、C=[大, 小] で、2 枚の移動が完了しました。

問題 \(f(2)\) の手順は、B を一時置き場として、2 枚の円盤を A から C に移すとまとめられます。ここで C を移動先の棒、B を作業用の棒と呼びます。

2.   部分問題への分割¶

問題 \(f(3)\)、つまり円盤が 3 枚の場合は、少し複雑になります。

\(f(1)\) と \(f(2)\) の解はすでに分かっています。そこで分割統治の考え方を使い、A の上の 2 枚をひとまとまりと見て、図 12-13 の手順を実行します。こうして 3 枚とも A から C に移せます。

  1. B を移動先、C を作業用の棒として、2 枚の円盤を A から B に移します。
  2. A に残った 1 枚を、A から C に直接移します。
  3. C を移動先、A を作業用の棒として、2 枚の円盤を B から C に移します。

図 12-13   規模 3 の問題の解

図解 12-13：円盤 3 枚のハノイの塔を分割統治法で解く

上の 2 枚を B に移し、次に最大の円盤を C に移し、最後に B の 2 枚を C に移します。三つの段階で 1 枚ずつ計 7 回移します。

棒は左から A、B、C で、A の 3 枚を C へ移します。一度に移せるのは棒の一番上の 1 枚だけで、小さい円盤の上に大きい円盤は置けません。以下では各棒の円盤を下から上の順に表します。

緑が大、青が中、オレンジが小の円盤です。青緑の実線が中と小の円盤を囲み、規模 2 の部分問題 f(2) を表します。2 枚を同時に運べるという意味ではありません。

四つの画面は開始時と三つの段階の終了時を示します。二つの f(2) の段階ではそれぞれ 1 枚ずつ規則に従って 3 回移し、間に大きい円盤を 1 回移すので計 7 回です。プレーヤーの手順番号は画面に対応し、移動回数の累計とは異なります。

  1. 上の 2 枚を部分問題として扱う

    初めは A=[大, 中, 小]、B=[]、C=[] で、まだ移していません。一番下の大きい円盤を取り出すため、まず A の上部の青緑の枠内にある中と小の円盤を B に移します。この部分問題 f(2) では B が移動先、C が作業用の棒です。

  2. 2 枚の部分問題が完了：A から B へ

    最初の f(2) では A を出発点、C を作業用、B を移動先とし、小を A→C、中を A→B、小を C→B と移しました。1 枚ずつ計 3 回の移動です。現在は A=[大]、B=[中, 小]、C=[] で、青緑の枠も中と小の円盤とともに B に移りました。画面はこの段階の終了時を直接示し、途中の 3 回の移動は展開していません。

  3. 最大の円盤を A から C に移す

    小さいほうの 2 枚は B に仮置きされ、A の大きい円盤の上に何もなく、C は空です。大きい円盤を A から C に移します。現在は A=[]、B=[中, 小]、C=[大] で、1 枚ずつ計 4 回移しました。青緑の枠は B の中と小の円盤を囲んだままです。

  4. 2 枚の部分問題が完了：B から C へ

    二つ目の f(2) では B を出発点、A を作業用、C を移動先とし、小を B→A、中を B→C、小を A→C と移します。現在は A=[]、B=[]、C=[大, 中, 小] です。1 枚ずつ計 7 回で移動が完了し、青緑の枠は C の中と小の円盤を囲んでいます。

ここでは、問題 \(f(3)\) を二つの部分問題 \(f(2)\) と一つの部分問題 \(f(1)\) に分けました。この三つを順に解けば元の問題も解けます。これは、部分問題が独立していて、それぞれの解をまとめられることを示しています。

以上から、ハノイの塔を解く分割統治法を図 12-14 のようにまとめられます。元の問題 \(f(n)\) を二つの部分問題 \(f(n-1)\) と一つの部分問題 \(f(1)\) に分け、次の順序で解きます。

  1. \(n-1\) 枚の円盤を、C を作業用の棒として A から B に移します。
  2. 残りの \(1\) 枚を A から C に直接移します。
  3. \(n-1\) 枚の円盤を、A を作業用の棒として B から C に移します。

二つの部分問題 \(f(n-1)\) は、同じ方法で再帰的に分割でき、やがて最小の部分問題 \(f(1)\) に達します。\(f(1)\) の解はすでに分かっており、1 回移すだけです。

図 12-14   ハノイの塔を解く分割統治法

図解 12-14：ハノイの塔を三つの段階に分ける

n 枚を A から C へ移す問題を、n−1 枚を A→B、最大の円盤を A→C、n−1 枚を B→C と移す三つの部分問題に分け、順に実行します。

元の問題 f(n) は、小さい円盤が上になるよう重ねた n 枚を、出発の棒 A から移動先の棒 C に移すことです。図は 5 枚の例です。一度に移せるのは棒の一番上の 1 枚だけで、小さい円盤の上に大きい円盤を置くことはできません。

最上位の問題では A が出発の棒、B が作業用の棒、C が移動先の棒です。部分問題に再帰的に入ると、3 本の棒の出発、作業用、移動先という役割が入れ替わります。

左側は 5 枚を A から C に移す全体の課題です。右側には三つの段階が上から順に並びます。まず上の小さい n−1 枚を C を使って A から B に移します。次に最大の円盤を A から C に移します。これが 1 枚の部分問題 f(1) です。最後に A を使って、B の小さい n−1 枚を C の最大の円盤の上に移します。

最初と最後の部分問題は、さらに再帰的に、規則に従った 1 枚ずつの移動に分けます。小さい円盤をひとまとめには運べません。破線は移動前、塗りつぶしはその段階を終えた位置を表し、円盤は終始同じ 5 枚です。

下の表に、各段階の移動内容、作業用の棒、終了時の 3 本の棒の状態を示します。

円盤 5 枚の例の三つの段階
段階移動内容作業用の棒終了時の A終了時の B終了時の C
小さい円盤をよける小さい 4 枚を A→BC最大の円盤小さい 4 枚空
最大の円盤を移す最大の円盤を A→C不要空小さい 4 枚最大の円盤
小さい円盤を重ね直す小さい 4 枚を B→CA空空5 枚を上から小さい順に重ねた状態

この三つの作業には実行順の依存関係があり、移動回数について T(n) = 2T(n−1) + 1 が導けます（漸化式は図にはありません）。最初と最後の部分問題は規模が同じですが、出発、作業用、移動先の棒の役割が異なります。

3.   実装¶

コードでは再帰関数 dfs(i, src, buf, tar) を定義します。棒 src の上から \(i\) 枚の円盤を、作業用の棒 buf を使って移動先の棒 tar に移す関数です。

hanota.py
def move(src: list[int], tar: list[int]):
    """円盤を 1 枚移す"""
    # src の一番上から円盤を 1 枚取り出す
    pan = src.pop()
    # 円盤を tar の一番上に置く
    tar.append(pan)

def dfs(i: int, src: list[int], buf: list[int], tar: list[int]):
    """ハノイの塔の問題 f(i) を解く"""
    # src の円盤が残り 1 枚なら、そのまま tar に移す
    if i == 1:
        move(src, tar)
        return
    # 部分問題 f(i-1)：src の上から i-1 枚を tar を使って buf に移す
    dfs(i - 1, src, tar, buf)
    # 部分問題 f(1)：src に残った 1 枚を tar に移す
    move(src, tar)
    # 部分問題 f(i-1)：buf の上から i-1 枚を src を使って tar に移す
    dfs(i - 1, buf, src, tar)

def solve_hanota(A: list[int], B: list[int], C: list[int]):
    """ハノイの塔を解く"""
    n = len(A)
    # A の上から n 枚の円盤を B を使って C に移す
    dfs(n, A, B, C)
hanota.cpp
/* 円盤を 1 枚移す */
void move(vector<int> &src, vector<int> &tar) {
    // src の一番上から円盤を 1 枚取り出す
    int pan = src.back();
    src.pop_back();
    // 円盤を tar の一番上に置く
    tar.push_back(pan);

図 12-15 のように、ハノイの塔の問題は高さ \(n\) の再帰木を作ります。各ノードは部分問題を表し、dfs() 関数の 1 回の呼び出しに対応します。したがって時間計算量は \(O(2^n)\)、空間計算量は \(O(n)\) です。

図 12-15   ハノイの塔の再帰木

図解 12-15：ハノイの塔の再帰木：二つの小さな課題と 1 枚の移動

規模が 1 より大きいハノイの塔の問題を、二つの小さな移動と、その間に行う 1 枚の移動に分けます。すべての作業が直接実行できるまで分割を続けます。

ノード f(k) は k 枚を移す部分問題の規模を表します。規模が 1 より大きければ、上の k−1 枚をよけ、一番下の最大の 1 枚を移し、最後に k−1 枚を移動先の棒に移します。図のノードには問題の規模だけを記し、部分問題ごとに異なる出発、作業用、移動先の棒は示していません。

再帰木の頂点は元の問題 f(n) で、その下に左から f(n−1)、f(1)、f(n−1) の三つの子があります。左右の緑の f(n−1) はそれぞれ f(n−2)、f(1)、f(n−2) に分かれます。中央の青緑の f(1) は 1 枚を 1 回移すだけの最小の部分問題なので、さらに分割しません。

緑の枠はさらに再帰的に分割する部分問題、青緑の枠は 1 枚を直接移す基本ケース f(1) です。中間の階層は「…」で省略し、最下層はすべて青緑の f(1) になります。任意の規模 n を表す模式図なので、描かれた青緑の枠を数えても、ある具体的な n の総移動回数にはなりません。

コードと照らし合わせると、各分割の中央の青緑の f(1) では move を直接実行し、dfs(1) を新たに呼ぶことはありません。dfs(1) として実行されるのは、左右の枝の再帰が底に達して f(2) の左右の部分問題となる f(1) です。したがってこの図は問題の分割を表す木で、すべての枠が 1 回ずつの dfs 呼び出しを表すわけではありません。

図の分割から次の式を導けます（式は図にはありません）。移動回数を T(n) とすると、n ≥ 1 について基本ケースは T(1) = 1、漸化式は T(n) = 2T(n−1) + 1 です。1 枚ずつ移す回数は 2 の n 乗から 1 を引いた値で、時間計算量は O(2^n) です。左右の枝は順に実行され、スタックから戻るたびに空間を再利用します。同時に有効な最長の呼び出し列は、左または右に下る f(n) → f(n−1) → … → f(1) の n 個の dfs スタックフレームなので、スタック空間は O(n) です。ここで数えているのはフレームの段数です。

引用

ハノイの塔には古い伝説があります。古代インドのある寺院には、ダイヤモンドでできた高い棒が 3 本と、大きさの異なる金の円盤が \(64\) 枚ありました。僧たちは円盤を移し続け、最後の 1 枚を正しく置いた瞬間に世界が終わると信じていました。

もっとも、僧たちが毎秒 1 枚移しても、全部で約 \(2^{64} \approx 1.84×10^{19}\) 秒、年にして約 \(5850\) 億年かかります。現在推定されている宇宙の年齢をはるかに超える長さです。伝説が本当でも、世界の終わりを心配せずに済みそうです。
