# 제 11 장 &nbsp; 정렬

![정렬](../assets/covers/chapter_sorting.jpg){ class="cover-image" }

!!! abstract "이 장을 시작하며"

    정렬은 혼란을 질서로 바꾸는 마법의 열쇠와 같아서, 데이터를 더 효율적으로 이해하고 처리하게 해 준다.

    단순한 오름차순이든 복잡한 분류와 배열이든, 정렬은 데이터가 지닌 조화로운 아름다움을 보여 준다.
