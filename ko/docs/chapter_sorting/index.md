# 제 11 장 &nbsp; 정렬

![정렬](../assets/covers/chapter_sorting.svg){ class="cover-image" }

!!! abstract

    정렬은 뒤섞인 데이터에 질서를 부여하는 마법의 열쇠와도 같다. 덕분에 우리는 데이터를 더 효율적으로 이해하고 처리할 수 있다.

    단순히 오름차순으로 늘어놓을 때도 복잡한 기준으로 분류해 배열할 때도 정렬은 데이터가 이루는 조화의 아름다움을 보여 준다.
