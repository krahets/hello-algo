# 10.6 &nbsp; 요약

### 1. &nbsp; 핵심 내용 돌아보기

- 이진 탐색은 데이터가 정렬되어 있다는 성질을 이용해 매번 탐색 구간을 절반으로 줄여 가며 원소를 찾는다. 입력 데이터가 정렬되어 있어야 하며, 배열이나 배열 기반 자료 구조에만 적합하다.
- 완전 탐색은 자료 구조를 순회해 데이터를 찾는다. 배열과 연결 리스트에는 선형 탐색을, 그래프와 트리에는 너비 우선 탐색과 깊이 우선 탐색을 적용할 수 있다. 이 알고리즘들은 범용성이 높고 데이터 전처리가 필요 없지만 시간 복잡도가 $O(n)$으로 높다.
- 해시 탐색, 트리 탐색, 이진 탐색은 특정 자료 구조에서 목표 원소를 빠르게 찾는 효율적인 방법이다. 시간 복잡도는 $O(\log n)$이거나 심지어 $O(1)$에 이르기도 하지만 대개 별도의 자료 구조가 필요하다.
- 실제로 탐색 방법을 선택할 때는 데이터 규모, 요구되는 탐색 성능, 데이터의 조회 및 갱신 빈도 등을 구체적으로 따져야 한다.
- 데이터가 적거나 자주 바뀌면 선형 탐색이 적합하고, 데이터가 많고 정렬되어 있으면 이진 탐색이 적합하다. 조회 효율이 중요하고 범위 조회가 필요 없으면 해시 탐색이, 데이터가 많고 자주 바뀌면서 정렬 순서 유지와 범위 조회가 필요하면 트리 탐색이 적합하다.
- 선형 탐색을 해시 탐색으로 바꾸는 것은 실행 시간을 줄이는 데 자주 쓰이는 전략이다. 시간 복잡도를 $O(n)$에서 $O(1)$로 줄일 수 있다.
