# 7.7 &nbsp; 연습 문제

## 7.7.1 &nbsp; 개념 다지기

### 1. &nbsp; 완전 이진 트리, 정 이진 트리, 포화 이진 트리

다음 두 배열은 이진 트리를 레벨 순서로 나타낸 것이다. `None`은 빈자리를 뜻한다.

- 트리 A: `[1, 2, 3, 4, 5, 6]`
- 트리 B: `[1, 2, 3, None, None, 6, 7]`

<!-- numbered-subquestions -->

1. 어느 트리가 완전 이진 트리인가?
2. 어느 트리가 정 이진 트리, 즉 리프가 아닌 모든 노드에 자식이 둘씩 있는 트리인가?
3. 두 트리 중 포화 이진 트리가 있는가? 각 트리에 대해 이유를 설명하라.

??? success "예시 답안"

    1. 트리 A는 완전 이진 트리다. 맨 아래 레벨만 덜 채워져 있고 그 노드들이 왼쪽부터 빈틈없이 늘어서 있다.
        트리 B는 맨 아래 레벨의 왼쪽에 빈자리가 있는데도 오른쪽에 노드가 있으므로 완전 이진 트리가 아니다.

    2. 트리 B는 정 이진 트리다. 노드 1과 노드 3에는 각각 자식이 둘이고 나머지는 모두 리프 노드다.
        트리 A에서 노드 3에는 왼쪽 자식 6만 있으므로 정 이진 트리가 아니다.

    3. 두 트리 모두 맨 아래 레벨이 완전히 채워지지 않았으므로 포화 이진 트리가 아니다.

### 2. &nbsp; 같은 트리를 순회하는 세 가지 순서

배열 `[1, 2, 3, 4, 5, 6, 7]`의 원소를 레벨 순서대로 완전 이진 트리에 넣는다.

<!-- numbered-subquestions -->

1. 이 트리를 그려라.
2. 전위, 중위, 후위 순회 결과를 각각 적어라.
3. 중위 순회 결과에서 루트 노드 1의 왼쪽과 오른쪽에 있는 두 부분은 각각 트리의 어느 부분에 해당하는가?

??? success "예시 답안"

    1. 트리의 모양은 다음과 같다.

        ```text
              1
            /   \
           2     3
          / \   / \
         4   5 6   7
        ```

    2. 전위 순회 결과는 `1, 2, 4, 5, 3, 6, 7`이다.
        중위 순회 결과는 `4, 2, 5, 1, 6, 3, 7`이다.
        후위 순회 결과는 `4, 5, 2, 6, 7, 3, 1`이다.

    3. 루트 노드 1 왼쪽의 `4, 2, 5`는 왼쪽 서브트리의 중위 순회 결과다.
        오른쪽의 `6, 3, 7`은 오른쪽 서브트리의 중위 순회 결과다.

### 3. &nbsp; 두 이진 탐색 트리 비교하기

다음 두 수열을 각각 왼쪽부터 차례로 빈 이진 탐색 트리에 삽입한다.

- 수열 A: `[4, 2, 6, 1, 3, 5, 7]`
- 수열 B: `[1, 2, 3, 4, 5, 6, 7]`

<!-- numbered-subquestions -->

1. 각 트리에서 7을 찾을 때 거치는 노드를 차례로 적어라.
2. 루트에서 가장 먼 리프까지 거치는 간선 수로 높이를 계산하면 두 트리의 높이는 각각 얼마인가?
3. 앞의 두 결과를 보면 두 트리에서 7을 찾는 효율이 같은가? 두 트리의 모양과 탐색 경로를 근거로 설명하라.

??? success "예시 답안"

    1. 수열 A로 만든 트리의 탐색 경로는 `4 → 6 → 7`이다.
        수열 B로 만든 트리의 탐색 경로는 `1 → 2 → 3 → 4 → 5 → 6 → 7`이다.

    2. 첫 번째 트리는 모든 레벨이 가득 차 있고 높이는 2다. 두 번째 트리는 자식이 모두 오른쪽에만 있고 높이는 6이다.

    3. 두 트리에서 7을 찾는 효율은 다르다. 삽입 순서에 따라 이진 탐색 트리의 모양과 높이가 달라진다. 7을 찾을 때 첫 번째 트리에서는 노드 3개만 거치지만
        두 번째 트리에서는 노드 7개를 차례로 거쳐야 한다. 트리가 높을수록 최악의 경우 경로를 따라 비교해야 하는 노드가 많아진다.

## 7.7.2 &nbsp; 프로그래밍 연습

### 1. &nbsp; 이진 트리의 최대 깊이

이진 트리의 루트 노드 `root`가 주어진다. 각 노드는 정숫값과 왼쪽 및 오른쪽 자식 노드를 가리키는 참조를 갖는다.

루트 노드에서 가장 먼 리프 노드까지의 경로에 있는 **노드 수**를 이진 트리의 최대 깊이라고 한다. 이 트리의 최대 깊이를 반환하라. 빈 트리의 최대 깊이는 0이다.
재귀를 사용하여 풀어라.

??? tip "풀이 힌트"

    1. 이 문제에서는 노드 수로 깊이를 계산한다. 루트 노드 하나만 있으면 최대 깊이는 1이다.
    2. 현재 노드를 루트로 하는 서브트리의 최대 깊이를 재귀 함수가 반환하도록 한다.
    3. 노드가 비어 있으면 0을, 그렇지 않으면 max(depth(left), depth(right)) + 1을 반환한다.

[LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; 이진 트리를 레벨별로 순회하기

이진 트리의 루트 노드 `root`가 주어진다. 큐를 사용하여 위에서 아래로 한 레벨씩 모든 노드를 방문하라. 같은 레벨에서는 왼쪽에서 오른쪽으로 방문한다.

이차원 배열을 반환하라. 첫 번째 부분 배열에는 루트 노드가 있는 레벨의 노드 값을, 두 번째 부분 배열에는 다음 레벨의 노드 값을 담는다. 이후 레벨도 마찬가지다.
이진 트리가 비어 있으면 빈 배열을 반환한다.

??? tip "풀이 힌트"

    1. 레벨 순회에서는 먼저 들어온 노드를 먼저 방문해야 하므로 큐를 사용한다.
    2. 매 라운드가 시작될 때 큐에는 정확히 한 레벨의 노드들이 들어 있다.
    3. 먼저 큐의 길이를 기록한 뒤 그 수만큼 노드를 꺼내면서 각 노드의 자식을 큐에 넣는다.

[LeetCode](https://leetcode.com/problems/binary-tree-level-order-traversal/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 3. &nbsp; 이진 탐색 트리에서 k번째로 작은 원소

이진 탐색 트리에 노드가 총 `n`개 있고 모든 노드의 값은 서로 다르다.
모든 노드 값을 오름차순으로 정렬하고 1부터 차례대로 위치에 번호를 붙인다.

루트 노드 `root`와 `1 <= k <= n`을 만족하는 정수 `k`가 주어질 때 `k`번째 노드 값을 반환하라.
모든 노드 값을 미리 모으지 말고 중위 순회 도중에 답을 찾아라.

??? tip "풀이 힌트"

    1. 이진 탐색 트리를 중위 순회하면 노드 값을 작은 것부터 차례로 방문한다.
    2. 중위 순회는 왼쪽 서브트리, 현재 노드, 오른쪽 서브트리 순으로 진행한다. 현재 노드를 방문할 때 카운트를 1 늘린다.
    3. 카운트가 처음으로 k가 되는 순간의 노드 값이 답이다. 이후에는 순회를 계속할 필요가 없다.

[LeetCode](https://leetcode.com/problems/kth-smallest-element-in-a-bst/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
