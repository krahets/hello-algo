# 요약

### 핵심 내용 돌아보기

- 이진 트리는 하나를 둘로 나누는 분할 정복의 원리를 담은 비선형 자료 구조다. 각 노드에는 값 하나와 왼쪽 자식 및 오른쪽 자식을 각각 가리키는 포인터 두 개가 있다.
- 한 노드의 왼쪽(오른쪽) 자식과 그 아래의 모든 노드로 이루어진 트리를 그 노드의 왼쪽(오른쪽) 서브트리라 한다.
- 이진 트리의 용어에는 루트 노드, 리프 노드, 레벨, 차수, 간선, 높이, 깊이 등이 있다.
- 이진 트리의 초기화와 노드 삽입 및 삭제는 연결 리스트에서의 연산과 비슷하다.
- 대표적인 유형은 포화 이진 트리, 완전 이진 트리, 정 이진 트리, 균형 이진 트리다. 포화 이진 트리가 가장 이상적인 상태라면 연결 리스트는 퇴화한 최악의 상태다.
- 이진 트리는 배열로도 표현할 수 있다. 노드 값과 빈자리를 레벨 순회 순서로 배치하고 부모와 자식의 인덱스 대응 관계로 포인터의 역할을 대신한다.
- 이진 트리의 레벨 순회는 한 겹씩 바깥으로 넓혀 가듯 레벨별로 방문하는 너비 우선 탐색 방법이다. 보통 큐로 구현한다.
- 전위, 중위, 후위 순회는 모두 깊이 우선 탐색이다. 한 경로를 끝까지 따라간 뒤 되돌아와 탐색을 이어 가며 보통 재귀로 구현한다.
- 이진 탐색 트리는 원소를 효율적으로 찾는 자료 구조로 탐색, 삽입, 삭제의 시간 복잡도는 모두 $O(\log n)$이다. 연결 리스트로 퇴화하면 각 연산의 시간 복잡도가 $O(n)$으로 나빠진다.
- 균형 이진 탐색 트리라고도 하는 AVL 트리는 회전 연산을 통해 노드를 계속 삽입하고 삭제해도 트리가 균형을 유지하도록 한다.
- AVL 트리의 회전에는 오른쪽 회전, 왼쪽 회전, 오른쪽 회전 후 왼쪽 회전, 왼쪽 회전 후 오른쪽 회전이 있다. 삽입이나 삭제 후에는 아래에서 위로 올라가며 회전하여 균형을 회복한다.

### Q & A

**질문**: 노드가 하나뿐인 이진 트리에서는 트리의 높이와 루트의 깊이가 모두 $0$인가?

그렇다. 높이와 깊이는 보통 경로에서 거치는 간선 수로 정의하기 때문이다.

**질문**: 이진 트리의 삽입과 삭제에는 보통 여러 연산을 조합한다고 하는데, 구체적으로 어떤 연산을 뜻하는가? 자식 노드의 자원을 해제하는 일로 이해해도 되는가?

이진 탐색 트리의 노드 삭제를 예로 들면 세 가지 경우로 나누어 처리해야 하고 각 경우마다 여러 단계의 노드 연산이 필요하다.

**질문**: 이진 트리의 DFS 순회에 전위, 중위, 후위라는 세 가지 순서가 있는 이유는 무엇이며 각각 어디에 쓰이는가?

배열을 순방향이나 역방향으로 순회하듯 이진 트리에서도 전위, 중위, 후위 순회를 이용해 원하는 순서의 결과를 얻을 수 있다. 예를 들어 이진 탐색 트리에서는 값 사이에 `왼쪽 자식 값 < 루트 노드 값 < 오른쪽 자식 값`의 관계가 성립한다. 따라서 ‘왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽’ 순서로 순회하면 정렬된 노드 수열을 얻는다.

**질문**: 오른쪽 회전은 불균형 노드 `node`와 `child`, `grand_child` 사이의 관계를 조정한다. 그러면 `node`의 부모와 `node` 사이의 원래 연결은 관리할 필요가 없는가? 오른쪽 회전 후에 연결이 끊어지지 않는가?

재귀의 관점에서 보면 `right_rotate(root)`에는 서브트리의 루트가 전달되고 마지막의 `return child`는 회전 후 서브트리의 루트를 반환한다. 새 루트와 부모의 연결은 함수가 반환된 뒤 이루어지며 오른쪽 회전 자체가 관리하는 범위 밖에 있다.

**질문**: C++에서 함수를 `private`와 `public`으로 나누는 기준은 무엇인가? 왜 `height()` 함수와 `updateHeight()` 함수를 각각 `public`과 `private`에 두는가?

주된 기준은 메서드의 사용 범위다. 클래스 안에서만 쓰는 메서드는 `private`으로 설계한다. 예를 들어 `updateHeight()`은 삽입이나 삭제의 한 단계일 뿐이어서 사용자가 따로 호출할 의미가 없다. 반면 `height()`은 `vector.size()`처럼 노드 높이를 조회하는 메서드이므로 편리하게 쓸 수 있도록 `public`으로 둔다.

**질문**: 주어진 입력 데이터로 이진 탐색 트리를 어떻게 만드는가? 루트를 고르는 일이 중요한가?

그렇다. 트리 생성 방법은 이진 탐색 트리 코드의 `build_tree()` 메서드에 나와 있다. 보통 입력 데이터를 정렬한 뒤 가운데 원소를 루트로 선택하고 양쪽 서브트리를 재귀적으로 만든다. 이렇게 하면 트리가 최대한 균형을 이루도록 할 수 있다.

**질문**: Java에서 문자열을 비교할 때는 반드시 `equals()` 메서드를 써야 하는가?

Java에서 기본 자료형의 경우 `==`는 두 변수의 값이 같은지 비교한다. 참조형의 경우 두 비교 방식의 동작 원리는 다르다.

- `==`는 두 변수가 같은 객체를 가리키는지, 즉 메모리에서 위치가 같은지를 비교한다.
- `equals()`는 두 객체의 값이 같은지 비교한다.

따라서 값을 비교하려면 `equals()`를 사용해야 한다. 다만 `String a = "hi"; String b = "hi";`처럼 초기화한 문자열은 문자열 상수 풀에 저장되어 같은 객체를 가리키므로 `a == b`로도 두 문자열의 내용을 비교할 수 있다.

**질문**: 너비 우선 순회에서 맨 아래 레벨을 방문하기 직전 큐에 있는 노드 수는 $2^h$인가?

그렇다. 예를 들어 높이가 $h = 2$인 포화 이진 트리는 전체 노드 수가 $n = 7$이므로 맨 아래 레벨의 노드 수는 $4 = 2^h = (n + 1) / 2$다.
