## 0.2.1 &nbsp; 표기 규칙

- 제목 뒤에 `*`가 붙은 절은 선택해서 읽는 내용으로 난도가 다소 높다. 시간이 부족하면 우선 건너뛰어도 좋다.
- 전문 용어는 종이책과 PDF판에서는 굵은 글꼴로, 웹판에서는 밑줄로 표시한다. 예를 들면 <u>배열(array)</u>과 같다. 문헌을 읽을 때 도움이 되므로 기억해 두기를 권한다.
- 중요한 내용과 요약 문장은 **굵게** 표시한다. 이런 부분은 특히 주의 깊게 읽어 보자.
- 특정한 뜻으로 쓰는 표현은 혼동을 피하도록 “따옴표”로 표시한다.
- 프로그래밍 언어마다 용어가 다를 때는 파이썬을 기준으로 한다. 예를 들어 ‘값이 없음’은 `None`으로 나타낸다.
- 이 책은 내용을 간결하게 배치하기 위해 언어별 주석 작성 관례를 일부 따르지 않는다. 주석은 주로 제목 주석, 내용 주석, 여러 줄 주석 세 가지로 나눈다.

## 0.2.3 &nbsp; 코드 실습으로 이해를 깊게 하기

이 책의 예제 코드는 [깃허브 저장소](https://github.com/krahets/hello-algo)에 있다. 아래 그림(0-3)처럼 **소스 코드에는 테스트 예제가 포함되어 있어 클릭 한 번으로 실행할 수 있다**.

시간이 된다면 **예제를 참고해 코드를 직접 한 번 작성해 보기를 권한다**. 공부할 시간이 부족하더라도 적어도 모든 코드를 읽고 실행해 보자.

눈으로 읽기만 할 때보다 직접 코드를 작성할 때 얻는 것이 더 많은 경우가 많다. **직접 해 보아야 제대로 배울 수 있다**.

![코드 실행 예시](../index.assets/running_code.gif){ class="animation-figure" }

<p align="center"> 그림 0-3 &nbsp; 코드 실행 예시 </p>

코드를 실행하기 위한 준비는 크게 세 단계로 나뉜다.

**첫째, 로컬 프로그래밍 환경을 설치한다**. 부록의 [설치 안내](../chapter_appendix/installation.md)를 따른다. 이미 설치했다면 이 단계는 건너뛰어도 된다.

**둘째, 코드 저장소를 복제하거나 내려받는다**. [깃허브 저장소](https://github.com/krahets/hello-algo)로 이동한다. [Git](https://git-scm.com/downloads)을 설치했다면 다음 명령으로 저장소를 복제할 수 있다.

```shell
git clone https://github.com/krahets/hello-algo.git
```

아래 그림(0-4)의 위치에서 ‘Download ZIP’ 버튼을 눌러 코드 압축 파일을 바로 내려받은 뒤 컴퓨터에서 압축을 풀어도 된다.

![저장소 복제와 코드 다운로드](suggestions.assets/download_code.png){ class="animation-figure" }

## 0.2.5 &nbsp; 알고리즘 학습 경로

자료 구조와 알고리즘 학습은 크게 세 단계로 나눌 수 있다.

1. **1단계: 알고리즘 입문**. 다양한 자료 구조의 특성과 사용법을 익히고 여러 알고리즘의 원리, 절차, 용도, 효율 등을 배운다.
2. **2단계: 알고리즘 문제 풀이**. 널리 알려진 문제부터 시작해 적어도 100문제를 풀면서 주요 알고리즘 문제에 익숙해지기를 권한다. 처음에는 배운 내용을 잊어버려 어려움을 겪을 수도 있지만 자연스러운 일이다. 에빙하우스의 망각 곡선에 맞춰 문제를 복습해 보자. 보통 3~5차례 되풀이하면 오래 기억할 수 있다. 추천 문제 목록과 풀이 계획은 이 [깃허브 저장소](https://github.com/krahets/LeetCode-Book)를 참고하자.
3. **3단계: 지식 체계 세우기**. 알고리즘 연재 글, 문제 풀이의 기본 틀, 알고리즘 교재를 읽으면 지식 체계가 계속 풍부해진다. 연습할 때는 주제별로 문제를 분류하거나, 한 문제를 여러 방법으로 풀거나, 한 해법을 여러 문제에 적용하는 등 심화 전략도 시도해 보자. 관련 경험담은 여러 커뮤니티에서 찾아볼 수 있다.

아래 그림(0-8)처럼 이 책은 주로 ‘1단계’를 다룬다. 이를 바탕으로 2단계와 3단계의 학습을 더 효율적으로 시작하도록 돕는 것이 목표다.
