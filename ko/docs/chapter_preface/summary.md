# 요약

### 핵심 정리

- 이 책은 주로 알고리즘 입문자를 대상으로 한다. 이미 기초를 갖추었다면 알고리즘 지식을 체계적으로 복습하는 데 도움이 되며, 소스 코드는 ‘문제 풀이 도구 모음’으로 활용할 수 있다.
- 내용은 크게 복잡도 분석, 자료 구조, 알고리즘의 세 부분으로 구성되어 있으며, 이 분야의 주요 주제를 폭넓게 다룬다.
- 알고리즘 초보자에게는 처음 공부할 때 입문서를 읽는 일이 매우 중요하다. 불필요하게 돌아가는 길을 많이 줄일 수 있다.
- 애니메이션 그림은 주로 핵심 내용과 어려운 개념을 설명하는 데 쓰인다. 책을 읽을 때 이러한 내용을 특히 주의 깊게 살펴보자.
- 실습은 프로그래밍을 배우는 가장 좋은 방법이다. 소스 코드를 실행하고 직접 코드를 작성해 볼 것을 적극 권장한다.
- 웹 버전의 각 장에는 댓글란이 있다. 궁금한 점이나 생각을 언제든 나누기 바란다.
