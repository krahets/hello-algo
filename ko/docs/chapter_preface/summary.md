# 0.3 &nbsp; 요약

### 1. &nbsp; 핵심 정리

- 이 책의 주된 독자는 알고리즘을 처음 배우는 사람이다. 이미 기초가 있다면 알고리즘 지식을 체계적으로 복습하는 데 활용하고, 소스 코드는 ‘문제 풀이 도구 모음’으로 써도 좋다.
- 이 책은 크게 복잡도 분석, 자료 구조, 알고리즘의 세 부분으로 구성되며 이 분야의 주요 주제를 대부분 다룬다.
- 알고리즘을 처음 배울 때 입문서 한 권을 읽는 일은 매우 중요하다. 시행착오를 많이 줄일 수 있다.
- 이 책의 애니메이션 그림은 주로 중요하거나 어려운 개념을 소개한다. 읽을 때 특히 주의 깊게 살펴보자.
- 프로그래밍을 배우는 가장 좋은 방법은 실습이다. 소스 코드를 실행하고 직접 작성해 보기를 적극 권한다.
- 웹판의 각 절에는 댓글란이 있다. 궁금한 점이나 자신의 생각을 언제든 나누기 바란다.
