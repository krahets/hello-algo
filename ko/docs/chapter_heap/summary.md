# 8.4 &nbsp; 요약

### 1. &nbsp; 핵심 내용

- 힙은 완전 이진 트리이며 만족하는 조건에 따라 최대 힙과 최소 힙으로 나뉜다. 최대 힙의 루트는 최댓값이고 최소 힙의 루트는 최솟값이다.
- 우선순위 큐는 우선순위에 따라 원소를 꺼내는 큐이며 보통 힙으로 구현한다.
- 힙의 주요 연산과 시간 복잡도로는 원소 삽입 $O(\log n)$, 루트 원소 꺼내기 $O(\log n)$, 루트 원소 조회 $O(1)$ 등이 있다.
- 완전 이진 트리는 배열로 표현하기 알맞으므로 힙은 보통 배열에 저장한다.
- 힙 복구는 힙의 성질을 유지하는 연산으로 삽입과 삭제에 모두 쓰인다.
- 원소 $n$개로 힙을 구성하는 시간 복잡도는 $O(n)$까지 낮출 수 있어 매우 효율적이다.
- 상위 k개 찾기(Top-k)는 전형적인 알고리즘 문제다. 힙을 사용하면 시간 복잡도 $O(n \log k)$으로 효율적으로 풀 수 있다.

### 2. &nbsp; Q & A

**질문**: 자료 구조의 힙과 메모리 관리에서 말하는 힙은 같은 개념인가?

둘은 이름만 같을 뿐 다른 개념이다. 컴퓨터 시스템 메모리의 힙은 동적 메모리 할당에 쓰이는 영역으로, 프로그램이 실행 중에 데이터를 저장하는 데 사용할 수 있다. 프로그램은 필요한 크기의 힙 메모리를 요청해 객체나 배열 같은 복합 구조를 저장한다. 데이터가 더 이상 필요하지 않으면 메모리 누수를 막기 위해 해당 메모리를 해제해야 한다. 힙 메모리는 스택 메모리보다 주의해서 관리하고 사용해야 한다. 잘못 사용하면 메모리 누수가 발생하거나 포인터가 유효하지 않은 주소를 가리킬 수 있다.
