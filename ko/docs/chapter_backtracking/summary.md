# 13.5 &nbsp; 요약

### 1. &nbsp; 핵심 정리

- 백트래킹은 해 공간을 깊이 우선으로 순회해 조건에 맞는 해를 찾는 완전 탐색 방법이다. 탐색 중 조건을 만족하는 해를 만나면 기록하고, 모든 해를 찾거나 순회를 마치면 종료한다.
- 백트래킹 탐색은 시도와 되돌리기로 이루어진다. 깊이 우선 탐색으로 여러 선택을 시도하다가 제약 조건을 어기면 직전 선택을 취소하고 이전 상태로 돌아가 다른 선택을 시도한다. 시도와 되돌리기는 서로 반대 방향의 연산이다.
- 백트래킹 문제에는 보통 여러 제약 조건이 있으며 이를 가지치기에 활용할 수 있다. 가지치기는 불필요한 가지의 탐색을 일찍 끝내 탐색 효율을 크게 높인다.
- 백트래킹은 주로 탐색 문제와 제약 충족 문제를 푸는 데 쓰인다. 조합 최적화 문제도 풀 수 있지만 더 효율적이거나 더 좋은 결과를 내는 방법이 있는 경우가 많다.
- 순열 문제에서는 주어진 집합의 원소로 만들 수 있는 모든 순열을 찾는다. 배열에 각 원소의 선택 여부를 기록하고 같은 원소를 다시 선택하는 가지를 잘라 내면 각 원소를 한 번씩만 선택하게 된다.
- 순열 문제에서 집합에 중복 원소가 있으면 결과에 같은 순열이 여러 번 나타난다. 각 단계에서 값이 같은 원소 중 하나만 선택하도록 제한해야 하며, 보통 해시 집합을 사용한다.
- 부분집합의 합 문제에서는 주어진 집합에서 원소의 합이 목표값과 같은 모든 부분집합을 찾는다. 집합은 원소의 순서를 구분하지 않지만 탐색은 가능한 순서를 모두 출력하므로 중복 부분집합이 생긴다. 백트래킹 전에 데이터를 정렬하고 각 단계의 순회 시작점을 변수로 지정하면 중복을 만드는 가지를 잘라 낼 수 있다.
- 부분집합의 합 문제에서 배열에 값이 같은 원소가 있으면 중복 부분집합이 생긴다. 배열이 정렬되어 있다는 점을 이용해 이웃한 원소의 값이 같은지 확인하고 가지치기하면 각 단계에서 같은 값을 한 번만 고를 수 있다.
- $n$-퀸 문제는 퀸 $n$개를 $n \times n$ 체스판에 서로 공격할 수 없도록 놓는 방법을 찾는 문제이다. 행, 열, 주대각선, 부대각선 제약을 지켜야 한다. 행 제약은 행마다 퀸을 하나씩 놓는 전략으로 만족시킨다.
- 열 제약과 대각선 제약은 비슷하게 처리한다. 각 열에 퀸이 있는지 배열에 기록하면 선택한 칸에 놓아도 되는지 판단할 수 있다. 대각선은 배열 두 개에 각 주대각선과 부대각선에 퀸이 있는지 따로 기록한다. 어려운 점은 같은 주대각선 또는 부대각선에 속한 칸의 행과 열 인덱스 사이에서 규칙을 찾는 것이다.

### 2. &nbsp; Q & A

**Q**: 백트래킹과 재귀는 어떤 관계인가?

백트래킹이 ‘알고리즘 전략’이라면 재귀는 그 전략을 구현하는 ‘도구’에 가깝다.

- 백트래킹은 보통 재귀로 구현한다. 백트래킹은 재귀의 여러 활용 사례 중 하나로, 탐색 문제에 재귀를 적용한다.
- 재귀 구조는 문제를 부분 문제로 나누는 풀이 방식을 반영한다. 분할 정복, 백트래킹, 동적 계획법(메모이제이션을 이용한 재귀) 등에 널리 쓰인다.
