# 연습 문제

## 개념 다지기

### 어떤 작업에 분할 정복이 적합할까?

한 학생이 다음 작업을 ‘둘로 나누고, 각각 해결한 뒤, 결과를 합치는’ 방법으로 수행하려 한다.
각 작업이 ‘분할 정복에 적합하다’, ‘분할 정복이 가능하지만 전체 작업량은 줄지 않는다’, ‘두 부분을 독립적으로 해결할 수 없다’ 중 어디에 해당하는지 판단하고 이유를 설명하라.

<!-- numbered-subquestions -->

1. 정렬되지 않은 배열을 정렬한다.
2. 배열의 최댓값을 구한다.
3. 스택 연산 `push(x)`와 `pop()`로 이루어진 연산열을 순서대로 수행하고 `pop()`으로 꺼낸 원소를 매번 출력한다.

??? success "예시 답안"

    1. 적합하다. 배열을 반으로 나누어 각 절반을 독립적으로 정렬하고 $O(n)$ 시간에 합치면 된다. 이것이 바로 병합 정렬이다.
    2. 분할 정복이 가능하지만 전체 작업량은 줄지 않는다. 양쪽을 합쳐 원소 $n$개를 모두 검사해야 하므로
        배열을 직접 훑을 때와 마찬가지로 $O(n)$ 시간이 걸린다.
    3. 두 부분을 독립적으로 해결할 수 없다. 뒷부분을 시작할 때 스택에 무엇이 들어 있는지가 앞부분의 실행 결과에 달려 있으므로
        두 부분을 서로의 결과를 모르는 상태에서 독립적으로 처리할 수 없다.

### 빠른 거듭제곱은 어떻게 계산을 줄일까?

다음 재귀 함수는 분할 정복으로 $x^n$을 계산한다.

```src
[file]{fast_power}-[class]{}-[func]{fast_pow}
```

`x = 3`, `n = 5`로 두고 이 함수로 계산해 보자.

<!-- numbered-subquestions -->

1. 재귀 호출이 진행되면서 매개변수 `n`은 차례로 어떤 값을 갖는가?
2. 가장 깊은 호출부터 돌아올 때 각 층은 차례로 어떤 값을 반환하는가?
3. 곱셈의 양쪽에서 같은 부분 문제를 각각 호출하지 않고 재귀 호출의 결과를 `half`에 저장하는 이유는 무엇인가?

??? success "예시 답안"

    1. 매개변수는 `5 → 2 → 1 → 0` 순으로 바뀐다. 종료 조건에 도달할 때까지 지수가 매번 절반으로 줄어든다.

    2. `n = 0`이면 1을 반환하고 `n = 1`이면 $1×1×3=3$을 반환한다.
        `n = 2`이면 $3×3=9$를 반환하고 `n = 5`이면 $9×9×3=243$을 반환한다.

    3. 곱셈의 양쪽에서 같은 부분 문제를 각각 호출하면 두 재귀 호출이 똑같은 계산을 수행한다.
        결과를 `half`에 저장하면 각 층에서 재귀 호출이 한 번만 일어나고 재귀 깊이는 약 $\log n$이다.
        두 번씩 호출하면 같은 계산이 많이 반복된다.

### 순회 결과에서 왼쪽과 오른쪽 서브트리 나누기

중복된 노드가 없는 이진 트리의 전위 순회와 중위 순회 결과가 다음과 같다.

- 전위 순회: `[A, B, D, E, C]`
- 중위 순회: `[D, B, E, A, C]`

루트 노드에서 한 번만 나누어 보자. 더 깊이 재귀적으로 나누거나 트리 전체를 그릴 필요는 없다.

<!-- numbered-subquestions -->

1. 루트 노드는 무엇인가?
2. 왼쪽과 오른쪽 서브트리는 중위 순회에서 각각 어느 구간에 해당하는가?
3. 왼쪽과 오른쪽 서브트리는 전위 순회에서 각각 어느 구간에 해당하는가? 루트 노드의 왼쪽 자식과 오른쪽 자식은 무엇인가?

??? success "예시 답안"

    1. 전위 순회의 첫 노드가 루트이므로 루트 노드는 `A`이다.

    2. `A`를 기준으로 중위 순회를 나누면 왼쪽 서브트리는 `[D, B, E]`, 오른쪽 서브트리는 `[C]`이다.

    3. 왼쪽 서브트리에 노드가 3개 있으므로 전위 순회에서 루트 `A` 바로 뒤의 원소 3개가 왼쪽 서브트리에 속한다.
        즉, `[B, D, E]`가 왼쪽 서브트리에 속하고 나머지 `[C]`는 오른쪽 서브트리에 속한다.
        따라서 루트 노드의 왼쪽 자식은 `B`이고 오른쪽 자식은 `C`이다.

### 빠른 거듭제곱

실수 `x`와 정수 `n`이 주어질 때 $x^n$을 구하라. 언어에 내장된 거듭제곱 함수는 사용할 수 없다.
재귀적 분할 정복을 사용하라. 매번 지수를 절반으로 줄이고 이미 구한 부분 문제의 결과를 재사용하라.
이 문제에서는 `x = 0`일 때도 $x^0=1$로 정의한다. `n < 0`이면 `x != 0`이 보장되므로 $(1/x)^{-n}$를 계산해 답을 구할 수 있다.

??? tip "풀이 힌트"

    1. n이 0이면 답은 1이다
    2. x의 n // 2 제곱을 구해 half에 저장하고 같은 재귀 호출을 다시 하지 않는다
    3. n < 0이면 먼저 x를 1 / x로 바꾸고 n을 -n으로 바꾼다. C++나 Java에서는 n을 먼저 64비트 정수로 변환하면 32비트 정수의 최솟값을 부호 반전할 때 생기는 오버플로를 피할 수 있다
