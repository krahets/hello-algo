# 요약

### 핵심 정리

- 분할 정복은 널리 쓰이는 알고리즘 설계 전략이다. 분할(나누기)과 정복(합치기)의 두 단계로 이루어지며 보통 재귀로 구현한다.
- 분할 정복이 적합한지 판단하려면 문제를 나눌 수 있는지, 부분 문제들이 독립적인지, 그 해를 합칠 수 있는지를 살펴본다.
- 병합 정렬은 분할 정복의 대표적인 예이다. 배열을 같은 길이의 두 부분 배열로 재귀적으로 나누다가 원소 하나만 남으면 한 층씩 병합해 정렬을 마친다.
- 분할 정복을 도입하면 알고리즘의 효율이 높아지는 경우가 많다. 연산 횟수를 줄일 수 있고 시스템의 병렬 처리도 활용하기 쉽다.
- 분할 정복은 많은 알고리즘 문제를 푸는 데 쓰이며 자료 구조와 알고리즘 설계 전반에서도 찾아볼 수 있다.
- 적응형 탐색은 완전 탐색보다 효율적이다. 시간 복잡도가 $O(\log n)$인 탐색 알고리즘은 대개 분할 정복 전략을 사용한다.
- 이진 탐색도 분할 정복의 대표적인 예이며 부분 문제의 해를 합치는 단계가 없다. 재귀적 분할 정복으로 이진 탐색을 구현할 수 있다.
- 이진 트리 구성 문제에서는 트리 구성(원래 문제)을 왼쪽과 오른쪽 서브트리 구성(부분 문제)으로 나눈다. 전위 순회와 중위 순회의 인덱스 구간을 나누어 이를 구현할 수 있다.
- 하노이의 탑에서 크기가 $n$인 문제는 크기가 $n-1$인 부분 문제 두 개와 크기가 $1$인 부분 문제 하나로 나눌 수 있다. 세 부분 문제를 차례로 풀면 원래 문제도 풀린다.
