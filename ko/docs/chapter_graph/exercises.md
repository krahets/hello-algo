# 연습 문제

## 개념 다지기

### 같은 그래프를 표현하는 두 가지 방법

무방향 그래프의 정점은 `A, B, C, D`의 4개이고 간선은
`A-B, A-C, B-C, C-D`이다.

<!-- numbered-subquestions -->

1. 이 그래프의 인접 리스트를 작성하시오.
2. 0과 1만 사용하여 인접 행렬을 채우시오.
3. `A`와 `D`가 직접 연결되어 있는지 확인할 때, 저장된 항목 하나만 살펴보면 되는 표현 방식은 무엇인가?
4. 그래프에 정점은 많고 간선은 적다면 일반적으로 어느 표현 방식이 메모리를 더 적게 사용하는가?

??? success "예시 답안"

    1. 인접 리스트는 다음과 같다.

        ```text
        A: B, C
        B: A, C
        C: A, B, D
        D: C
        ```

    2. 인접 행렬은 다음과 같다.

        | | A | B | C | D |
        | --- | --- | --- | --- | --- |
        | A | 0 | 1 | 1 | 0 |
        | B | 1 | 0 | 1 | 0 |
        | C | 1 | 1 | 0 | 1 |
        | D | 0 | 0 | 1 | 0 |

    3. 인접 행렬에서는 `A`행과 `D`열이 만나는 위치의 값을 바로 확인할 수 있다. 따라서 임의의 두 정점이 직접 연결되어 있는지 판단하기에 적합하다.

    4. 정점이 많고 간선이 적을 때는 인접 리스트가 일반적으로 메모리를 더 적게 사용한다. 인접 리스트는 실제로 존재하는 간선만 기록하지만, 인접 행렬은 모든 정점 쌍에 대해 공간을 확보하기 때문이다.

### 너비 우선 탐색과 깊이 우선 탐색의 정점 방문 순서

무방향 그래프의 정점은 `A, B, C, D, E`이고 간선은
`A-B, A-C, B-D, C-D, D-E`이다.

A에서 출발한다. 아직 방문하지 않은 인접 정점이 여러 개이면 알파벳순으로 선택한다.

<!-- numbered-subquestions -->

1. 너비 우선 탐색(BFS)에서 정점을 방문하는 순서를 쓰시오.
2. 재귀 방식의 깊이 우선 탐색(DFS)에서 정점을 방문하는 순서를 쓰시오.
3. 두 탐색 모두 이미 방문한 정점을 기록해야 하는 이유는 무엇인가?

??? success "예시 답안"

    1. BFS의 방문 순서는 `A, B, C, D, E`이다. 먼저 A에서 간선 하나만 따라가면 닿는 B와 C를 방문하고,
        그다음으로 더 멀리 있는 D와 E를 방문한다.

    2. DFS의 방문 순서는 `A, B, D, C, E`이다. 현재 정점에서 아직 방문하지 않은 인접 정점으로 하나씩 들어가므로
        먼저 `A → B → D → C` 순서로 이동한다. C에는 더 방문할 인접 정점이 없으므로 D로 돌아가 E를 방문한다.

    3. 이 그래프에는 `A-B-D-C-A`와 같은 사이클이 있다. 이미 방문한 정점을 기록하지 않으면
        사이클을 따라 같은 정점들을 계속 방문하면서 탐색이 끝나지 않을 수 있다.

### BFS 한 번으로 그래프 전체를 방문할 수 있는가?

무방향 그래프의 정점은 `A, B, C, D, E, F`이고 간선은
`A-B, B-C, D-E`뿐이다.

<!-- numbered-subquestions -->

1. A에서 BFS를 한 번 수행하면 어떤 정점을 방문할 수 있는가?
2. 1번의 결과를 보면, 이번 BFS에서 그래프의 모든 정점을 방문했는가? 그 이유는 무엇인가?
3. 모든 정점을 알파벳순으로 살펴보면서 아직 방문하지 않은 정점을 만날 때마다 그곳에서 BFS를 새로 시작한다고 하자.
    각 BFS의 시작 정점은 무엇인가? 이 그래프는 서로 연결되지 않은 몇 개의 부분(연결 요소)으로 나뉘는가?

??? success "예시 답안"

    1. A에서 출발하면 `A, B, C`만 방문할 수 있다.

    2. 모든 정점을 방문한 것은 아니다. 두 정점 `D, E`는 서로 연결되어 별도의 연결 요소를 이루고, F는 고립된 정점이다.
        A에서 이 세 정점 중 어느 곳으로도 가는 경로가 없으므로 A에서 출발해서는 도달할 수 없다.

    3. 세 번의 BFS는 `A, D, F`에서 차례로 시작하며, 각 탐색이 방문하는 정점의 집합은 순서대로
        `{A, B, C}`, `{D, E}`, `{F}`이다. 따라서 이 그래프의 연결 요소는 3개이다.

## 프로그래밍 연습

### 무방향 그래프에서 경로의 존재 여부 판별하기

정점이 $n$개인 무방향 그래프가 주어진다. 정점 번호는 $0$부터 $n-1$까지다. 배열 `edges`의 각 원소 `[u, v]`는 정점 `u`와 `v` 사이에 무방향 간선이 하나 있음을 나타낸다.

시작 정점 `source`와 도착 정점 `destination`도 주어진다. 먼저 `edges`로 인접 리스트를 만든 뒤 BFS 또는 DFS를 사용하여
`source`에서 `destination`까지 가는 경로가 있는지 판별하라. 경로가 있으면 `true`를, 없으면 `false`를 반환하라.
그래프에는 사이클이 있을 수 있으며, 모든 정점이 서로 연결되어 있지 않을 수도 있다.

??? tip "풀이 힌트"

    1. 각 무방향 간선을 양방향으로 추가해야 한다.
    2. 그래프에는 사이클이 있을 수 있으므로 이미 방문한 노드를 기록해야 한다.
    3. source에서 출발해 destination을 만나면 true를 반환하고, 순회를 마칠 때까지 만나지 못하면 false를 반환한다.
