# Глава 15. &nbsp; Жадный подход

![Жадные алгоритмы](../assets/covers/chapter_greedy.svg){ class="cover-image" }

!!! abstract

    Подсолнечник поворачивается к солнцу, в каждый момент выбирая лучшее направление для роста.

    Следуя жадной стратегии, мы делаем один простой выбор за другим и шаг за шагом приближаемся к лучшему ответу.
