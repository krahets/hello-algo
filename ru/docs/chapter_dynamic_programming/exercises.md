## Вопросы для закрепления

### Когда стоит применять динамическое программирование

Студент утверждает: «Если можно записать рекуррентное соотношение, следует применять динамическое программирование».
Для каждой из трёх задач выберите подход: динамическое программирование, поиск с возвратом либо цикл или формула без таблицы `dp`. Приведите по одному аргументу.

<!-- numbered-subquestions -->

1. Набрать сумму 6 наименьшим числом монет с номиналами `[1, 3, 4]`. Монеты каждого номинала можно брать многократно.
2. Вывести все перестановки `[1, 2, 3]`.
3. Вычислить $1 + 2 + \dots + n$.

    Для задачи, где вы выбрали динамическое программирование, объясните также смысл `dp[i]`.

??? success "Вариант ответа"

    1. Подходит динамическое программирование. Пусть `dp[i]` — минимальное число монет, которыми можно набрать сумму `i`.
        Для каждой монеты, номинал которой не больше `i` и равен `c`, рассмотрим значение `dp[i-c] + 1`.
        Из полученных значений выберем минимум. При разных вариантах выбора встречаются одни и те же суммы, а оптимальное решение для большей суммы складывается из оптимального решения для меньшей суммы и выбранной монеты.
        Для суммы 6 ответ равен 2: `3 + 3`.

    2. Подходит поиск с возвратом. Нужно по очереди сгенерировать все 6 перестановок. Поиск с возвратом позволяет последовательно делать выбор, продолжать поиск,
        затем отменять выбор и исследовать другие ветви. Чтобы вывести все перестановки, при любом методе придётся их перечислить.

    3. Достаточно цикла или формулы суммы арифметической прогрессии. Можно записать `S(i) = S(i-1) + i`, но для вычисления `S(i)` нужна лишь одна предыдущая сумма `S(i-1)`.
        Каждая частичная сумма вычисляется один раз. Повторяющихся подзадач нет, поэтому таблица `dp` не нужна. Само наличие рекуррентного соотношения ещё не означает, что требуется динамическое программирование.

### Как вычислить значение одной ячейки таблицы для задачи о рюкзаке

В задаче о рюкзаке 0–1 веса предметов заданы массивом `wgt = [1, 2, 3]`, стоимости — массивом `val = [5, 11, 15]`. Вместимость рюкзака равна 4.
Значение `dp[i][c]` — максимальная стоимость, которую можно получить, выбирая из первых $i$ предметов при вместимости $c$.
Заполнять рюкзак целиком необязательно.

Рассчитайте только состояние `dp[3][4]`. Известны значения `dp[2][4] = 16` и `dp[2][1] = 5`.

<!-- numbered-subquestions -->

1. Какова стоимость варианта без третьего предмета?
2. Сколько места останется, если взять третий предмет? Какова стоимость этого варианта?
3. Какое значение получит `dp[3][4]`? Какие предметы ему соответствуют?

??? success "Вариант ответа"

    1. Если не брать третий предмет, сохраняется результат для первых двух: `dp[2][4] = 16`.

    2. Третий предмет весит 3. Если взять его, останется место на вес $4-3=1$. Стоимость этого варианта равна
        `dp[2][1] + 15 = 5 + 15 = 20`.

    3. Сравниваем 16 и 20 и получаем `dp[3][4] = 20`. Этому значению соответствует выбор первого и третьего предметов.
        Их суммарный вес равен $1+3=4$, а суммарная стоимость — $5+15=20$.

        Так при вычислении одного состояния рюкзака 0–1 сравниваются варианты «взять» и «пропустить».

### В каком порядке обновлять значения для разной вместимости рюкзака

В задаче о рюкзаке 0–1 дан всего один предмет весом 2 и стоимостью 5. Вместимость рюкзака равна 4.
Каждый предмет можно взять не более одного раза. Начальное состояние одномерного массива: `dp = [0, 0, 0, 0, 0]`.

Студент обрабатывает этот предмет, перебирая вместимость от 2 до 4:

- После обновления `dp[2]` получает 5.
- После обновления `dp[3]` также получает 5.
- При обновлении `dp[4]` использует только что вычисленное `dp[2]` и получает `dp[4] = 10`.

<!-- numbered-subquestions -->

1. Верен ли результат `dp[4] = 10`? Почему?
2. Чему должно равняться `dp[4]`, если каждый предмет разрешено брать не более одного раза?
3. В каком порядке нужно перебирать вместимость для каждого предмета: по убыванию или по возрастанию? Какой ошибки это позволяет избежать?

??? success "Вариант ответа"

    1. Результат неверен. Стоимость 10 означает, что предмет стоимостью 5 положили в рюкзак дважды,
        хотя по условию каждый предмет можно взять не более одного раза.

    2. В рюкзак можно положить лишь один экземпляр этого предмета, поэтому верное значение `dp[4]` равно 5.

    3. Вместимость нужно перебирать по убыванию: 4, 3, 2.
        Тогда при вычислении `dp[c]` значение `dp[c-2]` ещё соответствует моменту до обработки текущего предмета,
        и за один проход этот предмет не будет учтён дважды.

### Число способов подняться по лестнице

В лестнице `n` ступеней. За шаг можно подняться на 1 или 2 ступени. Требуется попасть точно на ступень с номером `n`.
Подсчитайте число способов подъёма при `n >= 1`. Способы различаются только последовательностью шагов длиной 1 и 2.
Используйте одномерный массив динамического программирования. Оптимизацию, при которой хранят только два состояния, пока отложите.

??? tip "Подсказки"

    1. Последний шаг до ступени i имеет длину 1 или 2
    2. Отсюда dp[i] = dp[i-1] + dp[i-2]
    3. Сначала разберите случаи n = 1 и n = 2, затем заполняйте таблицу со ступени 3

### Рюкзак 0–1

Даны массивы `wgt` и `val` одинаковой длины. Для предмета с индексом `i` вес задаётся положительным целым числом `wgt[i]`, а стоимость — неотрицательным целым числом `val[i]`.
Вместимость рюкзака `cap` — неотрицательное целое число. Каждый предмет можно взять не более одного раза. При условии, что суммарный вес не превышает `cap`,
найдите максимальную суммарную стоимость предметов в рюкзаке. Используйте динамическое программирование с одномерным массивом.

??? tip "Подсказки"

    1. Инициализируйте массив dp длины cap + 1, где dp[c] — максимальная стоимость при допустимом весе c
    2. Для предмета i сравните стоимость без него, dp[c], и стоимость с ним, dp[c-wgt[i]] + val[i]
    3. Перебирайте значения вместимости от больших к меньшим, чтобы не выбрать текущий предмет повторно за один проход
