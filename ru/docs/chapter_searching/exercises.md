# 10.7 &nbsp; Упражнения

## 10.7.1 &nbsp; Вопросы для закрепления

### 1. &nbsp; Как двоичный поиск сужает интервал

Найдите число 16 в отсортированном массиве `[2, 5, 8, 12, 16, 23, 38]`.
Используйте замкнутый интервал `[i, j]`. Индекс середины вычисляется по формуле
$m=i+(j-i)/2$ (с округлением вниз).

Для каждой итерации запишите `(i, j, m)`, значение среднего элемента и то, как изменятся границы интервала,
пока не найдёте искомое число.

??? success "Вариант ответа"

    Рассмотрим поиск по итерациям.

    | Итерация | `(i, j, m)` | Средний элемент | Следующий шаг |
    | --- | --- | --- | --- |
    | 1 | `(0, 6, 3)` | 12 | `12 < 16`, поэтому положим `i = 4` |
    | 2 | `(4, 6, 5)` | 23 | `23 > 16`, поэтому положим `j = 4` |
    | 3 | `(4, 4, 4)` | 16 | Искомое число найдено, возвращаем индекс 4 |

    Массив упорядочен. Если средний элемент меньше искомого, можно исключить сам средний элемент и всё слева от него.
    Если средний элемент больше искомого, можно исключить его и всё справа от него.

### 2. &nbsp; Левая и правая границы группы равных элементов

Найдите число 2 в массиве `[1, 2, 2, 2, 4, 6]`.
Ученик применил двоичный поиск, нашёл искомое число по индексу 2, сразу вернул этот индекс и сказал:
«Индекс 2 — левая граница вхождений числа 2».

<!-- numbered-subquestions -->

1. Прав ли ученик? Чему равны левая и правая границы вхождений числа 2? Обоснуйте ответ.
2. Если при поиске левой границы средний элемент равен искомому, в какую сторону нужно продолжить поиск?
3. А при поиске правой границы? Укажите только направления, не расписывая весь ход поиска.

??? success "Вариант ответа"

    1. Ученик ошибается. Если завершить поиск сразу, как только встретилась двойка, мы найдём одно из её вхождений, но оно не обязательно будет первым или последним.
        В этом примере левая граница имеет индекс 1, а правая — индекс 3.

    2. При поиске левой границы, даже если средний элемент равен 2, нужно продолжить поиск слева,
        например, для замкнутого интервала положить `j = m - 1`.

    3. При поиске правой границы, если средний элемент равен 2, нужно продолжить поиск справа,
        например, положить `i = m + 1`.

### 3. &nbsp; Как выбрать способ поиска для разных данных

Для каждой из трёх ситуаций выберите подходящий метод — последовательный поиск, двоичный поиск или хеш-таблицу. Обоснуйте свой выбор.

<!-- numbered-subquestions -->

1. Нужно многократно выполнять поиск среди $10^7$ уже упорядоченных целых чисел. Данные не меняются, создавать дополнительные структуры нельзя.
2. В набор часто добавляют данные и удаляют их. Нужно многократно проверять наличие ключа. Поддерживать порядок и выполнять поиск по диапазону не требуется.
3. В неотсортированном массиве нужно один раз найти заданное значение.

??? success "Вариант ответа"

    1. Двоичный поиск: данные упорядочены и не меняются, время поиска — $O(\log n)$, дополнительная память не требуется.
    2. Хеш-таблица: если хеш-функция достаточно равномерно распределяет ключи по корзинам, вставка, удаление и поиск по ключу в среднем занимают $O(1)$.
    3. Пройдём массив от начала до конца. Для однократного поиска и сортировка, и построение хеш-таблицы потребовали бы предварительно обработать весь массив,
        поэтому общий объём работы не уменьшился бы.

        Выбор зависит от того, упорядочены ли данные, можно ли создавать дополнительные структуры, сколько будет запросов и какие операции понадобятся.

## 10.7.2 &nbsp; Задачи по программированию

### 1. &nbsp; Двоичный поиск в отсортированном массиве

Даны массив целых чисел `nums`, упорядоченный по строгому возрастанию, и искомое значение `target`. Найдите `target` двоичным поиском. Если значение есть в массиве, верните его индекс, иначе верните -1.

??? tip "Подсказки"

    1. Начальные границы интервала: left = 0 и right = n - 1. Интервал непуст, пока left <= right
    2. Вычислите индекс середины по формуле mid = left + (right - left) // 2
    3. Если `nums[mid]` меньше `target`, сдвиньте левую границу на `mid + 1`. Если `nums[mid]` больше `target`, сдвиньте правую границу на `mid - 1`. При равенстве сразу верните индекс середины

[LeetCode](https://leetcode.com/problems/binary-search/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; Позиция вставки в отсортированном массиве

Даны массив целых чисел `nums`, упорядоченный по строгому возрастанию, и искомое значение `target`.

Если `target` уже есть в массиве, верните его индекс. Иначе верните позицию, в которую можно вставить `target`, сохранив строго возрастающий порядок. Ответ может быть как нулём, так и длиной массива. Используйте двоичный поиск.

??? tip "Подсказки"

    1. Ответ может равняться 0 или длине массива n
    2. Если при поиске на замкнутом интервале `nums[mid]` больше или равно `target`, положите `right = mid - 1` и продолжайте поиск левее. В противном случае положите `left = mid + 1`
    3. После завершения цикла left указывает на позицию вставки

[LeetCode](https://leetcode.com/problems/search-insert-position/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
