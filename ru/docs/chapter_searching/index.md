# Поиск

![Поиск](../assets/covers/chapter_searching.jpg)

!!! abstract

    Поиск — путешествие в неизвестность. Порой приходится заглянуть в каждый уголок таинственного пространства, а порой цель удаётся отыскать почти сразу.
    
    На этом пути за каждым новым поворотом может ждать неожиданный ответ.
