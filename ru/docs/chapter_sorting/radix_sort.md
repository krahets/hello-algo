# 11.10 &nbsp; Поразрядная сортировка

В предыдущем разделе мы рассмотрели сортировку подсчётом. Она удобна, когда объём данных $n$ велик, а диапазон значений $m$ мал. Пусть нужно упорядочить $n = 10^6$ номеров учащихся, каждый длиной в $8$ цифр. Диапазон значений $m = 10^8$ тогда очень велик, и для сортировки подсчётом понадобится много памяти. Поразрядная сортировка позволяет этого избежать.

<u>Поразрядная сортировка (radix sort)</u>, как и сортировка подсчётом, упорядочивает данные с помощью подсчёта вхождений. При этом она учитывает старшинство разрядов: последовательно сортирует числа по каждой цифре и в итоге получает нужный порядок.

## 11.10.1 &nbsp; Ход алгоритма

Рассмотрим номера учащихся. Пусть младший разряд имеет номер $1$, а старший — $8$. На рисунке показан ход поразрядной сортировки.

1. Задаём начальный номер разряда $k = 1$.
2. Сортируем номера учащихся подсчётом по разряду $k$. После этого данные упорядочены по возрастанию цифры в разряде $k$.
3. Увеличиваем $k$ на $1$ и возвращаемся к шагу `2.`. Продолжаем, пока не обработаем все разряды.

Разберём реализацию. Пусть число $x$ записано в системе счисления с основанием $d$. Его цифру $x_k$ в разряде $k$ можно получить по формуле:

$$
x_k = \lfloor\frac{x}{d^{k-1}}\rfloor \bmod d
$$

Здесь $\lfloor a \rfloor$ означает округление числа с плавающей точкой $a$ вниз, а $\bmod \: d$ — взятие остатка по модулю $d$. Для номеров учащихся $d = 10$ и $k \in [1, 8]$.

Немного изменим код сортировки подсчётом, чтобы он сортировал числа по разряду $k$:

    ```python title="radix_sort.py"
    def digit(num: int, exp: int) -> int:
        """Получить k-ю цифру числа num, где exp = 10^(k-1)"""
        # Передаём exp вместо k, чтобы не повторять дорогое возведение в степень
        return (num // exp) % 10

    def counting_sort_digit(nums: list[int], exp: int):
        """Сортировка подсчётом по k-й цифре элементов nums"""
        # Десятичные цифры лежат в пределах 0–9, поэтому в массиве блоков 10 ячеек
        counter = [0] * 10
        n = len(nums)
        # Подсчитать вхождения каждой цифры от 0 до 9
        for i in range(n):
            d = digit(nums[i], exp)  # Получить k-ю цифру nums[i] и обозначить её d
            counter[d] += 1  # Подсчитать вхождения цифры d
        # Вычислить префиксные суммы, чтобы по частотам найти индексы в массиве
        for i in range(1, 10):
            counter[i] += counter[i - 1]
        # Пройти массив с конца и заполнить res по данным счётчиков
        res = [0] * n
        for i in range(n - 1, -1, -1):
            d = digit(nums[i], exp)
            j = counter[d] - 1  # Найти индекс j в массиве для цифры d
            res[j] = nums[i]  # Записать текущий элемент по индексу j
            counter[d] -= 1  # Уменьшить счётчик d на 1
        # Скопировать результат в исходный массив nums
        for i in range(n):
            nums[i] = res[i]

    def radix_sort(nums: list[int]):
        """Поразрядная сортировка"""
        # Найти максимум массива, чтобы определить наибольшее число разрядов
        m = max(nums)
        # Перебирать разряды от младшего к старшему
        exp = 1
        while exp <= m:
            # Отсортировать элементы подсчётом по k-й цифре
            # k = 1 -> exp = 1
            # k = 2 -> exp = 10
            # То есть exp = 10^(k-1)
            counting_sort_digit(nums, exp)
            exp *= 10
    ```

      // Передаём exp вместо k, чтобы не повторять дорогое возведение в степень
      return (_num ~/ exp) % 10;
    }

    /* Сортировка подсчётом по k-й цифре элементов nums */
    void countingSortDigit(List<int> nums, int exp) {
      // Десятичные цифры лежат в пределах 0–9, поэтому в массиве блоков 10 ячеек
      List<int> counter = List<int>.filled(10, 0);
      int n = nums.length;
      // Подсчитать вхождения каждой цифры от 0 до 9
      for (int i = 0; i < n; i++) {
        int d = digit(nums[i], exp); // Получить k-ю цифру nums[i] и обозначить её d
        counter[d]++; // Подсчитать вхождения цифры d
      }
      // Вычислить префиксные суммы, чтобы по частотам найти индексы в массиве
      for (int i = 1; i < 10; i++) {
        counter[i] += counter[i - 1];
      }
      // Пройти массив с конца и заполнить res по данным счётчиков
      List<int> res = List<int>.filled(n, 0);
      for (int i = n - 1; i >= 0; i--) {
        int d = digit(nums[i], exp);
        int j = counter[d] - 1; // Найти индекс j в массиве для цифры d
        res[j] = nums[i]; // Записать текущий элемент по индексу j
        counter[d]--; // Уменьшить счётчик d на 1
      }
      // Скопировать результат в исходный массив nums
      for (int i = 0; i < n; i++) nums[i] = res[i];
    }

      // В Dart тип int имеет длину 64 бита

        // k = 2 -> exp = 10
        // То есть exp = 10^(k-1)
        countingSortDigit(nums, exp);

!!! question "Почему сортировку начинают с младшего разряда?"

    При последовательных проходах порядок, установленный на следующем проходе, имеет приоритет над предыдущим. Например, если первый проход дал $a < b$, а второй — $a > b$, то результат второго заменяет результат первого. Поскольку старшие разряды важнее младших, сначала нужно сортировать по младшим, а затем по старшим.

## 11.10.2 &nbsp; Свойства алгоритма

В отличие от обычной сортировки подсчётом, поразрядная сортировка подходит для широкого диапазона значений. **При этом данные должны допускать запись с фиксированным, не слишком большим числом разрядов**. Например, числа с плавающей точкой подходят плохо: число разрядов $k$ слишком велико и может привести к временной сложности $O(nk) \gg O(n^2)$.

- **Временная сложность $O(nk)$, неадаптивная сортировка**. Пусть объём данных равен $n$, основание системы счисления — $d$, а максимальное число разрядов — $k$. Сортировка подсчётом по одному разряду занимает $O(n + d)$ времени, а по всем $k$ разрядам — $O((n + d)k)$. Обычно $d$ и $k$ относительно малы, и сложность приближается к $O(n)$.
- **Пространственная сложность $O(n + d)$, сортировка с дополнительной памятью**. Как и при сортировке подсчётом, нужны массивы `res` и `counter` длины $n$ и $d$ соответственно.
- **Устойчивая сортировка**. Если сортировка подсчётом устойчива, то и поразрядная сортировка устойчива. При неустойчивой сортировке подсчётом правильность результата поразрядной сортировки не гарантируется.
