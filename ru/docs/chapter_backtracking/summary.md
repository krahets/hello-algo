# 13.5 &nbsp; Итоги

### 1. &nbsp; Основные положения

- Поиск с возвратом — это перебор: алгоритм обходит пространство решений в глубину и находит варианты, удовлетворяющие условиям. Каждый подходящий вариант записывается. Поиск завершается, когда найдены все решения или закончился обход.
- Поиск с возвратом чередует пробу и возврат. Алгоритм пробует варианты в глубину. Если ограничение нарушено, он отменяет последний выбор, возвращается к предыдущему состоянию и пробует другие варианты. Проба и возврат — взаимно обратные операции.
- В задачах поиска с возвратом обычно есть несколько ограничений. По ним можно заранее отсечь ненужные ветви и тем самым значительно ускорить поиск.
- Поиск с возвратом применяют прежде всего в задачах поиска и удовлетворения ограничений. Он пригоден и для комбинаторной оптимизации, хотя здесь часто есть методы, которые работают быстрее или дают лучшие результаты.
- Задача о перестановках состоит в том, чтобы найти все возможные порядки элементов заданного набора. В массиве отмечаем уже выбранные элементы и отсекаем ветви, где один элемент был бы выбран повторно. Так каждый элемент используется лишь раз.
- Если в исходном наборе есть одинаковые элементы, в результат попадут повторяющиеся перестановки. На каждом отдельном шаге перебора нужно выбирать каждое значение не более одного раза. Для этого обычно используют хеш-множество.
- В задаче о сумме подмножества нужно найти все подмножества с заданной суммой. В множестве порядок элементов не важен, а поиск перебирает все порядки, из-за чего возникают повторы. До начала поиска отсортируем данные и заведём переменную, задающую начальную позицию перебора на каждом шаге. Это позволит отсечь ветви, порождающие повторы.
- В задаче о сумме подмножества одинаковые значения массива могут порождать одинаковые подмножества. Поскольку массив отсортирован, равные значения стоят рядом. Сравнивая соседние элементы, можно отсекать повторы и выбирать каждое значение лишь раз за шаг.
- В задаче о $n$ ферзях требуется расставить $n$ ферзей на доске $n \times n$ так, чтобы никакие два не били друг друга. Ограничения касаются строк, столбцов, прямых и обратных диагоналей. Чтобы выполнить ограничение по строкам, заполняем доску последовательно, ставя в каждую строку по одному ферзю.
- Ограничения по столбцам и диагоналям учитываются похожим образом. Массив занятых столбцов позволяет проверить, подходит ли выбранная клетка. Ещё два массива отмечают занятые прямые и обратные диагонали. Сложнее всего заметить, как связаны индексы строк и столбцов клеток одной прямой или одной обратной диагонали.

### 2. &nbsp; Q & A

**Вопрос**. Как связаны поиск с возвратом и рекурсия?

Поиск с возвратом — это алгоритмическая стратегия, а рекурсия — инструмент.

- Поиск с возвратом обычно реализуют с помощью рекурсии. Это один из способов применения рекурсии, в данном случае — к задачам поиска.
- Структура рекурсии отражает разбиение задачи на подзадачи. Рекурсию часто применяют в методе «разделяй и властвуй», поиске с возвратом и динамическом программировании (рекурсия с запоминанием).
