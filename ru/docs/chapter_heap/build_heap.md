# 8.2 &nbsp; Построение кучи

Иногда нужно построить кучу из всех элементов списка. Эту операцию называют построением кучи.

## 8.2.1 &nbsp; Построение последовательными вставками

Сначала создаём пустую кучу, затем перебираем список и по очереди вставляем каждый элемент: добавляем его в конец кучи и просеиваем снизу вверх.

С каждой вставкой длина кучи увеличивается на единицу. Узлы добавляются в бинарное дерево в порядке от верхних уровней к нижним, поэтому сама куча строится сверху вниз.

Пусть элементов $n$. Вставка одного элемента занимает время $O(\log{n})$, поэтому временная сложность такого построения равна $O(n \log n)$.

## 8.2.2 &nbsp; Построение просеиванием при обходе массива

Кучу можно построить эффективнее, всего за два шага.

1. Поместите все элементы списка в массив кучи в исходном порядке. Свойство кучи пока не обеспечено.
2. Обойдите массив в обратном порядке (обратном обходу дерева по уровням). Для каждого узла, кроме листьев, выполните просеивание сверху вниз.

**После просеивания узла поддерево с корнем в этом узле удовлетворяет свойству кучи**. Поскольку узлы перебираются в обратном порядке, куча строится снизу вверх.

Обратный порядок гарантирует, что поддеревья детей текущего узла уже являются кучами. Именно при этом условии просеивание корректно восстанавливает кучу с корнем в текущем узле.

**У листьев нет детей, поэтому каждый лист сам по себе уже образует кучу и не нуждается в просеивании**. Последний внутренний узел — родитель последнего узла дерева. Как видно в коде ниже, с него и начинают обратный обход с просеиванием:

=== "Python"

    ```python title="my_heap.py"
    def __init__(self, nums: list[int]):
        """Конструктор кучи по входному списку"""
        # Поместить элементы списка в кучу в прежнем порядке
        self.max_heap = nums
        # Выполнить просеивание для всех узлов, кроме листьев
        for i in range(self.parent(self.size() - 1), -1, -1):
            self.sift_down(i)
    ```

=== "Kotlin"

    ```kotlin title="my_heap.kt"
    /* Макс-куча */
    class MaxHeap(nums: MutableList<Int>?) {
        // Список, в отличие от массива, расширяется автоматически
        private val maxHeap = mutableListOf<Int>()

        /* Конструктор кучи по входному списку */
        init {
            // Поместить элементы списка в кучу в прежнем порядке
            maxHeap.addAll(nums!!)
            // Выполнить просеивание для всех узлов, кроме листьев
            for (i in parent(size() - 1) downTo 0) {
                siftDown(i)
            }
        }

        /* Индекс левого ребёнка */
        private fun left(i: Int): Int {
            return 2 * i + 1
        }

        /* Индекс правого ребёнка */
        private fun right(i: Int): Int {
            return 2 * i + 2
        }

        /* Индекс родителя */
        private fun parent(i: Int): Int {
            return (i - 1) / 2 // Целочисленное деление с округлением вниз
        }

        /* Поменять элементы местами */
        private fun swap(i: Int, j: Int) {
            val temp = maxHeap[i]
            maxHeap[i] = maxHeap[j]
            maxHeap[j] = temp
        }

        /* Размер кучи */
        fun size(): Int {
            return maxHeap.size
        }

        /* Проверить, пуста ли куча */
        fun isEmpty(): Boolean {
            /* Проверить, пуста ли куча */
            return size() == 0
        }

        /* Посмотреть элемент в корне */
        fun peek(): Int {
            return maxHeap[0]
        }

        /* Вставить элемент в кучу */
        fun push(_val: Int) {
            // Добавить узел
            maxHeap.add(_val)
            // Просеивание вверх
            siftUp(size() - 1)
        }

        /* Просеивать вверх от узла i */
        private fun siftUp(it: Int) {
            // Параметры функции в Kotlin неизменяемы, поэтому создаём временную переменную
            var i = it
            while (true) {
                // Найти родителя узла i
                val p = parent(i)
                // Если вышли за корень или узел уже на своём месте, завершить просеивание
                if (p < 0 || maxHeap[i] <= maxHeap[p]) break
                // Поменять два узла местами
                swap(i, p)
                // Продолжить просеивание вверх
                i = p
            }
        }

        /* Извлечь элемент из кучи */
        fun pop(): Int {
            // Проверить, пуста ли куча
            if (isEmpty()) throw IndexOutOfBoundsException()
            // Поменять местами корень и крайний правый лист (первый и последний элементы)
            swap(0, size() - 1)
            // Удалить узел
            val _val = maxHeap.removeAt(size() - 1)
            // Просеивание вниз
            siftDown(0)
            // Вернуть элемент из корня
            return _val
        }

        /* Просеивать вниз от узла i */
        private fun siftDown(it: Int) {
            // Параметры функции в Kotlin неизменяемы, поэтому создаём временную переменную
            var i = it
            while (true) {
                // Сохранить в ma индекс наибольшего из узлов i, l и r
                val l = left(i)
                val r = right(i)
                var ma = i
                if (l < size() && maxHeap[l] > maxHeap[ma]) ma = l
                if (r < size() && maxHeap[r] > maxHeap[ma]) ma = r
                // Если ни у одного потомка значение не больше, чем у родителя, завершить просеивание
                if (ma == i) break
                // Поменять два узла местами
                swap(i, ma)
                // Продолжить просеивание вниз
                i = ma
            }
        }

        /* Вывести кучу в виде бинарного дерева */
        fun print() {
            val queue = PriorityQueue { a: Int, b: Int -> b - a }
            queue.addAll(maxHeap)
            printHeap(queue)
        }
    }
    ```

## 8.2.3 &nbsp; Анализ сложности

Определим временную сложность второго способа построения кучи.

- Пусть в полном бинарном дереве $n$ узлов. Тогда листьев $(n + 1) / 2$, где $/$ означает целочисленное деление с округлением вниз. Следовательно, просеять нужно $n / 2$ узлов.
- При просеивании вниз узел может опуститься самое большее до листа, поэтому число итераций ограничено высотой бинарного дерева $\log n$.

Перемножив эти величины, получим оценку времени построения $O(n \log n)$. **Однако она завышена: мы не учли, что на нижних уровнях бинарного дерева гораздо больше узлов, чем на верхних**.

Проведём более точный расчёт. Для простоты возьмём совершенное бинарное дерево с $n$ узлами и высотой $h$. Это допущение не изменит итоговую оценку сложности.

![Число узлов на каждом уровне совершенного бинарного дерева](build_heap.assets/heapify_operations_count.svg){ class="animation-figure" }

<p align="center"> Рисунок 8-5 &nbsp; Число узлов на каждом уровне совершенного бинарного дерева </p>

Как видно на рисунке, максимальное число итераций просеивания вниз равно расстоянию от узла до листа, то есть высоте узла. Поэтому, сложив по всем уровням произведения «число узлов $\times$ высота узла», **получим суммарное число итераций просеивания всех узлов в худшем случае**.

$$
T(h) = 2^0h + 2^1(h-1) + 2^2(h-2) + \dots + 2^{(h-1)}\times1
$$

Упростим выражение с помощью знакомых из школы свойств последовательностей. Для начала умножим $T(h)$ на $2$:

$$
\begin{aligned}
T(h) & = 2^0h + 2^1(h-1) + 2^2(h-2) + \dots + 2^{h-1}\times1 \newline
2 T(h) & = 2^1h + 2^2(h-1) + 2^3(h-2) + \dots + 2^{h}\times1 \newline
\end{aligned}
$$

Вычтем со сдвигом предыдущее выражение $T(h)$ из полученного выражения $2 T(h)$:

$$
2T(h) - T(h) = T(h) = -2^0h + 2^1 + 2^2 + \dots + 2^{h-1} + 2^h
$$

Видим, что $T(h)$ представляет собой геометрическую прогрессию. Применив формулу её суммы, получаем оценку времени:

$$
\begin{aligned}
T(h) & = 2 \frac{1 - 2^h}{1 - 2} - h \newline
& = 2^{h+1} - h - 2 \newline
& = O(2^h)
\end{aligned}
$$

В совершенном бинарном дереве высоты $h$ число узлов равно $n = 2^{h+1} - 1$. Следовательно, сложность составляет $O(2^h) = O(n)$. Итак, **по готовому списку кучу можно построить очень эффективно, за время $O(n)$**.
