# Упражнения

## Вопросы для закрепления

### Как восстановить кучу после вставки числа 10?

Массив `[9, 7, 8, 3, 5]` представляет макс-кучу. Добавим в неё число 10.

<!-- numbered-subquestions -->

1. Сначала добавьте 10 в конец массива. Каково значение родителя нового узла?
2. Выполните просеивание вверх от нового узла. Запишите массив после каждого обмена.
3. Какой элемент окажется в корне? Сколько обменов понадобилось?

??? success "Вариант ответа"

    1. После добавления число 10 имеет индекс 5. Индекс его родителя равен
        $\lfloor(5-1)/2\rfloor=2$, а значение родителя равно 8.

    2. Число 10 больше 8. После первого обмена получаем `[9, 7, 10, 3, 5, 8]`.
        Число 10 больше и нового родителя, 9. После второго обмена получаем `[10, 7, 9, 3, 5, 8]`.
        Теперь число 10 достигло корня. Просеивание завершено.

    3. В корне оказалось число 10. Всего выполнено два обмена.

### Проверка отношений между родителями и детьми в мин-куче

Массив `[1, 4, 3, 7, 6, 2]` представляет полное бинарное дерево. В мин-куче значение каждого родителя не превышает значения ни одного из его детей.
У узла с индексом $i$ левый и правый дети имеют индексы $2i+1$ и $2i+2$ соответственно.

<!-- numbered-subquestions -->

1. Каковы индексы и значения детей узла с индексом 2?
2. В узле с индексом 2 записано число 3. Нарушается ли свойство мин-кучи между ним и его детьми? Если да, какие элементы нужно поменять местами?
3. Используя ответ на второй вопрос, запишите массив после обмена или объясните, почему обмен не требуется. Затем проверьте остальные пары «родитель — ребёнок».

??? success "Вариант ответа"

    1. У узла с индексом 2 левый ребёнок имеет индекс 5 и значение 2. Правому ребёнку соответствовал бы индекс 6, но длина массива равна 6, поэтому правого ребёнка нет.

    2. Значение родителя 3 больше значения ребёнка 2. Свойство мин-кучи нарушено, поэтому меняем местами элементы с индексами 2 и 5.

    3. После обмена получаем `[1, 4, 2, 7, 6, 3]`. Проверим все пары:
        `1 ≤ 4`, `1 ≤ 2`; `4 ≤ 7`, `4 ≤ 6`; `2 ≤ 3`.
        Значение каждого родителя не превышает значений его детей, поэтому теперь свойство мин-кучи выполнено.

### Отбор трёх наибольших чисел с помощью мин-кучи

Чтобы сохранить три наибольших числа из потока `[4, 1, 7, 3, 8]`, можно использовать мин-кучу размером не более трёх.

Сначала по очереди поместите в мин-кучу первые три числа. Когда куча заполнится, обрабатывайте каждое новое число по следующему правилу:
если оно больше корня, удалите корень и вставьте новое число. В противном случае оставьте кучу без изменений.

Для каждого прочитанного числа укажите, какие числа остались в куче и какое из них находится в корне.
Достаточно записать оставшиеся числа как множество. Их порядок в массиве кучи указывать не требуется.

??? success "Вариант ответа"

    После чтения каждого числа получаем следующие результаты:

    | Прочитанное число | Числа в куче | Корень кучи |
    | --- | --- | --- |
    | 4 | `{4}` | 4 |
    | 1 | `{1, 4}` | 1 |
    | 7 | `{1, 4, 7}` | 1 |
    | 3 | `{3, 4, 7}` | 3 |
    | 8 | `{4, 7, 8}` | 4 |

    Когда куча заполнена, в её корне находится наименьшее из сохранённых чисел. Только если новое число больше корня,
    заменяем им корень. В результате остаётся множество `{4, 7, 8}` — именно три наибольших числа.

## Задачи по программированию

### Поиск k-го по величине элемента массива

Даны целочисленный массив `nums` и целое число $k$, причём $1 \le k \le n$, где $n$ — длина массива. Верните элемент, который занял бы $k$-е место при упорядочении по убыванию.

Повторяющиеся элементы учитывайте по отдельности. Например, в массиве `[5, 5, 2]` второй по величине элемент тоже равен 5. Решите задачу с помощью мин-кучи размером не более $k$.

??? tip "Подсказки"

    1. k-й по величине элемент — наименьший среди k наибольших чисел
    2. Добавляйте каждое число в мин-кучу. Если её размер превышает k, извлекайте минимум
    3. После обхода в куче останутся k наибольших чисел, а в её корне будет ответ
