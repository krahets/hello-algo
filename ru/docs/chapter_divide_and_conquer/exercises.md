# Упражнения

## Вопросы для закрепления

### Для каких задач подходит метод «разделяй и властвуй»?

Ученик хочет решить следующие задачи по одной схеме: разделить задачу пополам, решить каждую половину отдельно и объединить результаты.
Для каждой задачи выберите одну из оценок: «метод подходит», «метод применим, но не сокращает объём работы» или «половины нельзя обработать независимо». Обоснуйте выбор.

<!-- numbered-subquestions -->

1. Отсортировать неупорядоченный массив.
2. Найти максимальный элемент массива.
3. Последовательно выполнить операции `push(x)` и `pop()` над стеком и вывести элемент, полученный при каждой операции `pop()`.

??? success "Вариант ответа"

    1. Метод подходит: разделим массив пополам, независимо отсортируем половины и сольём их за $O(n)$. Так работает сортировка слиянием.
    2. Метод применим, но не сокращает объём работы: в двух половинах в сумме всё равно придётся проверить все $n$ элементов,
        поэтому время составит $O(n)$, как и при обычном проходе по массиву.
    3. Половины нельзя обработать независимо: содержимое стека в начале второй половины зависит от результата первой,
        поэтому выполнить обе половины, не зная результата другой, нельзя.

### Как быстрое возведение в степень сокращает число вычислений?

Следующая рекурсивная функция вычисляет $x^n$ методом «разделяй и властвуй»:

```src
[file]{fast_power}-[class]{}-[func]{fast_pow}
```

Пусть `x = 3` и `n = 5`. Проследите за вычислением:

<!-- numbered-subquestions -->

1. Какие значения по очереди принимает параметр `n` при рекурсивных вызовах?
2. Какие значения по очереди возвращают вызовы, начиная с самого глубокого?
3. Почему стоит сохранить результат рекурсии в `half`, а не вызывать функцию для одной и той же подзадачи отдельно для каждого множителя?

??? success "Вариант ответа"

    1. Параметр принимает значения `5 → 2 → 1 → 0`: на каждом шаге показатель уменьшается вдвое, пока не выполнится условие остановки.

    2. При `n = 0` функция возвращает 1, при `n = 1` — $1×1×3=3$,
        при `n = 2` — $3×3=9$, а при `n = 5` — $9×9×3=243$.

    3. Если для каждого множителя отдельно вызвать функцию с одними и теми же аргументами, оба вызова выполнят одни и те же вычисления.
        Если сохранить результат в `half`, на каждом уровне понадобится всего один рекурсивный вызов, а глубина рекурсии составит примерно $\log n$.
        Два вызова на каждом уровне привели бы к многократному повторению вычислений.

### Как выделить левое и правое поддеревья по последовательностям обхода

Даны последовательности прямого и симметричного обходов двоичного дерева с различными значениями узлов:

- Прямой обход: `[A, B, D, E, C]`
- Симметричный обход: `[D, B, E, A, C]`

Выполните разбиение только на уровне корня. Продолжать рекурсию и рисовать всё дерево не требуется.

<!-- numbered-subquestions -->

1. Какой узел является корнем?
2. Какие части последовательности симметричного обхода соответствуют левому и правому поддеревьям?
3. Какие части последовательности прямого обхода соответствуют левому и правому поддеревьям? Какие узлы являются непосредственными потомками корня?

??? success "Вариант ответа"

    1. Первым при прямом обходе посещается корень, следовательно, корень — `A`.

    2. Узел `A` делит последовательность симметричного обхода на две части: `[D, B, E]` соответствует левому поддереву, `[C]` — правому.

    3. В левом поддереве 3 узла, поэтому в последовательности прямого обхода за корнем `A` идут 3 элемента левого поддерева,
        а именно `[B, D, E]`. Оставшаяся часть `[C]` принадлежит правому поддереву.
        Значит, левый потомок корня — `B`, а правый — `C`.

### Быстрое возведение в степень

Даны вещественное число `x` и целое число `n`. Вычислите $x^n$ без встроенной функции возведения в степень.
Примените рекурсивный метод «разделяй и властвуй»: каждый раз уменьшайте показатель вдвое и повторно используйте уже вычисленный результат подзадачи.
По условию $x^0=1$, в том числе при `x = 0`. Если `n < 0`, гарантируется, что `x != 0`, и ответ можно вычислить как $(1/x)^{-n}$.

??? tip "Подсказки"

    1. При n = 0 ответ равен 1
    2. Вычислив x в степени n // 2, сохраните результат в half, чтобы не вызывать функцию повторно
    3. При n < 0 сначала замените x на 1 / x, затем n на -n. В C++ и Java можно предварительно преобразовать n в 64-битное целое, чтобы избежать переполнения при смене знака минимального 32-битного целого
