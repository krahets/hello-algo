# 12.5 &nbsp; Итоги

### 1. &nbsp; Основные положения

- «Разделяй и властвуй» — распространённая стратегия проектирования алгоритмов. Она включает два этапа: разделение (разбиение) и решение (объединение). Обычно её реализуют рекурсивно.
- Чтобы понять, подходит ли метод, нужно проверить, делится ли задача на подзадачи, независимы ли они и можно ли объединить их решения.
- Сортировка слиянием — типичное применение этой стратегии. Массив рекурсивно делят на равные половины, пока не останется по одному элементу, а затем последовательно сливают подмассивы уровень за уровнем, получая отсортированный массив.
- Метод «разделяй и властвуй» часто ускоряет алгоритмы. Во-первых, разбиение сокращает число операций. Во-вторых, оно облегчает параллельное выполнение подзадач.
- Метод «разделяй и властвуй» помогает решать многие задачи. Его также широко используют при проектировании структур данных и алгоритмов.
- Адаптивный поиск эффективнее поиска перебором. Алгоритмы поиска с временной сложностью $O(\log n)$ обычно используют метод «разделяй и властвуй».
- Двоичный поиск — ещё один характерный пример. Решения подзадач объединять не нужно. Двоичный поиск можно реализовать рекурсивно методом «разделяй и властвуй».
- При построении двоичного дерева исходную задачу разбивают на построение левого и правого поддеревьев. Для этого выделяют соответствующие интервалы индексов в последовательностях прямого и симметричного обходов.
- В задаче о ханойских башнях задачу размера $n$ разбивают на две подзадачи размера $n-1$ и одну подзадачу размера $1$. Последовательно решая эти три подзадачи, получают решение исходной задачи.
