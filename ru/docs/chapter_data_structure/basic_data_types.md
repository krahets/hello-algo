# Базовые типы данных

Данные в компьютере могут иметь вид текста, изображений, видео, звука, трёхмерных моделей. Как бы ни различалась их организация, все они строятся из данных базовых типов.

**Базовые типы данных — типы, со значениями которых процессор может выполнять операции непосредственно**. Они используются и в алгоритмах. Рассмотрим основные типы.

- Целочисленные типы: `byte`, `short`, `int`, `long`.
- Типы с плавающей точкой `float` и `double` позволяют представлять числа с дробной частью.
- Символьный тип `char` используется для представления букв разных языков, знаков препинания и даже эмодзи.
- Логический тип `bool` позволяет представить ответ «да» или «нет».

**В компьютере значения базовых типов хранятся в двоичном виде**. Один двоичный разряд — это $1$ бит. В подавляющем большинстве современных операционных систем $1$ байт (byte) состоит из $8$ битов (bit).

Диапазон значений базового типа зависит от того, сколько места он занимает. Рассмотрим пример на Java.

- Целочисленный тип `byte` занимает $1$ байт = $8$ бит и может представлять $2^{8}$ различных значений.
- Целочисленный тип `int` занимает $4$ байта = $32$ бита и может представлять $2^{32}$ различных значений.

В таблице приведены размеры, диапазоны и значения по умолчанию для базовых типов Java. Заучивать таблицу не нужно. Достаточно понять общие закономерности и при необходимости сверяться с ней.

| ------ | -------- | -------- | ------------------------ | ----------------------- | -------------- |
| Целое число   | `byte`   | 1 байт   | $-2^7$ ($-128$)          | $2^7 - 1$ ($127$)       | $0$            |
|        | `short`  | 2 байта   | $-2^{15}$                | $2^{15} - 1$            | $0$            |
|        | `int`    | 4 байта   | $-2^{31}$                | $2^{31} - 1$            | $0$            |
|        | `long`   | 8 байт   | $-2^{63}$                | $2^{63} - 1$            | $0$            |
| Число с плавающей точкой | `float`  | 4 байта   | $1.175 \times 10^{-38}$  | $3.403 \times 10^{38}$  | $0.0\text{f}$  |
|        | `double` | 8 байт   | $2.225 \times 10^{-308}$ | $1.798 \times 10^{308}$ | $0.0$          |

| Логическое значение   | `bool`   | 1 байт   | $\text{false}$           | $\text{true}$           | $\text{false}$ |

Таблица описывает базовые типы Java. В других языках типы определяются по-своему, поэтому их размеры, диапазоны и значения по умолчанию могут отличаться.

- В Python целое число типа `int` может иметь любой размер в пределах доступной памяти. Тип `float` — 64-битное число двойной точности. Отдельного типа `char` нет, один символ представляет собой строку `str` длины 1.
- В C и C++ точные размеры базовых типов зависят от реализации и платформы. Для приведённых выше размеров в 64-битных Unix-системах, включая Linux и macOS, используется [модель данных](https://en.cppreference.com/w/cpp/language/types#Properties) LP64.
- В C и C++ размер `char` равен 1 байту. В большинстве языков размер представления символа зависит от кодировки. Подробнее об этом — в разделе «Кодирование символов».
- Хотя для логического значения достаточно одного бита ($0$ или $1$), в памяти оно обычно занимает один байт, поскольку в современных компьютерах наименьшая адресуемая единица памяти, как правило, равна байту.

Как связаны базовые типы данных и структуры данных? Мы уже знаем, что структура данных — это способ организации и хранения данных в компьютере. Главное слово здесь — «структура».

Чтобы представить ряд чисел, естественно выбрать массив. Его линейная структура передаёт соседство чисел и их порядок. А будут ли храниться в массиве целые числа `int`, дробные числа `float` или символы `char`, от самой структуры не зависит.

Иными словами, **базовый тип задаёт, что хранится, а структура данных — как это организовано**. В следующем примере одна и та же структура, массив, используется для хранения значений разных базовых типов, в том числе `int`, `float`, `char` и `bool`.
