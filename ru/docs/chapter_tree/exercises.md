# 7.7 &nbsp; Упражнения

## 7.7.1 &nbsp; Вопросы для закрепления

### 1. &nbsp; Полные, строгие и совершенные двоичные деревья

Два массива ниже задают двоичные деревья в порядке обхода по уровням. Символ `None` обозначает пустую позицию:

- Дерево A: `[1, 2, 3, 4, 5, 6]`
- Дерево B: `[1, 2, 3, None, None, 6, 7]`

<!-- numbered-subquestions -->

1. Какое из деревьев полное?
2. Какое из деревьев строгое, то есть у каждого его внутреннего узла ровно два потомка?
3. Есть ли среди них совершенное дерево? Обоснуйте ответ для каждого дерева.

??? success "Вариант ответа"

    1. Дерево A полное. Только последний уровень заполнен частично, и его узлы расположены слева направо без пропусков.
        Дерево B не полное: на последнем уровне есть пустые позиции слева от занятых.

    2. Дерево B строгое: у узлов 1 и 3 по два потомка, а все остальные узлы — листья.
        Дерево A не строгое: у узла 3 есть только левый потомок 6.

    3. Ни одно из деревьев не является совершенным, поскольку у обоих последний уровень заполнен лишь частично.

### 2. &nbsp; Три порядка обхода одного дерева

Заполните полное двоичное дерево элементами массива `[1, 2, 3, 4, 5, 6, 7]` в порядке обхода по уровням.

<!-- numbered-subquestions -->

1. Нарисуйте это дерево.
2. Запишите последовательности узлов при прямом, симметричном и обратном обходах.
3. Каким частям дерева соответствуют участки последовательности симметричного обхода слева и справа от корня 1?

??? success "Вариант ответа"

    1. Получится следующее дерево:

        ```text
              1
            /   \
           2     3
          / \   / \
         4   5 6   7
        ```

    2. Прямой обход: `1, 2, 4, 5, 3, 6, 7`.
        Симметричный обход: `4, 2, 5, 1, 6, 3, 7`.
        Обратный обход: `4, 5, 2, 6, 7, 3, 1`.

    3. Слева от корня 1 находится `4, 2, 5` — последовательность симметричного обхода левого поддерева.
        Справа находится `6, 3, 7` — последовательность симметричного обхода правого поддерева.

### 3. &nbsp; Сравнение двух двоичных деревьев поиска

Для каждой из следующих последовательностей начните с пустого двоичного дерева поиска и вставьте элементы по порядку слева направо:

- Последовательность A: `[4, 2, 6, 1, 3, 5, 7]`
- Последовательность B: `[1, 2, 3, 4, 5, 6, 7]`

<!-- numbered-subquestions -->

1. Для каждого дерева запишите узлы, через которые проходит поиск числа 7.
2. Какова высота каждого дерева, если измерять её числом рёбер на пути от корня до самого удалённого листа?
3. С учётом ответов на первые два вопроса определите, одинаково ли эффективен поиск числа 7 в этих деревьях. Объясните ответ, опираясь на форму деревьев и пути поиска.

??? success "Вариант ответа"

    1. В дереве для последовательности A путь поиска таков: `4 → 6 → 7`.
        В дереве для последовательности B путь поиска таков: `1 → 2 → 3 → 4 → 5 → 6 → 7`.

    2. У первого дерева все уровни заполнены, и его высота равна 2. У второго есть только правые потомки, и его высота равна 6.

    3. Эффективность поиска числа 7 различна. Порядок вставки влияет на форму и высоту двоичного дерева поиска. В первом дереве при поиске 7 достаточно посетить 3 узла,
        а во втором приходится последовательно посетить 7 узлов. Чем выше дерево, тем больше узлов на пути поиска приходится проверять в худшем случае.

## 7.7.2 &nbsp; Задачи по программированию

### 1. &nbsp; Максимальная глубина двоичного дерева

Дан корень `root` двоичного дерева. Каждый узел содержит целое число и ссылки на левого и правого потомков.

Максимальная глубина двоичного дерева — это **число узлов** на пути от корня до самого удалённого листа. Верните максимальную глубину дерева. Глубина пустого дерева равна 0.
Решите задачу с помощью рекурсии.

??? tip "Подсказки"

    1. В этой задаче глубину измеряют в узлах: если в дереве есть только корень, максимальная глубина равна 1
    2. Пусть рекурсивная функция возвращает максимальную глубину поддерева с корнем в текущем узле
    3. Для пустого узла верните 0, для непустого — max(depth(left), depth(right)) + 1

[LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; Обход двоичного дерева по уровням

Дан корень `root` двоичного дерева. С помощью очереди посетите все узлы по уровням сверху вниз, а внутри каждого уровня — слева направо.

Верните двумерный массив. В первом подмассиве должны находиться значения узлов на уровне корня, во втором — на следующем уровне и так далее.
Если дерево пусто, верните пустой массив.

??? tip "Подсказки"

    1. При обходе по уровням узлы посещают в порядке поступления, поэтому удобно использовать очередь
    2. В начале каждой итерации в очереди находятся узлы ровно одного уровня
    3. Сначала запомните длину очереди, затем извлеките из неё именно столько узлов, добавляя в очередь их потомков

[LeetCode](https://leetcode.com/problems/binary-tree-level-order-traversal/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 3. &nbsp; k-й наименьший элемент двоичного дерева поиска

В двоичном дереве поиска `n` узлов, и все их значения различны.
Упорядочим значения узлов по возрастанию и пронумеруем их позиции начиная с 1.

Даны корень дерева `root` и целое число `k`, для которого `1 <= k <= n`. Верните значение узла на позиции `k`.
Найдите ответ непосредственно во время симметричного обхода, без предварительного сбора всех значений.

??? tip "Подсказки"

    1. При симметричном обходе двоичного дерева поиска значения узлов идут по возрастанию
    2. При симметричном обходе сначала обрабатывают левое поддерево, затем текущий узел, затем правое поддерево. При посещении текущего узла увеличьте счётчик на 1
    3. Когда счётчик впервые достигнет k, ответом будет значение текущего узла. На этом обход можно завершить

[LeetCode](https://leetcode.com/problems/kth-smallest-element-in-a-bst/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
