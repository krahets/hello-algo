# Упражнения

## Вопросы для закрепления

### Два способа представить один и тот же граф

У неориентированного графа четыре вершины `A, B, C, D` и рёбра
`A-B, A-C, B-C, C-D`.

<!-- numbered-subquestions -->

1. Составьте список смежности графа.
2. Заполните матрицу смежности, используя только 0 и 1.
3. Какое представление позволяет проверить, соединены ли `A` и `D` ребром, по одному элементу структуры данных?
4. Если в графе много вершин, но мало рёбер, какое представление обычно занимает меньше памяти?

??? success "Вариант ответа"

    1. Список смежности имеет следующий вид:

        ```text
        A: B, C
        B: A, C
        C: A, B, D
        D: C
        ```

    2. Матрица смежности имеет следующий вид:

        | | A | B | C | D |
        | --- | --- | --- | --- | --- |
        | A | 0 | 1 | 1 | 0 |
        | B | 1 | 0 | 1 | 0 |
        | C | 1 | 1 | 0 | 1 |
        | D | 0 | 0 | 1 | 0 |

    3. В матрице смежности можно сразу посмотреть элемент на пересечении строки `A` и столбца `D`. Поэтому матрица удобна для проверки того, соединены ли ребром любые две выбранные вершины.

    4. Если вершин много, а рёбер мало, список смежности обычно занимает меньше памяти. В нём хранятся только существующие рёбра, а в матрице смежности под каждую пару вершин отводится отдельная ячейка.

### Порядок посещения вершин при обходе в ширину и в глубину

У неориентированного графа вершины `A, B, C, D, E` и рёбра
`A-B, A-C, B-D, C-D, D-E`.

Начните обход с вершины A. Если есть несколько ещё не посещённых соседних вершин, выбирайте их в алфавитном порядке.

<!-- numbered-subquestions -->

1. Запишите порядок посещения вершин при поиске в ширину (BFS).
2. Запишите порядок посещения вершин при рекурсивном поиске в глубину (DFS).
3. Почему при обоих обходах нужно отмечать уже посещённые вершины?

??? success "Вариант ответа"

    1. При BFS порядок посещения вершин такой: `A, B, C, D, E`. Сначала обход достигает B и C, до которых от A одно ребро,
        а затем D и E, которые находятся дальше.

    2. При DFS порядок посещения вершин такой: `A, B, D, C, E`. Из текущей вершины алгоритм по очереди переходит к ещё не посещённым соседям,
        поэтому сначала проходит по пути `A → B → D → C`. Когда у C не остаётся непосещённых соседей, алгоритм возвращается в D и переходит к E.

    3. В графе есть цикл, например `A-B-D-C-A`. Если не отмечать посещённые вершины,
        обход может так и не завершиться, раз за разом проходя по циклу через одни и те же вершины.

### Можно ли обойти весь граф за один запуск BFS?

У неориентированного графа вершины `A, B, C, D, E, F` и только следующие рёбра:
`A-B, B-C, D-E`.

<!-- numbered-subquestions -->

1. Какие вершины можно посетить за один запуск BFS из A?
2. Судя по ответу на первый вопрос, все ли вершины графа удалось посетить за этот запуск BFS? Почему?
3. Перебирайте все вершины в алфавитном порядке. Каждый раз, когда встречаете ещё не посещённую вершину, начинайте из неё новый поиск в ширину.
    С каких вершин начинаются отдельные обходы? На сколько не связанных между собой частей (компонент связности) разбивается граф?

??? success "Вариант ответа"

    1. Из A можно посетить только вершины `A, B, C`.

    2. Нет. Вершины `D, E` связаны между собой и образуют отдельную компоненту связности, а F — изолированная вершина.
        Из A ни к одной из этих трёх вершин нет пути, поэтому при обходе из A они недостижимы.

    3. Три обхода BFS начинаются по порядку с вершин `A, D, F`. Множества посещённых при этих обходах вершин —
        `{A, B, C}`, `{D, E}` и `{F}` соответственно. Таким образом, в графе три компоненты связности.

## Задачи по программированию

### Существует ли путь в неориентированном графе?

Дан неориентированный граф с $n$ вершинами, пронумерованными от $0$ до $n-1$. Каждый элемент `[u, v]` массива `edges` задаёт неориентированное ребро между вершинами `u` и `v`.

Также заданы начальная вершина `source` и конечная вершина `destination`. Постройте список смежности по `edges`, затем с помощью BFS или DFS
определите, существует ли путь из `source` в `destination`. Если путь есть, верните `true`, иначе верните `false`.
Граф может содержать циклы и может быть несвязным.

??? tip "Подсказки"

    1. Каждое неориентированное ребро нужно добавить в обоих направлениях
    2. В графе возможны циклы, поэтому нужно отмечать посещённые вершины
    3. Начните с source. Если встретите destination, верните true. Если обход закончился, а destination не встретилась, верните false
