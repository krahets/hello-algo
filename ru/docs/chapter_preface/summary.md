# Итоги

### Главное в этой главе

- Книга адресована прежде всего тем, кто только знакомится с алгоритмами. Если у вас уже есть базовые знания, она поможет систематически их повторить, а примеры кода пригодятся как набор инструментов для решения задач.
- Три основные части книги — анализ сложности, структуры данных и алгоритмы. Вместе они охватывают большинство тем этой области.
- Хорошая вводная книга особенно важна в начале пути: она помогает избежать многих ненужных трудностей.
- Анимированные схемы обычно объясняют самые важные и трудные идеи. Уделяйте им особое внимание при чтении.
- Практика — лучший способ научиться программировать. Обязательно запускайте примеры и пробуйте писать код самостоятельно.
- В каждом разделе веб-версии есть место для комментариев. Делитесь вопросами и наблюдениями в любое время.
