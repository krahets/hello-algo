# Упражнения

## Вопросы для закрепления

### Какой элемент извлекается первым из стека, а какой — из очереди?

Возьмите пустой стек `S` и пустую очередь `Q`. Для каждого из них выполните следующие шаги.

Шаг 1. Добавьте `A`.
Шаг 2. Добавьте `B`.
Шаг 3. Извлеките один элемент и запишите его.
Шаг 4. Добавьте `C`.
Шаг 5. Извлекайте элементы по одному и записывайте каждый, пока контейнер не опустеет.

Запишите, в каком порядке извлекаются элементы из `S` и из `Q`. Объясните разницу, выбрав для каждой структуры подходящее правило: «последним пришёл — первым вышел» или «первым пришёл — первым вышел».

??? success "Вариант ответа"

    Из стека `S` элементы извлекаются в порядке `B, C, A`. После добавления элементов `A, B` извлекаем элемент `B`, добавленный последним. Затем добавляем `C`
    и по очереди извлекаем оставшиеся элементы `C, A`. Так работает правило «последним пришёл — первым вышел».

    Из очереди `Q` элементы извлекаются в порядке `A, B, C`. После добавления элементов `A, B` извлекаем элемент `A`, добавленный первым.
    Затем добавляем `C` и по очереди извлекаем оставшиеся элементы `B, C`. Так работает правило «первым пришёл — первым вышел».

### Куда добавить элемент, если хвост очереди достиг конца массива?

Очередь реализована на кольцевом массиве длины 5. Диапазон индексов массива — `0–4`.
Сейчас `front = 3`, `size = 2`. Элементы очереди `A, B` находятся в ячейках с индексами 3 и 4 соответственно.

<!-- numbered-subquestions -->

1. В очередь добавляют элемент `C`. По какому индексу нужно записать `C`? Чему будет равно `size` после добавления?
2. Теперь извлеките один элемент из очереди. Какой это элемент? Чему теперь равны `front` и `size`?
3. В каком порядке теперь расположены элементы от начала очереди до её конца? Нужно ли при извлечении элемента перемещать другие элементы массива? Почему?

??? success "Вариант ответа"

    1. Вычислим индекс нового элемента по формуле
        `(front + size) % 5 = (3 + 2) % 5 = 0`.
        Поэтому запишем `C` в ячейку с индексом 0. После добавления `size = 3`.

    2. Из начала очереди извлекаем элемент `A`. Вычислим новый индекс начала очереди:
        `(3 + 1) % 5 = 4`. Теперь `front = 4`, `size = 2`.

    3. Элементы очереди идут в порядке `B, C`. Элемент `B` находится в ячейке с индексом 4, а `C` — в ячейке с индексом 0.
        При извлечении элемента достаточно сдвинуть `front` на одну позицию и уменьшить `size` на единицу. Благодаря операции взятия остатка после последней ячейки кольцевого массива индекс возвращается к нулю,
        поэтому сдвигать остальные элементы к началу массива не нужно.

### Операции на обоих концах дека

Будем обозначать через `push_first` добавление в начало дека, а через `push_last` — добавление в конец.
Тогда `pop_first` обозначает извлечение из начала, а `pop_last` — извлечение с конца.

Над пустым деком `deq` последовательно выполняют следующие операции.

1. `push_last(A)`
2. `push_last(B)`
3. `push_first(C)`
4. `pop_last()`
5. `push_last(D)`
6. `pop_first()`

<!-- numbered-subquestions -->

1. Какие элементы вернули две операции извлечения?
2. Какие элементы остались в деке после всех операций, если перечислить их от начала к концу?
3. Рассмотрите все шесть шагов. Можно ли выполнить их с очередью, в которой разрешено добавлять элементы только в конец и удалять только из начала? Если нельзя, укажите, какие операции выполнить не удастся. Можно ли выполнить все шаги с деком и почему?

??? success "Вариант ответа"

    После первых трёх шагов содержимое дека от начала к концу имеет вид `[C, A, B]`.

    <!-- numbered-subquestions -->

    1. Вызов `pop_last()` извлекает `B`. После добавления `D` дек принимает вид `[C, A, D]`,
        а затем `pop_first()` извлекает `C`.

    2. В итоге остаются `[A, D]`.

    3. Очередь, в которой элементы добавляют только в конец и удаляют только из начала, не позволяет выполнить все операции.
        На шаге 3 вызов `push_first(C)` требует добавить элемент в начало, а на шаге 4 вызов `pop_last()` требует удалить элемент с конца. Обе операции для такой очереди недоступны.
        В деке добавлять и удалять элементы можно с обоих концов, поэтому с ним можно выполнить все шесть шагов.

## Задачи по программированию

### Проверка скобочной последовательности

Дана строка `s`, состоящая только из скобок трёх типов: `()`, `[]` и `{}`. С помощью стека определите, образуют ли они правильную скобочную последовательность.

Для этого должны выполняться оба условия: каждая закрывающая скобка должна совпадать по типу с ближайшей предшествующей открывающей скобкой, у которой ещё нет пары,
а к концу обхода не должно остаться открывающих скобок без пары. Верните результат проверки в виде логического значения.

??? tip "Подсказки"

    1. Можно сопоставить каждой закрывающей скобке соответствующую открывающую
    2. Встретив закрывающую скобку, сначала проверьте, не пуст ли стек, а затем — подходит ли скобка на его вершине
    3. После обхода стек тоже должен быть пуст
