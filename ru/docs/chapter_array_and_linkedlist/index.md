# Массивы и связные списки

![Массивы и связные списки](../assets/covers/chapter_array_and_linkedlist.jpg)

!!! abstract

    Мир структур данных напоминает прочную кирпичную стену.

    Кирпичи массива уложены ровно и вплотную друг к другу. Кирпичи связного списка разбросаны по разным местам, а соединяющие их побеги свободно вьются между кирпичами.
