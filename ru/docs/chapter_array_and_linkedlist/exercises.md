# 4.6 &nbsp; Упражнения

## 4.6.1 &nbsp; Вопросы для закрепления

### 1. &nbsp; Как обратиться к элементу массива и связного списка

В массиве и в односвязном списке элементы записаны в порядке `[A, B, C, D, E]`. Нужно прочитать четвёртый элемент `D`.

<!-- numbered-subquestions -->

1. По какому индексу можно сразу обратиться к элементу массива?
2. Через какие узлы нужно пройти в односвязном списке, если начать с головного узла `A` и переходить по ссылкам `next`?
3. Как меняется число шагов для каждой структуры по мере удаления нужного элемента от начала? Какая структура лучше подходит для частого чтения по позиции и почему?

??? success "Вариант ответа"

    1. При нумерации с нуля четвёртый элемент имеет индекс 3, поэтому в массиве можно сразу прочитать `arr[3]`.

    2. В односвязном списке нужно начать с головы. Путь `A → B → C → D` требует трёх переходов по ссылке `next`.

    3. Адрес элемента массива можно вычислить по начальному адресу и индексу, поэтому доступ по позиции занимает время $O(1)$.
        Чтобы найти узел с порядковым номером $k$ в односвязном списке, нужно начать с головы и пройти по ссылке `next` ровно $k-1$ раз.
        В худшем случае это занимает время $O(n)$.

        Здесь мы сравниваем только чтение по позиции. Из этого сравнения нельзя заключить, что связный список медленнее при любой операции.

### 2. &nbsp; Как вставить элемент в массив и связный список

В массиве и в односвязном списке хранятся `A, B, C, D`. Требуется после `B` вставить `X`.

- Ёмкость массива равна 5, его текущее состояние — `[A, B, C, D, _]`.
- Связный список имеет вид `A → B → C → D`, и у нас уже есть ссылка на узел `B`.

<!-- numbered-subquestions -->

1. Какие элементы массива придётся сдвинуть? Запишите массив после вставки.
2. В каком порядке следует изменить `X.next` и `B.next`? Запишите связный список после вставки.
3. Почему при сравнении эффективности вставки важно уточнить, что ссылка на узел B уже известна?

??? success "Вариант ответа"

    1. Сначала сдвигаем `D` на одну позицию вправо, затем так же сдвигаем `C` и записываем `X` по индексу 2.
        Получаем `[A, B, X, C, D]`.

    2. Изначально `B.next` указывает на `C`. Сначала выполняем `X.next = B.next`, чтобы `X` указывал на `C`.
        Затем выполняем `B.next = X`. Получаем `A → B → X → C → D`.
        Если сначала перезаписать `B.next`, не сохранив прежнюю связь, можно потерять доступ к `C`.

    3. Когда положение `B` известно, для вставки достаточно изменить две связи. Это занимает время $O(1)$.
        Если сначала нужно найти `B`, двигаясь от головы, сам поиск может занять время $O(n)$.

### 3. &nbsp; Как растёт ёмкость списка

Список на основе массива содержит `[A, B, C]`. Его длина — `size = 3`, ёмкость — `capacity = 4`.
Если места не хватает, создаётся массив вдвое большей ёмкости.

<!-- numbered-subquestions -->

1. Какими будут длина и ёмкость списка после добавления `D` в конец? Потребуется ли увеличить ёмкость?
2. Какой станет ёмкость при следующем добавлении, когда в конец запишут `E`? Сколько прежних элементов придётся скопировать?
3. Длина массива, лежащего в основе списка, фиксирована. Как же растёт ёмкость списка?

??? success "Вариант ответа"

    1. Элемент `D` помещается в последнюю свободную ячейку. Теперь список содержит `[A, B, C, D]`.
        При этом `size = 4` и `capacity = 4`. Увеличивать ёмкость не требуется.

    2. При добавлении `E` свободных ячеек уже нет. Нужно создать новый массив ёмкостью 8,
        скопировать в него четыре прежних элемента `A, B, C, D`, затем добавить `E`.
        Теперь `size = 5` и `capacity = 8`.

    3. Длина исходного массива осталась прежней. Список создаёт массив большего размера, копирует в него прежние элементы
        и использует новый массив для хранения данных. С точки зрения пользователя ёмкость списка выросла.

## 4.6.2 &nbsp; Задачи по программированию

### 1. &nbsp; Прибавление единицы к большому целому числу, заданному массивом

В массиве `digits` слева направо записаны цифры неотрицательного целого числа. Например, `[3, 0, 8]` обозначает число 308.
Нуль представлен массивом `[0]`. У остальных входных чисел первая цифра отлична от нуля.

Смоделируйте сложение в столбик в десятичной системе: прибавьте к числу 1 и верните результат в виде такого же массива цифр.
Можно менять сам массив `digits`. Если появится перенос в новый старший разряд, можно вернуть более длинный массив.

??? tip "Подсказки"

    1. Начните с последней цифры массива, как при сложении в столбик.
    2. Если текущая цифра меньше 9, прибавьте к ней единицу и сразу верните результат.
    3. Если текущая цифра равна 9, замените её нулём. Если все цифры равны 9, добавьте в начало единицу.

[LeetCode](https://leetcode.com/problems/plus-one/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }

### 2. &nbsp; Разворот односвязного списка

Дан головной узел `head` односвязного списка. Каждый узел содержит значение и ссылку `next` на следующий узел.

Итеративно измените направление всех связей между узлами на противоположное и верните новый головной узел.
Используйте только существующие узлы списка.

??? tip "Подсказки"

    1. Сначала нарисуйте на бумаге три связанных узла и два указателя prev и cur.
    2. Прежде чем изменить cur.next, сохраните ссылку на следующий узел в nxt.
    3. Развернув ссылку cur.next, выполните prev = cur, затем cur = nxt и перейдите к обработке следующего узла исходного списка.

[LeetCode](https://leetcode.com/problems/reverse-linked-list/){ .rounded-button .exercise-button target="_blank" rel="noopener noreferrer" }
