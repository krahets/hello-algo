11.7   Пирамидальная сортировка¶

Tip

Перед чтением этого раздела изучите главу «Куча».

Пирамидальная сортировка (heap sort) — эффективный алгоритм, основанный на структуре данных «куча». Его можно реализовать с помощью уже знакомых операций построения кучи и извлечения её вершины.

  1. Построим из входного массива минимальную кучу. На её вершине окажется наименьший элемент.
  2. Будем извлекать вершину и записывать извлечённые элементы по порядку. Получим последовательность от меньшего к большему.

Этот способ работает, но для хранения извлечённых элементов нужен отдельный массив, что увеличивает расход памяти. На практике обычно применяют более изящный способ.

11.7.1   Ход алгоритма¶

Пусть длина массива равна \(n\). На рисунке показан ход пирамидальной сортировки.

  1. Построим из входного массива максимальную кучу. На вершине окажется наибольший элемент.
  2. Поменяем местами вершину (первый элемент) и конец кучи (последний элемент). После обмена длина кучи уменьшается на \(1\), а число отсортированных элементов увеличивается на \(1\).
  3. Начиная с вершины, выполним просеивание вниз (sift down). После него свойство кучи восстановится.
  4. Повторяем шаги 2. и 3.. После \(n - 1\) проходов массив будет отсортирован.

Tip

Шаги 2. и 3. входят и в операцию извлечения вершины. В ней дополнительно удаляют извлечённый элемент.

Рисунок 11-12   Шаги пирамидальной сортировки

Иллюстрация 11-12: Пирамидальная сортировка на месте: перенос максимумов в правую часть массива

Построив максимальную кучу, меняем её вершину с последним элементом действующей кучи и сокращаем кучу. Повторяя эти действия, упорядочиваем шесть элементов: [1, 1, 2, 3, 4, 5].

Рисунок начинается с уже построенной кучи [5, 4, 3, 1, 1, 2]. Исходный порядок до построения не показан. В максимальной куче значение любого родителя не меньше значений его детей, поэтому после восстановления свойства кучи в корне находится максимум действующей кучи.

Двоичное дерево слева вверху и массив под ним соответствуют друг другу при обходе по уровням. Индексация начинается с 0. Левый и правый дети узла i имеют индексы 2i+1 и 2i+2. К куче принадлежат только индексы в её действующих границах. Зелёные узлы образуют действующую кучу, серые — отсортированный участок справа.

При каждом извлечении сначала меняем вершину с последним, крайним правым, элементом действующей кучи. Текущий максимум присоединяется к серому отсортированному суффиксу справа. Затем выполняем просеивание вниз (sift down) только в укороченном зелёном префиксе.

Когда узел становится серым и входит в отсортированный участок, ведущее к нему ребро слева исчезает: узел больше не участвует в сравнениях при просеивании. В нижнем массиве элемент остаётся на месте. Сокращение кучи не удаляет элементы из массива.

  1. Начальная максимальная куча построена

    Действующая куча занимает позиции с 0 по 5. Корень — 5 с индексом 0, его дети — 4 и 3. Оба ребёнка узла 4 равны 1. Левый ребёнок узла 3 — последний элемент кучи, 2. Сейчас nums = [5, 4, 3, 1, 1, 2], отсортированного суффикса ещё нет.

  2. Обмен вершины 5 с последним элементом массива

    Меняем местами вершину 5 с индексом 0 и последний элемент 2 с индексом 5. Максимум 5 закрепляется на последней позиции 5 и становится серым. Новый корень 2 меньше своих детей 4 и 3, поэтому потребуется просеивание вниз. Сейчас nums = [2, 4, 3, 1, 1, 5], действующая куча занимает [0, 4], отсортированный суффикс — [5].

  3. Просеивание вниз восстанавливает максимальную кучу из пяти элементов

    Корень 2 меньше большего ребёнка 4, поэтому свойство кучи нарушено. Среди корня 2 и его детей 4 и 3 выбираем наибольший узел 4 и меняем его местами с корнем. На позиции 1 число 2 уже не меньше обоих детей со значениями 1. Дальше опускать его не нужно: максимальная куча из пяти элементов восстановлена. Сейчас nums = [4, 2, 3, 1, 1, 5], действующая куча занимает [0, 4], отсортированный суффикс — [5].

  4. Обмен перемещает вершину 4 на позицию 4

    Меняем вершину 4 и единицу в конце действующей кучи (индекс 4). Число 4 закрепляется на позиции 4. Новый корень 1 меньше обоих детей, 2 и 3. Сейчас nums = [1, 2, 3, 1, 4, 5], действующая куча занимает [0, 3], отсортированный суффикс — [4, 5].

  5. Просеивание вниз восстанавливает максимальную кучу из четырёх элементов

    Корень 1 меньше большего ребёнка 3, поэтому свойство кучи нарушено. Сравниваем корень 1 с детьми 2 и 3. Правый ребёнок 3 — наибольший, меняем его местами с корнем. Единица спускается на позицию 2 и становится листом. Максимальная куча из четырёх элементов восстановлена. Сейчас nums = [3, 2, 1, 1, 4, 5], действующая куча занимает [0, 3], отсортированный суффикс — [4, 5].

  6. Обмен перемещает вершину 3 на позицию 3

    Меняем вершину 3 с единицей в конце действующей кучи (индекс 3). Число 3 закрепляется на левом краю отсортированного суффикса. Корень 1 теперь меньше левого ребёнка 2. Сейчас nums = [1, 2, 1, 3, 4, 5], действующая куча занимает [0, 2], отсортированный суффикс — [3, 4, 5].

  7. Просеивание вниз восстанавливает максимальную кучу из трёх элементов

    Корень 1 меньше большего ребёнка 2, поэтому свойство кучи нарушено. Сравниваем корень 1 с детьми 2 и 1. Левый ребёнок 2 — наибольший, меняем его местами с корнем и восстанавливаем кучу [2, 1, 1]. Сейчас nums = [2, 1, 1, 3, 4, 5], действующая куча занимает [0, 2], отсортированный суффикс — [3, 4, 5].

  8. Обмен перемещает вершину 2 на позицию 2

    Меняем вершину 2 с единицей в конце действующей кучи (индекс 2). Двойка присоединяется к отсортированному суффиксу. Оба оставшихся элемента равны 1. Сейчас nums = [1, 1, 2, 3, 4, 5], действующая куча занимает [0, 1], отсортированный суффикс — [2, 3, 4, 5].

  9. Две единицы равны, при просеивании обмен не нужен

    В куче из двух элементов проверяем, нужно ли просеивать корень 1 вниз к левому ребёнку 1. Родитель уже не меньше ребёнка. Хотя путь сравнения выделен, обмена нет и значения массива остаются прежними. Сейчас nums = [1, 1, 2, 3, 4, 5], действующая куча занимает [0, 1], отсортированный суффикс — [2, 3, 4, 5].

  10. Последний обмен вершины с концом действующей кучи

    В куче из двух элементов меняем местами элементы с индексами 0 и 1. Оба равны 1, поэтому значения массива не меняются. Единица на позиции 1 становится серой и входит в отсортированный суффикс. Сейчас nums = [1, 1, 2, 3, 4, 5], действующая куча занимает [0, 0], отсортированный суффикс — [1, 2, 3, 4, 5].

  11. Куче из одного узла просеивание не требуется

    В действующей куче остался только корень 1 с индексом 0. Сравнивать его не с чем, поэтому просеивание вниз сразу заканчивается. Корень по-прежнему выделен зелёным, пять элементов справа остаются серыми. Сейчас nums = [1, 1, 2, 3, 4, 5], действующая куча занимает [0, 0], отсортированный суффикс — [1, 2, 3, 4, 5].

  12. Последний элемент уже на своём месте, сортировка завершена

    Последний элемент 1 на позиции 0 — минимум всего массива. Извлекать его больше не нужно. На рисунке он тоже становится серым: все шесть элементов вошли в отсортированную часть. Сейчас nums = [1, 1, 2, 3, 4, 5]. Действующая куча пуста, все шесть элементов отсортированы.

В реализации используется та же функция просеивания вниз sift_down(), что и в главе «Куча». Поскольку каждое извлечение максимума сокращает кучу, добавим в sift_down() параметр \(n\), задающий её текущую действующую длину. Пример кода:

heap_sort.py
def sift_down(nums: list[int], n: int, i: int):
    """Размер кучи равен n. Выполнить просеивание вниз от узла i"""
    while True:
        # Найти среди i, l, r узел с наибольшим значением и обозначить его ma
        l = 2 * i + 1
        r = 2 * i + 2
        ma = i
        if l < n and nums[l] > nums[ma]:
            ma = l
        if r < n and nums[r] > nums[ma]:
            ma = r
        # Если максимум уже в i или индексы l и r вне кучи, завершить просеивание
        if ma == i:
            break
        # Поменять два узла местами
        nums[i], nums[ma] = nums[ma], nums[i]
        # Продолжить просеивание вниз
        i = ma

def heap_sort(nums: list[int]):
    """Пирамидальная сортировка"""
    # Построить кучу: выполнить просеивание для всех узлов, кроме листьев
    for i in range(len(nums) // 2 - 1, -1, -1):
        sift_down(nums, len(nums), i)
    # Извлечь максимум из кучи n-1 раз
    for i in range(len(nums) - 1, 0, -1):
        # Обменять корень с крайним правым листом (первый элемент с последним)
        nums[0], nums[i] = nums[i], nums[0]
        # Выполнить просеивание вниз от корня
        sift_down(nums, i, 0)
heap_sort.cpp
/* Размер кучи равен n. Выполнить просеивание вниз от узла i */
void siftDown(vector<int> &nums, int n, int i) {
    while (true) {
        // Найти среди i, l, r узел с наибольшим значением и обозначить его ma
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma])
            ma = l;
        if (r < n && nums[r] > nums[ma])
            ma = r;
        // Если максимум уже в i или индексы l и r вне кучи, завершить просеивание
        if (ma == i) {
            break;
        }
        // Поменять два узла местами
        swap(nums[i], nums[ma]);
        // Продолжить просеивание вниз
        i = ma;
    }
}

/* Пирамидальная сортировка */
void heapSort(vector<int> &nums) {
    // Построить кучу: выполнить просеивание для всех узлов, кроме листьев
    for (int i = nums.size() / 2 - 1; i >= 0; --i) {
        siftDown(nums, nums.size(), i);
    }
    // Извлечь максимум из кучи n-1 раз
    for (int i = nums.size() - 1; i > 0; --i) {
        // Обменять корень с крайним правым листом (первый элемент с последним)
        swap(nums[0], nums[i]);
        // Выполнить просеивание вниз от корня
        siftDown(nums, i, 0);
    }
}

/* Размер кучи равен n. Выполнить просеивание вниз от узла i */
void siftDown(int[] nums, int n, int i) {
    while (true) {
        // Найти среди i, l, r узел с наибольшим значением и обозначить его ma
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma])
            ma = l;
        if (r < n && nums[r] > nums[ma])
            ma = r;
        // Если максимум уже в i или индексы l и r вне кучи, завершить просеивание
        if (ma == i)
            break;
        // Поменять два узла местами
        int temp = nums[i];
        nums[i] = nums[ma];
        nums[ma] = temp;
        // Продолжить просеивание вниз
        i = ma;
    }
}

/* Пирамидальная сортировка */
void heapSort(int[] nums) {
    // Построить кучу: выполнить просеивание для всех узлов, кроме листьев
    for (int i = nums.length / 2 - 1; i >= 0; i--) {
        siftDown(nums, nums.length, i);
    }
    // Извлечь максимум из кучи n-1 раз
    for (int i = nums.length - 1; i > 0; i--) {
        // Обменять корень с крайним правым листом (первый элемент с последним)
        int tmp = nums[0];
        nums[0] = nums[i];
        nums[i] = tmp;
        // Выполнить просеивание вниз от корня
        siftDown(nums, i, 0);
    }
}

/* Размер кучи равен n. Выполнить просеивание вниз от узла i */
void SiftDown(int[] nums, int n, int i) {
    while (true) {
        // Найти среди i, l, r узел с наибольшим значением и обозначить его ma
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma])
            ma = l;
        if (r < n && nums[r] > nums[ma])
            ma = r;

        if (ma == i)

11.7.2   Свойства алгоритма¶

  • Временная сложность \(O(n \log n)\), неадаптивная сортировка. Построение кучи занимает \(O(n)\) времени. Извлечение максимума имеет сложность \(O(\log n)\) и повторяется \(n - 1\) раз.
  • Пространственная сложность \(O(1)\), сортировка на месте. Несколько переменных-указателей занимают \(O(1)\) памяти. И обмены, и просеивание выполняются в исходном массиве.
  • Неустойчивая сортировка. При обмене вершины с последним элементом кучи взаимный порядок равных элементов может измениться.
