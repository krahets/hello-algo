8.1   Куча¶

Куча (heap) — полное бинарное дерево, удовлетворяющее определённому условию. В зависимости от этого условия различают два основных типа куч, показанных ниже.

  • Мин-куча (min heap): значение любого узла \(\leq\) значение каждого из его детей.
  • Макс-куча (max heap): значение любого узла \(\geq\) значение каждого из его детей.

Рисунок 8-1   Мин-куча и макс-куча

Иллюстрация 8-1: Строение минимальной и максимальной куч и порядок значений в них

Минимальная куча слева и максимальная куча справа имеют одинаковую форму дерева, но противоположные условия на значения родителя и потомка.

Каждая куча — полное двоичное дерево из 12 узлов. Первые три уровня заполнены целиком, а на четвёртом 5 узлов занимают подряд крайние левые позиции. В таблице значения с рисунка перечислены по уровням сверху вниз, внутри уровня — слева направо. Номера уровней определены по их положению, на рисунке они не подписаны.

Узлы соединены в обоих деревьях одинаково. У корня и каждого узла второго уровня по два потомка. На третьем уровне, если считать слева, у первых двух узлов по два потомка, у третьего есть только левый потомок, а четвёртый — лист. По этому описанию и таблице можно определить каждую связь между родителем и потомком.

Под рисунком указаны условия: в минимальной куче значение родителя не больше значения потомка, а в максимальной — не меньше. Значения могут совпадать. Например, в минимальной куче у правого узла второго уровня и у его левого потомка значение 2. Значения в пределах уровня не обязаны идти по порядку слева направо. Порядок между потомками одного родителя также не задан.

Сравнивая родителя с потомками на каждом уровне, видим, что в корне минимальной кучи находится наименьшее значение всей кучи (1), а в корне максимальной — наибольшее (9).

Как частный случай полного бинарного дерева, куча обладает следующими свойствами.

  • Нижний уровень заполняется слева направо, все остальные уровни заполнены целиком.
  • Корень дерева называют вершиной кучи, а крайний правый узел нижнего уровня — последним узлом кучи.
  • В макс-куче корень содержит максимальный элемент, а в мин-куче — минимальный.

8.1.1   Основные операции с кучей¶

Многие языки программирования предоставляют очередь с приоритетом (priority queue). Это абстрактная структура данных, в которой порядок извлечения определяется приоритетом элементов.

Кучу часто используют для реализации очереди с приоритетом. Макс-куча соответствует очереди, из которой элементы извлекаются в порядке убывания. С точки зрения использования очередь с приоритетом и кучу можно считать равнозначными структурами данных. Поэтому в этой книге будем называть обе «кучей».

В таблице перечислены основные операции с кучей. Имена методов зависят от языка программирования.

Таблица 8-1   Эффективность операций с кучей

Метод Описание Временная сложность

pop() Извлечь элемент из корня \(O(\log n)\)

На практике можно воспользоваться готовым классом кучи или очереди с приоритетом в выбранном языке.

Как и при выборе сортировки по возрастанию или убыванию, мин-кучу можно заменить макс-кучей и наоборот, задав flag или изменив Comparator. Ниже приведён код:

heap.go
// В Go макс-кучу целых чисел можно построить, реализовав heap.Interface
// Для реализации heap.Interface требуется также реализовать sort.Interface
type intHeap []any

// Метод Push интерфейса heap.Interface добавляет элемент в кучу
func (h *intHeap) Push(x any) {
    // Методы Push и Pop используют указатель в качестве получателя,
    // поскольку изменяют как содержимое среза, так и его длину.
    *h = append(*h, x.(int))
}

// Метод Pop интерфейса heap.Interface извлекает последний элемент среза (heap.Pop уже переместил туда корень)
func (h *intHeap) Pop() any {
    // Извлекаемый элемент находится в конце
    last := (*h)[len(*h)-1]
    *h = (*h)[:len(*h)-1]
    return last
}

// Метод Len интерфейса sort.Interface
func (h *intHeap) Len() int {
    return len(*h)
}

// Метод Less интерфейса sort.Interface
func (h *intHeap) Less(i, j int) bool {
    // Для мин-кучи нужно использовать знак «меньше»
    return (*h)[i].(int) > (*h)[j].(int)
}

// Метод Swap интерфейса sort.Interface
func (h *intHeap) Swap(i, j int) {
    (*h)[i], (*h)[j] = (*h)[j], (*h)[i]
}

// Метод Top возвращает элемент в корне
func (h *intHeap) Top() any {
    return (*h)[0]
}

func TestHeap(t *testing.T) {
    /* Инициализировать кучу */
    // Инициализировать макс-кучу
    maxHeap := &intHeap{}
    heap.Init(maxHeap)
    /* Вставить элемент в кучу */
    // Вызвать метод heap.Interface для добавления элемента

    heap.Push(maxHeap, 2)

    /* Извлечь элемент из корня */
    // Вызвать метод heap.Interface для удаления элемента
    fmt.Printf("Извлечённый элемент: %d\n", heap.Pop(maxHeap)) // 5
    fmt.Printf("Извлечённый элемент: %d\n", heap.Pop(maxHeap)) // 4
    fmt.Printf("Извлечённый элемент: %d\n", heap.Pop(maxHeap)) // 3
    fmt.Printf("Извлечённый элемент: %d\n", heap.Pop(maxHeap)) // 2
    fmt.Printf("Извлечённый элемент: %d\n", heap.Pop(maxHeap)) // 1

    fmt.Printf("Число элементов в куче: %d\n", size)

    isEmpty := len(*maxHeap) == 0
    fmt.Printf("Пуста ли куча: %t\n", isEmpty)
}

1.   Хранение и представление кучи¶

В главе «Бинарное дерево» мы видели, насколько удобно представлять полное бинарное дерево массивом. Куча — именно такое дерево, поэтому будем хранить её в массиве.

При представлении дерева массивом элемент хранит значение узла, а индекс задаёт его позицию в дереве. Вместо указателей на узлы используются формулы для вычисления индексов.

Как показано ниже, у узла с индексом \(i\) левый ребёнок имеет индекс \(2i + 1\), правый — \(2i + 2\), а родитель — \((i - 1) / 2\) (деление с округлением вниз). Если индекс выходит за границы массива, соответствующий узел пуст или отсутствует.

Рисунок 8-2   Представление и хранение кучи

Иллюстрация 8-2: Представление кучи массивом

Одну и ту же кучу можно изобразить полным бинарным деревом или записать в массив по уровням. Два представления связывают формулы индексов.

Слева подпись «Логическая структура кучи (куча — полное бинарное дерево)», справа — «Физическая структура кучи (хранение полного бинарного дерева в массиве)». Массив справа расположен горизонтально. Слева направо идут индексы от 0 до 11 и соответствующие им 12 значений в порядке обхода по уровням: [9, 8, 6, 6, 7, 5, 2, 1, 4, 3, 6, 2].

Слева под каждым круглым узлом дерева указан его индекс в массиве. У корня 9 (индекс 0) левый ребёнок 8 (индекс 1), правый — 6 (индекс 2). Дети узла 1 слева направо: индекс 3 (значение 6) и индекс 4 (7). У узла с индексом 2 дети имеют индексы 5 (5) и 6 (2), у узла с индексом 3 — 7 (1) и 8 (4), у узла с индексом 4 — 9 (3) и 10 (6). У узла с индексом 5 есть только левый ребёнок с индексом 11 (значение 2).

Справа показано, как формулы для индексов заменяют указатели. Для некорневого узла с индексом i индекс родителя равен ⌊(i−1)/2⌋ (деление с округлением вниз), левого ребёнка — 2i+1, правого — 2i+2. Бирюзовым выделен узел i=4 со значением 7. Серая стрелка ведёт к оранжевому родителю с индексом ⌊(4−1)/2⌋ = 1 и значением 8. Две стрелки вправо от индекса 4 указывают на синего левого ребёнка с индексом 2×4+1 = 9 и значением 3 и сине-фиолетового правого ребёнка с индексом 2×4+2 = 10 и значением 6. Одинаковые цвета в дереве и массиве обозначают одни и те же узлы.

Если вычисленный индекс ребёнка выходит за границы массива, такого ребёнка нет. У корня с индексом 0 нет родителя. При плотной записи по уровням у каждого узла свой индекс, поэтому даже несколько узлов со значением 6 или 2 легко различить.

Компактное хранение полного бинарного дерева в массиве обходится без отдельных полей для указателей на родителя и детей. Позиции родителя, левого и правого ребёнка и их существование определяются за O(1) времени.

3.   Вставить элемент в кучу¶

Сначала добавим элемент val в конец кучи. Поскольку val может быть больше других элементов, свойство кучи после вставки может нарушиться. Нужно восстановить порядок на пути от вставленного узла к корню. Эту операцию называют восстановлением свойства кучи (heapify).

Начнём с нового узла и выполним просеивание снизу вверх. Как показано ниже, сравниваем новый узел с его родителем и меняем их местами, если новый узел больше. Повторяем это, восстанавливая порядок снизу вверх, пока не дойдём до границы за корнем или до узла, для которого обмен не нужен.

my_heap.py
def push(self, val: int):
    """Вставить элемент в кучу"""
    # Добавить узел
    self.max_heap.append(val)
    # Просеивание вверх
    self.sift_up(self.size() - 1)

def sift_up(self, i: int):
    """Просеивать вверх от узла i"""
    while True:
        # Найти родителя узла i
        p = self.parent(i)
        # Если вышли за корень или узел уже на своём месте, завершить просеивание
        if p < 0 or self.max_heap[i] <= self.max_heap[p]:
            break
        # Поменять два узла местами
        self.swap(i, p)
        # Продолжить просеивание вверх
        i = p

4.   Извлечь элемент из корня¶

Корень кучи — корень дерева и первый элемент списка. Если удалить первый элемент непосредственно из списка, индексы всех остальных узлов изменятся. После этого восстановить порядок просеиванием будет трудно. Чтобы изменить как можно меньше индексов, поступим так.

  1. Поменяем местами корень и последний элемент кучи (корень дерева и крайний правый лист).
  2. Удалим последний элемент из списка. После обмена там находится прежний корень, так что удаляем именно его.
  3. Начиная с корня, выполним просеивание сверху вниз.

Как показано ниже, просеивание сверху вниз идёт в направлении, обратном просеиванию снизу вверх. Сравниваем корень с обоими детьми и, если нужен обмен, меняем его с бо́льшим ребёнком. Повторяем действие, пока не выйдем за уровень листьев или не дойдём до узла, для которого обмен не нужен.

Иллюстрация 8-4: Извлечение корня макс-кучи

После извлечения максимума восстанавливаем макс-кучу от корня вниз, на каждом шаге меняя узел с бо́льшим из детей.

Изначально в куче 13 элементов. В корне с индексом 0 находится максимум 9, в конце с индексом 12 — число 5. В макс-куче значение каждого родителя не меньше значения любого из его детей.

Дерево и массив представляют одни и те же данные. В массиве узлы расположены по уровням сверху вниз и слева направо внутри уровня. Индексы начинаются с 0. Для некорневого узла i индекс родителя равен (i−1)/2 с округлением вниз, индексы детей — 2i+1 и 2i+2. Выход индекса за границы означает, что такого ребёнка нет. Равные значения различаем по индексам.

При извлечении меняем местами корень (индекс 0) и последний элемент (индекс 12), затем удаляем прежний корень с конца массива. Так не приходится сдвигать все элементы, как при удалении с начала. Затем просеиваем от корня вниз. На каждом шаге выбираем максимум среди текущего узла и его детей. Если ребёнок больше родителя, меняем родителя с бо́льшим из детей: только тогда новый родитель окажется не меньше и второго ребёнка. Останавливаемся, когда текущий узел не меньше своих детей или достиг листа.

def pop(self) -> int:
    """Извлечь элемент из кучи"""
    # Проверить, пуста ли куча
    if self.is_empty():
        raise IndexError("Куча пуста")
    # Поменять местами корень и крайний правый лист (первый и последний элементы)
    self.swap(0, self.size() - 1)
    # Удалить узел
    val = self.max_heap.pop()
    # Просеивание вниз
    self.sift_down(0)
    # Вернуть элемент из корня
    return val

def sift_down(self, i: int):
    """Просеивать вниз от узла i"""
    while True:
        # Сохранить в ma индекс наибольшего из узлов i, l и r
        l, r, ma = self.left(i), self.right(i), i
        if l < self.size() and self.max_heap[l] > self.max_heap[ma]:
            ma = l
        if r < self.size() and self.max_heap[r] > self.max_heap[ma]:
            ma = r
        # Если ни у одного потомка значение не больше, чем у родителя, завершить просеивание
        if ma == i:
            break
        # Поменять два узла местами
        self.swap(i, ma)
        # Продолжить просеивание вниз
        i = ma

8.1.3   Где применяют кучу¶

  • Очередь с приоритетом. Куча часто оказывается первым выбором для такой очереди: вставка и извлечение имеют временную сложность \(O(\log n)\), а построение кучи — \(O(n)\). Все эти операции эффективны.
  • Пирамидальная сортировка. Из заданного набора данных можно построить кучу, а затем извлекать элементы один за другим и получить упорядоченную последовательность. Обычно используют более изящную реализацию, описанную в разделе «Пирамидальная сортировка».
  • Поиск \(k\) наибольших элементов. Эта классическая алгоритмическая задача часто встречается на практике. Примеры — выбор десяти самых популярных новостей для списка трендов Weibo или десяти самых продаваемых товаров.
